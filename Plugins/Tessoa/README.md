# tessoa 插件

Lertaro 可以读取 tessoa 窗口的当前目录和已打开的文件夹标签页。在 tessoa 中使用快速导航时，选文件夹会在当前标签页进入目录，选文件会定位并选中它。普通搜索结果菜单里的「在 tessoa 中打开或定位」由 tessoa 在所有窗口中选择合适的标签页。

## 可执行文件

「tessoa.exe 路径」留空即可自动查找。插件优先使用目标窗口所属的程序，再依次查询当前用户和本机的 `App Paths\tessoa.exe`（各查 64 位、32 位视图），最后检查 `%LOCALAPPDATA%\tessoa\tessoa.exe`。便携版用户也可以在插件设置中指定完整路径，这样即使关闭了 tessoa，也能从搜索结果启动它。手动指定的路径无效时，需要修正该设置。

当前标签页导航需要支持文件应用接口 2 的 tessoa（0.31.2 起）。只支持接口 1 的版本使用程序级导航。

## 测试

在仓库根目录运行 `dotnet test Tests/Plugins/Tessoa/Tessoa.csproj -c Release`。要验证指定的便携版，可在当前 PowerShell 会话设置 `$env:TESSOA_TEST_EXE = 'D:\Tools\tessoa\tessoa.exe'`。真机测试只读取程序版本和窗口状态。缺少程序时自动跳过两项真机测试，已安装但没有打开窗口时只跳过窗口查询测试。协议和导航单元测试始终运行。

## 桌面验收

重新启动本次构建的 Lertaro，在插件设置中确认已启用 tessoa。

1. 打开两个 tessoa 窗口，每个窗口打开不同的文件夹标签页。在其中一个窗口使用中键快速导航，选择一个含空格和中文的文件夹。确认当前标签页进入该目录，其他窗口保持原目录，按「后退」能回到起点。
2. 在同一窗口通过快速导航选择一个文件，确认其父目录打开、文件被选中。随后从 Lertaro 普通搜索结果菜单执行「在 tessoa 中打开或定位」，确认已有的文件夹标签页可以被复用。
3. 切到起始页或设置页，确认当前搜索范围不会显示另一窗口的目录。在 tessoa 地址栏和重命名框输入文字，默认设置下应由 tessoa 接收。需要从文件列表直接打字搜索时，可在插件设置中开启该选项，它也会作用于文本框。
