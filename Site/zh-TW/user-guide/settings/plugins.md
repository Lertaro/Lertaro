# 外掛模組管理

Lertaro 擁有高度模組化的外掛模組架構體系。無論是核心擴充元件、本機工具還是社群第三方生態，均可在外掛模組管理中心中統一檢視、管理與設定。頁面路徑為**設定 → 外掛模組**。

## 1. 頁面配置與 SDK 版本

- **Plugin SDK 徽標**：頁面頂部右上角醒目標註了目前執行階段載入的 `Lertaro.PluginSdk` 版本號。按一下該徽標可直接跳轉至[**開發者手冊**](../../dev-guide/)查閱介面文件。
- **左右雙欄獨立捲動**：左側展示已安裝的所有外掛模組清單，右側展示目前選取外掛模組的詳細資訊與設定面板，兩側獨立捲動互不干擾。

## 2. 外掛模組詳情與元件開關

按一下左側清單中的任意外掛模組後，右側會展示該外掛模組的圖示、名稱、版本號與功能簡介：

### 詳情索引標籤頁（Details）

- **元件清單與分組**：清晰列出該外掛模組註冊的所有底層功能元件（例如：搜尋來源、完整視窗檔案結果、快顯動作、快速導覽提供者、即時預覽剖析器等）。
- **完整視窗結果獨立開關**：`IFullSearchFileResultProvider` 會作為獨立元件類型顯示，可單獨啟用或停用，不會影響外掛模組的即時結果提供者。
- **元件級獨立開關**：每個非必要元件均配有獨立的**啟用/停用核取方塊**；帶有鎖形圖示的元件為系統級必要核心，不可關閉。
- **一鍵全選/全不選**：當某個元件分組包含多個可切換項目時，標題右側會提供便捷的「全選/全不選」連結。
- **元件停留說明**：滑鼠停留在元件旁邊的 **(!)** 圖示上，可檢視該元件的底層實作說明與觸發方式。

### 設定索引標籤頁（Configure）

- **原生嵌入式表單**：外掛模組自訂的設定項會直接轉譯在右側面板中，無需快顯額外的雜亂對話方塊。支援文字方塊、數字調節、開關、下拉式選單及多分組子索引標籤頁。
- **安全認可與回復機制**：在右下角按一下**確定**之前，任何修改均僅暫存於記憶體中；若直接切換至其他外掛模組或離開頁面，未儲存的修改會自動安全回復至原始狀態，防止誤認可。

## 3. Flow Launcher 社群生態深度支援

除了基於 `Lertaro.PluginSdk` 建置的原生 C# 外掛模組之外，Lertaro 還透過內建的 **Flow Launcher Bridge** 提供了對龐大 Flow Launcher 社群外掛模組生態的原生級相容支援。

### 多語言執行階段與隔離環境

- **全類型外掛模組相容**：無縫執行由 **C# (.NET)**、**Python 3.12**、**Node.js v20 LTS** 以及獨立可執行程式（`.exe`）編寫的 Flow Launcher 外掛模組。
- **零相依性污染與自包含執行階段**：Python（`FlowData\PythonEmbeded-{arch}`）與 Node.js（`FlowData\NodeEmbeded-{arch}`）執行階段完全隔離在 Lertaro 的使用者資料目錄中按需自動下載部署，不依賴且絕不污染 Windows 系統的全域環境變數與 PATH。
- **相依性自動安裝**：外掛模組首次載入時，系統會在背景無訊息根據 `requirements.txt` 安裝 Python `pip` 相依套件，或根據 `package.json` 執行 `npm` 相依套件安裝。

### 線上社群市場與套件管理指令

你可以直接在 Lertaro 搜尋框中鍵入以下指令管理 Flow 外掛模組：

- **`flow install <關鍵字>`**：即時線上檢索 Flow.Launcher 官方社群外掛模組庫，選取後一鍵自動下載、解壓、部署並拉起相依性安裝。
- **`flow update`**：自動偵測所有已安裝 Flow 外掛模組的更新版本並支援一鍵升級。
- **`flow uninstall <外掛模組名>`**：一鍵安全解除安裝指定的 Flow 外掛模組並清理相關本機目錄。
- **手動安裝**：亦可將下載好的第三方 Flow 外掛模組資料夾直接放入 `<使用者資料目錄>\FlowData\Plugins\` 完成本機離線安裝。

### 外掛模組設定、觸發詞與互動式預覽

- **集中管理與觸發詞修改**：在**設定 → 外掛模組 → Flow Launcher Bridge → 設定**中，可為每個 Flow 外掛模組單獨開關，並自由修改其專屬**觸發詞（ActionKeyword）**。設定集中保存於 `FlowData\Settings\Plugins.json` 中，外掛模組更新後設定不遺失。
- **動態設定表單**：完整支援 Flow 外掛模組基於 YAML/JSON 範本表單（`SettingsTemplate.yaml`/`.json`）或 C# WPF 設定面板（`ISettingProvider`）的設定介面，自動融合目前深淺色主題並支援 i18n 當地語系化。
- **WebView2 互動式豐富文字預覽**：支援 Flow 外掛模組傳回的複雜預覽面板（如 MDict 字典釋義、天氣卡片、API 偵錯資訊、網頁快照等），在 QuickLook 中免額外按鍵平滑展開；Lertaro 會自動插入深淺色自適應樣式、清晰字型與精緻捲軸。
- **宿主能力深度融合**：Flow 外掛模組透過 API 開啟資料夾時自動遵循宿主配置的第三方檔案管理員，快顯訊息方塊自動轉譯為宿主主題自繪樣式，且內部記錄無縫匯入設定中心記錄檢視器。
- **快速概覽**：在搜尋方塊中直接輸入 `flow` 即可列出目前已載入的所有 Flow 外掛模組及其觸發詞；選取外掛模組後會直接跳轉至設定中的對應設定群組。

## 4. 內容搜尋

**內容搜尋**外掛模組可以搜尋已設定的本機文件內文。開啟它的**設定**標籤頁，可以設定觸發關鍵字、監控資料夾、索引副檔名、單一檔案大小上限、索引容量上限以及排除完整路徑的正規表示式。預設觸發關鍵字為 `cs`，因此輸入 `cs 專案計畫` 即可搜尋文件內文，並顯示附有片段的符合檔案。

設定中還提供**清除索引**與**重建索引**。清除索引只刪除內容索引，重建索引則會刪除內容索引並重新掃描所有監控資料夾。這兩個操作都不會刪除 Lertaro 的普通檔名索引。

## 5. 外掛模組執行狀態

在**設定 → 外掛模組 → 執行狀態**中，可以查看 Lertaro 執行期間已安裝外掛模組的宿主側呼叫情況。資料按外掛模組彙總，並在該標籤頁開啟時持續重新整理。

- **外掛模組篩選**：使用篩選框按外掛模組名稱進行模糊搜尋。
- **欄位排序**：點擊欄位標題可依次切換升序、降序和預設外掛模組順序。
- **可用指標**：呼叫次數、平均耗時、最近耗時、最大耗時、受管理配置量和觀察到的例外次數。
- **統計範圍**：統計在目前 Lertaro 程序執行期間累計，重新啟動後重設。數值為零表示尚未記錄到對應呼叫；受管理配置量是受測呼叫產生的受管理記憶體配置，不代表外掛模組的全部私有記憶體佔用。
