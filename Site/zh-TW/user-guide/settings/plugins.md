# 外掛

列出所有已安裝的外掛，頁面頂部的徽章顯示目前載入的 Plugin SDK 版本——點擊它可以直接開啟[開發手冊](../../dev-guide/)，這個版本號正是為了對照手冊開發外掛而準備的。

頁面分成左右兩欄：左邊是已安裝的外掛，右邊是選取外掛的詳細資料。兩欄各自獨立捲動，外掛清單很長和設定表單很長互不牽扯。

如果沒有安裝任何外掛，頁面會顯示一個空狀態提示。

## 外掛清單

每個已安裝的外掛佔一列，顯示名稱，下方是它的版本號。點擊某一列，右側就會開啟該外掛。

清單按「有什麼可操作的」排序：先是有自己設定項的外掛，其次是有元件可以關閉的，最後是其餘的；每一檔內部按名稱排列。

## 選取的外掛

右欄最上方是外掛的圖示、名稱和**整體功能簡介**。

再往下，如果外掛公開了自己的設定項(超出簡單啟用/停用的範疇)，會出現**詳細資料**和**設定**兩個索引標籤。沒有任何設定項的外掛不會顯示索引標籤列——整欄就是它的詳細資料。

### 詳細資料

該外掛註冊的功能元件，按類型分組（搜尋來源、動態選單提供者等）。每個可切換的元件都有自己的**啟用/停用核取方塊**；標記為必要項目的元件會顯示一個鎖形圖示，不能關閉。把滑鼠停留在元件旁邊的 **(!)** 上，可以看到該元件的詳細功能說明。

當某個分組（或整個外掛）有 2 個及以上可切換元件時，標題旁會出現一個**全選/全不選**連結，點擊即可一次性切換該範圍內的所有核取方塊，不用逐個手動勾選。

### 設定

外掛自己的設定項，直接在這裡編輯，不再另外開啟對話方塊。如果外掛把設定分成了 2 組及以上，這裡還會有一列屬於它自己的索引標籤，每組一個。

按下**確定**之前，什麼都不會寫入。離開這個索引標籤——切回詳細資料，或者選擇另一個外掛——會把這些欄位回復到已儲存的值，這樣你放棄掉的修改就不會在之後被誤送出。

想看外掛設定實際長什麼樣、能改什麼(比如改一個觸發關鍵字)，可以參考[即時答案與關鍵字功能](../instant-answers)。

## Flow Launcher 外掛生態支援

除了基於 `Lertaro.PluginSdk` 構建的原生 C# 外掛之外，Lertaro 還透過內建的 Flow Launcher Bridge 提供了對龐大 Flow Launcher 社群外掛生態的原生級相容支援。

- **支援的外掛類型**：相容 **C# (.NET)**、**Python 3.12**（支援根據 `requirements.txt` 自動在背景安裝 `pip` 相依套件）、**Node.js v20 LTS**（支援根據 `package.json` 自動在背景安裝 `npm` 相依套件）以及獨立**可執行檔**（`.exe`）編寫的 Flow Launcher 外掛。
- **安裝方式**：直接將第三方 Flow Launcher 外掛資料夾放入 `<使用者資料目錄>\FlowData\Plugins\`，Lertaro 會自動辨識、載入並註冊其搜尋觸發詞與動作。
- **純淨隔離執行環境**：Python（`FlowData\PythonEmbeded-{arch}`）與 Node.js（`FlowData\NodeEmbeded-{arch}`）執行階段完全隔離在 Lertaro 的資料目錄中視需要自動下載部署，不依賴也不污染系統的全域環境變數與 PATH。
- **集中管理與獨立開關**：在**設定 → 外掛 → Flow Launcher Bridge** 的**設定**索引標籤中，統一列出所有已載入的 Flow 外掛子分組；每個外掛頂部均設有專屬的**啟用此外掛**開關，可單獨開啟或關閉該外掛功能。
- **自訂觸發詞與狀態隔離**：支援自訂修改每個 Flow 外掛的專屬**觸發詞（ActionKeyword）**，設定與啟用狀態集中儲存於 `FlowData\Settings\Plugins.json`，不會污染外掛內部設定，外掛更新與重啟後始終保持有效。
- **原生內嵌設定與多語言**：無縫支援基於 YAML/JSON 範本表單（`SettingsTemplate.yaml`/`.json`）及 C# WPF 自訂設定面板（`ISettingProvider`）的外掛設定介面，自動融合應用程式主題並完整支援多語言 i18n 在地化。
- **快捷搜尋與調用**：在搜尋方塊中輸入 `flow` 全域關鍵字即可列出已載入的全部 Flow 外掛及其觸發詞與執行狀態；直接輸入此外掛的觸發詞（如 `md`、`tr` 等）即可即時檢索。
