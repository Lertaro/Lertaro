# 一般設定

一般設定涵蓋系統的核心執行行為、搜尋視窗外觀與配置參數、各結果類型的優先順序權重以及預覽元件的排程順序。頁面頂部共分為六個索引標籤頁：**系統**、**快速搜尋視窗**、**完整搜尋視窗**、**預覽視窗**、**快速導航**與**預覽與縮圖**。

## 1. 系統（System）

- **開機自動啟動 Lertaro**：勾選後在 Windows 使用者登入時自動啟動 Lertaro。
- **啟動時自動檢查更新**：勾選後在軟體每次啟動時自動連線查詢最新版本。
- **自動無訊息更新**：僅在以系統管理員身分執行 Lertaro 且開啟「檢查更新」時可用。偵測到新版本後將在背景無訊息下載並自動覆蓋升級，免去手動操作。
- **啟用硬體加速**：預設開啟，作用於設定、完整搜尋和預覽視窗。快速搜尋、內嵌卡片和通知固定使用軟體轉譯，以縮短首次顯示的延遲。若 Lertaro 導致雙顯示卡筆電無法切回內顯，可關閉此項。修改後需重新啟動。
- **隱藏系統匣圖示**：勾選後隱藏 Windows 工作列右下角的系統匣圖示。快速搜尋視窗內的 Logo 圖示依然能呼出完整的系統選單，不會遺失任何入口。
- **啟用 Everything 相容服務 (IPC)**：預設關閉。開啟後，Lertaro 會在背景模擬標準 Everything Win32 IPC 通訊協定介面，讓 Directory Opus、Total Commander 等第三方軟體無需額外安裝執行 Everything 即可直接呼叫 Lertaro 的記憶體索引。
- **啟用模糊比對**：預設開啟。開啟時支援跳躍字元模糊比對；關閉後要求普通查詢詞必須為連續子字串（詳見[**搜尋語法**](../search-syntax)）。即時生效無需重啟。
- **關閉後保留搜尋框內容**：預設關閉。開啟後，關閉快速視窗或在完整視窗按 `Esc` 時保留查詢，完整視窗按一次 `Esc` 即關閉。再次開啟時查詢會**全選**，輸入即可取代。內容只保留到本次程式結束。
- **在內嵌搜尋中顯示目前開啟的資料夾**：內嵌視窗停靠在檔案對話方塊時，在搜尋內容為空的狀態下顯示該對話方塊目前開啟的資料夾，預設開啟。
- **內嵌視窗寬度 (%)**：可設 `20`–`100`。除預設值 `60` 外，數值表示宿主視窗寬度的百分比；`60` 表示自動寬度，取宿主寬度的 40% 與螢幕寬度的 1/5 中較大者。實際寬度下限為宿主的 20% 與螢幕的 1/6 中較大者，上限為宿主寬度與螢幕的 90% 中較小者。
- **內嵌視窗顯示條數（普通視窗）**：停駐在一般視窗時顯示的結果數，可設 4–10，預設 10，不含分區標題。Ctrl+1–9 選取第 1–9 項，Ctrl+0 選取第 10 項。畫面放不下的結果可捲動查看。
- **內嵌視窗顯示條數（檔案對話方塊）**：在開啟、儲存或瀏覽對話方塊中顯示 `4`–`10` 項結果，預設 `4`。分區標題、跳轉快捷鍵和螢幕高度限制同上。
- **外掛模組查詢標記前綴**：外掛標記前綴在「設定 → 一般 → 系統」中設定，目前只支援 `\`。新輸入的無效值會阻止儲存；未修改的舊值只顯示提示。空值或不可用的舊值在搜尋時使用 `\`。
- **記錄等級**：下拉選擇「錯誤 / 警告 / 資訊 (預設) / 偵錯」，控制系統各處理程序記錄輸出的詳細程度。
- **介面語言**：下拉選擇 Lertaro 的全域顯示語言。

## 2. 快速搜尋視窗（Quick Search Window）

本索引標籤頁用於精細化設定快速置中浮動視窗的幾何尺寸與結果排序：

### 搜尋列配置

- **搜尋列寬度 (像素)**：取值範圍 `300–1200px`，預設 `570px`。
- **搜尋列高度 (像素)**：取值範圍 `45–120px`，預設 `60px`。該數值會按比例同步驅動結果清單的圖示大小、行高與字型大小，確保視覺協調。
- **搜尋框內顯示時鐘**：開啟後，在搜尋框為空時將提示文字替換為目前即時日期、星期與時間。輸入文字後時鐘自動隱藏。
- **再次按下快速鍵時開啟完整視窗**：開啟後，在快速視窗已顯示狀態下再次按下全域呼出快速鍵，將攜帶目前輸入內容直接切換至完整主搜尋視窗。
- **鎖定位置**：開啟後禁止滑鼠拖曳移動快速視窗，防止誤觸改變位置。
- **自動將剪貼簿文字填入快速搜尋框**：預設關閉。快速視窗在沒有預填內容時，如果剪貼簿中有新的非空文字，就將其用作搜尋內容。手動貼上和其他視窗不受影響。
- **顯示類型篩選欄**：預設開啟。顯示快速搜尋框下方的類型分頁。關閉後篩選重設為「全部」，騰出的空間用於顯示結果。
- **記住類型篩選欄最後停留的標籤**：預設關閉。再次開啟快速搜尋時保留上次選擇的類型分頁。重新啟動 Lertaro 後恢復為「全部」。
- **重設配置設定**：一鍵將快速視窗尺寸與配置恢復為系統初始預設值。

### 結果類型優先順序與觸發符

- **優先順序排序清單**：拖曳應用程式、系統設定、檔案和資料夾，調整同等級、同優先順序、同使用權重和同符合位置下的類型順序。應用程式或系統設定排在檔案、資料夾之前時，後者的完整名稱符合會按一般強符合參與排序。範例見[搜尋語法](../search-syntax)。
- **專屬單字元觸發符**：可為特定結果類型設定專屬單字元前綴（如將檔案篩選器設為 `;`）。在搜尋框開頭輸入該字元即可直接過濾出該類型的專屬結果。觸發符不能使用搜尋語法自身占用的字元（`\` `<` `>` `:` `*` `/` `?`），因為語法會先消耗掉該字元，觸發符會靜默失效；同一個字元也不能被兩個類型共用。設定項會明確報出這兩種情況。內建即時功能也有各自專屬的首字元——`#` 與 `$` 用於執行命令、`%` 用於搜尋環境變數——因此這些字元同樣不可用。
- **排序詳情匯出**：在快速視窗中右鍵任意結果，選擇**匯出本頁排序詳情**，會為目前顯示頁寫出一個純文字 `.txt`。後台不記錄任何排序日誌；「允許匯出本頁排序詳情」開關預設開啟。

## 3. 完整搜尋視窗（Full Search Window）

用於設定大尺寸主搜尋視窗（`Ctrl+F`）的預設行為與表格檢視：

- **視窗寬度 / 高度 (像素)**：寬度範圍 `640–2000px`（預設 `854px`），高度範圍 `400–1400px`（預設 `480px`）。
- **僅允許一個完整搜尋視窗**：開啟後，再次開啟完整視窗將直接啟用已有執行個體，避免重複建立多開。
- **再次按下快速鍵時關閉完整視窗**：預設關閉，此時在完整視窗已取得焦點的情況下再次按下全域呼出快速鍵，會攜帶目前輸入內容切回快速搜尋視窗，並在兩個視窗之間反覆切換，直到按 `Esc` 退出。啟用後，再次按下快速鍵將直接關閉完整視窗。無論開關如何設定，完整視窗可見但未取得焦點時按下快速鍵都只會將其帶回前景。
- **重設搜尋視窗設定**：一鍵恢復主視窗預設寬高設定。
- **結果表格欄順序**：拖曳自訂表格檢視中各欄（名稱、路徑、修改時間等）的先後排列順序。
- **側邊欄篩選順序**：拖曳調整主視窗左側**側邊欄篩選**的展示順序；會即時動態呈現目前關鍵字在各分類下的比對項目數量。
- **動作選單分組順序**：拖曳調整快顯動作選單（`Ctrl+O`）中各功能分組的顯示先後。

## 4. 預覽視窗（Preview Window）

- **預覽視窗寬度 / 高度 (像素)**：寬度範圍 `250–900px`，高度範圍 `250–1200px`。
- **重設預覽視窗設定**：將 QuickLook 預覽浮動視窗的尺寸重設為標準預設比例。系統會自動計算避免預覽視窗超出目前顯示器的工作可視區域。

## 5. 快速導航（Quick Navigation）

- **提供者順序**：透過上下箭頭或拖曳手柄，調整快速導航選單根層級各個提供者分組的排列順序。每行對應一個快速導航提供器，例如級聯資料夾瀏覽器、系統命令執行器，以及各檔案管理員外掛貢獻的書籤分組。

## 6. 預覽與縮圖（Previews & Thumbnails）

- **檔案預覽提供者順序**：調整多個預覽外掛模組（如內建富文字/媒體解碼器與第三方 QuickLook 橋接）的呼叫優先順序。
- **縮圖提供者順序**：調整結果清單中檔案圖示與縮圖擷取元件的呼叫優先順序。
