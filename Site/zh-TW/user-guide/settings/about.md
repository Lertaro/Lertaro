# 關於

顯示 App、Core、Service、CLI 四個元件的版本號(顏色會反映服務目前是否健康)、Lertaro 的簡短說明，以及專案首頁和線上使用手冊的連結。

## 資料目錄

緊接著下方還有兩個連結，用來開啟 Lertaro 讀寫自身設定的資料夾——連結文字本身就是實際路徑，點擊時如果資料夾還不存在會先建立出來:

- **使用者資料目錄** —— 存放 `user-settings.json` 的每使用者目錄。每次儲存設定時，都會先把目前檔案輪替備份為 `user-settings.json.bak.1`(舊的備份依次往後順延，最多保留到 `.bak.5`)，再寫入新檔案，所以一次誤改或者儲存過程中當機，總能找到一份最近的備份還原。搜尋記錄、憑證和使用者專屬快取也保存在這裡。
- **機器資料目錄** —— 背景服務使用的機器層級目錄(`machine-settings.json`、本機磁碟索引快取，以及服務端記錄)。

安裝版使用 `%LocalAppData%\Lertaro` 和 `%ProgramData%\Lertaro`。可攜版在程式旁使用 `Data\Users\<SID hash>` 和 `Data\Machine`;如果可攜版的 `Data` 目錄尚未建立，為了相容會重複使用已有的安裝版資料。目錄優先順序請參閱[可攜版資料](../getting-started#可攜版資料)。

## 檢查更新

- **檢查更新** 按鈕 —— 查詢是否有新版本;按鈕文字本身會反映進度(「正在檢查更新...」，之後顯示「已是最新版本」或找到的新版本號)。
- 如果非系統管理員帳戶無法停止背景服務來原地安裝更新，會顯示一條警告橫幅，並引導你前往手動下載頁面。
- 一旦發現新版本:
  - **靜默自動更新** —— 背景下載安裝，顯示進度條，完成後自動重新啟動 Lertaro。
  - **前往下載頁面** —— 在瀏覽器中開啟 GitHub release 頁面，手動安裝。

這個頁面和[通用 → 系統](./general#系統)裡的**啟動時自動檢查更新** / **自動靜默更新**兩個核取方塊是配套的——那兩項控制是否在啟動時自動執行這次檢查;這個頁面則是讓你隨時手動觸發一次。
