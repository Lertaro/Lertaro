# 快速面板

面板開啟期間，目前選取分組標題裡顯示的資料夾也會被當作目前目錄。選取項目是檔案還是資料夾都沒有關係：只要標題路徑非空，開啟支援的檔案對話框後按快速切換（預設 `Ctrl+G`）即可跳到這裡。

由熱鍵呼出、停靠在目前前景視窗右下角的浮動面板，尺寸為該視窗的一半高、一半寬。它顯示你指定的資料夾，以及外掛提供的清單——縮圖平鋪或明細清單——讓你不必離開正在工作的視窗就能取用檔案、把檔案拖出去，或者把檔案拖進來。拖動它的頂部區域可以在本次呼叫期間把它挪到別處。

- **啟用快速面板** — 總開關；關掉之後熱鍵不再有任何反應。

呼出它的按鍵在[熱鍵](./hotkeys-page)頁面上(預設 `Ctrl+F2`)。

這個開關下面的頁面分成兩半：**工作區**，你自己湊起來的那些資料夾；以及**外掛標籤**，外掛提供的那些。兩者最終都出現在同一條標籤列上。

## 工作區

面板一次只顯示一個標籤，**工作區**就是其中一種。工作區是為某一類工作湊起來的一組來源——某個專案的幾個資料夾、放參考資料的地方、專門往裡丟東西的收件匣。

左側清單就是工作區本身，配有**新增工作區**、**複製工作區**、**刪除工作區**按鈕，以及設定裡其他地方同樣的上下箭頭(或拖動)排序清單(參見[收藏夾](./favorites))。這裡的從上到下，就是面板標籤列裡的從左到右。

- **名稱** — 標籤上顯示的文字。留空則回落到一個帶翻譯的預設名，所以從沒改過名的工作區會跟隨介面語言。
- **啟用** — 每個工作區旁邊的核取方塊。關掉之後工作區的設定還在，但不再有標籤，適合那些這個月用不上、刪掉又得重新搭一遍來源清單的工作區。面板裡標籤上的 **×** 做的就是這件事，所以要重新開啟得回到這裡。

選中的工作區透過兩個子標籤編輯：**來源**和**應用程式**。

## 來源

每個來源就是面板裡的一個分組，按這個清單的順序顯示。**新增資料夾**用來加入；每列前面的核取方塊可以隱藏該分組而不刪除它；名稱框用來覆蓋分組標題(留空則用資料夾自己的名字)；**更多選項**裡是其餘設定：

- **顯示** — 這個分組從資料夾裡取什麼：
  - **最近變動的檔案** — 只取最近有變動的，最新在前，由索引回答而不是去走訪資料夾。
  - **全部，最新在前** — 不會因為時間久就隱藏檔案，只決定誰排在前面。
  - **全部，依名稱** — 把資料夾當捷徑列用。
- **資料夾** — 資料夾本身，旁邊的 **…** 按鈕可以瀏覽選擇。
- **包含子資料夾** — 預設關閉。
- **接受拖入的檔案** — 拖到這個分組上的檔案和資料夾，會被複製進它的資料夾，走 Windows 自己的檔案複製(它的進度對話方塊、它的衝突提示、它的復原)。永遠是複製，不會是移動。預設關閉，而且是逐個來源分別設定的：當收件匣用的資料夾需要它，而只讀不寫的資料夾不需要。
- **篩選** — 可選地用一條或多條萬用字元限制這個來源顯示的內容，用 `;` 或 `,` 分隔(例如 `*.mp4;*.mkv`)。預設留空，代表不篩選。
- **最多** — 這個分組最多顯示幾筆。0 表示來源裡有多少顯示多少。
- **變動於(分鐘內)** — 只有這段時間內有變動的項目才算數。0 表示不限時間。
- **以清單顯示** — 這個分組以明細清單而不是縮圖平鋪開啟。哪種更合適是資料夾自己的屬性：圖片適合平鋪，文件適合看名稱和日期。平鋪時把一列**平分**給五個——所以面板停靠在寬視窗上時，得到的是值得一看的大縮圖，而不是更多的小圖。五不是死數：寬到連五個都比縮圖能填滿的還寬時，一列就多放幾個；窄到放不下五個還看得清時，就少放幾個。無論幾個，一列都是**平分**而不是按固定尺寸擺放，所以列尾永遠不會空出一塊。每張圖保持自己的比例，所以整個資料夾的 16:9 影片不會變成一格格直立的方框、每格上下各空一條。

在這裡新增的資料夾，預設是**全部內容，依名稱排序**——手動挑一個資料夾進來，多半是因為裡面存著東西。全新安裝自帶的那個工作區是例外，而且是刻意的：桌面、下載、文件是東西「抵達」的地方，所以預設按最近變動的檔案顯示。

## 外掛標籤

由外掛提供的標籤，列在頁面自己的第二個標籤下，而不是塞進某個工作區裡：外掛給出的是一整份清單，它和這個工作區的資料夾並沒有比和那個工作區更親近。每個標籤只需勾選一次進標籤列、取消一次出標籤列，對整個面板生效。

CoreExtensions 自帶五個：

| 標籤 | 列出什麼 |
|---|---|
| **我的最愛** | 你的[我的最愛](./favorites)，按你排好的順序。其中的網址會在瀏覽器裡開啟。 |
| **歷史記錄** | 你透過 Lertaro 自己開啟過的東西，最近的在前——這幾個裡只有它會包含應用程式。 |
| **Windows 歷史記錄** | 系統自己的最近使用文件清單，已解析成它指向的真實檔案，最新在前。 |
| **上次目錄** | 你最後瀏覽過的那個資料夾——不論是在檔案總管裡，還是在任何應用程式的檔案對話方塊裡，所以面板能直接把你剛離開的那個目錄遞回來。 |
| **最近檔案** | 面板設定要看的那些資料夾裡最新的檔案，由索引回答而不是去走訪它們。只含檔案。 |

- 核取方塊決定這個標籤在不在標籤列裡。面板裡標籤上的 **×** 做的是同一件事，所以要重新開啟得回到這裡。
- **以清單顯示** — 這個標籤以明細清單而不是縮圖平鋪開啟，和資料夾來源是同一個選項；之所以問在這裡，是因為外掛標籤在來源清單裡沒有自己的一列可問。面板標題列上的檢視開關在面板開啟期間仍然可以覆蓋它。
- 清單裡只會出現外掛元件在[外掛](./plugins)頁面處於啟用狀態的標籤，而這是另一個問題：在這裡取消勾選只是把標籤移出標籤列，在那邊停用則是讓它壓根不再執行。外掛被關掉期間關閉的標籤，外掛回來時依然是關著的——這個狀態是記在元件上的，而不是按目前載入了什麼重新算出來的。

一個外掛標籤只裝一份清單，並且不帶分組標題——標籤本身已經是它的名字了。它不接受拖入的檔案；外掛什麼都沒回傳時，標籤壓根不會出現。

## 應用程式

這個工作區歸屬的應用程式，每行一個處理程序名稱(`chrome` 或 `chrome.exe` 都行)。在其中任一個上面呼出面板，它就會開在這個工作區，而不是停在上次的位置——你正身處的應用程式本身已經說明了你指的是哪一組資料夾。留空則這個工作區只能手動切過去。

## 僅快速面板

面板不去打擾的應用程式，每行一個處理程序名稱。它是**疊加**在全域[處理程序黑名單](./hotkeys-page#process-blacklist)之上而不是取代它：全域擋掉的在這裡同樣被擋掉。這份名單是給那些只有這個面板才有理由避開的應用程式準備的——它會把自己貼到前景視窗上，所以全螢幕播放器或遊戲會被它毀掉，但這些應用程式並不至於要進全域黑名單。

## 使用面板

- **篩選框** — 在標籤列右側，面板一開啟就有焦點。它做的是模糊比對(和搜尋視窗同一套 fzf 模式比對，含拼音別名)，範圍僅限目前工作區。篩選期間沒有任何符合項目的分組會被隱藏。
- **Enter** 開啟選中項，和按兩下等效。第一筆從一開始就是選中的，所以一次呼叫可以在篩選框裡「打字然後 Enter」一氣呵成，全程不用離開輸入框。
- **上下方向鍵**移動選取項，而且到了一個分組的最後一列不會停下，會跨進下一個分組——所有分組從上到下就是一整份清單。在篩選框裡也能用，且不會把焦點從框裡搶走，所以「篩」和「選」是同一串動作。以縮圖平鋪顯示的分組內部，仍然按格線一列一列地走。設定裡的「選擇下一項／上一項」熱鍵(預設 `Ctrl+N`／`Ctrl+P`)效果相同；但如果有外掛動作綁在同一個鍵上，動作優先。
- **切換標籤** — 按住「跳到第 N 筆結果」的修飾鍵(預設 `Ctrl`，見[熱鍵](../hotkeys))再按 1–9，或者直接點標籤。工作區和外掛標籤共用同一條標籤列、同一份順序；標籤可以拖動改順序，每個標籤上的 **×** 把它移出標籤列(工作區被關掉，外掛標籤被關閉——兩者都在上面的設定裡復原)。關掉最後一個時，面板本身也會關閉。
- **分組標題**上有排序開關(依名稱／依修改日期)、檢視開關(平鋪／清單)和摺疊箭頭。你在這裡做的調整在面板開啟期間一直有效；起始狀態由上面的設定決定。
- **行號** — 所有分組共用左側行號欄。清單檢視按項目編號，縮圖平鋪按視覺行編號；欄寬隨可見分組中的最大編號調整，數字始終對齊。分組只會在你點擊摺疊箭頭時摺疊或展開，捲動不會改變其展開狀態。
- **多選** — 平鋪檢視下，在空白處拖出一個框即可框選。選取狀態屬於某一個分組，因為每個分組各畫各的清單；點擊空白處會取消選取。
- **拖入檔案** — 檔案、資料夾，或者直接從網頁上拖一張圖片，丟到允許拖入的分組上即可。只要拖動本身能提供檔案，就都收，不只是圖片。複製完成後該分組會自動重新載入。
- **預覽** — 按 QuickLook 那個鍵(預設 `Alt+P`，和其他熱鍵一樣可以在[熱鍵](./hotkeys-page)頁面改)，為選取的檔案開啟預覽視窗，之後它會跟著選取項走。它停靠在面板右側；右側被螢幕邊緣擠得放不下時，才翻到左側——面板貼在最大化視窗的右下角時就是這種情況。點進預覽視窗不會讓面板消失；兩個都點開才會。面板關閉時它一起關。
- **不讓它消失** — 面板失去焦點時會關閉。「釘選」按鈕，或者「保持視窗不消失」熱鍵(預設 `Ctrl+T`，和快速視窗用的是同一個)，可以在本次呼叫期間暫停這個行為。
- **Esc** 在篩選框有內容時先清空它，否則關閉面板。
- 面板會讓自己保持最新：正在顯示的資料夾在磁碟上發生變化時會重新載入，走的是全應用統一的、基於索引的監聽，而不是自己再掃一遍。
