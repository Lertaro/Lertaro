# 快速面板設定

**快速面板（Quick Panel）** 是 Lertaro 專為高頻檔案取用、專案上下文管理與桌面拖曳互動打造的浮動工作區。它會在按下快速鍵時自動停靠在目前前景活動視窗的右下角，讓你無需離開目前工作視窗即可快速瀏覽、拖入或分發常用檔案。

## 1. 核心機制與總開關

- **啟用快速面板**：總開關，關閉後將不再監聽呼出快速鍵。
- **喚起快速鍵**：預設快速鍵為 **`Ctrl+F2`**（可在[**設定 → 快速鍵**](./hotkeys-page)中自訂）。
- **智慧貼靠與尺寸條件約束**：面板預設尺寸為宿主視窗寬高的各二分之一（最小尺寸限制為 `280 × 200px`，確保內容與篩選框完整可用）。若目前處於 Lertaro 自身視窗時按快速鍵會被安全忽略，防止視窗重疊；面板開啟狀態下再次按下同款快速鍵可一鍵關閉。
- **快速跳轉聯動**：面板開啟期間，目前選取分組所指向的實體目錄會被自動記錄為活動目錄。在任意系統檔案對話方塊中按下快速跳轉快速鍵（預設 `Ctrl+G`），即可直接跳轉到該目錄。

## 2. 工作區（Workspaces）

工作區用於按專案或任務組織一組相關的資料夾來源：

- **工作區清單管理**：左側清單呈現已建立的工作區，支援**新建工作區**、**複製工作區**與**刪除工作區**，可透過拖曳左側手柄調整其在面板索引標籤列中的前後排列順序。
- **工作區屬性**：
  - **名稱**：索引標籤頁顯示的文字（留空時將自動使用跟隨系統語言的預設名稱）。
  - **啟用開關**：勾選狀態決定是否在面板索引標籤列中顯示。在面板中按一下索引標籤上的 **×** 按鈕即是將該工作區臨時隱藏，可在此處重新勾選還原。

選取的工作區可透過右側的兩個子索引標籤進行精細化設定：**來源**與**應用程式**。

## 3. 來源設定（Sources）

每個來源代表工作區內部的一個獨立內容分組：

- **新增資料夾**：按一下**新增資料夾**按鈕選取實體目錄。
- **顯示模式（Display Mode）**：
  - **最近改動的檔案** —— 由記憶體索引毫秒級直接應答，僅展示近期發生變動的檔案（最新排在最前）。
  - **全部內容，最新在前** —— 呈現全部檔案，按修改時間降序排列。
  - **全部內容，按名稱** —— 適合作為固定檔案的快捷工具列。
- **包含子資料夾**：開啟後將遞迴收錄其所有子目錄下的檔案。
- **接受拖入的檔案**：開啟後，支援直接從外部將檔案、資料夾或瀏覽器圖片拖入該分組，Lertaro 會自動呼叫 Windows 原生複製介面將檔案複製進該目錄（具備衝突提示與復原支援）。
- **檔案過濾規則**：可使用萬用字元或搜尋語法中的 `@` 篩選器限制該分組展示的檔案類型（例如 `*.mp4;*.mkv`、`*.lnk;:@doc;:@img` 或 `*.lnk;:@doc|img`）。
- **最大條數與時間限制**：可限制最大展示數量（設為 0 表示不限制）及僅展示若干分鐘內改動過的檔案。
- **詳細清單 vs 縮圖平鋪**：支援按分組獨立選擇以清單形式還是縮圖網格平鋪展示（平鋪時自動等比拉伸並保持畫面原始比例）。

## 4. 外掛模組索引標籤（Plugin Tabs）

除自訂工作區外，外掛模組亦可直接向快速面板註冊全域動態清單。CoreExtensions 核心外掛模組內建了五個實用索引標籤：

| 外掛模組索引標籤 | 內容說明 |
| :--- | :--- |
| **我的最愛** | 集中展示你的星標收藏項目，網址點擊後在瀏覽器中開啟。 |
| **搜尋歷程記錄** | 展示你透過 Lertaro 開啟過的最近項目與應用程式。 |
| **Windows 歷程記錄** | 自動解析 Windows 系統級的「最近使用的文件」並列出真實實體檔案。 |
| **上次目錄** | 自動追蹤並遞回你在檔案總管或檔案對話方塊中剛剛離開的目錄。 |
| **最近檔案** | 由背景記憶體索引直接彙總呈現所有設定目錄下的最新變動檔案。 |

可在清單右側獨立控制此類外掛模組索引標籤的顯示狀態以及採用平鋪還是清單檢視。

## 5. 應用程式綁定與獨立黑名單

- **應用程式關聯（Applications）**：可為工作區指定一個或多個前景處理程序名稱（如 `chrome.exe` 或 `devenv.exe`）。當你在該軟體上呼出快速面板時，面板將自動直達該關聯工作區，免去手動切換索引標籤的麻煩。
- **僅快速面板黑名單**：可在此設定不希望被快速面板打擾的處理程序名單。該名單會**疊加**在全域快速鍵黑名單之上，專用於處理不希望被面板遮擋但無需全域停用的特殊程式。

## 6. 面板互動指南

- **即時模糊過濾**：面板右上角內建搜尋過濾框，支援 fzf 模糊比對與拼音別名，輸入即可即時篩選目前工作區。它只篩選**名稱**，絕不會重排清單順序；某個分組的項目全數被濾掉時該分組會消失，但它的索引標籤仍然保留。按 `Escape` 會先清空篩選詞，只有**第二次**按 `Escape` 才關閉面板。
- **全鍵盤流暢導覽**：使用上下方向鍵可無縫跨越不同分組連續捲動；在選取的項目上按下 `Enter` 鍵即可直接開啟，面板會保持展開。這個順序**不**循環：第一個與最後一個可見項目就是硬性終點，空分組會被跳過，而尚未選取任何項目時 `↑` 與 `↓` 都會落在第一個項目上。在平鋪檢視中，四個方向鍵改為沿著視覺網格移動——`←`/`→` 依閱讀順序並跨越行邊界，`↑`/`↓` 則維持在同一欄。
- **索引標籤快捷切換**：按住 `Ctrl` + `1`–`9` 即可在各個工作區與外掛模組索引標籤間快速跳轉。
- **QuickLook 預覽與釘住**：選取項目後按 `Alt+P` 可在面板側邊呼出即時預覽；按 `Ctrl+T`——或標題列上的釘住按鈕——可釘住面板使其在失去焦點時不自動消失。
- **焦點落點**：呼出面板時游標會落在篩選框內，同時已替你選好第一個項目，因此一打字就能立刻縮小範圍。只要該篩選框持有焦點，外掛模組的動作快速鍵就會刻意讓位——在這裡 `Ctrl+A` 與 `Ctrl+C` 代表文字編輯，而非檔案操作。
- **動作浮動面板**：放開滑鼠右鍵時（不是按下時）會開啟與主視窗相同的動作浮動面板，並錨定在游標處，因此對尚未選取的列按右鍵就會以該列為作用對象。面板開啟後由它接管 `↑ ↓ ← →`、`Enter`、`Space` 與 `Escape`。由於它的按鍵處理程式掛在面板之下，動作浮動面板開啟期間，原本會關閉面板的「點擊面板外部」會遭到忽略。
- **滑鼠在列上的行為**：按兩下左鍵開啟；按兩下**右**鍵只會重新開出浮動面板，絕不啟動。按一下中鍵切換預覽面板。滑鼠停留在列上就會移動選取。
- **移動面板**：游標靠近標題列時該處會浮出拖曳條；在那裡拖曳可移動面板，而面板不會因這次拖曳而消失（這正是從檔案總管拖出檔案時能放進它裡面的原因）。
- **點擊面板外部**：面板失去焦點約 200 毫秒後即會隱藏；但你正在拖曳它、它已釘住、動作浮動面板開著，或是它所開啟的預覽面板正處於前景時都會暫停隱藏——點進自己的預覽面板並不算點擊面板外部。
- **選取編輯**：在分組內的空白處按一下，會一次清空**所有**分組的選取（按住 `Ctrl` 或 `Shift` 時除外）。拖曳框選只在自己那個分組內選取項目，`Ctrl` 可改為累加；從某個分組起手的框選不會延伸到另一個分組。
- **拖入檔案**：**起點在 Lertaro 內部**的拖曳一律不被接受，因此拖曳到一半的動作不會變成多餘的複製。由於面板會在「點擊面板外部」時關閉，從檔案總管把檔案拖進來只有在面板**已釘住**時才有效。拖放一律是複製，絕不會搬移。
- **分組標題**：點一下標題的名稱、路徑或規則行即可摺疊與展開該分組；排序與檢視方式是它旁邊獨立的按鈕。排序、檢視模式與摺疊狀態只維持本次工作期間，索引標籤順序與已關閉的索引標籤則會儲存下來。
