# 索引

按順序共五個分頁：**本機磁碟機**、**網路磁碟機**、**WSL**（只在偵測到發行版時才出現）、**資料夾**、**排除規則**。

## 本機磁碟機

- 頂部狀態卡片彙總已索引的磁碟機數量與項目數量，並提供**重建索引**按鈕做全量重新掃描。
- 每個本機磁碟機一行：**啟用/停用核取方塊**、磁碟機名稱、檔案系統（NTFS/ReFS 等）、目前狀態、已索引項目數，以及每行獨立的**重建**/**移除**操作——重建進行中時還會出現**停止**操作（真正的 NTFS 走 $MFT 掃描沒有安全的中斷點，是唯一的例外）。
- NTFS 和 ReFS 磁碟透過 Windows USN 記錄檔持續追蹤變更；其他本機檔案系統（FAT32、exFAT 等）沒有記錄檔可讀，改為直接監看檔案系統變化。不管哪種方式，手動重建都很少需要，但如果發現內容不同步，隨時可以用它——如果重建過程中被中斷（手動停止，或者應用程式/服務中途重新啟動），下次會從中斷的地方繼續，而不是從頭再來。

重建期間搜尋照常可用。正在重建的磁碟機會繼續用它先前的索引回應，直到新索引就緒；其餘磁碟機完全不受影響——重建不會讓你面對一個空的結果清單。

## 網路磁碟機

- 與本機磁碟機相同的狀態卡片和**重建索引**按鈕。
- 每個已對應的網路磁碟機一行：啟用核取方塊、路徑/名稱、狀態（索引中 / 就緒 / 已快取 / 失敗 / 等待中 / 已連線）、項目數，以及**重新整理模式**下拉式選單：
  - **手動** —— 只在手動觸發（重建索引）時重新整理。
  - **每 15 分鐘**
  - **每小時**
  - **每天**

網路共用沒有本機 NTFS 磁碟區那樣的變更記錄檔可供監看，所以採用定時重新整理而不是即時更新。掃描引擎內建了分支祖先路徑堆疊與符號連結迴圈檢測機制，即使 NAS/SMB 共享上存在指向父目錄的軟連結或重解析點，也能自動攔截無窮迴圈，確保索引數量準確不膨脹。

## WSL

只有偵測到至少一個 WSL 發行版時才會出現——形態和網路磁碟機一樣（狀態卡片、**重建索引**按鈕，每個發行版一行，顯示狀態/項目數/**重新整理模式**）。發行版是自動偵測的，沒有手動「新增」這一步。

## 資料夾

單獨索引任意資料夾，而不是整個磁碟機或共用——適合只想索引某一個子目錄，而不想把這個磁碟/共用下的其他內容也納入索引的情境。

- **新增資料夾**按鈕會開啟資料夾選擇器；**重建索引**按鈕會重新掃描清單中的所有資料夾。
- 每個已新增的資料夾一行：啟用核取方塊、路徑、狀態、項目數，以及和網路磁碟機一樣的**重新整理模式**下拉式選單（手動 / 每 15 分鐘 / 每小時 / 每天）——資料夾和網路共用一樣按排程掃描，而不是持續即時追蹤。
- 資料夾選擇器也支援直接選一個 **UNC 網路共用路徑**（比如 `\\server\share`，或者它裡面的子目錄）——在選擇器裡透過「網路」瀏覽過去即可，適合只想索引某一個共用或子目錄，而不想把整台伺服器都加成對應的網路磁碟機。

## 排除規則

三個子分頁，形態完全一致：一個單條輸入框 + **新增**按鈕，一個可編輯/刪除每一條規則的清單，以及一個批次多行文字框，配 **從清單產生** / **套用到清單**兩個按鈕，用來一次性編輯全部規則。

- **路徑排除** —— 完整路徑或環境變數（例如 `D:\Cache`、`%ProgramData%`）。
- **Glob 萬用字元** —— `*`（檔名中任意字元）、`?`（單一字元）、`**`（遞迴目錄）。範例：`*.tmp`、`**/node_modules/**`、`bin/**`。
- **正規表示式** —— 針對路徑/檔名做部分比對的任意正規表示式。範例：`^\.`（隱藏檔案）、`~$`（Office 暫存檔）、`\.git\`。

排除規則對本機、網路、資料夾索引都生效，套用排除規則的改動後，網路磁碟機/資料夾會自動重新掃描。
