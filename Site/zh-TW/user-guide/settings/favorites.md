# 我的最愛

我的最愛用於將你最高頻使用的資料夾、檔案、指令碼或網頁 URL 固定下來，賦予專屬的自訂名稱與最高檢索優先順序。設定頁面路徑為**設定 → 我的最愛**。

## 1. 新增收藏項目

在頁面上方的新增表單中：

- **顯示名稱**：自訂名稱（可選）。若留空且目標為本機路徑，系統會自動使用目標檔案或資料夾的檔案名稱作為預設名稱。
- **目標路徑**：支援輸入本機檔案/目錄的絕對路徑，或以 `http://` / `https://` 開頭的完整網頁網址。
- **瀏覽選取**：按一下**瀏覽資料夾**或**瀏覽檔案**按鈕可直接呼叫原生檔案選取器，免去手動輸入路徑的繁瑣。
- **新增**：填入有效路徑後按一下**新增**按鈕即可將該項存入收藏清單。

## 2. 清單管理與拖曳排序

下方清單集中展示所有已新增的收藏項目，支援細緻的排序與維護：

- **六點拖曳手柄排序**：每一行左側均配有六點拖曳手柄，你可以按住手柄直接上下拖動調整項目順序，亦可按一下右側的**向上移動** / **向下移動**按鈕微調。這裡的排列順序直接決定了該收藏項目在搜尋結果與快速導覽功能表中的先後次序。
- **就地編輯**：按一下編輯後，目前項目列會直接變成編輯器，可在該列儲存或取消，不會重用上方的新增表單。
- **刪除此項**：從我的最愛中安全移除該項目。
- **清空清單**：清單有內容時，可以使用清單標題右側的按鈕一次移除所有我的最愛；清單為空時該按鈕會隱藏。

你也可以在搜尋結果的動作功能表中，將單一已存在的檔案或資料夾直接加入我的最愛。Lertaro 會顯示對話方塊讓你填寫顯示名稱；如果相同路徑已經收藏，該動作不會顯示。

## 3. 搜尋召回與視覺呈現

- **專屬星標徽標（★）**：在快速視窗或主搜尋視窗中檢索到收藏項目時，結果旁會顯示醒目的 **★** 星標徽標。
- **自訂別名搜尋**：你可以為複雜的路徑起一個簡短好記的顯示名稱（例如將 `D:\Workspace\2026\Q1\Financial\Summary.xlsx` 命名為 `財務總表`）。在搜尋框中輸入 `cwzb` 即可透過拼音別名秒級召回該檔案。
- **多端聚合呈現**：所有收藏項目會自動同步呈現在[**滑鼠快速導覽**](../hotkeys#3-快速導覽滑鼠觸發)功能表與[**快速面板**](./quick-panel#4-外掛模組索引標籤plugin-tabs)的「我的最愛」索引標籤中，按一下即可秒開。
