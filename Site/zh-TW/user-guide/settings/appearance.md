# 外觀

固定在側邊欄底部、[關於](./about) 的上方。分兩組:**佈景主題模式**和佈景主題選擇器本身。

## 佈景主題模式

三張卡片，點擊即可切換:

- **淺色** —— 固定使用單一佈景主題，下方網格只篩選淺色風格的佈景主題。
- **深色** —— 同上，只篩選深色風格的佈景主題。
- **跟隨系統**(淺深分割畫面預覽)—— Lertaro 會在你分別指定的兩個佈景主題之間切換——一個用於
  Windows 處於淺色模式時，一個用於深色模式時——而不是固定用一個佈景主題，並且 Windows 自己的設定一變化就立刻生效(不需要重新啟動)。

在**淺色**和**深色**之間切換時，會自動跳到該風格下你上一次選過的佈景主題(跟「跟隨系統」用來記住淺/深兩側選擇的是同一份記憶)，所以來回切換不會遺失任一側已經選好的佈景主題。

## 介面佈景主題

選中上方的**淺色**或**深色**時，下面是一個只列出對應風格佈景主題的卡片網格。選中**跟隨系統**
時，網格會拆成兩組:**淺色佈景主題**和**深色佈景主題**——兩者預設取符合對應風格、且恰好排在最前面的那個已安裝佈景主題，具體有哪些佈景主題完全取決於安裝了哪些佈景主題外掛。

每個佈景主題都以卡片形式展示，而不只是一個名稱:卡片裡是一個用該佈景主題配色繪製的快速搜尋視窗縮圖(搜尋框加幾行搜尋結果，其中一行顯示為選中態)，切換前就能看到佈景主題的實際觀感。目前生效的佈景主題卡片上會有一個核取徽章。

內建與隨附佈景主題外掛:

- **CoreExtensions**(內建)—— 淺色、深色、北歐藍、櫻花粉、賽博龐克。
- **AnimeThemes**(隨附提供，需已安裝並啟用)—— 新世紀、櫻花盛開、天氣之子。
- **臻選佈景主題 Curated Themes**(隨附提供，需已安裝並啟用)—— 十組淺色/深色成對佈景主題:冰川藍、陶土棕、森林綠、紫水晶、緋紅、石墨灰、靛藍夜、薄荷青、香檳金、琥珀金。

其他佈景主題外掛也可以用同樣的方式往網格裡再加卡片。
