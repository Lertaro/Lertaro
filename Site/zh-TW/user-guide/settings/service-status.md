# 執行狀態

執行狀態頁面集中監控 Lertaro 核心背景服務的生命週期健康度，並內建了面向 Service、App 與 Hook 三大核心處理程序的高效能即時記錄檢視器。頁面路徑為**設定 → 執行狀態**。

## 1. 服務狀態與控制

頁面頂部展示背景提權索引服務的執行狀態卡片：

- **即時狀態顯示**：
  - **就緒（Ready）**：服務執行健康，即時呈現目前已索引的實體檔案與資料夾總項目數。
  - **索引中（Indexing）**：正在執行初始建置或全量增量更新，顯示動態進度指示器。
  - **安裝中（Installing）**：正在註冊並部署 Windows 背景服務。
  - **錯誤（Error）**：服務未執行或遇到異常中斷，顯示醒目的警告標記與錯誤描述。
- **服務自我修復與安裝按鈕**：當且僅當背景服務尚未安裝或由於系統權限受損進入異常狀態時，頁面會提供**安裝並啟動服務**按鈕；在服務健康執行期間，系統會維持背景持續常駐，避免誤操作導致索引中斷。

## 2. 三處理程序即時記錄檢視器

頁面下方提供了內建記錄終端機，分為三個獨立的索引標籤頁，分別對應 Lertaro 執行的三大處理程序：

- **App 索引標籤頁**：記錄前景 WPF 使用者介面、搜尋互動、快速鍵回應與視窗轉譯相關的操作記錄。
- **Hook 索引標籤頁**：記錄低階全域鍵盤攔截獨立處理程序（`Lertaro.Hook.exe`）的按鍵擷取與處理程序隔離狀態。
- **Service 索引標籤頁**：記錄提權 Windows 背景服務（`Lertaro.Service.exe`）的 USN 記錄檔剖析、磁碟周遊、記憶體樹建置與 IPC 通訊記錄。

### 過濾與記錄清理功能

- **記錄等級過濾**：下拉式方塊支援篩選「全部 / 錯誤 / 警告 / 資訊 / 偵錯」，記錄行按嚴重等級自動呈現不同的顏色標記。
- **即時搜尋過濾**：在搜尋框中輸入關鍵字可瞬間對目前記錄內容進行全文過濾，並與等級過濾條件疊加生效。
- **安全清空記錄**：按一下**清空記錄**按鈕可清理目前索引標籤頁的歷程記錄輸出。清理 Service 記錄時會自動透過提權服務代理安全截斷，無需手動提升管理員權限。
