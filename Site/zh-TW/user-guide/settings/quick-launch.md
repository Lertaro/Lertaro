# 快速啟動設定

快速啟動是快速搜尋視窗在搜尋框留空時顯示的啟動面板。它會組合手動管理的項目，以及我的最愛、搜尋歷程記錄等已選取的動態資料來源。

## 1. 總開關

- **啟用快速啟動面板**：啟用此面板。只有在快速搜尋視窗的搜尋框留空，且至少有一個資料來源存在可用資料時，面板才會顯示。
- 關閉後，面板不會載入任何資料來源。
- 面板高度會根據項目數量最多的資料來源計算，同時不會超過快速搜尋視窗結果區域的最大高度。

## 2. 手動快速啟動項目

開啟**設定 → 快速啟動 → 快速啟動**，即可管理自己的項目：

- 可以新增檔案、資料夾、網址或 Windows Shell 路徑，檢查目標時支援展開環境變數。
- 顯示名稱可以留空，留空時 Lertaro 會根據目標自動產生名稱。
- 檔案和資料夾瀏覽按鈕支援一次選取多個項目，每個有效且不重複的目標都會作為獨立項目加入。
- 使用拖曳手柄調整順序。按一下編輯後，目前項目列會變成帶有儲存和取消按鈕的就地編輯器；刪除按鈕用於移除項目。
- 目前無法使用的目標會從面板中隱藏，目標恢復可用後會自動重新出現。

## 3. 資料來源

開啟**設定 → 快速啟動 → 資料來源**，即可選擇動態資料來源：

- 資料來源來自已安裝的快速面板標籤頁提供者，因此快速啟動可以直接重用我的最愛、搜尋歷程記錄、Windows 歷程記錄、上次目錄、最近檔案以及後續外掛模組資料來源，不需要維護第二份資料。
- 資料來源提供者存在時預設啟用，使用者設定中只儲存明確關閉的資料來源。
- 只有已啟用且目前能返回資料的資料來源才會建立面板標籤頁，沒有資料的來源會隱藏。
- 當所有手動項目和動態資料來源都沒有資料時，快速啟動面板會隱藏。

## 4. 面板互動

- 面板欄數會根據搜尋列寬度自動調整。
- 只有一個資料來源時，底部資料來源指示器會隱藏。
- 有多個資料來源時，底部會為每個資料來源顯示一個圓點。選取的圓點為藍色，未選取的圓點為灰色；滑鼠停留時圓點會展開顯示資料來源名稱。
- 在面板上按住 **Shift** 滾動滑鼠滾輪可以循環切換資料來源，切換後的資料來源會短暫播放同樣的展開動畫。
- 開始輸入搜尋內容後，面板會隱藏。
