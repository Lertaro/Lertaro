# LocalSend 區域網路傳輸設定

Lertaro 內建了與官方開源 [LocalSend](https://localsend.org) 通訊協定原生相容的區域網路無線傳輸引擎。無需依賴外部網際網路或傳輸線，即可在同一區域網路下的 Windows 電腦、Mac、Linux、iPhone、iPad 以及 Android 手機之間極速互傳檔案、資料夾與純文字。設定頁面路徑為**設定 → LocalSend**。

## 1. 基礎服務設定

- **啟用 LocalSend 區域網路傳輸**：總開關。開啟後，Lertaro 會在背景啟動輕量級傳輸監聽服務，並在系統匣功能表中啟用「傳送到其他裝置...」功能項目。
- **裝置名稱**：本機在區域網路多播廣播中向其他裝置展示的別名。預設根據電腦名稱自動產生，你可以隨時修改為一個更具辨識度的名稱（例如 `工作筆記型電腦`）。
- **服務連接埠**：HTTP / HTTPS 傳輸監聽連接埠（遵循 LocalSend 官方標準，預設為 `53317`）。若本機該連接埠被其他服務占用，可在此自訂更改。

## 2. 安全加密與儲存規則

- **加密傳輸 (HTTPS)**：預設開啟。啟用後裝置間的資料往來均採用 TLS 加密傳輸，防止區域網路封包窺探。
- **接收 PIN 碼**：可設定 4–6 位數 PIN 碼。設定後，其他裝置向你發起傳輸請求時必須在發送端輸入相符的 PIN 碼方可建立連線（留空則不開啟驗證）。
- **自動儲存檔案**：開啟後，接收來自區域網路裝置的傳輸請求將自動確認並下載儲存，無需每次手動按一下快顯視窗確認。
- **儲存目錄**：設定接收到的檔案與資料夾預設儲存的實體目標路徑（預設儲存在使用者系統的 `Downloads\LocalSend` 目錄下），按一下右側瀏覽按鈕可隨時更改。

## 3. 發送視窗與快捷呼叫

- **快速鍵喚起**：可在全域任何介面按下預設快速鍵 **`Ctrl+S`**（可在[**設定 → 快速鍵**](./hotkeys-page)中重新綁定）瞬間喚起 LocalSend 獨立發送視窗。
- **發送模式切換**：發送視窗頂部支援在 **[發送檔案 / 資料夾]** 與 **[發送文字]** 兩種模式之間一鍵切換。
- **即時拖曳分發**：支援直接從 Lertaro 搜尋結果清單、快速面板或檔案總管中將多個檔案或整個專案目錄拖入發送視窗，雷達掃描會自動列出區域網路內目前連線的所有裝置，按一下目標裝置圖示即可全速發送。
