# 設定項參考

設定視窗可以像一般視窗一樣調整大小和最大化：拖曳邊緣、點擊標題列的最大化按鈕，或者按兩下標題列。外掛頁尤其值得這麼做——它把外掛清單和該外掛的設定並排放在一起，寬度是用得上的。

設定視窗標題列上有一個搜尋框。比對方式是模糊比對(和主搜尋視窗同一套 fzf 模式比對,支援拼音別名)，不只是簡單的子字串比對，涵蓋所有分區——包括外掛頁面下每個外掛自己的項目、熱鍵頁「外掛動作」標籤裡的動態內容。每條結果都會顯示麵包屑(例如「索引 › 網路磁碟機」),避免不同標籤下同名的設定混淆。選中一條結果(點擊，或用上下鍵高亮後按 Enter)會跳轉到對應分區和標籤、把具體控制項捲動到可見範圍，並短暫給它加一個高亮邊框閃爍提示。

部分分區(通用、熱鍵、索引、歷史記錄、快速面板、執行狀態)頁面頂部還會再分一層子標籤。如果標籤文字放不下——最常見於英文介面，因為翻譯後的文字通常比中文原文長——兩端會出現左右箭頭按鈕，可以捲動看到剩下的標籤，而不是被直接裁掉看不到。

設定視窗左側導覽列共有十個分區:

| 分區 | 內容 |
|---|---|
| [執行狀態](./service-status) | 背景服務的安裝，以及 App/Hook/Service 記錄檢視器。 |
| [索引](./index-drives) | 本機磁碟機、網路磁碟機、WSL 發行版(偵測到時才出現)、資料夾索引，以及排除規則。 |
| [通用](./general) | 啟動行為、更新、語言、搜尋列版面配置、預覽視窗大小。 |
| [熱鍵](./hotkeys-page) | 全域熱鍵、各外掛動作熱鍵、處理程序黑名單。 |
| [外掛](./plugins) | 已安裝的外掛及各功能元件的啟用/停用開關。 |
| [LocalSend](./localsend) | 局域網跨裝置檔案、資料夾與純文字傳輸設定（協定相容 LocalSend 官方用戶端）。 |
| [我的最愛](./favorites) | 自訂命名的資料夾/檔案/網址捷徑。 |
| [歷史記錄](./history) | 搜尋歷史與快速視窗關鍵字歷史。 |
| [快速面板](./quick-panel) | 停靠在前景視窗上的浮動面板:它的工作區、每個工作區的來源、外掛提供的標籤，以及各工作區歸屬的應用程式。 |
| [外觀](./appearance) | 佈景主題選擇器(每個佈景主題都有預覽卡片)，以及「跟隨系統淺色/深色」模式。固定在「關於」上方。 |
| [關於](./about) | 版本資訊與檢查更新。 |

以下每篇文章都會按順序列出該分區的每一項設定，包括預設值和取值範圍。
