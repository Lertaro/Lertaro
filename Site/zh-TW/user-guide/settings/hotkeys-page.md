# 快速鍵設定

快速鍵設定頁面集中管理 Lertaro 的所有全域呼出按鍵、應用程式內導覽快速鍵、外掛模組動作快捷方式以及前景處理程序過濾規則。頁面頂部包含三個索引標籤頁：**全域**、**外掛模組動作**與**處理程序黑名單**。

## 1. 全域（Global）

### 全域快速鍵分組

- **顯示/隱藏快速搜尋**：專屬按鍵錄製框。支援錄製為**單鍵連按兩下模式**（預設按兩下 `Ctrl`，亦可設為按兩下 `Alt` 或 `Shift`），或錄製為**常規組合鍵**（如 `Alt+Space`）。
- **預設開啟完整面板**：核取方塊（預設關閉）。開啟後，全域呼出快速鍵會改為開啟主視窗，而不是快速視窗。首次呼出時只將視窗置於前景並聚焦一次；視窗已顯示但未啟用時再次按下會重新啟用，視窗已啟用時再次按下預設會切回快速視窗（若啟用「再次按下快速鍵時關閉完整視窗」則直接關閉）。視窗不會自動保持置頂。
- **全螢幕應用程式聚焦時仍然回應**：核取方塊（預設關閉）。開啟後，即使前景有獨占全螢幕程式（如全螢幕遊戲或影片），Lertaro 依然會回應快速鍵呼出搜尋框；保持關閉則自動放行按鍵不搶佔焦點。
- **快速跳轉（Quick Jump）**：預設 `Ctrl+G`。在各類檔案對話方塊中按下即可直接跳轉到最近在檔案管理器中瀏覽過的目錄。
- **快速導覽選單**：預設不分配快速鍵。可為它指定一個可選的全域快速鍵來開啟階層式選單。在桌面或普通應用程式中呼出時使用桌面情境；在檔案總管和原生檔案對話方塊中呼出時使用目前視窗情境。即使普通前景保護會抑制全域快速鍵，檔案管理器和檔案對話方塊仍會放行。

### 功能按鍵分組

頁面提供了一系列獨立的按鍵錄製控制項，支援任意單鍵或組合鍵錄製：

- **選取下一項 / 上一項**：預設 `Ctrl+N` / `Ctrl+P`（與方向鍵 `↓` / `↑` 等效）。
- **跳轉結果修飾鍵**：預設 `Ctrl`，配合數字鍵 `1`–`9` 即可在快速視窗中直達前 9 項結果。
- **開啟動作功能表**：預設 `Ctrl+O`（與方向鍵 `→` 等效）。兩者都適用於快速視窗，以及檔案對話方塊之外的內嵌卡片；主視窗則改用按一下滑鼠右鍵或 `Apps` 鍵開啟同一個功能表。
- **從選取項補全搜尋詞**：預設 `Ctrl+Tab`。
- **QuickLook 即時預覽**：預設 `Alt+P`。
- **上/下一條關鍵字歷程**：預設 `Alt+Up` / `Alt+Down`。
- **刪除目前關鍵字歷程**：預設 `Ctrl+Delete`。
- **開啟完整搜尋主視窗**：預設 `Ctrl+F`。
- **開啟傳送視窗（LocalSend）**：預設 `Ctrl+S`。
- **保持視窗不消失（釘住）**：預設 `Ctrl+T`。
- **呼出/關閉快速面板**：預設 `Ctrl+F2`。

### 快速導覽滑鼠觸發分組

- **在空白處按兩下左鍵**：核取方塊（**預設關閉**）。在桌面或檔案總管空白處按兩下快顯快速導覽功能表。
- **在空白處按一下中鍵**：核取方塊（預設開啟）。在桌面、檔案總管或檔案選取對話方塊中按一下滑鼠中鍵快顯快速導覽功能表。

只有桌面與檔案總管會接受按兩下的觸發形式；第三方檔案管理器只支援滑鼠中鍵。只要游標位在 Lertaro 自己的卡片上，這兩種觸發都會一併略過；而即使處理程序黑名單或全螢幕通常會讓全域觸發失效，檔案管理器與對話方塊的這兩種觸發仍舊保持有效。

### 錄製快速鍵

錄製期間每一次按鍵都會進入錄製框，而不會落到背後的程式，這讓錄製器本身也成了一組手勢：

- **`Escape`**：取消錄製並清掉數值。這裡沒有「捨棄後還原」這回事，一按下去錄製框就變成空的。
- **`✕`** 清空錄製框；**`↺`** 還原該列的出廠預設值。兩者同時只會出現其中一個：已設定組合鍵時顯示清空按鈕，清空之後才顯示還原按鈕。
- **單獨的修飾鍵**（`Ctrl`、`Alt`、`Shift`）只在本身自成意義的列上才會被接受，也就是呼出快速鍵（會成為連按兩下）與跳轉結果修飾鍵。在一般的組合鍵列上，按下並放開一個孤立的修飾鍵會**清空**該列，而不會存下一個永遠無法觸發的數值。
- **Windows 保留的組合鍵**（`Win+E`、`Win+D`……）會遭到拒絕：數值被歸為空值，於是錄製框直接變成空白。
- **沒有衝突偵測。**兩列可以綁定同一組按鍵而不會有任何警告；只有我的最愛項目的快速鍵會回報重複或遭作業系統拒絕的組合，而且要等你套用之後才回報。

### 我的最愛專屬快速鍵

每個我的最愛項目（[**設定 → 我的最愛**](./favorites)）都可以帶有自己的**作業系統層級全域**快速鍵，即使 Lertaro 沒有任何開啟中的視窗也能作用，並讓前景的檔案管理器直接跳轉到該資料夾。與上述錄製列不同的是，它必須包含修飾鍵、不接受單獨的修飾鍵，而且不能使用 `F12`。

## 2. 外掛模組動作（Plugin Actions）

各外掛模組註冊的專屬動作快速鍵（例如內建的檔案操作：複製路徑 `Ctrl+Shift+C`、複製名稱 `Shift+C`、剪下 `Ctrl+X`、複製 `Ctrl+C`、貼上 `Ctrl+V`、刪除 `Delete`、徹底刪除 `Shift+Delete` 等）均匯集於此。

- **分組檢視**：按註冊動作的來源外掛模組清晰分組。
- **獨立重錄**：每個動作均配有專屬的按鍵錄製框，按一下即可按下新按鍵進行覆蓋綁定。

## 3. 處理程序黑名單（Process Blacklist）

用於設定特定前景應用程式的無訊息放行機制。當黑名單中的程式處於系統前景聚焦狀態時，Lertaro 會完全放行所有全域快速鍵與滑鼠觸發手勢，絕不進行攔截。

- **不區分大小寫**：新增 `game.exe` 或 `game` 均可生效。
- **單筆新增**：在單筆輸入框中輸入處理程序名稱，按一下**新增處理程序**按鈕。
- **批次管理**：支援按一下**產生文字**將目前黑名單匯出為多行文字，或在多行文字方塊中直接貼上編輯後按一下**套用到清單**進行一鍵批次匯入。
- **檔案對話方塊安全豁免**：即使某個程式處於黑名單中，當它快顯系統檔案選取對話方塊時，Lertaro 的內嵌搜尋與滑鼠快速導覽依然會被安全放行，確保檔案選取效率不受影響。
