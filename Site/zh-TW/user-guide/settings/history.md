# 搜尋歷程記錄

搜尋歷程記錄頁面用於管理 Lertaro 的使用痕跡與智慧推薦權重。頁面頂部包含兩個相互獨立的索引標籤頁：**搜尋歷程**與**關鍵字歷程**。

## 1. 搜尋歷程（Search History）

搜尋歷程追蹤你實際點擊或按 Enter 開啟過的搜尋結果，並將開啟時的「搜尋關鍵字」與「目標實體路徑」進行雙向綁定學習：

- **智慧優先召回**：當你之後輸入與先前查詢相似或模糊相關的字元時，Lertaro 會自動在結果清單前列優先召回該檔案。例如，你曾透過輸入 `bcomp` 開啟過 `BCompare.exe`，未來只需輸入 `bc`，該程式依然會被優先推至前排。
- **內嵌視窗智慧分區**：在檔案選取對話方塊的內嵌搜尋中，歷程比對項目若屬於目前資料夾內，會自動歸入「目前資料夾」分組，其餘則歸入「全域搜尋」分組。
- **失效路徑自動過濾**：若已記錄的檔案或目錄被外部刪除或移動，Lertaro 在檢索時會自動過濾不存在的無效連結，且相同路徑在清單中絕不重複顯示。
- **管理操作**：
  - **啟用歷程記錄功能**：總開關，關閉後保留現有資料；不會新增記錄，但再次開啟已有項目仍會累計使用次數。
  - **搜尋過濾**：在上方搜尋框輸入關鍵字快速定位特定歷程項目。
  - **使用次數與清理**：每筆記錄會顯示開啟次數。選擇次數門檻並按一下**清除少於等於 N 次的記錄**即可清理低頻記錄，也可以刪除單筆記錄或按一下**清空全部歷程**重設所有開啟記錄。
  - **即時更新**：其他搜尋視窗記錄新的開啟行為後，清單會自動更新使用次數。

## 2. 關鍵字歷程（Keyword History）

關鍵字歷程用於記憶實際執行過結果或動作，或用於開啟完整視窗的**原始查詢字串**。僅輸入關鍵字後關閉或離開快速搜尋視窗，不會新增記錄：

- **快速鍵快速翻閱**：在快速搜尋視窗中，可使用快速鍵 **`Alt+Up`** 向前翻閱、**`Alt+Down`** 向後翻閱最近輸入過的搜尋詞；按下 **`Ctrl+Delete`** 即可從歷程中直接刪除目前顯示的這條詞彙。
- **使用次數與清理**：每個關鍵字會顯示使用次數。選擇次數門檻並按一下**清除少於等於 N 次的記錄**即可清理低頻關鍵字。
- **獨立控制與維護**：與搜尋歷程一樣提供專屬的**啟用歷程記錄功能**開關、關鍵字搜尋過濾、單筆刪除與**清空全部歷程**按鈕。關閉後已有關鍵字仍會累計使用次數，但不會加入新關鍵字。
