# 使用者手冊

Lertaro 是一款為 Windows 打造的、鍵盤優先的極速檔案搜尋啟動器。它在背景索引你的本機磁碟(NTFS
和 ReFS 透過各自的變更記錄檔，其他檔案系統則直接監看變化)及網路共用，讓你能在極短時間內跳轉到任意檔案、資料夾或應用程式。

本手冊涵蓋日常使用所需的一切：

- **[快速上手](./getting-started)** —— 安裝 Lertaro，了解它的三種搜尋視窗(主視窗/快速視窗/內嵌視窗)。
- **[搜尋語法](./search-syntax)** —— 模糊比對、排除/精確/前綴/後綴運算子、或組、磁碟機代號定向、路徑模式，以及中文檔名的拼音別名比對。
- **[熱鍵](./hotkeys)** —— 每一個可設定快捷鍵與硬編碼按鍵，及其預設綁定。
- **[動作選單與預覽](./actions-and-preview)** —— 類右鍵選單的動作清單，以及 QuickLook 預覽視窗。
- **[即時答案與關鍵字功能](./instant-answers)** —— 計算機、環境變數、執行命令這些捷徑，以及處理程序管理、視窗切換器、瀏覽器資料、設定搜尋、網頁搜尋、翻譯這類關鍵字觸發的外掛。
- **[命令列搜尋（lff）](./cli)** —— 可以在終端機裡使用的、fzf 風格的命令列夥伴工具。
- **[URI 通訊協定（lertaro://）](./uri-protocol)** —— 透過一個連結、別的程式或指令碼，直接跳轉到某次搜尋或某項具體設定。
- **[支援的檔案管理員](./file-manager-support)** —— Lertaro 可以嵌入、觸發快速導覽、或偵測目前資料夾的檔案管理員和檔案選擇對話方塊都有哪些。
- **[設定項參考](./settings/)** —— 每一個設定頁面、每一個分頁、每一項設定，逐條列出。
- **[疑難排解](./troubleshooting)** —— 常見問題與解決辦法。
- **[捐款贊助](./donate)** —— 如果 Lertaro 對你有幫助。

如果是第一次設定 Lertaro，建議從**快速上手**開始閱讀。
