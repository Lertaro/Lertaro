# 內容搜尋

內容搜尋外掛模組可以搜尋本機文件中的內文，並在背景建立索引，與 Lertaro 原有的檔名搜尋並行運作。

## 開始使用

開啟**設定 → 外掛模組 → 內容搜尋 → 設定**，至少設定一個監控資料夾並儲存。預設觸發關鍵字為 `cs`：

```text
cs 專案計畫
```

關鍵字後必須跟一個空格。如果 `cs` 與你的使用習慣衝突，可以在外掛模組設定中改成其他關鍵字。

## 索引內容

- **監控資料夾**：外掛模組會遞迴掃描設定的本機資料夾，並支援 `%USERPROFILE%` 等環境變數。
- **檔案副檔名**：預設包含 `txt`、`md`、`pdf`、`docx`、`docm`、`pptx`、`pptm`、`xlsx`、`xlsm` 和 `csv`，你可以按需要修改以逗號分隔的清單。
- **PDF 檔案**：會同時搜尋可擷取的頁面內文和已儲存的可填寫 PDF 表單欄位值。
- **檔案大小**：超過單一檔案大小上限的檔案會被略過；內容索引還有獨立的容量上限，設為 `0` 表示不限制。
- **排除路徑**：輸入以分號分隔的正規表示式來排除符合的完整路徑。資料夾路徑符合時，其內容也會被排除。

只有成功擷取出內文的檔案才會參與搜尋。沒有對應文件擷取器的二進位檔案會被略過，不會作為亂碼文字寫入索引。

## 搜尋方式

在快速搜尋視窗中輸入 `cs`、空格和關鍵字即可搜尋。結果會顯示符合檔案的內文片段及所在資料夾，按下 `Enter` 可開啟選取的檔案。查詢有結果時，在未選取類型篩選的情況下，完整搜尋視窗中也會顯示這些檔案結果。

首次建立索引時，`cs` 佔位結果會顯示已索引檔案數和剩餘工作數。新檔案和發生變更的檔案會在背景處理，索引期間不會影響普通檔名搜尋。

## 清除與重建

內容搜尋設定中提供兩個不同的操作：

- **清除索引**：刪除內容索引，但不會重新掃描監控資料夾。
- **重建索引**：刪除內容索引，然後重新掃描所有監控資料夾。

這兩個操作只影響內容搜尋索引，不會刪除 Lertaro 的普通檔名索引。

## 使用提示

- 如果檔案沒有出現在結果中，請檢查它所在的資料夾、副檔名、排除規則和大小上限。
- 修改監控資料夾或索引規則後，請儲存設定並等待背景掃描完成。
- 修改規則後如果希望重新擷取已有檔案，請使用**重建索引**。
