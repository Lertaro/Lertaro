# 快速鍵與互動手勢

Lertaro 採用鍵盤優先的互動設計，同時提供多種滑鼠快捷手勢與多級導覽系統。除固定按鍵外，所有全域與應用程式內快速鍵均可在[**設定 → 快速鍵**](./settings/hotkeys-page)中自由重新綁定。

## 1. 全域快速鍵速查表

| 功能動作 | 預設快速鍵 | 功能說明與互動細節 |
| :--- | :--- | :--- |
| **呼出/隱藏快速視窗** | 按兩下 `Ctrl` | 可設定為連按兩下模式或常規組合鍵（例如 `Alt+Space`）。所謂連按兩下，是指按下**同一個**修飾鍵兩次、兩次放開之間相隔 **100–300 毫秒**，左 `Ctrl` 與右 `Ctrl` 屬於不同按鍵，期間按下任何其他鍵都會讓計數重新開始。採用連按兩下模式時，修飾鍵本身絕不會被吞掉，因此 `Ctrl`+`C` 這類普通快速鍵照常可用。啟用「預設開啟完整面板」後，此快速鍵會改為開啟主視窗：首次顯示時只將其置於前景並聚焦一次，視窗已顯示但未啟用時重新啟用，視窗已啟用時再次按下預設會切回快速視窗（若啟用「再次按下快速鍵時關閉完整視窗」則直接關閉）；不會自動保持置頂。 |
| **快速切換（Quick Jump）** | `Ctrl+G` | 在檔案對話方塊中直接跳轉到最近一次在檔案總管、受支援檔案管理器或檔案對話方塊中瀏覽的資料夾。 |
| **快速導覽選單** | 無預設快速鍵 | 可選的全域快速鍵，用於開啟階層式快速導覽選單。在桌面或普通應用程式中呼出時使用桌面情境；在檔案總管和原生檔案對話方塊中呼出時使用目前視窗情境。即使普通前景保護會抑制全域快速鍵，檔案管理器和檔案對話方塊仍會放行。 |
| **選取下一項** | `Ctrl+N` 或 `↓` | 向下移動清單反白項目。在快速面板中支援跨群組連續瀏覽；在快速啟動面板中，方向鍵按照可見網格移動：**←** 和 **→** 依照閱讀順序移動並可跨越列邊界，**↑** 和 **↓** 則保持目前欄位、僅在相鄰列之間移動，當目標列在該欄沒有項目時就會停止；快速啟動面板顯示且搜尋內容為空時，`Ctrl+N` 會循環切換到下一個資料來源。 |
| **選取上一項** | `Ctrl+P` 或 `↑` | 向上移動清單反白項目。在快速面板中同樣支援跨群組巡覽；在快速啟動面板中，方向鍵按照可見網格移動：**←** 和 **→** 依照閱讀順序移動並可跨越列邊界，**↑** 和 **↓** 則保持目前欄位、僅在相鄰列之間移動，當目標列在該欄沒有項目時就會停止；快速啟動面板顯示且搜尋內容為空時，`Ctrl+P` 會循環切換到上一個資料來源。 |
| **跳轉至第 1–9 項結果** | `Ctrl` + `1`–`9` | 修飾鍵可自訂，快速視窗結果旁會顯示對應的數字徽章，直接按鍵開啟目標項目。數字代表**從第一個可見行算起**的第 N 個可選取列，因此捲動時徽章會隨之重新編號；`0` 並未綁定。快速啟動面板是例外，它綁定 `1`–`9`、`0` 與 `A`–`Z`，最多可對應 36 個平鋪項目。 |
| **開啟動作功能表** | `Ctrl+O` 或 `→` | 展開選取結果的快顯動作面板（複製路徑、屬性、以系統管理員身分執行、檔案操作等）。快速視窗以及**檔案對話方塊以外**的內嵌卡片都能使用；主視窗則改用按一下滑鼠右鍵或 `Apps` 鍵（`Shift+F10`）開啟同一個動作功能表。 |
| **從選取項補全搜尋詞** | `Ctrl+Tab` | 將目前選取項目的名稱或完整路徑直接填入搜尋框，便於在此基礎上做二次篩選。 |
| **QuickLook 即時預覽** | `Alt+P` | 開啟/關閉選取項目的側邊預覽面板（圖片、文件、音訊/影片即時播放、資料夾結構等）。快速視窗、主視窗與快速面板皆可使用，內嵌卡片不適用；在可預覽的列上按一下滑鼠中鍵也能切換同一個預覽面板。 |
| **上一條搜尋記錄詞** | `Alt+Up` | 向前翻閱最近輸入過的搜尋關鍵字。 |
| **下一條搜尋記錄詞** | `Alt+Down` | 向後翻閱最近輸入過的搜尋關鍵字。 |
| **刪除目前歷史詞** | `Ctrl+Delete` | 從最近搜尋歷程記錄中移除目前顯示的這一條詞彙。 |
| **開啟完整搜尋主視窗** | `Ctrl+F` | 直接開啟大尺寸主搜尋視窗，並自動同步目前快速視窗中的搜尋詞。 |
| **開啟傳送視窗（LocalSend）** | `Ctrl+S` | 開啟 LocalSend 無線區域網路傳輸視窗，快速傳送檔案或文字至跨平台裝置。 |
| **保持視窗不消失（釘住）** | `Ctrl+T` | 臨時鎖定視窗，在失去焦點時不再自動隱藏（便於從其他視窗複製文字組合查詢）。 |
| **呼出/關閉快速面板** | `Ctrl+F2` | 在目前前景活動視窗旁展開包含最近檔案、我的最愛、工作區的快速停靠面板。 |

### 檔案對話方塊中的空白搜尋

當內嵌搜尋框位於原生檔案對話方塊中且搜尋內容為空時，清單會先顯示「上次目錄」分組。開啟「在內嵌搜尋中顯示目前開啟的資料夾」後，還會顯示彙總受支援檔案管理器正在瀏覽目錄的「目前開啟的資料夾」分組，該分組會刻意包含目前檔案對話方塊所在的資料夾；重複路徑會自動去重，空分組不會顯示，分組標題也不會顯示快速鍵徽章。此開關預設開啟，可在[**設定 → 一般 → 系統**](./settings/general)中修改。此行為只適用於檔案對話方塊中的內嵌搜尋，快速視窗和完整視窗不受影響。

### 內嵌視窗的呼出與焦點交接

停靠在原生檔案對話方塊中的卡片刻意**不搶佔鍵盤**：焦點仍留在對話方塊，你可以繼續在它自己的檔案名稱欄位中打字，卡片則同步反映搜尋內容。會移動游標的手勢有：

| 手勢 | 效果 | 條件 |
| :--- | :--- | :--- |
| **輸入字母或數字** | 呼出卡片，同時把那個第一個字元帶進搜尋框；後續按鍵會持續輸入其中 | 僅限真實按鍵，自動化工具合成的輸入會原樣放行而不予攔截，內容功能表或系統功能表開啟期間也不會擷取任何按鍵 |
| **按兩下 `Ctrl`**（或你設定的呼出快速鍵） | 把游標放進卡片自己的搜尋框。若搜尋框已取得游標且內容為空，則改為清空搜尋詞，並把焦點交還給對話方塊的欄位，卡片保持開啟 | 與其他地方用的是同一個快速鍵，所以在[**設定 → 快速鍵**](./settings/hotkeys-page)中改綁，這裡也會跟著變。即使黑名單或全螢幕通常會使全域快速鍵沉默，檔案對話方塊仍然適用 |
| **`Escape`** | **對話方塊**持有鍵盤時，卡片關閉。**卡片**持有鍵盤時，清空搜尋詞並將焦點交還對話方塊（檔案對話方塊中），或關閉卡片（停靠在普通檔案總管視窗上時） | |
| **在空框按 `Backspace`** | 與 `Escape` 完全相同地離開搜尋 | 僅在卡片取得游標時；對話方塊持有鍵盤時，該鍵只會編輯卡片的搜尋詞 |
| **在空框按 `Enter`** | 像 `Escape` 一樣離開搜尋 | 僅在卡片取得游標時；對話方塊持有鍵盤時，`Enter` 會開啟反白的瀏覽列 |
| **`Tab`** | 永遠留給對話方塊自己的控制項遍歷，因此請改用呼出快速鍵進入卡片 | |

> [!NOTE]
> 在檔案對話方塊內，卡片無法使用動作功能表（`Ctrl+O`、`→` 與滑鼠右鍵在那裡都沒有作用），也不提供 `Alt+P` 預覽。滑鼠在清單列上仍然可用：**按一下左鍵**開啟反白的結果，**`Ctrl`+按一下**以系統管理員身分開啟，列可以**拖曳出去**放進對話方塊，而單純**停留在列上**就會移動選取，宿主檔案管理器也會同步跟進。

## 2. 搜尋框圖示與滑鼠手勢

搜尋框內的小圖示除了品牌識別，還集成了多種實用的滑鼠快捷手勢：

### 快速搜尋視窗中的圖示手勢

- **滑鼠左鍵按一下**：直接在游標處彈出快捷主功能表（與系統匣功能表相同：顯示主視窗、傳送至其他裝置、停用/啟用快速鍵、設定、關於、乾淨結束、結束程式）。其中「顯示主視窗」會自動攜帶目前輸入的內容。
- **滑鼠左鍵按住拖曳**：自由拖曳調整搜尋列在螢幕上的顯示位置。**拖曳時按住 `Ctrl` 鍵**可將移動方向嚴格鎖定為**純垂直方向**，避免水平位置發生偏移。
- **滑鼠右鍵按一下**：一鍵將快速視窗重設回螢幕初始預設置中位置（不改變已配置的視窗尺寸）。
- **滑鼠中鍵按一下**：快捷切換視窗「釘住（保持不消失）」狀態，釘住期間 Logo 圖示會反白發光。

> [!NOTE]
> 快速視窗記錄的螢幕座標是相對於所在顯示器的**相對比例座標**。當你將視窗喚出在另一台不同解析度、不同 DPI 縮放的顯示器上時，Lertaro 會自動等比換算位置，絕不會跑出螢幕可視區域。

### 內嵌視窗與主視窗中的圖示

- **內嵌視窗**：當嵌入在原生檔案對話方塊（開啟/儲存/瀏覽）時，按一下左鍵圖示可直接展開[**快速導覽**](#_3-快速導覽-滑鼠觸發)階層式功能表；停靠在普通檔案總管時僅作展示。拖曳圖示會移動卡片本身，而之後每次停靠都會重新套用該偏移量。
- **主視窗**：按一下左鍵圖示會開啟快顯功能表；由於主視窗已經開啟，功能表中的「顯示主視窗」項目會隱藏。按一下中鍵可切換視窗的釘住狀態。

### 搜尋框手勢（快速視窗）

- **在搜尋框上滾動滑鼠滾輪**：向前/向後翻閱最近的搜尋詞，與 `Alt+Up` / `Alt+Down` 的導覽完全相同，手不必離開滑鼠。
- **以滑鼠中鍵按一下搜尋框**：刪除目前顯示的那筆歷史記錄。此手勢是硬編碼的，並非可設定的 `Ctrl+Delete` 綁定。
- **隨時輸入任何文字**都會結束本次歷史瀏覽，因此下一格滾輪會重新從你目前的搜尋詞開始。歷史不會循環：翻到最舊一詞就停在那裡，翻到最新一詞則回到你最初開始的那個搜尋詞。

### 系統匣圖示

- **按一下左鍵**：切換快速視窗，效果與呼出快速鍵完全相同。
- **按一下右鍵**（或第二次按一下，因為並沒有按兩下的處理程式）：在游標處開啟功能表，包含顯示主視窗、傳送至其他裝置（僅在 LocalSend 啟用期間）、停用/啟用快速鍵、設定、關於、乾淨結束（僅在 Lertaro 是唯一執行中的處理程序時）與結束程式。
- **隱藏系統匣圖示**（[**設定 → 一般 → 系統**](./settings/general)）只會移除圖示，絕不會移除視窗內的 Logo 功能表。當快速鍵透過該功能表被停用時，圖示會被強制恢復顯示，讓你不會把自己鎖在外面。

## 3. 快速導覽（滑鼠觸發）

快速導覽功能讓你無需打字，透過滑鼠按一下即可在任意視窗中直達常用目錄或開啟檔案。

你也可以在[**設定 → 快速鍵**](./settings/hotkeys-page)中為快速導覽選單指定一個可選的全域快速鍵。在桌面或普通應用程式中呼出時使用桌面情境；在檔案總管和原生檔案對話方塊中呼出時使用目前視窗情境。

### 觸發方式與支援環境

- **桌面空白處**：滑鼠中鍵按一下（或開啟按兩下左鍵）直接彈出快速導覽功能表，按一下目錄或檔案直接開啟。
- **檔案總管**：在檔案總管空白處按一下滑鼠中鍵觸發，按一下目標後目前視窗立即跳轉到該路徑。
- **第三方檔案管理器**：在 Directory Opus、Total Commander、XYplorer、Files、One Commander 等工具的檔案清單區按一下滑鼠中鍵觸發（詳見[**支援的檔案管理器**](./file-manager-support)）。
- **系統檔案對話方塊**：在任意軟體的「開啟/儲存/瀏覽資料夾」對話方塊中按一下中鍵或按一下內嵌圖示觸發，按一下後對話方塊直接跳轉至目標目錄，絕不會誤觸發「儲存/開啟」確認。

### 階層式功能表內容與管理

快速導覽功能表由**階層式資料夾瀏覽器（Folder Cascader）**外掛模組驅動，內容分為四類：

1. **目前開啟的資料夾**：自動彙總並去重所有受支援檔案管理器目前正在瀏覽的真實目錄，方便在不同應用程式間快速同步路徑。
2. **我的最愛與歷程記錄**：自動按分類列出你的加星收藏與最近造訪歷程。
3. **自訂快捷分類**：支援在**設定 → 外掛模組 → 階層式資料夾瀏覽器**中自訂目錄與子功能表（如使用 `工作/專案A` 建立多級分類）。
4. **一鍵新增目錄（`+` 按鈕）**：功能表每個層級的標題右側均設有一個 `+` 按鈕，按一下即可直接將目前正在瀏覽的資料夾快速儲存到該分類下，無需開啟設定面板。

## 4. 硬編碼核心按鍵（不可修改）

為了保證最核心互動的確定性與一致性，以下按鍵在任何配置下行為始終保持統一：

| 按鍵 | 觸發場景 | 統一行為 |
| :--- | :--- | :--- |
| `Enter` | 結果清單 | 直接開啟選取的結果（檔案/目錄/程式/動作）。在主視窗中會開啟**每一個**選取列。內嵌搜尋框為空時則改為離開搜尋，此時沒有排在最前的結果可開啟。 |
| `Ctrl+Enter` | 結果清單 | 在檔案總管中開啟並定位選取項目所在目錄。 |
| `Ctrl+Shift+Enter` | 結果清單 | 以系統管理員權限啟動選取的程式或檔案。 |
| `Escape` | 快速視窗 | 隱藏視窗。這一次按鍵絕不會清空搜尋框，搜尋詞是留下還是清除，改由**關閉後保留搜尋框內容**決定。 |
| `Escape` | 主視窗 | 清空搜尋詞並讓搜尋框重新取得焦點；搜尋框已為空時則關閉視窗，而若**關閉後保留搜尋框內容**已開啟就會直接關閉視窗（所以你不必無謂地按第二次）。 |
| `Escape` | 內嵌卡片 | 詳見上文**內嵌視窗的呼出與焦點交接**：對話方塊持有鍵盤時它會關閉卡片，卡片持有鍵盤時則交還焦點。 |
| `Escape` | 動作功能表 | 一次按一層：先清空動作篩選詞，接著退出子功能表，最後離開動作功能表並還原原本的搜尋詞。 |
| `Backspace` | 動作功能表 | 當搜尋過濾詞已為空時，按下直接退出動作功能表返回結果清單。 |
| `←` / `→` 方向鍵 | 動作功能表 | 左箭頭返回上一級功能表，右箭頭進入子功能表。`Tab` 同樣能進入子功能表，除非你已把它綁定為選取上一項/下一項的快速鍵。 |
| `Tab` | 內嵌卡片 | 會被吸收，使焦點無法離開搜尋框；而對話方塊內部的 `Tab` 仍照常遍歷它自己的控制項。 |
| `Tab` | 動作功能表 | 進入反白的子功能表——除非你已把 `Tab` 綁定為選取上一項/下一項的快速鍵，此時該綁定優先。 |
| `Apps` / `Shift+F10` | 主視窗 | 為目前選取的項目開啟動作功能表，效果與按一下滑鼠右鍵完全相同。 |
| `Alt+Space` | 所有 Lertaro 視窗 | 強制遮蔽系統標題列功能表，防止誤觸快顯視窗。 |
| `Alt+F4` | 主視窗 / 設定視窗 | 關閉目前視窗。在快速視窗、內嵌視窗、快速面板、預覽浮動視窗、LocalSend 視窗以及程式內對話方塊上會被遮蔽（防止誤關閉常駐服務）。 |

## 5. 外掛模組動作快速鍵與處理程序黑名單

### 外掛模組獨立動作快速鍵

內建檔案動作的預設快速鍵為：剪下 `Ctrl+X`、複製檔案 `Ctrl+C`、貼上 `Ctrl+V`、刪除 `Delete`、徹底刪除 `Shift+Delete`、複製路徑 `Ctrl+Shift+C`、複製名稱 `Shift+C`、在檔案總管中定位 `Ctrl+Enter`、以系統管理員身分執行 `Ctrl+Shift+Enter`。

兩個防護讓具破壞性的按鍵在搜尋框底下依然安全。組合鍵只在搜尋框**沒有反白文字**時才會觸發動作，因此 `Ctrl+X` / `Ctrl+C` / `Ctrl+V` 照舊剪下、複製與貼上你的搜尋詞。像 `Delete` 這樣的單獨按鍵，只在游標**已位於搜尋詞末尾**、沒有字元剩下來給它刪除時才會觸發動作；游標在文字中間時它仍然是打字按鍵。而兩個刪除動作都經過 Shell 自己的 `IFileOperation`，所以在按鍵與檔案之間仍會先出現原生的「是否移入資源回收筒？」／「是否永久刪除？」確認。要重新綁定或清除其中任何一個，請到**設定 → 快速鍵 → 外掛模組動作**。

### 處理程序黑名單與全螢幕自動放行

- **全螢幕應用程式自動放行**：當偵測到前景有獨占全螢幕執行的應用程式（如全螢幕 3D 遊戲、全螢幕影片播放器）時，Lertaro 預設會自動放行所有全域快速鍵，絕不搶佔遊戲控制。
- **自訂處理程序黑名單**：在[**設定 → 快速鍵頁面**](./settings/hotkeys-page#_3-處理程序黑名單-process-blacklist)中新增特定處理程序名稱（如 `game.exe`），當該程式處於前景時，全域快速鍵與滑鼠快速導覽將完全無訊息放行。
