# 動作功能表與即時預覽

Lertaro 既能定位檔案，也集成了快顯操作體系與即時預覽面板，讓你無需頻繁開啟檔案總管即可完成檔案的檢視、管理與分發。

## 1. 動作功能表詳解

在快速視窗中，於反白的結果項目上按下 `Ctrl+O` 或 `→`，即可展開該項目的快顯動作功能表；只有在游標已停在搜尋詞最末端時 `→` 才會生效，因此你在修改文字前半段時它絕不會搶走游標移動。相同的按鍵在內嵌卡片上也一樣有效，但限於檔案對話方塊**之外**；停靠在開啟/儲存/瀏覽對話方塊內的卡片完全沒有動作功能表。在完整搜尋視窗中這兩個按鍵都沒有綁定：請在結果上按一下滑鼠右鍵，或按 `Apps`（`Shift+F10`），同樣能在那裡開啟動作功能表。

並非每個項目都有功能表。**顯示更多**列、外掛模組提供的結果、網址型我的最愛、沒有任何提供者認領的即時結果、快速視窗之外的應用程式，以及所有檔案對話方塊，都不提供動作功能表；在這種列上按功能表按鍵不會有任何反應，而不會開出一個空白面板。

### 內建核心動作速查

| 動作名稱 | 預設快速鍵 | 功能說明 |
| :--- | :--- | :--- |
| **開啟** | `Enter` | 使用系統預設關聯程式開啟選取的檔案或啟動應用程式。在完整搜尋視窗中，`Enter` 會作用於**所有**選取列；按兩下則只開啟你按兩下的那一列。 |
| **在檔案總管中定位** | `Ctrl+Enter` | 開啟檔案所在目錄，並在檔案總管中直接選取該檔案。 |
| **以系統管理員身分執行** | `Ctrl+Shift+Enter` | 以系統管理員權限啟動選取的程式（支援可執行檔案、捷徑、批次處理指令碼等）。 |
| **複製完整路徑** | `Ctrl+Shift+C` | 將檔案的絕對路徑（如 `D:\Projects\app.exe`）複製到剪貼簿。 |
| **複製名稱** | `Shift+C` | 將選取的檔案或資料夾名稱複製到剪貼簿，不含路徑。 |
| **複製檔案** | `Ctrl+C` | 將檔案本身放入剪貼簿，可直接在檔案總管或其他目錄中貼上。 |
| **剪下 / 複製檔案** | `Ctrl+X` / `Ctrl+C` | 將檔案本身放入剪貼簿，可直接在檔案總管或其他目錄中貼上。搜尋框內有反白文字時，它們仍是文字指令。 |
| **貼上到此處** | `Ctrl+V` | 反白的項目是資料夾時，直接把剪貼簿中的檔案貼進該目錄；反白的項目是檔案時，則貼入其上層資料夾。它需要剪貼簿上有真正的檔案清單，因此把文字貼進搜尋詞並不受影響。 |
| **刪除（移入資源回收筒）** | `Delete` | 將選取的檔案或資料夾安全移至 Windows 資源回收筒。只有在游標已位於搜尋詞末尾時，這個單獨按鍵才會觸發動作，隨後仍會出現原生的資源回收筒確認。 |
| **徹底刪除** | `Shift+Delete` | 永久刪除選取的項目（快顯原生的「是否永久刪除？」確認；過了那一步就無法還原）。 |
| **重新命名** | — | 透過 Windows Shell 重新命名單一已存在的檔案或資料夾，對話方塊會預先選取名稱主體。 |
| **開啟 Windows 右鍵功能表** | — | 展開原生的 Windows 檔案總管完整操作功能表（包含第三方軟體擴充和傳送到子功能表）。 |

### 動作功能表互動與即時篩選

- **即輸即篩選**：展開動作功能表後，直接打字即可按動作名稱快速篩選（例如輸入 `copy` 即刻定位到所有複製相關操作）。篩選框會接管鍵盤，因此移開選取時絕不會動到你原本的搜尋詞。
- **助記字母**：每個動作都可能顯示一個反白字母。按下該字母會**立刻執行該動作**而不只是讓它反白，且只在篩選框仍然為空時成立，所以你為了篩選而輸入的第一個字母絕不會被搶走。
- **獨立搜尋框**：動作功能表擁有獨立且開啟後自動取得焦點的搜尋框，篩選動作不會改變主搜尋詞。切換功能表層級時會清空動作篩選詞，並讓新層級的搜尋框取得焦點。
- **浮動動作面板**：快速視窗、快速啟動面板和完整搜尋視窗中的動作都會以懸浮面板顯示，並錨定在目前項目附近。快速啟動面板會暫時擴展到動作清單的完整工作高度，關閉動作功能表後恢復緊湊高度。
- **層級導覽**：在帶有子功能表的項目（如「傳送到」或階層式動作）上按下 `→`、`Tab` 或 `Enter` 進入下一級；按 `←` 或在過濾詞為空時按 `Backspace` 返回上一級。在巢狀功能表中按 `Escape` 或按一下滑鼠右鍵會返回上一級；在根層級則關閉動作功能表。
- **導覽快速鍵依然有效**：你設定的「選取下一項 / 選取上一項」快速鍵（預設 `Ctrl+N` / `Ctrl+P`）在動作清單內同樣會移動反白，會越過首尾循環，並跳過分隔線、標題與停用的動作。只有在你沒有把 `Tab` 綁到其中一個導覽快速鍵時，`Tab` 才會用來進入子功能表。
- **點擊空白處關閉**：點擊浮動動作面板以外的區域會關閉面板。主機支援時，在動作面板開啟期間按一下其他結果的滑鼠右鍵會就地替換目前動作目標。
- **動作快速鍵**：動作面板取得焦點後即可使用提供者定義的動作快速鍵。執行後會關閉浮動面板，但完整搜尋視窗或快速啟動面板仍保持開啟。

## 2. 完整搜尋視窗的結果清單互動

主搜尋視窗（`Ctrl+F`）專為海量檔案管理與多維度瀏覽設計：

- **按兩下路徑欄定位**：按兩下結果清單中的**檔案名稱**為直接開啟檔案；按兩下**路徑**欄則會自動開啟該檔案所在的父級資料夾。此處的按兩下只指*左*鍵；在欄標題上按兩下不會有任何作用，最大化／還原來自按兩下視窗頂部的非輸入拖曳帶。
- **多選**：結果表格就是一般 Windows 清單：`Ctrl`+按一下會加入或移除該列，`Shift`+按一下會取一段範圍；接著按 `Enter` 會一次作用於**全部**選取列，而按兩下只會開啟你按兩下的那一列。在已屬於選取範圍的列上按右鍵會保留整個選取，而不會收合到該列。
- **無限串流式結果載入**：在搜尋大容量磁碟或數百萬項目時，結果會隨背景索引引擎的檢索即時串流式呈現在清單中，無需等待全盤掃描完畢即可隨時點擊或選取操作；追加新列時會保留你的選取與捲動位置，而真正全新的結果清單會從最上方重新開始。
- **鍵盤循環導覽**：在結果第一行按 `↑` 可直接跳轉到末尾行，在最後一行按 `↓` 可回到首行。快速視窗與內嵌卡片也適用相同的循環規則，尚未選取任何項目時按 `↑` 會落到最後一列，按 `↓` 則落在第一列。只有快速面板會把各群組當成一個連續清單巡覽，且**不**循環。
- **水平捲動**：在表格上按住 `Shift` 並轉動滑鼠滾輪，每格滾動三個欄位，這就是在窄視窗下取用右側欄位的方法。
- **拖曳檔案外出**：任何一列都能直接拖進檔案總管、對話方塊或聊天視窗，成為真正的檔案拖放；多列選取時，拖曳其中一列會把它**全部**帶出去。在 Lertaro 之外放下會隱藏視窗，而拖曳進行中會延後關閉，避免拖曳游標卡住。
- **選取數量摘要**：選取多個結果時，狀態列會在結果總數旁顯示目前選取的項目數量。
- **游標懸停預覽**：滑鼠移過某列時，已開啟的預覽面板會在**不**改變選取的情況下改指向該列，讓你能逐列翻看，再回到選定的那一列按 `Enter`。
- **視窗無邊框拖曳與尺寸記憶**：主視窗頂部非輸入區域可作為拖曳抓取條，滑鼠游標懸停時會有提示條淡入；手動調整的視窗寬高會自動記憶並在下次啟動時沿用。

## 3. QuickLook 即時預覽機制

在可預覽的結果上按下 `Alt+P`，即可在搜尋視窗旁呼出停靠的即時預覽面板；或**在該列上按一下滑鼠中鍵**切換同一個面板。整個內嵌視窗都沒有這兩種手勢，快速面板則兩者都支援。

### 預覽面板不接受鍵盤輸入

該面板刻意設計成不會取得焦點：它絕不會從搜尋視窗搶走焦點，所以沒有可供輸入的地方，按 `Escape` 也不會關閉它。請用 `Alt+P` 切換，或關閉它所停靠的視窗來隱藏它。面板上的所有控制項——媒體播放列、捲軸、外掛模組卡片——一律只能用滑鼠操作，鍵盤焦點會完全留在原本的位置。

### 多格式預覽支援

- **圖片**：支援 JPG、PNG、GIF、BMP、ICO 影像格式的縮放呈現。
- **文件與文字代碼**：支援 TXT、Markdown、JSON、XML、YAML、C#、Python、JS、HTML 等代碼與文字的等寬純文字呈現（不含語法高亮）。
- **音訊/影片即時播放**：影片檔（MP4、M4V、WMV、AVI、MOV、MPG/MPEG）與音訊檔（MP3、WAV、WMA、M4A、AAC）在預覽面板開啟時會**自動開始播放**，並配備自適應主題的迷你控制條（播放/暫停、拖曳進度、即時長度、靜音控制），切換選取項目時立即停止。
- **資料夾結構透視**：選取資料夾時，預覽面板會自動列出其前 30 個直接子項目並顯示檔案圖示與大小，自動過濾系統和隱藏檔案。

### 細節設計與避讓機制

- **尺寸與邊界自適應**：預覽視窗的尺寸可在[**設定 → 一般 → 預覽視窗**](./settings/general#_4-預覽視窗-preview-window)中自訂，系統會自動確保預覽視窗不會超出目前顯示器的可視工作區。
- **停靠側邊**：面板停靠在其搜尋視窗的**右側**，只有右側放不下時才翻到左側，它不會主動改追較寬敞的一邊，所以在捲動寬視窗時會安分地留在原位。而後它會跟著宿主視窗一起移動或縮放。
- **縮放記憶只維持本次**：只要預覽還在用，拖曳縮放手柄或移動面板的位置都會被記住；但搜尋視窗下次隱藏或關閉後，面板就會回到設定的尺寸與停靠側邊。
- **原生彈窗自動避讓**：當預覽 Office 加密文件彈出輸入密碼對話方塊時，Lertaro 會自動臨時隱藏快速視窗與預覽面板，待密碼輸入完成或彈窗關閉後自動還原。
- **預覽視窗拖曳源**：預覽面板頂部可作為拖曳源，直接將正在預覽的檔案拖入編輯器、瀏覽器或外部通訊軟體中。面板底部的狀態列則用於拖曳面板本身。

## 4. 外掛模組互動式與富文字預覽

QuickLook 除了本機檔案預覽，還開放了外掛模組互動擴充能力：

- **自適應深淺色富文字**：基於 WebView2 與原生元件轉譯，自動適配系統的深色/淺色主題，並注入高對比字型與半透明細捲軸。
- **豐富的外掛模組卡片**：支援詞典釋義卡片、即時天氣、網頁即時快照、API 偵錯資訊等複雜互動式面板。

## 5. 第三方獨立 QuickLook 橋接（可選）

如果你已在系統中安裝了獨立的第三方開放原始碼工具 **QuickLook**（[GitHub 上的 QL-Win/QuickLook](https://github.com/QL-Win/QuickLook)），可以在[**設定 → 外掛模組**](./settings/plugins)中啟用內建的 **QuickLook 橋接** 外掛模組。

- **接管預覽**：該外掛模組會透過本機具名管道連接獨立的 QuickLook 處理程序，並將外部預覽視窗自動吸附在 Lertaro 旁。
- **自動回退**：若第三方 QuickLook 處理程序未執行或已關閉，Lertaro 會回退至內建的原生預覽面板。

## 6. 解除檔案佔用

官方的**檔案佔用解除**外掛模組為已存在的檔案提供單選動作。它會列出目前正在使用該檔案的處理程序、PID 和可執行檔路徑，並要求這些處理程序釋放檔案。選取資料夾、檔案不存在或同時選取多個項目時，該動作不可用；未偵測到佔用處理程序時，要求釋放按鈕也會停用。視窗使用主機佈景主題，並在對話方塊模式下保持在搜尋視窗上方且不出現在 Alt+Tab 切換清單中，同時提供重新整理功能。

## 7. 加入我的最愛

CoreExtensions 提供**加入我的最愛**動作，適用於單一已存在的檔案或資料夾。該動作會開啟佈景主題化對話方塊讓你填寫顯示名稱；如果相同路徑已經是收藏項目，動作會隱藏。

## 8. 重新命名

CoreExtensions 提供**重新命名**動作，適用於單一已存在的檔案或資料夾。佈景主題化對話方塊會顯示完整的目前名稱並預先選取名稱主體：例如 `report.pdf` 只選取 `report`，資料夾和沒有副檔名的名稱會全選。按 `Enter` 確認，按 `Esc` 取消。確認後由 Windows Shell 執行實際重新命名。
