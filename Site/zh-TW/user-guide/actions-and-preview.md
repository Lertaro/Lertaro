# 動作功能表與預覽

## 動作功能表

每個結果——檔案、資料夾或應用程式——除了"直接開啟"之外還有一整套動作：在檔案總管中定位、複製路徑、以系統管理員身分執行、剪下/複製/貼上檔案本身、刪除(移至資源回收筒)或永久刪除，以及外掛程式新增的任何動作(例如完整的 Windows 快顯功能表，包含串聯子功能表)。

使用**開啟動作功能表**快速鍵(預設 `Ctrl+O`)或在選取的結果上按方向鍵向右即可開啟。功能表內：

- **上/下一個項目**——方向鍵，或您自行設定的[上/下一個項目快速鍵](./hotkeys)，都可以移動醒目提示。即使自訂繫結為單獨的 `Tab` 鍵，在此處的表現也會與主要結果清單完全一致。
- 在包含子功能表的項目(例如"傳送到"這類串聯功能表)上按**向右方向鍵/Enter**會進入子功能表；**向左方向鍵**或(搜尋方塊為空時的)**Backspace** 會返回上一層。
- **Escape** 退出動作功能表；如果之前輸入過文字用來篩選動作清單，會先清除搜尋方塊。
- 輸入文字可以依照名稱篩選目前可見的動作，與篩選搜尋結果的方式相同。

## 完整視窗的結果清單

按兩下結果通常就是開啟它，與按 Enter 相同——只有一個例外：按兩下**路徑**欄位會改為開啟該結果所在的資料夾，效果與在該列其他位置按 `Ctrl`+Enter 相同。外掛程式自己的自訂欄位也可以為自己定義相同的按兩下行為。

結果清單會保留每一筆相符項目，而不是截斷為固定的頁面；而且它會隨著結果陸續送達逐步填入，無需等待搜尋結束才一次顯示——在大容量磁碟機上，廣泛的查詢可能需要執行數秒，而在此期間各列始終可用。方向鍵導覽會在兩端循環：在第一列按 ↑ 會跳至最後一列，在最後一列按 ↓ 會回到第一列。

此視窗沒有標題列，其頂部區域即為拖曳區：按住其中任何不是搜尋方塊、也不是視窗按鈕的位置拖曳，即可移動視窗。游標位於頂部區域時，頂端會淡入顯示提示條，指示可抓取的位置。

## QuickLook 預覽

在選取的結果上按 **QuickLook** 快速鍵(預設 `Alt+P`)會開啟停靠在搜尋視窗旁的預覽面板——圖片、文件等可預覽的檔案類型無需離開 Lertaro 即可檢視。再按一次(或切換至 QuickLook 無法預覽的結果)即可關閉。

資料夾預覽最多列出 30 個直接子項目，並顯示對應的檔案或資料夾圖示。即使 Windows 檔案總管已設定為顯示隱藏項目，預覽中仍會排除隱藏項目與系統項目。

音訊與視訊檔案——只要是 WPF 內建播放功能無需額外轉碼器即可支援的格式(MP4、WMV、AVI、MOV、MP3、WAV、WMA 等)——一開啟預覽就會自動播放，並提供隨佈景主題變化的小型播放控制列(播放/暫停、進度拖曳、目前/總時長、靜音)，而不是顯示靜態縮圖。切換至其他結果或關閉預覽會立即停止播放。如果特定檔案的轉碼器無法解碼，則會退回顯示靜態縮圖。

預覽視窗的大小固定且可由使用者設定——請參閱[設定 → 一般 → 預覽視窗](./settings/general#預覽視窗)——不會隨目前顯示的結果數量而改變。無論設定多大，Lertaro 都會自動確保預覽視窗完整顯示在螢幕範圍內：如果設定的大小在目前螢幕上無法與搜尋視窗並排顯示，會自動靠齊有空間的一側；如果設定的大小本身大於螢幕可用區域，視窗將縮小以完整容納，而不會超出螢幕邊緣。

如果正在預覽的檔案需要其原生的處理常式顯示快顯對話方塊——最常見的是 Word 或 Excel 要求輸入加密文件的密碼——快速視窗與預覽面板在此快顯視窗開啟期間會自動隱藏，否則它們會遮擋在前方導致無法點選。這並非 Lertaro 當機或關閉：處理該快顯視窗(輸入密碼、關閉它等操作)之後，兩個視窗將完全恢復原狀，搜尋文字與選取狀態皆會保留。

預覽視窗的頂部標題本身即可作為被預覽檔案的拖曳來源——將其拖曳至檔案總管、編輯器或任何放置目標，效果與從搜尋視窗拖曳結果列完全相同。

### 外掛程式與互動式預覽

除了本機檔案和資料夾之外，QuickLook 還支援外掛程式提供的自訂互動式預覽面板（例如 Flow Launcher 外掛程式中的 MDict 詞典釋義、天氣卡片、API 調試資訊或網頁預覽）。

當選中帶有即時預覽能力的外掛程式搜尋結果時，QuickLook 會自動展開預覽面板，並在你切換選中項時平滑重新整理內容，不會重複觸發彈出或滑入動畫。對於基於 WebView2/HTML 的多格式文字預覽，Lertaro 會自動注入深淺色自適應佈景主題樣式、清晰的高對比度字型（Segoe UI / 微軟正黑體）及精緻的半透明細捲軸。

從快速視窗開啟完整視窗時，會保留預覽視窗的開啟狀態，因此原本開啟的預覽將保持開啟。

### 透過 QuickLook 進行外部預覽 (選用)

雖然名稱相同，但這與上述內建的預覽面板不同：此處指的是獨立的第三方應用程式，同樣名為 **QuickLook** ([GitHub 上的 QL-Win/QuickLook](https://github.com/QL-Win/QuickLook)，採 GPL 授權)，需由您自行安裝——Lertaro 並未隨附此程式。

若已安裝且正在執行，隨附的 (實驗性) **QuickLook 橋接**外掛程式——與其他外掛程式相同，可在[設定 → 外掛程式](./settings/plugins)中檢視與切換——會透過其專屬的具名管道與其連線，並接管上述所有內建預覽類型的運作，且優先權高於所有內建類型。在此期間，Lertaro 自身的預覽面板會隱藏，QuickLook 獨立的浮動視窗將移至預覽面板原先所佔據的位置——視覺上呈現為"預覽面板變成了 QuickLook"，但在技術上 QuickLook 的視窗始終為獨立的頂層視窗，僅由 Lertaro 移動以隨同跟隨。

動作功能表中包含**在 QuickLook 中預覽**項目，即使內建預覽類型原本優先，亦可使用此項目手動將結果傳送至 QuickLook 檢視。

由於此功能完全依賴 QuickLook 專屬且未公開文件的內部跨處理程序通訊協定，而非公開發佈的整合 API，未來 QuickLook 的版本更新可能會變更該協定並導致功能失效。解除安裝或關閉 QuickLook 不會影響其他功能——Lertaro 會直接回復使用自身的內建預覽類型。
