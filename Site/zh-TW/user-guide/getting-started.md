# 快速上手

## 安裝

在首頁的[下載按鈕](../)取得最新版本——每次發布都會提供兩種形式：

- **安裝程式**（`Lertaro-Setup.exe`）—— 建議使用。會註冊背景索引服務，也可以設定為隨 Windows 啟動。
- **可攜版**（`Lertaro-Portable.zip`）—— 解壓縮即可執行，無需安裝。之後仍然可以在 **設定 → 執行狀態** 裡手動安裝背景服務。如果電腦上還沒有 Lertaro 需要的 .NET 桌面執行階段，執行一次自帶的 `install-dotnet-runtime.bat` 即可——安裝程式會自動處理這一步，但可攜版做不到。可攜版用完不再需要時，沒有解除安裝程式幫你清理：刪除資料夾前，按兩下自帶的 `portable-cleanup-registry.reg`（確認彈出視窗提示）即可移除 Lertaro 自己建立的兩項每使用者登錄檔項目——`lertaro://` URI 通訊協定註冊，以及「開機自動啟動」這一項。兩者都只在 HKCU（目前使用者）範圍內，不需要系統管理員權限。

這兩種形式都分別提供 **x64** 和 **ARM64** 版本。上面這些是 x64 版本，在絕大多數電腦上都能執行——包括 Windows on ARM 裝置，只是以模擬方式執行。如果用的是 ARM 裝置，建議改用 `Lertaro-Setup-arm64.exe` 或 `Lertaro-Portable-arm64.zip`，它們是原生版本。自動更新會一直維持在你安裝時的架構上，所以要換成另一種，需要自己去下載。

## 可攜版資料

可攜版會在程式旁將機器資料儲存到 `Data\Machine`，並把每位使用者的私有資料儲存到 `Data\Users\<SID hash>`。如果其 `Data` 目錄尚未建立，為了相容會重複使用已有的 `%ProgramData%\Lertaro` 和 `%LocalAppData%\Lertaro` 資料；建立 `Data` 後，該可攜版將優先使用自己的資料並成為自包含副本。

首次執行時，Lertaro 會安裝並啟動一個 Windows 服務（`Lertaro.Service`），專門負責檔案索引。這個拆分是有意為之的——如果好奇原因可以參考[架構設計](../dev-guide/architecture)——但作為一般使用者，只需要知道：**設定 → 執行狀態** 頁面會告訴你服務是否已安裝、是否在執行，如果還沒安裝，也可以在這裡安裝。

## 三種視窗

Lertaro 不是只有一個搜尋視窗——它會根據使用情境自動調整：

- **主視窗** —— 從工作列/開始功能表捷徑開啟的完整視窗，結果清單最大，還帶有窗內動作面板。
- **快速視窗** —— 按下全域叫出熱鍵（預設按兩下 `Ctrl`）召喚出來的精簡型置頂彈出視窗，專為「按熱鍵 → 輸入 → Enter」這套肌肉記憶設計。
- **內嵌視窗** —— 直接把 Lertaro 的搜尋框嵌入到受支援的原生檔案對話方塊或檔案總管視窗裡，不用離開目前對話方塊就能搜尋。

三種視窗共用同一套搜尋引擎、熱鍵系統和動作選單——差別只在於它們出現的位置和形態。

## 基本搜尋

最近檔案、我的最愛和歷史記錄不用輸入任何東西就能拿到——它們是[快速面板](./settings/quick-panel)裡的標籤，而這個面板是疊在目前前景視窗上開啟的，並不在搜尋視窗裡面。

直接開始打字即可。結果會隨輸入即時更新，並按相關度排序（比對與排序的原理見[搜尋語法](./search-syntax)）。用[可設定的上/下一項熱鍵](./hotkeys)（預設是方向鍵）移動選取項，按 Enter 開啟高亮的結果。
