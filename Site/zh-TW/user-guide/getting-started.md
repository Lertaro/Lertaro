# 快速上手

歡迎使用 Lertaro！Lertaro 是一款為 Windows 深度自訂的極速檔案檢索與生產力啟動器。本章將帶你了解安裝方式、核心架構、三種視窗形態以及基本的日常搜尋操作。

## 1. 下載與安裝

你可以在官方網站首頁獲取最新版本。每個正式發佈版本均提供兩種執行形式，並分別編譯了 **x64** 與 **ARM64** 原生版本：

### 安裝包（`Lertaro-Setup.exe`，推薦）

- **自動化設定**：安裝精靈會自動註冊背景索引服務（`Lertaro.Service`），設定開機自啟動項，並自動偵測與安裝所需的 .NET 桌面執行階段。
- **平滑升級**：支援無訊息自動檢查更新與一鍵覆蓋升級。

### 便攜版（`Lertaro-Portable.zip`）

- **解壓即用**：解壓至任意目錄即可直接執行主程式，不強制要求安裝。
- **環境補齊**：若系統尚未安裝對應的 .NET 桌面執行階段，可直接執行解壓目錄自帶的 `install-dotnet-runtime.bat` 指令碼一鍵安裝。
- **資料獨立與隔離**：便攜版預設將機器全域資料儲存在程式同級目錄的 `Data\Machine`，並將各使用者的私人設定儲存在 `Data\Users\<SID hash>`。若該 `Data` 目錄尚未建立，會自動相容讀取系統的 `%ProgramData%\Lertaro` 和 `%LocalAppData%\Lertaro`；一旦目錄生成，便攜版將優先讀取本機獨立資料，實現完全自包含。
- **乾淨解除安裝與清理**：當不再需要使用便攜版時，在刪除資料夾前請先執行自帶的 `portable-cleanup.bat` 指令碼。該指令碼會自動停止並解除安裝背景服務，並清理目前使用者的 `lertaro://` URI 通訊協定及自啟登錄檔項。

> [!TIP]
> 如果你在 Windows on ARM 裝置（如 Surface Pro X、高通 Snapdragon 筆記型電腦）上執行，請優先下載 `Lertaro-Setup-arm64.exe` 或 `Lertaro-Portable-arm64.zip` 原生版本，以獲得最佳效能與更低的功耗。

## 2. 核心架構認知

首次執行 Lertaro 時，系統會安裝並啟動一個獨立的 Windows 背景服務（`Lertaro.Service`）。理解該設計有助於你更好地掌握其運作原理：

- **前景 App（UI 與互動層）**：負責轉譯搜尋視窗、懸浮面板、動作功能表、快速鍵攔截與即時預覽。前景處理程序始終保持極低記憶體佔用與即時回應。
- **背景 Service（索引與資料層）**：以系統服務權限在背景執行，專門負責讀取 NTFS / ReFS 的 USN 記錄檔、監聽其他檔案系統的即時變動、維護網路共用索引，並建立極速記憶體索引樹。
- **架構優勢**：前景介面的重啟、當機或更新絕不會導致背景索引遺失或重新全盤掃描；而背景的即時索引同步也絕不會阻塞前景 UI 的流暢打字體驗。你可以在[**設定 → 執行狀態**](./settings/service-status)中隨時查看服務執行狀態與索引健康度。

## 3. 三種視窗形態

Lertaro 並非只有一個固定的搜尋視窗，而是針對不同工作流程設計了三種各具特色的視窗形態：

| 視窗形態 | 預設喚起方式 | 核心特點與設計定位 | 適用場景 |
| :--- | :--- | :--- | :--- |
| **快速視窗（Quick Window）** | 按兩下 `Ctrl`（可自訂） | 緊湊型螢幕置中浮動視窗，即輸即搜，肌肉記憶友好，支援數字鍵快速跳轉與全鍵盤流操作 | 日常高頻啟動應用程式、尋找特定檔案、快速計算或翻譯 |
| **主視窗（Full Window）** | 工作列/開始功能表，或快速鍵 `Ctrl+F` | 完整的大尺寸視窗，支援海量結果表格檢視、側邊欄進階篩選、欄排序與內建空間分析器 | 深度檔案瀏覽、大範圍檢索、磁碟空間清理與進階篩選 |
| **內嵌視窗（Inline Window）** | 開啟檔案對話方塊或檔案總管時自動嵌入 | 無縫內嵌到系統檔案對話方塊或第三方檔案管理器中，無需離開目前工作上下文 | 在 Office/瀏覽器等軟體中「開啟」或「另存為」檔案時快速定位目標 |

三種視窗形態底層共用完全相同的搜尋引擎、快速鍵體系、篩選規則與動作功能表。

## 4. 首次搜尋與基本互動

### 即輸即搜

開啟搜尋視窗後直接輸入關鍵字即可，結果將隨輸入即時呈現（毫秒級回應）。搜尋演算法預設採用智慧模糊比對，字元無需連續輸入即可跳躍命中。詳細比對規則與修飾符請參閱[**搜尋語法**](./search-syntax)。

### 結果導覽與開啟

- **移動游標**：使用方向鍵 `↑` / `↓`（或設定的導覽快速鍵 `Ctrl+P` / `Ctrl+N`）在結果清單中上下移動選取項目。
- **直接開啟**：按下 `Enter` 立即使用預設程式開啟選取的檔案或啟動應用程式。
- **定位目錄**：按下 `Ctrl+Enter` 可在檔案總管中直接定位並選取該檔案。
- **以系統管理員身分執行**：按下 `Ctrl+Shift+Enter` 以系統管理員權限執行程式。
- **數字直達**：在快速視窗中，可直接按下 `Ctrl` + `1`–`9` 直接開啟前 9 項結果。

### 動作功能表與擴充操作

按下 `Ctrl+O` 或在選取項目上按方向鍵 `→`，即可展開功能強大的**動作功能表**，執行複製路徑、屬性查看、檔案增刪剪貼或呼叫外掛模組擴充動作。更多操作技巧請閱讀[**動作功能表與預覽**](./actions-and-preview)與[**快速鍵**](./hotkeys)。
