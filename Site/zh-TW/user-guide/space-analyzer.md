# 空間分析

空間分析把 Lertaro 既有的檔案索引轉換成類似 SpaceSniffer 的快速視覺化概覽。它不會掃描磁碟，因此即使多個磁碟包含數百萬個項目，也能迅速開啟。

## 開啟空間分析

開啟 Lertaro 完整搜尋視窗並讓搜尋框保持空白，空間分析會自動作為視窗首頁顯示，並呈現 Lertaro 目前已載入的全部索引。輸入查詢會立即切換到搜尋結果，清空查詢則會返回空間分析根層。使用滑鼠左鍵按兩下磁碟或資料夾即可進入；使用向上箭頭或任意麵包屑路徑可返回上層位置。

## 查看和操作

- 左側矩形樹會為較大的項目分配更大的面積，明暗表示大小占比，不同邊框用來區分資料夾和檔案。
- 右側清單顯示同一批項目並依大小降冪排列，每列下方的細條表示它在目前位置可見總大小中的占比；在任意一側選取項目，另一側也會同步醒目顯示。
- 在卡片或清單列上按右鍵，會開啟與搜尋結果相同的動作選單，包括開啟、定位、複製以及適用的外掛動作。
- 在卡片或清單列上按滑鼠中鍵，會以按兩下檔案時的相同行為在已設定的檔案管理員中定位該項目。
- 選取卡片或清單列後，可使用已設定的預覽快速鍵開啟完整視窗的預覽；預覽開啟後會跟隨之後選取的項目。
- 右側清單中無法完整顯示的名稱會在項目被選取或游標停留時捲動，而不再顯示工具提示。

## 統計範圍

這裡只包含 Lertaro 已啟用索引中現有的項目，空間分析不會透過走訪檔案系統來補齊缺少的內容。被排除和未索引的內容不會參與統計；隱藏項目會正常顯示，系統項目不會單獨顯示，但其大小仍可能計入可見上層資料夾的總大小。

介面顯示的是檔案邏輯大小，而非實際占用的磁碟空間。資料夾總大小包含其已索引的後代項目，硬連結資料只會計入一次，因此統計結果可能與 Windows 檔案總管或磁區級磁碟分析工具不同。

空間分析頁面可見時會自動監看相關的記憶體索引變更事件，並合併連續通知後再更新。啟用、停用或刪除本機索引及資料夾索引時，根檢視會立即同步；進入某個目錄後，只有目前目錄或其後代發生變化才會重建檢視，上層變化只會檢查目前路徑是否仍然有效。如果目前目錄或任意上層被重新命名、刪除，或者從已啟用索引中消失，空間分析會自動返回第一個仍可用的上層目錄。它始終不會開啟或重新載入索引快取檔案。開始搜尋後會暫停空間分析更新，關閉完整搜尋視窗時會釋放已呈現的項目和共用介面快取。
