# 支援的檔案管理器與對話方塊整合

Lertaro 不僅是一款獨立的桌面啟動器，更具備深度嵌入各類檔案總管與軟體對話方塊的強大整合能力。透過無縫接管檔案互動，極大提升檔案開啟、儲存與目錄跳轉的效率。

## 1. 三大核心整合能力

根據目標宿主視窗的特性，Lertaro 的整合最多可提供以下三種核心能力：

- **內嵌搜尋（Inline Search）**：Lertaro 的極速搜尋框直接嵌入到目標視窗頂部或對話方塊內部，無需離開目前工作介面即可在目前目錄或全域發起檢索。
- **快速導覽（Quick Navigation）**：在目標視窗空白處按一下滑鼠中鍵（或按兩下左鍵），或按一下內嵌搜尋框的圖示，即可快顯包含目前已開啟資料夾、我的最愛、最近歷程與自訂快捷目錄的階層式功能表。
- **活動路徑偵測（Active Path Detection）**：即時感知宿主視窗目前所處的實體檔案目錄，自動將搜尋範圍智慧限定在目前目錄內，或用於解析相對路徑操作。

## 2. 系統原生元件支援（內建開箱即用）

以下系統原生元件均由 Lertaro 核心引擎直接支援，無需單獨安裝或設定任何外掛模組：

| 宿主視窗類型 | 內嵌搜尋 | 快速導覽觸發方式 | 活動路徑偵測 |
| :--- | :--- | :--- | :--- |
| **Windows 檔案總管** | 支援 | 空白區域按兩下左鍵或按一下滑鼠中鍵 | 支援 |
| **現代開啟/儲存檔案對話方塊** | 支援（直接嵌入對話方塊） | 滑鼠中鍵，或按一下左鍵內嵌搜尋框 Logo 圖示 | — |
| **傳統開啟/儲存檔案對話方塊** | 支援 | 滑鼠中鍵，或按一下左鍵內嵌搜尋框 Logo 圖示 | — |
| **傳統「瀏覽資料夾」對話方塊** | 支援 | 滑鼠中鍵，或按一下左鍵內嵌搜尋框 Logo 圖示 | — |

> [!NOTE]
> 在各類檔案選取對話方塊中，由於 Lertaro 已經直接內嵌在對話方塊內部，因此無需額外的活動路徑偵測；按一下快速導覽中的目標後，對話方塊會直接精準跳轉到該目錄。

## 3. 專業第三方檔案管理器支援（可選外掛模組）

針對進階使用者常用的第三方檔案管理工具，Lertaro 提供了深度對接外掛模組。你可以在[**設定 → 外掛模組**](./settings/plugins)中按需啟用，並在此類外掛模組的**設定**面板中單獨開關內嵌搜尋與快速導覽：

| 檔案管理器 | 內嵌搜尋 | 快速導覽觸發方式 | 活動路徑偵測 | 核心通訊技術與通訊協定 |
| :--- | :--- | :--- | :--- | :--- |
| **Directory Opus** | 支援 | 檔案清單區域按一下滑鼠中鍵 | 支援 | `WM_COPYDATA` 官方遠端控制介面 |
| **Total Commander** | 支援 | 檔案清單區域按一下滑鼠中鍵 | 支援 | `WM_COPYDATA` 官方訊息介面 |
| **XYplorer** | 支援 | 檔案清單區域按一下滑鼠中鍵 | 支援 | 專用處理程序介面通訊 |
| **Files** | 支援 | 檔案清單區域按一下滑鼠中鍵 | 支援 | Windows UI Automation 現代化自動化介面 |
| **One Commander** | 支援 | 檔案清單區域按一下滑鼠中鍵 | 支援 | Windows UI Automation 現代化自動化介面 |

### Directory Opus 專屬深度整合

- **遞迴資料夾大小欄（Lertaro 大小）**：啟用 Directory Opus 外掛模組中的「啟用 Lertaro 大小欄」後，Lertaro 會自動向 Directory Opus 注入自訂指令碼欄。該欄直接從 Lertaro 的記憶體索引讀取資料夾遞迴總容量，**完全無需掃描磁碟**即可秒級呈現整個磁碟所有資料夾的實際體積。
- **持久化設定**：在 Directory Opus 的欄選擇器中新增「Lertaro 大小」欄後，依次按一下**資料夾 → 資料夾格式 → 儲存 → 將格式儲存給所有資料夾**即可全域生效。

### Everything 相容服務 (IPC)

在[**設定 → 一般 → 系統**](./settings/general#系統)中勾選**啟用 Everything 相容服務 (IPC)**後，Lertaro 會在背景模擬標準的 Everything Win32 IPC 介面。Directory Opus、Total Commander、Flow Launcher 等第三方軟體無需額外安裝或執行 Everything，即可直接透過原有的 Everything 外掛模組呼叫 Lertaro 的極速記憶體索引。

## 4. 常用軟體自繪對話方塊支援（專用外掛模組）

許多專業軟體並未使用 Windows 原生對話方塊，而是自繪了特殊視窗。Lertaro 為以下主流軟體的專用對話方塊提供了客製化內嵌支援：

| 軟體名稱與對話方塊類型 | 內嵌搜尋 | 快速導覽觸發方式 | 配接說明 |
| :--- | :--- | :--- | :--- |
| **WPS Office** 開啟/儲存對話方塊 | 支援 | 滑鼠中鍵，或按一下內嵌 Logo 圖示 | 全面覆蓋 WPS 文字、試算表、簡報與 PDF 元件 |
| **WinRAR** 解壓縮對話方塊 | 支援 | 滑鼠中鍵，或按一下內嵌 Logo 圖示 | 解壓縮檔案時快速定位目標解壓縮目錄 |
| **Bandizip** 解壓縮對話方塊 | 支援 | 滑鼠中鍵，或按一下內嵌 Logo 圖示 | 快速指定解壓縮輸出路徑 |
| **Bandizip** 新增檔案對話方塊 | 支援 | 滑鼠中鍵，或按一下內嵌 Logo 圖示 | 壓縮封裝時快速選擇來源檔案 |
| **AutoCAD** 開啟/儲存對話方塊 | 支援 | 滑鼠中鍵，或按一下內嵌 Logo 圖示 | 適配工程圖紙的快速歸檔與呼叫 |

此類外掛模組透過識別視窗底層的控制項結構與控制代碼層級進行掛載，不受軟體多語言介面或不同版本介面微調的影響。
