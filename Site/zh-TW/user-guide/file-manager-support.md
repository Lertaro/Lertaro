# 支援的檔案管理員

Lertaro 不只是能搜尋——它還可以和你正在使用的檔案管理員或對話方塊進行整合。根據目標視窗的不同，整合最多可以提供以下三種能力：

- **內嵌搜尋** —— Lertaro 的搜尋框會直接嵌入目標視窗(也就是[內嵌視窗](./getting-started#三種視窗))，不用離開它就能搜尋。
- **快速導覽** —— 目標視窗會回應[快速導覽的滑鼠觸發方式](./hotkeys#快速導覽-滑鼠)(按兩下/中鍵，或者內嵌視窗自帶的圖示)，彈出一個包含我的最愛、歷史記錄和捷徑資料夾的串接式選單。
- **作用中路徑偵測** —— Lertaro 能識別目標視窗目前開啟的是哪個資料夾，從而把搜尋範圍限定在該資料夾內，並讓複製路徑這類基於相對路徑的動作能正確解析。

並不是每種整合都同時提供這三種能力——具體見下表。

## 內建(無需額外安裝)

以下幾項都隨 Lertaro 的核心擴充外掛一起提供，不需要單獨啟用。

| 目標 | 內嵌搜尋 | 快速導覽 | 作用中路徑偵測 |
|---|---|---|---|
| Windows 檔案總管 | 支援 | 按兩下或中鍵 | 支援 |
| 現代開啟/儲存檔案對話方塊 | 支援(這個對話方塊本身就是內嵌視窗) | 中鍵，或左鍵點擊內嵌視窗自帶的圖示 | —— |
| 傳統開啟/儲存檔案對話方塊 | 支援 | 中鍵，或左鍵點擊內嵌視窗自帶的圖示 | —— |
| 傳統瀏覽資料夾對話方塊 | 支援 | 中鍵，或左鍵點擊內嵌視窗自帶的圖示 | —— |

作用中路徑偵測對這幾個對話方塊本身沒有意義——一旦 Lertaro 已經嵌入對話方塊裡，就不存在另一個「其它視窗」可供它偵測並作為搜尋範圍了。

## 可選外掛(設定 → 外掛)

下面每一項都是獨立的外掛。在[設定 → 外掛](./settings/plugins)裡安裝/啟用，然後在該外掛自己的**設定**對話方塊裡分別開關**啟用內嵌搜尋**和**啟用快速導覽**——兩者預設都是開啟的。

| 目標 | 內嵌搜尋 | 快速導覽 | 作用中路徑偵測 |
|---|---|---|---|
| Directory Opus | 支援 | 在檔案清單區域點擊中鍵 | 支援 |
| Files | 支援 | 在檔案清單區域點擊中鍵 | 支援 |
| One Commander | 支援 | 在檔案清單區域點擊中鍵 | 支援 |
| Total Commander | 支援 | 在檔案清單區域點擊中鍵 | 支援 |
| XYplorer | 支援 | 在檔案清單區域點擊中鍵 | 支援 |

這五款都是透過比對執行中的處理程序來識別目標視窗的(其中 Directory Opus 和 Total Commander 還會透過它們各自公開文件記錄的 `WM_COPYDATA` 遠端控制介面通訊，而不是直接擷取畫面；Files 和 One Commander
沒有提供遠端控制通訊協定，因此改用 UI Automation)。

## 應用程式自帶的對話方塊(可選外掛)

這幾項針對的是第三方應用程式裡的某一個特定對話方塊——而不是整個應用程式，跟上面內建的那幾個對話方塊是同一個思路。在[設定 → 外掛](./settings/plugins)裡安裝/啟用，每個外掛只有一個元件，直接在那裡開關即可(沒有單獨的設定對話方塊，因為也沒有別的東西需要切換)。

| 目標 | 內嵌搜尋 | 快速導覽 | 作用中路徑偵測 |
|---|---|---|---|
| WPS Office 的開啟/儲存對話方塊 | 支援 | 中鍵，或左鍵點擊內嵌視窗自帶的圖示 | —— |
| WinRAR 的解壓縮對話方塊 | 支援 | 中鍵，或左鍵點擊內嵌視窗自帶的圖示 | —— |
| Bandizip 的解壓縮對話方塊 | 支援 | 中鍵，或左鍵點擊內嵌視窗自帶的圖示 | —— |
| Bandizip 的新增檔案對話方塊 | 支援 | 中鍵，或左鍵點擊內嵌視窗自帶的圖示 | —— |

識別靠的是控制項結構而不是視窗標題，所以每款軟體不管裝的是哪種語言包都能正常運作。WPS 那一項涵蓋文字、表格、簡報和 PDF——它們用的是同一個對話方塊；WPS 不使用 Windows 內建的對話方塊，而是自繪了一個，這也正是它需要單獨一個外掛、而大多數程式被上面內建的那幾項涵蓋的原因。跟內建的那幾個一樣，作用中路徑偵測在這裡也沒有意義——Lertaro 已經嵌入對話方塊本身了，不存在另一個「其它視窗」可供它偵測並作為搜尋範圍。
