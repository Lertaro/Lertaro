# 即時答案與關鍵字功能

有些結果會在你打字的同時立刻出現，不需要等檔案搜尋完成——要麼是始終生效的，要麼是需要你先輸入一個簡短的關鍵字、再接你真正想查的內容(這樣像「搜尋瀏覽器歷史記錄」這類分量較重的功能，就不會在你打每一個跟它無關的字元時都來搶注意力)。大多數需要關鍵字的功能，其關鍵字都可以在**設定 → 外掛 → 設定**
裡自行修改。

## 始終生效

這些不需要關鍵字——只要你輸入的內容符合它們的模式，就會立刻觸發。

### 計算機

直接輸入數學運算式，結果會即時顯示出來，按 **Enter** 把結果複製到剪貼簿:

```
12 * (4 + 3)
```

也支援明確的進位轉換:

```
255 to hex
0xFF to dec
```

### 環境變數

- `%NAME%` 展開某個具體的變數(包括像 `%PATH%` 這種多路徑變數，會按路徑逐條拆開列出)。
- `%partial` 模糊列出所有名稱裡包含 `partial` 的變數。

### 執行命令

- `#<命令>` 開啟命令提示字元視窗，**以系統管理員權限**執行 `<命令>`。
- `$<命令>` 開啟命令提示字元視窗，以一般權限執行 `<命令>`。

### 裸網址

直接輸入或貼上一個 `http://`/`https://` 位址，Lertaro 會提示直接開啟它。

## 關鍵字觸發(內建外掛，前綴可設定)

輸入關鍵字、一個空格，然後接你真正的查詢內容。每個關鍵字都有一個預設的簡短前綴，如果它和你常打的內容衝突，也可以在對應外掛自己的**設定**對話方塊裡單獨修改。

| 關鍵字(預設) | 外掛 | 搜尋的內容 |
|---|---|---|
| `ps` | 處理程序管理 | 按名稱、PID 或視窗標題搜尋正在執行的處理程序(也支援模糊/拼音比對)——選中一個即可結束它。 |
| `win` | 視窗切換器 | 目前開啟的、可切換的視窗(和 Alt+Tab 顯示的是同一批)，按標題、處理程序名稱或 PID 搜尋——選中即可切換到該視窗。 |
| `bm` | 瀏覽器資料 | 搜尋你在該外掛設定裡新增的 Chrome/Chromium 系和 Firefox 系瀏覽器設定檔裡的書籤與歷史記錄。 |
| `set` | 核心擴充 | 應用程式內的每一項設定，按名稱模糊比對——選中一項即可直接跳轉到設定裡對應的那一行並高亮。只打 `set` 不加任何內容會列出所有設定。 |
| `flow` | Flow 外掛程式橋接 | 列出所有已載入的 Flow.Launcher 外掛及其觸發詞，選中按 Enter 可直接開啟外掛的設定視窗。 |

視窗切換器預設會把每個視窗實際內容的即時縮圖作為圖示——擷圖在背景進行，不會拖慢輸入速度：先立即顯示程式圖示，縮圖準備好之後再補上。在**設定 → 外掛 → 視窗切換器 → 設定**裡關掉「用視窗內容作為圖示」就能完全跳過這部分擷圖，始終用程式圖示。真正的獨佔全螢幕視窗(大多數遊戲預設用的其實是無邊框視窗化，這種沒問題)擷不到內容，會自動退回程式圖示。

瀏覽器資料外掛的書籤和歷史記錄是各自獨立索引的——**索引書籤**和**索引歷史記錄**是**設定 → 外掛
→ 瀏覽器資料 → 設定**裡兩個獨立的開關，所以你可以只關掉歷史記錄(它通常比書籤多得多)而繼續搜尋書籤，反過來也一樣。

## 網頁搜尋

網頁搜尋外掛自帶了幾個引擎/網站的預設關鍵字——`bd`(百度)、`g`(Google)、`bing`(必應)、`gh`
(GitHub)、`wiki`(維基百科)、`yt`(YouTube)——你也可以在**設定 → 外掛 → 網頁搜尋 → 設定**裡完全自由地新增、編輯或刪除項目，每一條都有自己的名稱、關鍵字、圖示和網址範本。

```
g lertaro github
```

會在瀏覽器裡開啟一次「lertaro github」的 Google 搜尋。

## 翻譯

翻譯外掛的預設觸發關鍵字是`tr`。在它後面輸入文字，就會翻譯成目前 Lertaro 介面所選的語言：

```
tr hello
```

結果會非同步顯示；按**Enter**或點擊即可複製。待翻譯文字會傳送到 Microsoft Translator，因此需要連網；目標語言一律是 App 目前設定的介面語言。可在**設定 → 外掛 → 翻譯 → 設定**中變更觸發關鍵字。

## 檔案篩選器

在**設定 → 外掛 → 檔案篩選器 → 設定**裡，為特定資料夾單獨建立索引規則。每條規則都有自己的
**監控資料夾清單**(遞迴掃描)、一個**符合副檔名**欄位(例如 `*.exe;*.lnk`——支援用 `;` 或 `,`
分隔多個模式，全部都會被比對；預設的 `*` 符合所有檔案)，以及一個可選的**篩選器名稱**，會顯示在結果的描述裡。子資料夾永遠會被納入，不受符合副檔名影響——符合副檔名只篩選檔案。

給規則加上**觸發關鍵字**，可以把它的結果收在一個前綴關鍵字後面(和上面的內建關鍵字一樣)，而不是始終混在一般索引結果裡參與排序。

## 完全自訂(關鍵字你說了算)

### 自訂命令

定義你自己的 `<關鍵字> <參數>` 命令，用來啟動一個外部程式，全部在**設定 → 外掛 → 自訂命令 →
設定**裡設定。命令的參數範本支援位置預留位置(`%s1`、`%s2`……對應每個用空格分隔的參數)，以及一個「剩餘全部內容」預留位置(`%s`，代表關鍵字之後你輸入的所有內容)。

每條命令還有一個**在快速導覽中顯示**核取方塊(預設關閉)——開啟後，這條命令會額外作為一個項目出現在[快速導覽](./hotkeys#快速導覽-滑鼠)選單的根層級，不用打關鍵字也能點開執行。**快速導覽子選單**
欄位可以把它歸到某個具名子選單下，而不是直接放根層級——用 `/` 可以巢狀多層(比如「工具/網路」代表兩層子選單);留空則保持在根層級。以這種方式執行時，命令會按設定好的參數原樣執行，因為這裡沒有打字輸入的參數內容可以代入 `%s1`/`%s`。

---

本頁提到的外掛都不是必需的——每一個都可以在[設定 → 外掛](./settings/plugins)裡單獨停用，如果你不想讓它佔用鍵盤輸入的注意力;而[搜尋語法](./search-syntax)介紹的是另一套始終生效、用於檔案/
資料夾/應用程式搜尋的模糊查詢語言，和本頁內容是兩回事。
