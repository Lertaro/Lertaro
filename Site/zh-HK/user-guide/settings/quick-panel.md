# 快速面板設定

**快速面板（Quick Panel）** 是 Lertaro 專為高頻檔案取用、專案上下文管理與桌面拖曳互動打造的浮動工作區。它會在按下快速鍵時自動停靠在當前前景活動視窗的右下角，讓你無需離開當前工作視窗即可快速瀏覽、拖入或分發常用檔案。

## 1. 核心機制與總開關

- **啟用快速面板**：總開關，關閉後將不再監聽呼出快速鍵。
- **喚起快速鍵**：預設快速鍵為 **`Ctrl+F2`**（可在[**設定 → 快速鍵**](./hotkeys-page)中自訂）。
- **智慧貼靠與尺寸約束**：面板預設尺寸為宿主視窗寬高的各二分之一（最小尺寸限制為 `280 × 200px`，確保內容與篩選框完整可用）。若當前處於 Lertaro 自身視窗時按快速鍵會被安全忽略，防止視窗重疊；面板開啟狀態下再次按下同款快速鍵可一鍵關閉。

## 2. 工作區（Workspaces）

工作區用於按專案或任務組織一組相關的資料夾來源：

- **工作區列表管理**：左側列表呈現已建立的工作區，支援**新建工作區**、**複製工作區**與**刪除工作區**，可透過拖曳左側手柄調整其在面板標籤列中的前後排列順序。
- **工作區屬性**：
  - **名稱**：標籤頁顯示的文字（留空時將自動使用跟隨系統語言的預設名稱）。
  - **啟用開關**：勾選狀態決定是否在面板標籤列中顯示。在面板中按一下標籤上的 **×** 按鈕即是將該工作區臨時隱藏，可在此處重新勾選還原。

選取的工作區可透過右側的兩個子標籤進行精細化設定：**來源**與**應用程式**。

## 3. 來源設定（Sources）

每個來源代表工作區內部的一個獨立內容分組：

- **新增資料夾**：按一下**新增資料夾**按鈕選取實體目錄。
- **顯示模式（Display Mode）**：
  - **最近修改嘅檔案** —— 由記憶體索引毫秒級直接應答，僅展示近期發生變動的檔案（最新排在最前）。
  - **全部內容** —— 呈現全部檔案，可選擇按修改時間降序或按名稱排序（後者適合作為固定檔案的快捷工具列）。
  - **僅資料夾** —— 僅列出資料夾。
  - **僅檔案** —— 僅列出檔案。
- **包含子資料夾**：開啟後將遞迴收錄其所有子目錄下的檔案。
- **接受拖入的檔案**：開啟後，支援直接從外部將檔案、資料夾或瀏覽器圖片拖入該分組，Lertaro 會自動調用 Windows 原生複製介面將檔案複製進該目錄（具備衝突提示與復原支援）。
- **檔案過濾規則**：可使用萬用字元或搜尋語法中的 `@` 篩選器限制該分組展示的檔案類型（例如 `*.mp4;*.mkv`、`*.lnk;:@doc;:@img` 或 `*.lnk;:@doc|img`）。
- **最大條數與時間限制**：可限制最大展示數量（設為 0 表示不限制）及僅展示若干分鐘內改動過的檔案。
- **詳細列表 vs 縮圖平鋪**：支援按分組獨立選擇以列表形式還是縮圖網格平鋪展示（平鋪時自動等比拉伸並保持畫面原始比例）。

## 4. 外掛模組標籤（Plugin Tabs）

除自訂工作區外，外掛模組亦可直接向快速面板註冊全域動態清單。CoreExtensions 核心外掛模組內建了五個實用標籤：

| 外掛模組標籤 | 內容說明 |
| :--- | :--- |
| **我的最愛** | 集中展示你的星標收藏項目，網址點擊後在瀏覽器中開啟。 |
| **搜尋記錄** | 展示你透過 Lertaro 開啟過的最近項目與應用程式。 |
| **Windows 記錄** | 自動解析 Windows 系統級的「最近使用的文件」並列出真實實體檔案。 |
| **上次目錄** | 自動追蹤並遞回你在檔案總管或檔案對話方塊中剛剛離開的目錄。 |
| **最近檔案** | 由後台記憶體索引直接彙總呈現所有設定目錄下的最新變動檔案。 |

可在列表右側獨立控制此外掛模組標籤的顯示狀態以及採用平鋪還是列表檢視。

## 5. 應用程式綁定與獨立黑名單

- **應用程式關聯（Applications）**：可為工作區指定一個或多個前景程序名稱（如 `chrome.exe` 或 `devenv.exe`）。當你在該軟體上呼出快速面板時，面板將自動直達該關聯工作區，免去手動切標籤的麻煩。
- **僅快速面板黑名單**：可在此設定不希望被快速面板打擾的程序名單。該名單會**疊加**在全域快速鍵黑名單之上，專用於處理不希望被面板遮擋但無需全域禁用的特殊程式。

## 6. 面板互動指南

- **即時模糊過濾**：面板右上角內建搜尋過濾框，支援 fzf 模糊比對與拼音別名，輸入即可即時篩選當前工作區。它只篩選**名稱**，絕不會重新排列列表；某個分組的項目全被濾掉時該分組會消失，但它的標籤仍然保留。`Escape` 會先清空篩選詞，只有**第二次**按 `Escape` 才關閉面板。
- **全鍵盤流暢導覽**：使用上下方向鍵可跨越不同分組連續捲動；在反白的項目上按下 `Enter` 鍵即可直接開啟，而面板保持開啟。移動順序**不**會循環：第一個與最後一個可見項目就是硬性終點，空分組會被跳過，而在尚未選取任何項目時 `↑` 與 `↓` 都會落在第一個項目上。平鋪檢視下，四個方向鍵改為依視覺網格移動：`←`/`→` 遵循閱讀順序並跨越行邊界，`↑`/`↓` 則維持在同一欄。
- **標籤快捷切換**：按住 `Ctrl` + `1`–`9` 即可在各個工作區與外掛模組標籤間快速跳轉。
- **QuickLook 預覽與釘住**：選取項目後按 `Alt+P` 可在面板側邊呼出即時預覽；按 `Ctrl+T`（或標題列上的釘住按鈕）可釘住面板使其在失去焦點時不自動消失。
- **焦點落點**：呼出面板時游標會落在篩選框內，且第一項已經選取，因此輸入即可立刻縮小範圍。在該框取得焦點期間，外掛模組動作快速鍵會刻意不介入，在這裡 `Ctrl+A` 與 `Ctrl+C` 的意義是文字編輯，而不是檔案操作。
- **動作飛出選單**：放開滑鼠右鍵（不是按下）時會開啟與主視窗相同的動作飛出選單，並錨定在游標處，因此對尚未選取的行按一下右鍵就會作用於該行。飛出選單接著會接管 `↑ ↓ ← →`、`Enter`、`Space` 與 `Escape`。由於它的按鍵處理常式掛在面板之下，原本會關閉面板的「點到其他處」在飛出選單開啟期間會被忽略。
- **列表行上的滑鼠操作**：按兩下左鍵開啟；按兩下**右**鍵只會重新開啟飛出選單，絕不會啟動項目。按一下中鍵會切換預覽。滑鼠停留在某行就會移動選取。
- **移動面板**：滑鼠游標接近標題列時，頂部會出現一條拖曳區；在那裡拖曳可移動面板，而且面板會在拖曳後繼續存在（這正是從檔案總管拖出檔案時能落進面板的原因）。
- **點到其他處**：面板會在失去焦點後約 200 毫秒隱藏；但當你正在拖曳它、它已釘住、動作飛出選單開啟中，或它所開啟的預覽正持有前景時，都會暫停隱藏，點進它自己的預覽面板並不算點到其他處。
- **選取編輯**：在分組內點擊空白處會一次清空**所有**分組的選取（按住 `Ctrl` 或 `Shift` 時除外）。框選拖曳只在其所屬分組範圍內選取，按住 `Ctrl` 可改為累加；從某一個分組起始的框選不會延伸到另一個分組。
- **拖入檔案**：在 Lertaro **內部開始**的拖曳永遠不會被接受，因此拖到一半的動作不會變成多餘的複製。由於點到其他處會關閉面板，從檔案總管拖入檔案只在面板**已釘住**時才可行。拖放一律為複製，絕不會移動。
- **分組標題**：點擊標題的名稱、路徑或規則行即可摺疊與展開該分組；排序與檢視方式是它旁邊獨立的按鈕。排序、檢視模式與摺疊狀態只在本次工作期間有效，而標籤順序與關閉標籤則會持久保存。
