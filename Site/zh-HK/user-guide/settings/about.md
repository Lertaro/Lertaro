# 關於

顯示 App、Core、Service、CLI 四個組件的版本號(顏色會反映服務當前是否健康)、Lertaro 的簡短說明，以及項目主頁和在線使用手冊的鏈接。

## 配置資料夾

緊接着下方還有兩個鏈接，用來打開 Lertaro 讀寫自身配置的資料夾——鏈接文字本身就是實際路徑，點擊時如果資料夾還不存在會先創建出來:

- **使用者配置資料夾** —— 存放 `user-settings.json` 的每使用者資料夾。每次保存設定時，都會先把當前檔案輪轉備份為 `user-settings.json.bak.1`(舊的備份依次往後順延，最多保留到 `.bak.5`)，再寫入新檔案，所以一次誤改或者保存過程中崩潰，總能找到一份最近的備份恢復。
- **系統配置資料夾** —— 後臺服務使用的共享、機器級資料夾(`machine-settings.json`、索引快取，以及伺服器端日誌)。

## 檢查更新

- **檢查更新** 按鈕 —— 查詢是否有新版本;按鈕文字本身會反映進度("正在檢查更新..."，之後顯示
  "已是最新版本"或找到的新版本號)。
- 如果非系統管理員帳戶無法停止後臺服務來原地安裝更新，會顯示一條警告橫幅，並引導你前往手動下載頁面。
- 一旦發現新版本:
  - **靜默自動更新** —— 後臺下載安裝，顯示進度條，完成後自動重啓 Lertaro。
  - **前往下載頁面** —— 在瀏覽器中打開 GitHub release 頁面，手動安裝。

這個頁面和[通用 → 系統](./general#系統)裏的**啓動時自動檢查更新** / **自動靜默更新**兩個核取方塊是配套的——那兩項控制是否在啓動時自動執行這次檢查;這個頁面則是讓你隨時手動觸發一次。
