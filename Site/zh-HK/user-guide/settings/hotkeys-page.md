# 熱鍵設定

熱鍵設定頁面集中管理 Lertaro 的所有全域呼出按鍵、應用程式內導覽快捷鍵、外掛模組動作快捷方式以及前景程序過濾規則。頁面頂部包含三個標籤頁：**全域**、**外掛模組動作**與**程序黑名單**。

## 1. 全域（Global）

### 全域快捷鍵分組

- **顯示/隱藏快速搜尋**：專屬按鍵錄製框。支援錄製為**單鍵雙擊模式**（預設雙擊 `Ctrl`，亦可設為雙擊 `Alt` 或 `Shift`），或錄製為**常規組合鍵**（如 `Alt+Space`、`Win+Space` 等）。
- **預設開啟完整面板**：核取方塊（預設關閉）。開啟後，全域呼出快捷鍵會改為開啟主視窗，而不是快速視窗。首次呼出時只將視窗置於前景並聚焦一次；視窗已顯示但未啟用時再次按下會重新啟用，視窗已啟用時再次按下則關閉。視窗不會自動保持置頂。
- **全螢幕應用程式聚焦時仍然回應**：核取方塊（預設關閉）。開啟後，即使前景有獨占全螢幕程式（如全螢幕遊戲或影片），Lertaro 依然會回應快捷鍵呼出搜尋框；保持關閉則自動放行按鍵不搶佔焦點。
- **快速跳轉（Quick Jump）**：預設 `Ctrl+G`。在各類檔案對話方塊中按下即可直接跳轉到最近在檔案管理器中瀏覽過的目錄。

### 功能按鍵分組

頁面提供了一系列獨立的按鍵錄製控制項，支援任意單鍵或組合鍵錄製：

- **選取下一項 / 上一項**：預設 `Ctrl+N` / `Ctrl+P`（與方向鍵 `↓` / `↑` 等效）。
- **跳轉結果修飾鍵**：預設 `Ctrl`，配合數字鍵 `1`–`9` 即可在快速視窗中直達前 9 項結果。
- **開啟動作選單**：預設 `Ctrl+O`（與方向鍵 `→` 等效）。
- **從選取項補全搜尋詞**：預設 `Ctrl+Tab`。
- **QuickLook 即時預覽**：預設 `Alt+P`。
- **上/下一條關鍵字歷程**：預設 `Alt+Up` / `Alt+Down`。
- **刪除當前關鍵字歷程**：預設 `Ctrl+Delete`。
- **開啟完整搜尋主視窗**：預設 `Ctrl+F`。
- **開啟傳送視窗（LocalSend）**：預設 `Ctrl+S`。
- **保持視窗不消失（釘住）**：預設 `Ctrl+T`。
- **呼出/關閉快速面板**：預設 `Ctrl+F2`。

### 快速導覽滑鼠觸發分組

- **在空白處按兩下左鍵**：核取方塊（預設開啟）。在桌面或檔案總管空白處按兩下快顯快速導覽選單。
- **在空白處按一下中鍵**：核取方塊（預設開啟）。在桌面、檔案總管或檔案選取對話方塊中按一下滑鼠中鍵快顯快速導覽選單。

## 2. 外掛模組動作（Plugin Actions）

各外掛模組註冊的專屬動作快捷鍵（例如內建的檔案操作：複製路徑 `Ctrl+Shift+C`、剪下 `Ctrl+X`、複製 `Ctrl+C`、貼上 `Ctrl+V`、刪除 `Delete`、徹底刪除 `Shift+Delete` 等）均匯集於此。

- **分組檢視**：按註冊動作的來源外掛模組清晰分組。
- **獨立重錄**：每個動作均配有專屬的按鍵錄製框，按一下即可按下新按鍵進行覆蓋綁定。

## 3. 程序黑名單（Process Blacklist）

用於設定特定前景應用程式的無訊息放行機制。當黑名單中的程式處於系統前景聚焦狀態時，Lertaro 會完全放行所有全域熱鍵與滑鼠觸發手勢，絕不進行攔截。

- **不區分大小寫**：新增 `game.exe` 或 `game` 均可生效。
- **單筆新增**：在單筆輸入框中輸入程序名稱，按一下**新增程序**按鈕。
- **批次管理**：支援按一下**產生文字**將當前黑名單匯出為多行文字，或在多行文字方塊中直接貼上編輯後按一下**套用到列表**進行一鍵批次匯入。
- **檔案對話方塊安全豁免**：即使某個程式處於黑名單中，當它彈出系統檔案選取對話方塊時，Lertaro 的內嵌搜尋與滑鼠快速導覽依然會被安全放行，確保檔案選取效率不受影響。
