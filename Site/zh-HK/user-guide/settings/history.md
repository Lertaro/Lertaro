# 歷史記錄

兩個 Tab，各自獨立:**搜尋記錄**和**關鍵字記錄**。

## 搜尋記錄

記錄你實際打開過的結果，以便下次搜尋類似內容時能優先展示。

- **啓用歷史記錄** 核取方塊 —— 打開/關閉記錄功能;關閉後已有的記錄會保留，只是不再新增。
- **搜尋框** —— 按關鍵詞過濾當前顯示的歷史列表。
- 每條記錄都可以單獨刪除，也可以用**清空全部記錄**一次性清空。

## 關鍵字記錄

記錄你在快速視窗搜尋框裏實際輸入過的原始文字(而不是打開了什麼)，方便用[關鍵字歷史熱鍵](../hotkeys#全局熱鍵)(預設 `Alt+Up` / `Alt+Down`)翻閱最近的查詢。

- 同樣有**啓用歷史記錄**開關、搜尋過濾、單條刪除和**清空全部記錄**按鈕，只是作用對象是關鍵字而不是打開過的結果。
