# 搜尋記錄

搜尋記錄頁面透過三個相互獨立的標籤頁管理使用頻率、輸入詞條與跨名關聯：**搜尋記錄**、**關鍵字記錄**與**查詢關聯**。

## 1. 搜尋記錄（Search History）

搜尋記錄按路徑統計實際開啟過的檔案、資料夾與應用程式的使用頻率和最近時間：

- **同級衰減微調**：高頻使用的項目按 90 天半衰期計算有效分，僅在**同一文字比對等級內**優先排列，絕不會越過完整或更乾淨的直接名稱命中。
- **內嵌視窗智慧分區**：在檔案選取對話方塊的內嵌搜尋中，當前資料夾內項目歸入「當前資料夾」，其餘歸入「全域搜尋」，同層內直接命中始終排在學習關聯之前。
- **失效路徑自動過濾**：被移動或刪除的路徑在檢索時自動跳過，保證列表不重複、無死鏈。
- **管理操作**：支援**啟用記錄功能**總開關、關鍵字過濾、**清除少於等於 N 次的記錄**、單筆刪除、**清空全部記錄**以及即時自動更新。

## 2. 關鍵字記錄（Keyword History）

關鍵字記錄記憶實際執行過結果或動作，或用於開啟完整視窗的**原始查詢字串**。僅輸入關鍵字後關閉快速搜尋視窗不會新增記錄：

- **快速鍵快速翻閱**：在快速搜尋視窗中可使用快速鍵 **`Alt+Up`** / **`Alt+Down`** 翻閱最近搜尋詞，按 **`Ctrl+Delete`** 直接刪除當前詞彙。
- **獨立清理維護**：提供獨立的啟用開關、搜尋過濾、按次數門檻清理、單筆刪除與清空全部功能。

## 3. 查詢關聯（Query Associations）

查詢關聯獨立儲存已確認的 **查詢詞 → 目標路徑** 習慣映射，與路徑使用頻率完全分離：

- **3 次自然開啟門檻**：同一規範化查詢詞下至少**自然開啟 3 次**後，才會在後續輸入時補充召回該目標，避免偶爾誤按一次就長期污染結果。
- **阻斷自強化與尾部補充**：點擊由查詢關聯補充出的項目不會反向自增未確認計數，不召回低優先級快取路徑，且始終排在直接文字命中之後。
- **獨立清理**：可隨時篩選、單筆刪除或清空全部查詢關聯，而不會重設路徑使用頻率。
