# 索引

按順序共五個 Tab：**本地磁碟機**、**網絡磁碟機**、**WSL**（只在檢測到發行版時才出現）、**資料夾**、**排除規則**。

## 本地磁碟機

- 頂部狀態卡片彙總已索引的磁碟機數量與項目數量，並提供**重建索引**按鈕做全量重掃描。
- 每個本地磁碟機一行：**啓用/禁用核取方塊**、磁碟機名稱、檔案系統（NTFS/ReFS 等）、當前狀態、已索引項目數，以及每行獨立的**重建**/**移除**操作——重建進行中時還會出現**停止**操作（真正的 NTFS 走 $MFT 掃描沒有安全的中斷點，是唯一的例外）。
- NTFS 和 ReFS 磁碟通過 Windows USN 日誌持續跟蹤變更；其他本地檔案系統（FAT32、exFAT 等）沒有日誌可讀，改為直接監聽檔案系統變化。不管哪種方式，手動重建都很少需要，但如果發現內容不同步，隨時可以用它——如果重建過程中被中斷（手動停止，或者應用/服務中途重啓），下次會從中斷的地方繼續，而不是從頭再來。

重建期間搜尋照常可用。正在重建的磁碟機會繼續用它先前的索引回應，直到新索引就緒；其餘磁碟機完全不受影響——重建不會讓你面對一個空的結果列表。

## 網絡磁碟機

- 與本地磁碟機相同的狀態卡片和**重建索引**按鈕。
- 每個已映射的網絡磁碟機一行：啓用核取方塊、路徑/名稱、狀態（索引中 / 就緒 / 已快取 / 失敗 / 等待中 / 已連接）、項目數，以及**刷新模式**下拉式方塊：
  - **手動** —— 只在手動觸發（重建索引）時刷新。
  - **每 15 分鐘**
  - **每小時**
  - **每天**

網絡共享沒有本地 NTFS 卷那樣的變更日誌可供監聽，所以採用定時刷新而不是實時更新。掃描引擎內置了分支祖先路徑棧與符號鏈接環路檢測機制，即使 NAS/SMB 共享上存在指向父級目錄的軟鏈接或重解析點，也能自動攔截死循環，確保索引數量準確不膨脹。

## WSL

只有檢測到至少一個 WSL 發行版時才會出現——形態和網絡磁碟機一樣（狀態卡片、**重建索引**按鈕，每個發行版一行，顯示狀態/項目數/**刷新模式**）。發行版是自動檢測的，沒有手動“添加”這一步。

## 資料夾

單獨索引任意資料夾，而不是整個磁碟機或共享——適合只想索引某一個子目錄，而不想把這個盤/共享下的其他內容也納入索引的場景。

- **添加資料夾**按鈕會打開資料夾選擇器；**重建索引**按鈕會重新掃描列表中的所有資料夾。
- 每個已添加的資料夾一行：啓用核取方塊、路徑、狀態、項目數，以及和網絡磁碟機一樣的**刷新模式**下拉式方塊（手動 / 每 15 分鐘 / 每小時 / 每天）——資料夾和網絡共享一樣按計劃掃描，而不是持續實時跟蹤。
- 資料夾選擇器也支援直接選一個 **UNC 網絡共享路徑**（比如 `\\server\share`，或者它裏面的子目錄）——在選擇器裏通過“網絡”瀏覽過去即可，適合只想索引某一個共享或子目錄，而不想把整臺伺服器都加成映射的網絡磁碟機。

## 排除規則

三個子 Tab，形態完全一致：一個單條輸入框 + **添加**按鈕，一個可編輯/刪除每一條規則的列表，以及一個批量多行文字方塊，配 **從列表生成** / **應用到列表** 兩個按鈕，用來一次性編輯全部規則。

- **路徑排除** —— 完整路徑或環境變量（例如 `D:\Cache`、`%ProgramData%`）。
- **Glob 通配符** —— `*`（檔案名中任意字元）、`?`（單個字元）、`**`（遞歸目錄）。示例：`*.tmp`、`**/node_modules/**`、`bin/**`。
- **正則表達式** —— 針對路徑/檔案名做部分匹配的任意正則。示例：`^\.`（隱藏檔案）、`~$`（Office 臨時檔案）、`\.git\`。

排除規則對本地、網絡、資料夾索引都生效，應用排除規則的改動後，網絡磁碟機/資料夾會自動重新掃描。
