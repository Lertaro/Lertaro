# 插件

列出所有已安裝的插件，頁面頭部的徽標顯示當前加載的 Plugin SDK 版本——點擊它可以直接打開[開發手冊](../../dev-guide/)，這個版本號正是為了對照手冊開發插件而準備的。

頁面分成左右兩欄：左邊是已安裝的插件，右邊是選中插件的詳情。兩欄各自獨立捲動，插件列表很長和配置表單很長互不牽扯。

如果沒有安裝任何插件，頁面會顯示一個空狀態提示。

## 插件列表

每個已安裝的插件佔一行，顯示名稱，下方是它的版本號。點擊某一行，右側就會打開該插件。

列表按"有什麼可操作的"排序：先是有自己配置項的插件，其次是有組件可以關閉的，最後是其餘的；每一檔內部按名稱排列。

## 選中的插件

右欄最上方是插件的圖示、名稱和**總體功能簡介**。

再往下，如果插件暴露了自己的配置項(超出簡單啓用/禁用的範疇)，會出現**詳情**和**配置**兩個標籤頁。沒有任何配置項的插件不會顯示標籤欄——整欄就是它的詳情。

### 詳情

該插件註冊的功能組件，按類型分組（搜尋源、動態選單提供者等）。每個可切換的組件都有自己的**啓用/禁用核取方塊**；標記為必要項的組件會顯示一個鎖形圖示，不能關閉。把滑鼠懸停在組件旁邊的 **(!)** 上，可以看到該組件的詳細功能說明。

當某個分組（或整個插件）有 2 個及以上可切換組件時，標題旁會出現一個**全選/全不選**鏈接，點擊即可一次性切換該範圍內的所有核取方塊，不用逐個手動勾選。

### 配置

插件自己的設定項，直接在這裡編輯，不再另開對話方塊。如果插件把設定分成了 2 組及以上，這裡還會有一行屬於它自己的標籤頁，每組一個。

按下**確定**之前，什麼都不會寫入。離開這個標籤頁——切回詳情，或者選擇另一個插件——會把這些欄位回滾到已保存的值，這樣你放棄掉的修改就不會在之後被誤提交。

想看插件配置實際長什麼樣、能改什麼(比如改一個觸發關鍵詞)，可以參考[即時答案與關鍵詞功能](../instant-answers)。

## Flow Launcher 插件生態支援

除了基於 `Lertaro.PluginSdk` 構建的原生 C# 插件之外，Lertaro 還透過內建的 Flow Launcher Bridge 提供了對龐大 Flow Launcher 社區插件生態的原生級兼容支援。

- **支援的插件類型**：兼容 **C# (.NET)**、**Python 3.12**（支援根據 `requirements.txt` 自動在後台安裝 `pip` 依賴）、**Node.js v20 LTS**（支援根據 `package.json` 自動在後台安裝 `npm` 依賴）以及獨立**可執行程式**（`.exe`）編寫的 Flow Launcher 插件。
- **安裝方式**：直接將第三方 Flow Launcher 插件資料夾放入 `<用戶數據目錄>\FlowData\Plugins\`，Lertaro 會自動識別、加載並註冊其搜尋觸發詞與動作。
- **純淨隔離運行環境**：Python（`FlowData\PythonEmbeded-{arch}`）與 Node.js（`FlowData\NodeEmbeded-{arch}`）運行時完全隔離在 Lertaro 的數據目錄中按需自動下載部署，不依賴亦不污染系統的全局環境變數與 PATH。
- **集中管理與獨立開關**：在**設定 → 插件 → Flow Launcher Bridge** 的**配置**標籤頁中，統一列出所有已加載的 Flow 插件子分組；每個插件頂部均設有專屬的**啓用此插件**開關，可單獨開啟或關閉該插件功能。
- **自訂觸發詞與狀態隔離**：支援自訂修改每個 Flow 插件的專屬**觸發詞（ActionKeyword）**，配置與啓用狀態集中存儲於 `FlowData\Settings\Plugins.json`，不會污染插件內部配置，插件更新與重啟後始終保持有效。
- **原生內嵌配置與多語言**：無縫支援基於 YAML/JSON 模板表單（`SettingsTemplate.yaml`/`.json`）及 C# WPF 自訂設定面板（`ISettingProvider`）的插件配置界面，自動融合應用主題並完整支援多語言 i18n 本地化。
- **自訂互動式預覽與 WebView2 排版美化**：支援 Flow Launcher 插件返回的自訂互動式預覽面板（如 MDict 詞典釋義、天氣卡片、API 調試資訊、網頁預覽等），選定結果即可在 QuickLook 預覽面板中免額外按鍵平滑展開並即時切換；對於基於 WebView2/HTML 的富文本預覽，Lertaro 會自動注入深淺色自適應主題樣式、高對比度清晰字體（Segoe UI / 微軟雅黑）及精緻的半透明細捲動條。
- **快捷搜尋與調用**：在搜尋框中輸入 `flow` 全局關鍵詞即可列出已加載的全部 Flow 插件及其觸發詞與運行狀態；直接輸入各插件的觸發詞（如 `md`、`tr` 等）即可即时檢索。
