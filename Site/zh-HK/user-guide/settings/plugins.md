# 插件

列出所有已安裝的插件，頁面頭部的徽標顯示當前加載的 Plugin SDK 版本——點擊它可以直接打開[開發手冊](../../dev-guide/)，這個版本號正是為了對照手冊開發插件而準備的。

頁面分成左右兩欄：左邊是已安裝的插件，右邊是選中插件的詳情。兩欄各自獨立捲動，插件列表很長和配置表單很長互不牽扯。

如果沒有安裝任何插件，頁面會顯示一個空狀態提示。

## 插件列表

每個已安裝的插件佔一行，顯示名稱，下方是它的版本號。點擊某一行，右側就會打開該插件。

列表按"有什麼可操作的"排序：先是有自己配置項的插件，其次是有組件可以關閉的，最後是其餘的；每一檔內部按名稱排列。

## 選中的插件

右欄最上方是插件的圖示、名稱和**總體功能簡介**。

再往下，如果插件暴露了自己的配置項(超出簡單啓用/禁用的範疇)，會出現**詳情**和**配置**兩個標籤頁。沒有任何配置項的插件不會顯示標籤欄——整欄就是它的詳情。

### 詳情

該插件註冊的功能組件，按類型分組（搜尋源、動態選單提供者等）。每個可切換的組件都有自己的**啓用/禁用核取方塊**；標記為必要項的組件會顯示一個鎖形圖示，不能關閉。把滑鼠懸停在組件旁邊的 **(!)** 上，可以看到該組件的詳細功能說明。

當某個分組（或整個插件）有 2 個及以上可切換組件時，標題旁會出現一個**全選/全不選**鏈接，點擊即可一次性切換該範圍內的所有核取方塊，不用逐個手動勾選。

### 配置

插件自己的設定項，直接在這裡編輯，不再另開對話方塊。如果插件把設定分成了 2 組及以上，這裡還會有一行屬於它自己的標籤頁，每組一個。

按下**確定**之前，什麼都不會寫入。離開這個標籤頁——切回詳情，或者選擇另一個插件——會把這些欄位回滾到已保存的值，這樣你放棄掉的修改就不會在之後被誤提交。

想看插件配置實際長什麼樣、能改什麼(比如改一個觸發關鍵詞)，可以參考[即時答案與關鍵詞功能](../instant-answers)。
