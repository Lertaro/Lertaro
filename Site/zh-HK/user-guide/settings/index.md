# 設定中心參考

Lertaro 提供了極其豐富且細緻的個人化設定選項。無論你是想要微調搜尋框的像素級尺寸、定制全域熱鍵、調整不同磁碟的索引頻率，還是管理第三方外掛模組與工作區，都可以在設定中心中完成。

## 1. 視窗特性與即時互動

- **自適應視窗與全鍵盤操作**：設定視窗支援自由拖曳邊框調整寬高、按兩下標題列最大化，並自動記住你調整的尺寸。
- **全域設定模糊搜尋**：設定視窗標題列右上角內建了全域設定搜尋框。搜尋演算法採用與主搜尋相同的 fzf 模糊比對與拼音別名引擎。輸入關鍵字即可跨所有分區（包括外掛模組設定與動態動作）檢索選項，按 Enter 即可瞬間跳轉至目標頁面並閃爍反白該控制項。
- **防溢出標籤列導覽**：在包含多層子標籤頁的分區（如一般、熱鍵、索引等）中，當標籤文字較長時兩端會自動呈現捲動箭頭，確保在任何語言環境下標籤均能完整檢視。

## 2. 設定分區總覽

設定視窗左側導覽列共包含以下十個核心分區：

| 分區模組 | 核心管理內容 |
| :--- | :--- |
| **[運行狀態](./service-status)** | 後台 Windows 服務的運行狀態、健康度監控，以及 Service / App / Hook 三大程序的即時記錄檢視器。 |
| **[索引管理](./index-drives)** | 本機磁碟（NTFS / ReFS / FAT32）、網路共用磁碟機（SMB / NAS）、WSL 子系統發行版、自訂資料夾及三類排除規則。 |
| **[一般設定](./general)** | 開機自啟、硬體加速、IPC 相容服務、搜尋框像素級尺寸佈局、主視窗表格欄排序與預覽視窗參數。 |
| **[熱鍵綁定](./hotkeys-page)** | 全域呼出快捷鍵、功能熱鍵、外掛模組專屬動作快捷鍵，以及前景程序黑名單與全螢幕放行規則。 |
| **[外掛模組管理](./plugins)** | 已安裝外掛模組列表、各元件獨立開關、外掛模組表單設定面板、Flow Launcher 社群外掛模組生態管理，以及外掛模組執行狀態監控。 |
| **[LocalSend 傳輸](./localsend)** | 相容 LocalSend 官方用戶端的區域網路無線傳輸協定設定（裝置名稱、連接埠、PIN 碼與自動儲存）。 |
| **[我的最愛](./favorites)** | 常用資料夾、檔案與網址的星標別名收藏，支援拖曳排序與拼音檢索。 |
| **[搜尋記錄](./history)** | 搜尋結果命中記錄與輸入關鍵字記錄的管理、智慧召回及清理。 |
| **[快速啟動](./quick-launch)** | 管理手動快速啟動項目，並選擇哪些動態資料來源顯示在快速搜尋視窗的空白狀態。 |
| **[快速面板](./quick-panel)** | 停靠在活動視窗旁的浮動工作區、多來源資料夾聚合、檔案拖入接收與外掛模組動態標籤頁。 |
| **[外觀與主題](./appearance)** | 淺色/深色/跟隨系統模式切換，以及自帶與隨包精選主題卡片的即時縮圖預覽。 |
| **[關於與更新](./about)** | 各元件版本號、用戶與機器資料目錄快速直達、資料備份輪轉機制與一鍵無訊息升級。 |

以下各章節將按順序列出每一個設定分區的詳細選項、參數範圍與預設行為。
