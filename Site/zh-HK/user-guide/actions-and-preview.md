# 動作選單與即時預覽

Lertaro 不僅能極速定位檔案，更集成了完善的快顯操作體系與強大的即時預覽面板，讓你無需頻繁開啟檔案總管即可完成檔案的檢視、管理與分發。

## 1. 動作選單詳解

在任意搜尋結果（檔案、資料夾、應用程式或外掛模組項目）上按下 `Ctrl+O` 或按方向鍵 `→`，即可展開該項目的快顯動作選單。

### 內建核心動作速查

| 動作名稱 | 預設快捷鍵 | 功能說明 |
| :--- | :--- | :--- |
| **開啟** | `Enter` | 使用系統預設關聯程式開啟選取的檔案或啟動應用程式。 |
| **在檔案總管中定位** | `Ctrl+Enter` | 開啟檔案所在目錄，並在檔案總管中直接選取該檔案。 |
| **以系統管理員身分執行** | `Ctrl+Shift+Enter` | 以系統管理員權限啟動選取的程式（支援可執行檔案、捷徑、批次處理腳本等）。 |
| **複製完整路徑** | `Ctrl+Shift+C` | 將檔案的絕對路徑（如 `D:\Projects\app.exe`）複製到剪貼簿。 |
| **剪下 / 複製檔案** | `Ctrl+X` / `Ctrl+C` | 將檔案本身放入剪貼簿，可直接在檔案總管或其他目錄中貼上。 |
| **貼上到此處** | `Ctrl+V` | 當選取目標為資料夾時，將剪貼簿中的檔案直接貼上至該目錄下。 |
| **刪除（移入資源回收筒）** | `Delete` | 將選取的檔案或資料夾安全移至 Windows 資源回收筒。 |
| **徹底刪除** | `Shift+Delete` | 永久刪除選取的檔案或資料夾（不可從資源回收筒還原，會快顯二次確認）。 |
| **開啟 Windows 右鍵選單** | — | 展開原生的 Windows 檔案總管完整快顯功能表（包含第三方軟體擴充和傳送到子選單）。 |

### 動作選單互動與即時篩選

- **即輸即篩選**：展開動作選單後，直接打字即可按動作名稱快速篩選（例如輸入 `copy` 即刻定位到所有複製相關操作）。
- **層級導覽**：在帶有子選單的項目（如「傳送到」或階層式動作）上按下 `→` 或 `Enter` 進入下一級；按 `←` 或在過濾詞為空時按 `Backspace` 返回上一級。
- **退出選單**：按下 `Escape` 退出動作選單並返回主搜尋結果列表。

## 2. 完整搜尋視窗的結果列表互動

主搜尋視窗（`Ctrl+F`）專為海量檔案管理與多維度瀏覽設計：

- **按兩下路徑欄定位**：按兩下結果列表中的**檔案名稱**為直接開啟檔案；按兩下**路徑**欄則會自動開啟該檔案所在的父級資料夾。
- **無限串流式結果載入**：在搜尋大容量磁碟或數百萬項目時，結果會隨後台索引引擎的檢索即時串流式呈現在列表中，無需等待全盤掃描完畢即可隨時點擊或選取操作。
- **鍵盤循環導覽**：在結果第一行按 `↑` 可直接跳轉到末尾行，在最後一行按 `↓` 可回到首行。
- **視窗無邊框拖曳與尺寸記憶**：主視窗頂部非輸入區域可作為拖曳抓取條，滑鼠游標懸停時會有提示條淡入；手動調整的視窗寬高會自動記憶並在下次啟動時沿用。

## 3. QuickLook 即時預覽機制

在任意搜尋結果上按下 `Alt+P`，即可在搜尋視窗旁呼出一個功能強大的即時預覽面板，支援豐富的檔案類型：

### 多格式預覽支援

- **圖片與向量圖**：支援 JPG、PNG、GIF（動圖自動播放）、BMP、WebP、ICO、SVG 等常見影像格式的高畫質縮放呈現。
- **文件與文字代碼**：支援 TXT、Markdown、JSON、XML、YAML、C#、Python、JS、HTML 等代碼與文字的高亮排版呈現。
- **音訊/影片即時播放**：MP4、MKV、AVI、MOV、WMV、MP3、WAV、FLAC、WMA 等媒體檔案在預覽面板開啟時會**自動開始播放**，並配備自適應主題的迷你控制條（播放/暫停、拖曳進度、即時長度、靜音控制），切換選取項目時立即停止。
- **資料夾結構透視**：選取資料夾時，預覽面板會自動列出其前 30 個直接子項目並顯示檔案圖示與大小，自動過濾系統和隱藏檔案。

### 細節設計與避讓機制

- **尺寸與邊界自適應**：預覽視窗的尺寸可在[**設定 → 一般 → 預覽視窗**](./settings/general#預覽)中自訂，系統會自動確保預覽視窗不會超出當前顯示器的可視工作區。
- **原生彈窗自動避讓**：當預覽 Office 加密文件彈出輸入密碼對話方塊時，Lertaro 會自動臨時隱藏快速視窗與預覽面板，待密碼輸入完成或彈窗關閉後自動無縫還原。
- **預覽視窗拖曳源**：預覽面板頂部可作為拖曳源，直接將正在預覽的檔案拖入編輯器、瀏覽器或外部通訊軟體中。

## 4. 外掛模組互動式與富文本預覽

QuickLook 不僅支援本機檔案預覽，更開放了強大的外掛模組互動擴充能力：

- **自適應深淺色富文本**：基於現代化 WebView2 與原生元件渲染，自動適配系統的深色/淺色主題，並注入清晰的高對比字型與精緻的半透明細捲軸。
- **豐富的外掛模組卡片**：支援詞典釋義卡片、即時天氣、網頁即時快照、API 偵錯資訊等複雜互動式面板。

## 5. 第三方獨立 QuickLook 橋接（可選）

如果你已在系統中安裝了獨立的第三方開源工具 **QuickLook**（[GitHub 上的 QL-Win/QuickLook](https://github.com/QL-Win/QuickLook)），可以在[**設定 → 外掛模組**](./settings/plugins)中啟用內建的 **QuickLook 橋接** 外掛模組。

- **接管預覽**：該外掛模組會透過本地具名管道連接獨立的 QuickLook 程序，並將外部預覽視窗自動吸附在 Lertaro 旁。
- **無縫回退**：若第三方 QuickLook 程序未運行或已關閉，Lertaro 會自動平滑回退至內建的原生預覽面板，確保預覽體驗始終可用。

## 6. 解除檔案佔用

官方的**檔案佔用解除**外掛模組為已存在的檔案提供單選動作。它會列出目前正在使用該檔案的程序、PID 和可執行檔路徑，並請求這些程序釋放檔案。選取資料夾、檔案不存在或同時選取多個項目時，該動作不可用；未偵測到佔用程序時，請求釋放按鈕也會停用。視窗使用宿主主題，並在對話方塊模式下保持在搜尋視窗上方且不出現在 Alt+Tab 切換清單中，同時提供重新整理功能。

## 7. 加入我的最愛

CoreExtensions 提供**加入我的最愛**動作，適用於單一已存在的檔案或資料夾。該動作會開啟主題化對話方塊讓你填寫顯示名稱；如果相同路徑已經是收藏項目，動作會隱藏。
