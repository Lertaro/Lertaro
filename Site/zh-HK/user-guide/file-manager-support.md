# 支援的檔案管理器

Lertaro 不只是能搜尋——它還可以和你正在使用的檔案管理器或對話方塊進行集成。根據目標視窗的不同，集成最多可以提供以下三種能力：

- **內嵌搜尋** —— Lertaro 的搜尋框會直接嵌入目標視窗(也就是[內嵌視窗](./getting-started#三種視窗))，不用離開它就能搜尋。
- **快速導航** —— 目標視窗會響應[快速導航的滑鼠觸發方式](./hotkeys#快速導航-滑鼠)(雙擊/中鍵，或者內嵌視窗自帶的圖示)，彈出一個包含收藏夾、歷史記錄和快捷資料夾的級聯選單。
- **活動路徑檢測** —— Lertaro 能識別目標視窗當前打開的是哪個資料夾，從而把搜尋範圍限定在該資料夾內，並讓複製路徑這類基於相對路徑的動作能正確解析。

並不是每種集成都同時提供這三種能力——具體見下表。

## 內置(無需額外安裝)

以下幾項都隨 Lertaro 的核心擴展插件一起提供，不需要單獨啓用。

| 目標 | 內嵌搜尋 | 快速導航 | 活動路徑檢測 |
|---|---|---|---|
| Windows 檔案總管 | 支援 | 雙擊或中鍵 | 支援 |
| 現代打開/保存檔案對話方塊 | 支援(這個對話方塊本身就是內嵌視窗) | 中鍵，或左鍵點擊內嵌視窗自帶的圖示 | —— |
| 經典打開/保存檔案對話方塊 | 支援 | 中鍵，或左鍵點擊內嵌視窗自帶的圖示 | —— |
| 經典瀏覽資料夾對話方塊 | 支援 | 中鍵，或左鍵點擊內嵌視窗自帶的圖示 | —— |

活動路徑檢測對這幾個對話方塊本身沒有意義——一旦 Lertaro 已經嵌入對話方塊裏，就不存在另一個"其它視窗"可供它檢測並作為搜尋範圍了。

## 可選插件(設定 → 插件)

下面每一項都是獨立的插件。在[設定 → 插件](./settings/plugins)裏安裝/啓用，然後在該插件自己的**配置**對話方塊裏分別開關**啓用內嵌搜尋**和**啓用快速導航**——兩者預設都是開啓的。

| 目標 | 內嵌搜尋 | 快速導航 | 活動路徑檢測 |
|---|---|---|---|
| Directory Opus | 支援 | 在檔案列表區域點擊中鍵 | 支援 |
| Files | 支援 | 在檔案列表區域點擊中鍵 | 支援 |
| One Commander | 支援 | 在檔案列表區域點擊中鍵 | 支援 |
| Total Commander | 支援 | 在檔案列表區域點擊中鍵 | 支援 |
| XYplorer | 支援 | 在檔案列表區域點擊中鍵 | 支援 |

這五款都是通過匹配運行中的處理程序來識別目標視窗的(其中 Directory Opus 和 Total Commander 還會通過它們各自公開文檔記錄的 `WM_COPYDATA` 遠程控制接口通信，而不是直接抓取介面；Files 和 One Commander
沒有提供遠程控制協議，因此改用 UI Automation)。

## 應用程式自帶的對話方塊(可選插件)

這幾項針對的是第三方應用程式裏的某一個特定對話方塊——而不是整個應用程式，跟上面內置的那幾個對話方塊是同一個思路。在[設定 → 插件](./settings/plugins)裏安裝/啓用，每個插件只有一個組件，直接在那裏開關即可(沒有單獨的配置對話方塊，因為也沒有別的東西需要切換)。

| 目標 | 內嵌搜尋 | 快速導航 | 活動路徑檢測 |
|---|---|---|---|
| WPS Office 的打開/儲存對話方塊 | 支援 | 中鍵，或左鍵點擊內嵌視窗自帶的圖示 | —— |
| WinRAR 的解壓對話方塊 | 支援 | 中鍵，或左鍵點擊內嵌視窗自帶的圖示 | —— |
| Bandizip 的解壓對話方塊 | 支援 | 中鍵，或左鍵點擊內嵌視窗自帶的圖示 | —— |
| Bandizip 的添加檔案對話方塊 | 支援 | 中鍵，或左鍵點擊內嵌視窗自帶的圖示 | —— |

識別靠的是控件結構而不是視窗標題，所以每款軟件不管裝的是哪種語言包都能正常工作。WPS 那一項覆蓋文字、表格、演示和 PDF——它們用的是同一個對話方塊；WPS 不使用 Windows 自帶的對話方塊，而是自繪了一個，這也正是它需要單獨一個插件、而大多數程式被上面內置的那幾項覆蓋的原因。跟內置的那幾個一樣，活動路徑檢測在這裏也沒有意義——Lertaro 已經嵌入對話方塊本身了，不存在另一個"其它視窗"可供它檢測並作為搜尋範圍。
