# 空間分析

空間分析把 Lertaro 已有的檔案索引轉換成類似 SpaceSniffer 的快速視覺化概覽。它不會掃描磁碟，因此即使多個磁碟包含數百萬個項目，也能迅速開啟。

## 開啟空間分析

開啟 Lertaro 完整搜尋視窗並讓搜尋框保持空白，空間分析會自動作為視窗首頁顯示，並呈現 Lertaro 目前已載入的全部索引。輸入查詢會立即切換到搜尋結果，清空查詢則會返回空間分析先前所在的位置。使用滑鼠左鍵雙擊磁碟或資料夾即可進入；使用向上箭頭或任意麵包屑路徑可返回上層位置。

## 查看和操作

- 左側矩形樹會為較大的項目分配更大的面積，明暗表示大小佔比，不同邊框用於區分資料夾和檔案。
- 右側清單顯示同一批項目並按大小降序排列，每列下方的細條表示它在目前位置可見總大小中的佔比；在任意一側選取項目，另一側也會同步醒目顯示。
- 在卡片或清單列上按右鍵，會開啟與搜尋結果相同的動作選單，包括開啟、定位、複製以及適用的插件動作。
- 只有名稱或大小被截斷時才會顯示工具提示。

## 統計範圍

這裡只包含 Lertaro 已啟用索引中現有的項目，空間分析不會透過走訪檔案系統來補齊缺少的內容。被排除和未索引的內容不會參與統計；隱藏項目會正常顯示，系統項目不會單獨顯示，但其大小仍可能計入可見上層資料夾的總大小。

介面顯示的是檔案邏輯大小，而非實際佔用的磁碟空間。資料夾總大小包含其已索引的後代項目，硬連結資料只會計入一次，因此統計結果可能與 Windows 檔案總管或磁區級磁碟分析工具不同。

空間分析頁面可見時會自動監聽相關的記憶體索引變更事件，並合併連續通知後更新目前檢視；它始終不會開啟或重新載入索引快取檔案。開始搜尋後會暫停空間分析更新，關閉完整搜尋視窗時會釋放已呈現的項目和共用介面快取。
