# 空間分析

Lertaro 內建了極速磁碟與資料夾**空間分析器（Space Analyzer）**。與傳統的磁碟掃描分析工具不同，它直接復用 Lertaro 在後台已構建的記憶體索引樹，無需進行漫長耗時的全盤物理掃描，即便是包含數百萬檔案的多磁碟環境也能做到秒級瞬間呈現。

## 1. 如何進入空間分析

- **自動展示**：開啟 Lertaro 完整搜尋主視窗（`Ctrl+F`）且**搜尋框保持為空**時，空間分析會自動作為首頁呈現。
- **無縫切換**：在搜尋框中鍵入任意字元將立刻無縫切換為常規搜尋結果列表；按 `Escape` 或退格清空搜尋框後，將立即返回空間分析檢視。

## 2. 介面佈局與視覺呈現

空間分析採用左右雙欄聯動設計，直觀反映各目錄與檔案的空間佔比：

### 左側：Treemap 矩形樹狀圖

- **面積直觀表達**：體積越大的資料夾或檔案佔據越大的矩形面積。
- **色彩與明暗層級**：不同深淺明暗表達在當前父目錄中的相對比重，透過特定的邊框樣式清晰區分資料夾與普通檔案。

### 右側：降序統計列表

- **體積降序排列**：將當前層級的子項目從大到小排列，便於快速發現佔用空間的「大頭」。
- **佔比進度條**：每行項目下方配有細長佔比條，直觀反映該項目佔當前檢視總容量的百分比。
- **雙向聯動反白**：在左側矩形卡片或右側列表中選取任意一項，另一側都會同步反白聚焦。
- **長檔案名稱智能捲動**：超出顯示寬度的長名稱會在滑鼠懸停或選取時自動平滑捲動展開，告別傳統遮擋介面的浮動視窗提示。

## 3. 互動導覽與快捷操作

- **下鑽與返回**：
  - **進入目錄**：滑鼠左鍵按兩下左側矩形卡片或右側列表項，即可下鑽深入該目錄檢視內部結構。
  - **返回上級**：按一下頂部導覽列的「向上」箭頭，或直接按一下階層路徑上的任意父級節點即可瞬間返回。
- **快顯動作選單**：在任意卡片或列表行上按一下滑鼠右鍵，即可展開與主搜尋結果完全相同的**動作選單**（直接開啟、複製完整路徑、在檔案總管中定位、移入資源回收筒或徹底刪除）。
- **檔案管理器中鍵定位**：在卡片或列表項上按一下滑鼠中鍵，將直接在已設定的檔案管理器中開啟並定位該目標。
- **即時預覽聯動**：選取項目後按下 `Alt+P` 即可展開 QuickLook 預覽面板，隨後選取的所有項目都會自動跟隨預覽。

## 4. 統計口徑與即時索引同步

### 統計範圍與口徑說明

- **基於已有索引**：空間分析僅彙總 Lertaro 當前已啟用索引中的項目，不會額外發起磁碟 I/O 巡覽。被排除規則忽略的檔案不會計入統計。
- **邏輯大小統計**：介面展示的是檔案的邏輯實際大小，永久連結資料僅計入一次，避免容量虛高。
- **隱藏與系統檔案**：隱藏檔案會正常參與統計和展示；系統檔案大小會合併計入其所在父級資料夾的總容量中。

### 即時變更監聽與自癒

- **無感即時重新整理**：當後台檔案發生增刪改動時，空間分析會自動接收索引變更通知，並經過批次防抖合併後平滑更新當前檢視。
- **路徑自癒回退**：若當前正在瀏覽的資料夾或其上級目錄被外部程式刪除、重新命名或從索引中移除，空間分析會自動智能回退到第一個依然有效的上層可用目錄，確保介面絕不當機或顯示異常。
