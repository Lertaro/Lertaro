# 使用者手冊

Lertaro 是一款為 Windows 打造的、鍵盤優先的極速檔案檢索啓動器。它在後臺索引你的本地磁碟(NTFS
和 ReFS 通過各自的變更日誌，其他檔案系統則直接監聽變化)及網絡共享，讓你能在極短時間內跳轉到任意檔案、資料夾或應用程式。

本手冊涵蓋日常使用所需的一切：

- **[快速上手](./getting-started)** —— 安裝 Lertaro，瞭解它的三種搜尋視窗(主視窗/快速視窗/內嵌視窗)。
- **[搜尋語法](./search-syntax)** —— 模糊匹配、排除/精確/前綴/後綴操作符、或組、盤符定向、路徑模式，以及中文檔案名的拼音別名匹配。
- **[熱鍵](./hotkeys)** —— 每一個可配置快速鍵與硬編碼按鍵，及其預設綁定。
- **[動作選單與預覽](./actions-and-preview)** —— 類右鍵選單的動作列表，以及 QuickLook 預覽視窗。
- **[即時答案與關鍵詞功能](./instant-answers)** —— 計算器、環境變量、運行命令這些捷徑，以及處理程序管理、視窗切換器、瀏覽器資料、設定搜尋、網頁搜尋這類關鍵詞觸發的插件。
- **[命令列搜尋（lff）](./cli)** —— 可以在終端裏使用的、fzf 風格的命令列伴侶工具。
- **[URI 協議（lertaro://）](./uri-protocol)** —— 通過一個鏈接、別的程式或腳本，直接跳轉到某次搜尋或某項具體設定。
- **[支援的檔案管理器](./file-manager-support)** —— Lertaro 可以嵌入、觸發快速導航、或檢測當前資料夾的檔案管理器和檔案選擇對話方塊都有哪些。
- **[設定項參考](./settings/)** —— 每一個設定頁面、每一個 Tab、每一項設定，逐條列出。
- **[故障排查](./troubleshooting)** —— 常見問題與解決辦法。
- **[捐贈支持](./donate)** —— 如果 Lertaro 對你有幫助。

如果是第一次配置 Lertaro，建議從**快速上手**開始閱讀。
