# 用戶手冊

歡迎查閱 Lertaro 官方用戶手冊！Lertaro 是一款為 Windows 深度定制的極速檔案檢索與生產力啟動器。透過在後台維護高效的記憶體索引樹（NTFS / ReFS 基於底層 USN 變更記錄檔，其他檔案系統基於即時事件監聽），實現千萬級檔案的毫秒級檢索回應。

本手冊系統化介紹了日常使用所需掌握的各項核心功能與進階特性：

- **[快速上手](./getting-started)** —— 安裝與便攜版使用、App 與 Service 架構職責、三種視窗形態（快速視窗 / 主視窗 / 內嵌視窗）及基礎操作。
- **[搜尋語法](./search-syntax)** —— 智慧模糊比對、修飾符（`!` 排除、`'` 精確、`^` 前綴、`$` 後綴、`|` 或條件）、磁碟機定向、路徑模式與拼音別名比對。
- **[熱鍵與互動手勢](./hotkeys)** —— 全域熱鍵速查表、搜尋框 Logo 滑鼠拖曳與重設手勢、滑鼠快速導覽級聯選單與核心固定按鍵。
- **[動作選單與即時預覽](./actions-and-preview)** —— 結果快顯動作面板（`Ctrl+O`）、主視窗結果互動、內建 QuickLook 音訊影片/文件預覽與外掛模組富文本卡片。
- **[空間分析](./space-analyzer)** —— 零磁碟 I/O 的極速 Treemap 矩形樹狀圖與體積降序列表，輕鬆發現大檔案。
- **[即時解答與關鍵字功能](./instant-answers)** —— 始終生效的計算機、環境變數與執行命令，以及處理程序管理（`ps`）、視窗切換（`win`）、瀏覽器書籤（`bb`）、瀏覽器歷史（`bh`）、設定直達（`set`）等關鍵字外掛模組。
- **[命令列搜尋（lff）](./cli)** —— 終端機環境下的互動式模糊尋找伴侶工具，共享記憶體索引，支援管道傳參與 Shell 腳本聯動。
- **[URI 協議（lertaro://）](./uri-protocol)** —— 外部超連結、捷徑與腳本直達搜尋、設定分區及 LocalSend 傳輸。
- **[支援的檔案管理器](./file-manager-support)** —— Windows 原生檔案對話方塊、Directory Opus、Total Commander、XYplorer、Files 等工具的內嵌與快速導覽整合。
- **[設定項參考](./settings/)** —— 運行狀態、索引管理、一般選項、外觀主題、熱鍵綁定、外掛模組設定等各項設定詳細說明。
- **[故障排查](./troubleshooting)** —— 全域熱鍵失靈、索引未更新、輸入法候選字浮窗及記錄檢視排查指南。
- **[捐贈與支持](./donate)** —— 支持 Lertaro 的持續迭代與開源維護。

> [!TIP]
> 如果你是初次接觸 Lertaro，推薦從[**快速上手**](./getting-started)開始閱讀。
