# 快速上手

## 安裝

在首頁的[下載按鈕](../)獲取最新版本——每次發佈都會提供兩種形式：

- **安裝程式**（`Lertaro-Setup.exe`）—— 推薦使用。會註冊後臺索引服務，也可以設定為隨 Windows 啓動。
- **便攜版**（`Lertaro-Portable.zip`）—— 解壓即可運行，無需安裝。之後仍然可以在 **設定 → 運行狀態** 裏手動安裝後臺服務。如果電腦上還沒有 Lertaro 需要的 .NET 桌面運行時，運行一次自帶的 `install-dotnet-runtime.bat` 即可——安裝程式會自動處理這一步，但便攜版做不到。便攜版用完不再需要時，沒有解除安裝程式幫你清理：刪除資料夾前，雙擊自帶的 `portable-cleanup-registry.reg`（確認彈窗提示）即可移除 Lertaro 自己創建的兩項每使用者註冊表項——`lertaro://` URI 協議註冊，以及“開機自動啓動”這一項。兩者都只在 HKCU（當前使用者）範圍內，不需要系統管理員權限。

這兩種形式都分別提供 **x64** 和 **ARM64** 版本。上面這些是 x64 版本，在絕大多數電腦上都能運行——包括 Windows on ARM 裝置，只是以模擬方式運行。如果用的是 ARM 裝置，建議改用 `Lertaro-Setup-arm64.exe` 或 `Lertaro-Portable-arm64.zip`，它們是原生版本。自動更新會一直保持在你安裝時的架構上，所以要換成另一種，需要自己去下載。

## 便攜版資料

便攜版會在程式旁將機器資料保存到 `Data\Machine`，並把每位使用者的私有資料保存到 `Data\Users\<SID hash>`。如果其 `Data` 目錄尚未建立，為了兼容會重用已有的 `%ProgramData%\Lertaro` 和 `%LocalAppData%\Lertaro` 資料；建立 `Data` 後，該便攜版將優先使用自己的資料並成為自包含副本。

首次運行時，Lertaro 會安裝並啓動一個 Windows 服務（`Lertaro.Service`），專門負責檔案索引。這個拆分是有意為之的——如果好奇原因可以參考[架構設計](../dev-guide/architecture)——但作為普通使用者，只需要知道：**設定 → 運行狀態** 頁面會告訴你服務是否已安裝、是否在運行，如果還沒安裝，也可以在這裏安裝。

## 三種視窗

Lertaro 不是只有一個搜尋視窗——它會根據使用場景自動適配：

- **主視窗** —— 從工作列/開始功能表捷徑打開的完整視窗，結果列表最大，還帶有窗內動作面板。
- **快速視窗** —— 按下全局呼出熱鍵（預設雙擊 `Ctrl`）召喚出來的緊湊型置頂彈窗，專為“按熱鍵 → 輸入 → 回車”這套肌肉記憶設計。
- **內嵌視窗** —— 直接把 Lertaro 的搜尋框嵌入到受支援的原生檔案對話方塊或檔案總管視窗裏，不用離開當前對話方塊就能搜尋。

三種視窗共用同一套搜尋引擎、熱鍵系統和動作選單——區別只在於它們出現的位置和形態。

## 基本搜尋

最近檔案、收藏夾和歷史記錄不用輸入任何東西就能拿到——它們是[快速面板](./settings/quick-panel)裏的標籤，而這個面板是疊在當前前景視窗上打開的，並不在搜尋視窗裏面。

直接開始打字即可。結果會隨輸入實時更新，並按相關度排序（匹配與排序的原理見[搜尋語法](./search-syntax)）。用[可配置的上/下一項熱鍵](./hotkeys)（預設是方向鍵）移動選中項，回車打開高亮的結果。
