# 快速上手

歡迎使用 Lertaro！Lertaro 是一款為 Windows 深度定制的極速檔案檢索與生產力啟動器。本章將帶你了解安裝方式、核心架構、三種視窗形態以及基本的日常搜尋操作。

## 1. 下載與安裝

你可以在官方網站首頁獲取最新版本。每個正式發佈版本均提供兩種運行形式，並分別編譯了 **x64** 與 **ARM64** 原生版本：

### 安裝包（`Lertaro-Setup.exe`，推薦）

- **自動化設定**：安裝精靈會自動註冊後台索引服務（`Lertaro.Service`），設定開機自啟動項，並自動偵測與安裝所需的 .NET 桌面執行階段。
- **平滑升級**：支援靜默自動檢查更新與一鍵覆蓋升級。

### 便攜版（`Lertaro-Portable.zip`）

- **解壓即用**：解壓至任意目錄即可直接運行主程式，不強制要求安裝。
- **環境補齊**：若系統尚未安裝對應的 .NET 桌面執行階段，可直接運行解壓目錄自帶的 `install-dotnet-runtime.bat` 腳本一鍵安裝。
- **資料獨立與隔離**：便攜版預設將機器全域資料儲存在程式同級目錄的 `Data\Machine`，並將各用戶的私有設定儲存在 `Data\Users\<SID hash>`。若該 `Data` 目錄尚未建立，會自動兼容讀取系統的 `%ProgramData%\Lertaro` 和 `%LocalAppData%\Lertaro`；一旦目錄生成，便攜版將優先讀取本地獨立資料，實現完全自包含。
- **乾淨解除安裝與清理**：當不再需要使用便攜版時，在刪除資料夾前請先執行自帶的 `portable-cleanup.bat` 腳本。該腳本會自動停止並解除安裝後台服務，並清理當前用戶的 `lertaro://` URI 協議及自啟註冊表項。

> [!TIP]
> 如果你在 Windows on ARM 裝置（如 Surface Pro X、高通驍龍筆記本）上運行，請優先下載 `Lertaro-Setup-arm64.exe` 或 `Lertaro-Portable-arm64.zip` 原生版本，以獲得最佳效能與更低的功耗。

## 2. 核心架構認知

首次運行 Lertaro 時，系統會安裝並啟動一個獨立的 Windows 後台服務（`Lertaro.Service`）。理解該設計有助於你更好地掌握其運作原理：

- **前台 App（UI 與互動層）**：負責渲染搜尋視窗、懸浮面板、動作選單、快捷鍵攔截與即時預覽。前台程序始終保持極低記憶體佔用與即時回應。
- **後台 Service（索引與資料層）**：以系統服務權限在後台運行，專門負責讀取 NTFS / ReFS 的 USN 記錄檔、監聽其他檔案系統的即時變動、維護網路共用索引，並建立極速記憶體索引樹。
- **架構優勢**：前台介面的重啟、當機或更新絕不會導致後台索引遺失或重新全盤掃描；而後台的即時索引同步也絕不會阻塞前台 UI 的流暢打字體驗。你可以在[**設定 → 運行狀態**](./settings/service-status)中隨時查看服務運行狀態與索引健康度。

## 3. 三種視窗形態

Lertaro 並非只有一個固定的搜尋視窗，而是針對不同工作流設計了三種各具特色的視窗形態：

| 視窗形態 | 預設喚起方式 | 核心特點與設計定位 | 適用場景 |
| :--- | :--- | :--- | :--- |
| **快速視窗（Quick Window）** | 雙擊 `Ctrl`（可自訂） | 緊湊型螢幕置中浮窗，即輸即搜，肌肉記憶友好，支援數字鍵快速跳轉與全鍵盤流操作 | 日常高頻啟動應用程式、尋找特定檔案、快速計算或翻譯 |
| **主視窗（Full Window）** | 工作列/開始功能表，或快捷鍵 `Ctrl+F` | 完整的大尺寸視窗，支援海量結果表格檢視、側邊欄進階篩選、欄排序與內建空間分析器 | 深度檔案瀏覽、大範圍檢索、磁碟空間清理與進階篩選 |
| **內嵌視窗（Inline Window）** | 開啟檔案對話方塊或檔案總管時自動嵌入 | 無縫內嵌到系統檔案對話方塊或第三方管理器中，無需離開當前工作上下文 | 在 Office/瀏覽器等軟體中「開啟」或「另存為」檔案時快速定位目標 |

三種視窗形態底層共享完全相同的搜尋引擎、快捷鍵體系、篩選規則與動作選單。

## 4. 首次搜尋與基本互動

### 即輸即搜

開啟搜尋視窗後直接輸入關鍵字即可，結果將隨輸入即時呈現（毫秒級回應）。搜尋演算法預設採用智慧模糊比對，字元無需連續輸入即可跳躍命中。詳細比對規則與修飾符請參閱[**搜尋語法**](./search-syntax)。

### 結果導覽與開啟

- **移動游標**：使用方向鍵 `↑` / `↓`（或設定的導覽快捷鍵 `Ctrl+P` / `Ctrl+N`）在結果列表中上下移動選取項目。
- **直接開啟**：按下 `Enter` 立即使用預設程式開啟選取的檔案或啟動應用程式。
- **定位目錄**：按下 `Ctrl+Enter` 可在檔案總管中直接定位並選取該檔案。
- **系統管理員身分運行**：按下 `Ctrl+Shift+Enter` 以系統管理員權限運行程式。
- **數字直達**：在快速視窗中，可直接按下 `Ctrl` + `1`–`9` 直接開啟前 9 項結果。

### 動作選單與擴充操作

按下 `Ctrl+O` 或在選取項目上按方向鍵 `→`，即可展開功能強大的**動作選單**，執行複製路徑、屬性查看、檔案增刪剪貼或呼叫外掛模組擴充動作。更多操作技巧請閱讀[**動作選單與預覽**](./actions-and-preview)與[**熱鍵**](./hotkeys)。
