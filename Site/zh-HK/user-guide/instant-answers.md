# 即時解答與關鍵字擴充功能

除了本機檔案檢索之外，Lertaro 還內建了一系列強大的即時計算、系統工具與關鍵字擴充外掛模組。無需等待檔案檢索，輸入對應指令即可即刻得到答案或觸發專業功能。

## 1. 始終生效的即時解答

無需輸入任何前綴關鍵字，只要輸入的文字比對特定模式即可立即觸發：

### 計算機與進位制轉換

直接在搜尋框中輸入數學運算式，計算結果將在第一行即時呈現。按下 `Enter` 鍵即可將計算結果複製到剪貼簿：

```text
12 * (4 + 3)
100 * (1 - 0.15)
```

支援常見的進位制轉換表達：

```text
255 to hex
0xFF to dec
101010 to bin
```

### 環境變數展開與查詢

- **精準展開變數**：輸入 `%NAME%`（如 `%PATH%`、`%APPDATA%`）可直接檢視變數值。對於包含多個路徑的變數（如 `PATH`），Lertaro 會自動將其拆分為清晰的逐行列表，便於檢查環境設定。
- **模糊搜尋變數**：輸入 `%` 加上關鍵字（如 `%temp`）可模糊搜尋所有名稱中包含該關鍵字的系統與用戶環境變數。

### 快捷執行命令

無需先開啟終端機視窗，直接在搜尋框中輸入：

- `#<命令>`：開啟命令提示字元視窗並**以系統管理員權限**執行該命令（例如 `#sfc /scannow` 或 `#net start Lertaro.Service`）。
- `$<命令>`：開啟命令提示字元視窗以**當前普通用戶權限**執行該命令（例如 `$ping 1.1.1.1` 或 `$ipconfig /all`）。

### 網址直達

直接輸入或貼上以 `http://` 或 `https://` 開頭的完整網址，按下 `Enter` 即可立即在預設瀏覽器中開啟該頁面。輸入合法的無協定網址（例如 `example.com`）時，快速搜尋視窗會直接產生兩個即時結果：`https://...` 和 `http://...`。每個結果都採用兩行式的瀏覽器開啟文案，搜尋框內容不會被修改；已經包含協定的網址則只產生一個結果。

### 快速搜尋視窗匯入剪貼簿文字

快速搜尋視窗在沒有預填內容的情況下被呼叫時，如果剪貼簿文字不為空且不同於該視窗上一次匯入的剪貼簿內容，就會自動填入並全選文字。相同內容不會重複匯入，從 URI 或完整搜尋視窗返回時的預填內容也不會被覆蓋。

## 2. 關鍵字觸發功能（內建外掛模組）

透過輸入簡短的**觸發關鍵字 + 空格**，再輸入實際查詢內容，即可調用專項外掛模組能力。各關鍵字均可在[**設定 → 外掛模組**](./settings/plugins)中自訂修改。

| 預設關鍵字 | 外掛模組名稱 | 功能說明與使用場景 | 典型使用範例 |
| :--- | :--- | :--- | :--- |
| `ps` | **處理程序管理** | 按處理程序名、PID 或視窗標題搜尋運行中的處理程序（支援拼音），按 Enter 一鍵結束處理程序。 | `ps chrome` 或 `ps 1234` |
| `win` | **視窗切換器** | 搜尋並即時切換到當前開啟的應用程式視窗，支援背景即時抓取視窗縮圖。 | `win code` 或 `win 瀏覽器` |
| `bb` | **瀏覽器書籤** | 搜尋 Chrome、Edge、Firefox 等瀏覽器的書籤。 | `bb github` |
| `bh` | **瀏覽器歷史** | 搜尋 Chrome、Edge、Firefox 等瀏覽器的歷史造訪記錄。 | `bh github` |
| `set` | **設定搜尋** | 模糊搜尋 Lertaro 自身的所有設定選項，選取即可直接跳轉到對應設定頁並反白該項。 | `set 熱鍵` 或 `set 模糊` |
| `flow` | **Flow 外掛模組橋接** | 列出所有已載入的 Flow.Launcher 外掛模組及其觸發詞，支援無縫調用 Flow 社群生態。 | `flow` |
| `cs` | **內容搜尋** | 搜尋已建立索引的本機文件內文，並返回帶片段的相符檔案。 | `cs 專案計劃` |

## 3. 網頁搜尋快捷引擎

網頁搜尋外掛模組內建了主流搜尋引擎快捷方式，輸入對應前綴並跟隨關鍵字即可一鍵拉起瀏覽器搜尋：

| 快捷詞 | 對應搜尋引擎 | 範例 | 說明 |
| :--- | :--- | :--- | :--- |
| `bd` | 百度 (Baidu) | `bd 深度學習` | 在百度中搜尋關鍵字 |
| `g` | 谷歌 (Google) | `g lertaro github` | 在 Google 中搜尋關鍵字 |
| `bing` | 必應 (Bing) | `bing 微軟文件` | 在 Bing 中搜尋關鍵字 |
| `gh` | GitHub | `gh Lertaro` | 直接在 GitHub 儲存庫中搜尋 |
| `wiki` | 維基百科 (Wikipedia) | `wiki 量子力學` | 在維基百科中查閱條目 |
| `yt` | YouTube | `yt lofi hip hop` | 在 YouTube 中搜尋影片 |

你可以在**設定 → 外掛模組 → 網頁搜尋 → 設定**中自由新增、修改或刪除搜尋引擎與自訂 URL 範本。

## 4. 即時翻譯

輸入預設觸發詞 `tr` 並在其後輸入待翻譯的內容，即可自動翻譯為 Lertaro 當前所選的介面語言：

```text
tr Hello, how are you today?
```

- 翻譯結果隨輸入非同步呈現，按 `Enter` 鍵即可一鍵複製譯文。
- 可在**設定 → 外掛模組 → 翻譯 → 設定**中更改觸發詞或檢視連線狀態。

## 5. 檔案篩選器

在**設定 → 外掛模組 → 檔案篩選器 → 設定**中，你可以為觸發關鍵字綁定特定目錄，讓一般搜尋可以限定在這些目錄內：

- **範圍資料夾清單**：一行一個路徑（如 `D:\Engineering\Drawings`）。搜尋結果來自檔案索引，因此資料夾需被索引覆蓋（已啟用索引的本機磁碟，或在**設定 → 索引 → 資料夾**中新增，支援網絡共用路徑）；未被索引覆蓋的資料夾會被略過並記錄警告日誌。
- **比對規則**：檔案名稱萬用字元模式（如 `*.dwg;*.dxf`，資料夾一律保留）。
- **觸發關鍵字**：綁定前綴（如 `cad`）後，在快捷搜尋框輸入 `cad 零件圖` 即可只在綁定的資料夾內執行一般索引搜尋（按檔案名稱模糊比對，包含拼音別名）；僅輸入關鍵字時會提示繼續輸入。

## 6. 自訂命令

在**設定 → 外掛模組 → 自訂命令 → 設定**中，你可以將任意複雜的命令列工具、指令碼或外部應用程式包裝為一個簡短的啟動命令：

- **參數占位符**：支援位置占位符 `%s1`、`%s2`……（對應以空格分隔的參數）以及全文占位符 `%s`（代表關鍵字後的所有輸入文字）。
- **快速導覽整合**：勾選「在快速導覽中顯示」後，該命令會直接作為選單項出現在[**快速導覽**](./hotkeys#3-快速導覽滑鼠觸發)中，支援使用 `/` 建立多級子選單分類（如 `開發工具/重啟服務`）。
