# 即時答案與關鍵詞功能

有些結果會在你打字的同時立刻出現，不需要等檔案搜尋完成——要麼是始終生效的，要麼是需要你先輸入一個簡短的關鍵詞、再接你真正想查的內容(這樣像"搜尋瀏覽器歷史記錄"這類分量較重的功能，就不會在你打每一個跟它無關的字元時都來搶注意力)。大多數需要關鍵詞的功能，其關鍵詞都可以在**設定 → 插件 → 配置**
裏自行修改。

## 始終生效

這些不需要關鍵詞——只要你輸入的內容匹配它們的模式，就會立刻觸發。

### 計算器

直接輸入數學表達式，結果會實時顯示出來，按 **Enter** 把結果複製到剪貼簿:

```
12 * (4 + 3)
```

也支援顯式的進制轉換:

```
255 to hex
0xFF to dec
```

### 環境變量

- `%NAME%` 展開某個具體的變量(包括像 `%PATH%` 這種多路徑變量，會按路徑逐條拆開列出)。
- `%partial` 模糊列出所有名稱裏包含 `partial` 的變量。

### 運行命令

- `#<命令>` 打開命令提示字元視窗，**以系統管理員權限**運行 `<命令>`。
- `$<命令>` 打開命令提示字元視窗，以普通權限運行 `<命令>`。

### 裸網址

直接輸入或貼上一個 `http://`/`https://` 地址，Lertaro 會提示直接打開它。

## 關鍵詞觸發(內置插件，前綴可配置)

輸入關鍵詞、一個空格，然後接你真正的查詢內容。每個關鍵詞都有一個預設的簡短前綴，如果它和你常打的內容衝突，也可以在對應插件自己的**配置**對話方塊裏單獨修改。

| 關鍵詞(預設) | 插件 | 搜尋的內容 |
|---|---|---|
| `ps` | 處理程序管理 | 按名稱、PID 或視窗標題搜尋正在運行的處理程序(也支援模糊/拼音匹配)——選中一個即可結束它。 |
| `win` | 視窗切換器 | 當前打開的、可切換的視窗(和 Alt+Tab 顯示的是同一批)，按標題、處理程序名或 PID 搜尋——選中即可切換到該視窗。 |
| `bm` | 瀏覽器資料 | 搜尋你在該插件設定裏添加的 Chrome/Chromium 系和 Firefox 系瀏覽器配置檔案裏的書籤與歷史記錄。 |
| `set` | 核心擴展 | 應用內的每一項設定，按名稱模糊匹配——選中一項即可直接跳轉到設定裏對應的那一行並高亮。只打 `set` 不加任何內容會列出所有設定。 |

視窗切換器預設會把每個視窗實際內容的實時縮略圖作為圖示——截圖在後臺進行，不會拖慢輸入速度：先立即顯示程式圖示，縮略圖準備好之後再補上。在**設定 → 插件 → 視窗切換器 → 配置**裏關掉"用視窗內容作為圖示"就能完全跳過這部分截圖，始終用程式圖示。真正的獨佔全屏視窗(大多數遊戲預設用的其實是無邊框視窗化，這種沒問題)截不到內容，會自動回退到程式圖示。

瀏覽器資料插件的書籤和歷史記錄是各自獨立索引的——**索引書籤**和**索引歷史記錄**是**設定 → 插件
→ 瀏覽器資料 → 配置**裏兩個獨立的開關，所以你可以只關掉歷史記錄(它通常比書籤多得多)而繼續搜尋書籤，反過來也一樣。

## 網頁搜尋

網頁搜尋插件自帶了幾個引擎/網站的預設關鍵詞——`bd`(百度)、`g`(谷歌)、`bing`(必應)、`gh`
(GitHub)、`wiki`(維基百科)、`yt`(YouTube)——你也可以在**設定 → 插件 → 網頁搜尋 → 配置**裏完全自由地新增、編輯或刪除條目，每一條都有自己的名稱、關鍵詞、圖示和網址模板。

```
g lertaro github
```

會在瀏覽器裏打開一次"lertaro github"的谷歌搜尋。

## 翻譯

翻譯插件的預設觸發詞是`tr`。在它後面輸入文字，就會翻譯成目前 Lertaro 介面所選的語言：

```
tr hello
```

結果會非同步顯示；按**Enter**或點擊即可複製。待翻譯文字會傳送到 Microsoft Translator，因此需要連網；目標語言始終是 App 目前設定的介面語言。可在**設定 → 插件 → 翻譯 → 配置**中更改觸發詞。

## 檔案過濾器

在**設定 → 插件 → 檔案過濾器 → 配置**裏，為特定資料夾單獨建立索引規則。每條規則都有自己的
**監控資料夾列表**(遞歸掃描)、一個**匹配後綴**欄位(例如 `*.exe;*.lnk`——支援用 `;` 或 `,`
分隔多個模式，全部都會被匹配；預設的 `*` 匹配所有檔案)，以及一個可選的**過濾器名稱**，會顯示在結果的描述裏。子資料夾永遠會被收錄，不受匹配後綴影響——匹配後綴只過濾檔案。

給規則加上**觸發關鍵字**，可以把它的結果收在一個前綴關鍵詞後面(和上面的內置關鍵詞一樣)，而不是始終混在通用索引結果裏參與排序。

## 完全自訂(關鍵詞你說了算)

### 自訂命令

定義你自己的 `<關鍵詞> <參數>` 命令，用來啓動一個外部程式，全部在**設定 → 插件 → 自訂命令 →
配置**裏配置。命令的參數模板支援位置佔位符(`%s1`、`%s2`……對應每個用空格分隔的參數)，以及一個
"剩餘全部內容"佔位符(`%s`，代表關鍵詞之後你輸入的所有內容)。

每條命令還有一個**在快速導航中顯示**勾選框(預設關閉)——打開後，這條命令會額外作為一個條目出現在[快速導航](./hotkeys#快速導航-滑鼠)選單的根層級，不用打關鍵詞也能點開執行。**快速導航子選單**
欄位可以把它歸到某個具名子選單下，而不是直接放根層級——用 `/` 可以嵌套多級(比如"工具/網絡"代表兩級子選單);留空則保持在根層級。以這種方式執行時，命令會按配置好的參數原樣運行，因為這裏沒有打字輸入的參數內容可以代入 `%s1`/`%s`。

---

本頁提到的插件都不是必需的——每一個都可以在[設定 → 插件](./settings/plugins)裏單獨禁用，如果你不想讓它佔用鍵盤輸入的注意力;而[搜尋語法](./search-syntax)介紹的是另一套始終生效、用於檔案/
資料夾/應用程式搜尋的模糊查詢語言，和本頁內容是兩回事。
