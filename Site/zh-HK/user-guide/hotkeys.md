# 熱鍵

下面所有全局與應用內熱鍵都可以在**設定 → 熱鍵**裏重新綁定；這裏列出的是預設值。設定介面本身見[設定 → 熱鍵頁面](./settings/hotkeys-page)。

## 全局熱鍵

| 動作 | 預設 | 說明 |
|---|---|---|
| 呼出/隱藏快速視窗 | 雙擊 `Ctrl` | 也可以設定成完整組合鍵(例如 `Alt+Space`)而不是雙擊模式。 |
| 快速切換 | `Ctrl+G` | 在支援的檔案對話框中，跳到最近一次從支援的檔案管理器或快速面板收集的資料夾；內嵌搜尋欄為空時也會把該目標顯示成一筆結果。 |
| 選中下一項 | `Ctrl+N` | 與方向鍵的下鍵效果相同。在[快速面板](./settings/quick-panel)裏，它走的是整個標籤而不是單個分組：到了一個分組的末尾會繼續進入下一個分組。 |
| 選中上一項 | `Ctrl+P` | 與方向鍵的上鍵效果相同。在快速面板裏同樣是跨分組走完整個標籤。 |
| 跳轉到結果 1–9 | `Ctrl` + 數字 | 修飾鍵可自訂;數字固定為 1–9。快速視窗裏每個可見結果旁邊都會顯示對應快速鍵的小徽章，不用自己數行數。 |
| 打開動作選單 | `Ctrl+O` | 與在選中結果上按方向鍵右鍵效果相同。 |
| 從選中項補全 | `Ctrl+Tab` | 在快速視窗裏，用選中結果的名稱/路徑填充搜尋框。 |
| QuickLook 預覽 | `Alt+P` | 切換選中結果的預覽面板。[快速面板](./settings/quick-panel)用的是同一個鍵，並且會把預覽視窗停靠到自己放得下的那一側。 |
| 上一條關鍵字歷史 | `Alt+Up` | 向前翻閱最近輸入過的搜尋詞。 |
| 下一條關鍵字歷史 | `Alt+Down` | 向後翻閱最近輸入過的搜尋詞。 |
| 刪除當前關鍵字歷史 | `Ctrl+Delete` | |
| 打開完整視窗 | `Ctrl+F` | 直接打開完整視窗並帶上當前搜尋內容——效果和左鍵點擊[快速視窗自帶的圖示](#搜尋框圖示)、在彈出選單裏選"顯示主視窗"一樣,只是省了點選單這一步。可在**設定 → 熱鍵**裏自行設定。 |
| 開啟傳送視窗 | `Ctrl+S` | 開啟傳送檔案或文字至 LocalSend 裝置的視窗。可在**設定 → 熱鍵**裏自行設定。 |
| 保持視窗不消失 | `Ctrl+T` | 焦點移到別處時不再自動隱藏，便於把其他視窗裡複製來的文字拼成一條查詢——否則每次隱藏都會清空搜尋框。只在本次呼叫期間有效，下次隱藏時解除。在快速視窗裏，滑鼠中鍵點擊 logo 效果相同，開啟期間 logo 會變亮；視窗還在但沒有焦點時按呼出快速鍵，會讓它重新取得焦點而不是隱藏。[快速面板](./settings/quick-panel)沿用同一個鍵，並以它自己的「釘住」按鈕作為標識。 |
| 呼出/關閉快速面板 | `Ctrl+F2` | 把[快速面板](./settings/quick-panel)停靠到當前前景視窗的右下角；已經打開時則關閉它。打開之後，按住「跳到第 1–9 條結果」的修飾鍵再按 1–9 就能切換工作區。 |

## 搜尋框圖示

搜尋框裏那個小圖示(具體在左側還是右側,取決於視窗)在[三種視窗](./getting-started#三種視窗)裏各自有不同的作用：

- **快速視窗** —— 左鍵點擊(不移動)會彈出和系統匣圖示右鍵一樣的選單(顯示主視窗、切換熱鍵、設定、關於、乾淨退出、退出)，選單出現在遊標位置；選單裏的"顯示主視窗"還會帶上你當前輸入框裏的搜尋內容。按住左鍵拖動會移動視窗，和拖動搜尋欄其它部分一樣——拖動時(不管是拖搜尋欄還是拖圖示)按住 **Ctrl** 可以把移動方向限制成只能縱向，拖到一半按下/鬆開 Ctrl 也能實時生效，適合只想上下調整位置而不想帶偏橫向位置的時候用。右鍵點擊會把視窗重置回預設螢幕位置(不影響大小)——和首次啓動時的居中位置相同。滑鼠懸停時的提示會把這三種手勢都列出來。

  記住的位置是相對於上次所在顯示器的相對位置，不是絕對螢幕座標——換到另一臺顯示器(或者解析度、
  DPI 縮放不同的顯示器)上喚出時，會在那塊螢幕上按比例換算到對應位置，而不會跑出螢幕外或落到錯誤的顯示器上。
- **內嵌視窗** —— 只有當視窗停靠在原生的打開/保存/瀏覽資料夾對話方塊上時才可點擊：左鍵點擊會觸發[快速導航](#快速導航-滑鼠)，效果和下面專門的觸發方式一樣。當停靠在普通檔案總管視窗或桌面上時不可點擊，因為那種情況下沒有什麼可供跳轉的目標——這時既不會有懸停高亮，也不會有提示。
- **主視窗** —— 這個圖示在主視窗裏純粹是裝飾性的，點擊沒有任何效果。

## 快速導航(滑鼠)

中鍵點擊預設啓用，雙擊左鍵預設關閉；每種觸發方式都可單獨在設定裏開關：

- 開啓此觸發方式後，在桌面或檔案總管視窗的空白處**雙擊左鍵**觸發快速導航。
- 在桌面或檔案總管視窗的空白處、受支援的第三方檔案管理器(Directory Opus、Total Commander、
  XYplorer、Files 等)的檔案列表區域、或原生的打開/保存/瀏覽資料夾對話方塊裏**點擊中鍵**觸發快速導航。這些其它視窗只響應中鍵——雙擊在那裏已經是"打開這一項"的意思，所以沒有把雙擊挪作他用。參見[支援的檔案管理器](./file-manager-support)瞭解每種集成具體覆蓋哪些能力。
- 當內嵌搜尋視窗停靠在原生的打開/保存/瀏覽資料夾對話方塊上時，它自己的圖示同樣可以觸發快速導航
  ——見上面的[搜尋框圖示](#搜尋框圖示)。

無論哪種方式觸發，都會彈出一個級聯選單，內容是你的收藏夾、歷史記錄和配置好的快捷資料夾(見[設定 → 收藏夾](./settings/favorites)和[設定 → 歷史記錄](./settings/history))——插件也可以往裏加自己的條目，比如你在 `wincmd.ini` 裏配置過 Total Commander 的 Directory Hotlist 的話，它也會出現在這裏，Directory Opus 自己的收藏夾選單同樣如此，或者是某條勾選了"在快速導航中顯示"的[自訂命令](./instant-answers#自訂命令)(可以通過
`/` 分隔的路徑把它歸到某個子選單下)。每個貢獻條目的插件在選單根層級都有自己獨立的標題分組，這些分組的先後順序可以自己調整——見[設定 → 通用 → 快速導航](./settings/general#快速導航)。點擊資料夾會讓目標視窗跳轉過去；點擊檔案也會跳轉過去，並在其所在資料夾中選中該檔案，而不是打開它——唯一的例外是桌面，那裏沒有可供跳轉的現有視窗面板，所以在桌面上點擊資料夾或檔案會直接打開它，效果和雙擊一樣。如果是在檔案選擇器裏，點擊檔案則是讓對話方塊跳轉到該檔案所在的資料夾——絕不會替你自動確認"打開"/"保存"。

這個選單實際上是由**級聯資料夾瀏覽器**插件構建的。除了可以各自獨立開關的收藏夾和歷史記錄，它還有自己的一份可配置快捷資料夾列表——在**設定 → 插件 → 級聯資料夾瀏覽器 → 配置**裏添加路徑和可選的顯示名稱，再給它填一個 Submenu 值(比如 `工具/網絡`，用 `/` 分隔可以嵌套多級)，就能把它歸到某個分類下而不是直接顯示在根層級。選單的每一層——根層級和任意嵌套分類——的標題上都有一個小小的
**+** 按鈕：點它可以把你當前瀏覽到的資料夾直接加進來，名稱、路徑和這一層自己的子選單路徑都會預填好(添加前仍可編輯)，不用離開選單去設定裏操作。

## 硬編碼按鍵(不可配置)

無論熱鍵設定如何，以下按鍵始終保持相同行為：

| 按鍵 | 場景 | 行為 |
|---|---|---|
| `Escape` | 任意場景 | 若搜尋框有內容則清空;否則關閉視窗(或退出動作選單)。 |
| `Enter` | 結果列表 | 打開選中結果。 |
| `Ctrl+Enter` | 結果列表 | 在檔案總管中定位該結果，而不是打開它。 |
| `Ctrl+Shift+Enter` | 結果列表 | 以系統管理員身份打開該結果。 |
| 左/右方向鍵 | 動作選單 | 返回上一級選單 / 進入子選單。 |
| `Backspace` | 動作選單 | 當搜尋框已為空時，退出動作選單。 |
| `Alt+Space` / `Alt+F4` | Lertaro 的所有視窗 | `Alt+Space` 在所有視窗上都會被屏蔽——它們都沒有真正的標題欄，Windows 的系統選單在這裡無處可依。`Alt+F4` 在主視窗和設定視窗上照常關閉視窗；在快速視窗、內聯視窗、QuickLook 以及各類對話方塊上仍然被屏蔽，因為它們是顯示/隱藏的，而不是打開/關閉的。 |

## 插件動作熱鍵

插件可以註冊自己的動作並附帶一個預設熱鍵(例如複製路徑 `Ctrl+Shift+C`、以系統管理員身份運行，或是內置的檔案操作動作——剪下 `Ctrl+X`、複製 `Ctrl+C`、貼上 `Ctrl+V`、刪除 `Delete`、徹底刪除
`Shift+Delete`)。這些會顯示在**設定 → 熱鍵 → 插件動作** 裏，按註冊它們的插件分組，重新綁定方式和內置熱鍵相同。

## 處理程序黑名單

如果 Lertaro 的全局熱鍵和某個應用(比如會獨佔鍵盤原始輸入的遊戲)衝突，把該處理程序加入**處理程序黑名單**即可——詳見[設定 → 熱鍵頁面](./settings/hotkeys-page#process-blacklist)。當黑名單裏的處理程序處於前臺時，Lertaro 的全局熱鍵、按鍵攔截，以及上面的快速導航滑鼠觸發都會被完全放行，不會攔截。

任何真正全屏的前臺應用都會自動獲得同樣的效果，不需要手動加入黑名單。無論哪種情況，當前活動視窗如果是檔案選擇器，都會被豁免，快速導航依然可以正常使用。
