# 容量分析

容量分析は、Lertaro の既存のファイルインデックスを SpaceSniffer のような高速な視覚表示に変換します。ディスクを走査しないため、複数のドライブに数百万件の項目があってもすばやく開けます。

## 容量分析を開く

Lertaro のトレイアイコンを右クリックし、**容量分析**を選択します。最初の画面には、Lertaro が現在読み込んでいるすべてのインデックスが表示されます。ドライブまたはフォルダーをマウスの左ボタンでダブルクリックするとその中に移動でき、上矢印またはパンくずリストの任意の項目で上の階層に戻れます。

## 表示と操作

- 左側のツリーマップでは、大きな項目ほど広い面積を占めます。明暗は相対的なサイズを表し、枠線の違いでフォルダーとファイルを区別します。
- 右側のリストには同じ項目がサイズの降順で表示されます。どちらかで項目を選択すると、もう一方でも同期して強調表示されます。
- カードまたはリスト行を右クリックすると、検索結果と同じアクションメニューが開きます。開く、場所を表示、コピー、および該当するプラグインアクションを利用できます。
- ツールチップは名前またはサイズが省略された場合にのみ表示されます。

## 集計対象

Lertaro で有効になっているインデックスにすでに存在する項目だけが集計され、容量分析がファイルシステムを走査して不足分を補うことはありません。除外対象と未インデックスの内容は集計されません。隠し項目とシステム項目は個別には表示されませんが、そのサイズは表示中の上位フォルダーの合計に含まれる場合があります。

表示されるのはファイルの論理サイズであり、ディスク上の割り当て済み容量ではありません。フォルダーの合計にはインデックス済みの子孫が含まれ、ハードリンクされたデータは一度だけ数えられるため、Windows エクスプローラーやセクターレベルのディスク分析ツールとは結果が異なる場合があります。

ウィンドウを開いたときと**更新**を押したときには、ライブモニターがすでに受け取ったファイル変更を含む最新のメモリ内インデックス状態が照会されます。容量分析がインデックスキャッシュファイルを別途開いたり再読み込みしたりすることはありません。ウィンドウを閉じると、描画済みの項目と共有 UI キャッシュが解放されます。
