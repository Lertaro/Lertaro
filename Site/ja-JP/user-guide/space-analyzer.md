# ストレージ分析

Lertaro は、超高速なディスク・フォルダー**ストレージ分析（Space Analyzer）**機能を内蔵しています。時間を要する全セクタの物理スキャンを毎回行う従来のツールとは異なり、Lertaro がバックグラウンドですでに構築したインメモリインデックスツリーをそのまま活用するため、数百万件のファイルが存在するドライブでも瞬時に容量内訳を可視化できます。

## 1. ストレージ分析の表示方法

- **自動表示**：Lertaro のメイン検索ウィンドウ（`Ctrl+F`）を開き、**検索ボックスを空のまま**にすると、ストレージ分析が自動的にホーム画面として表示されます。
- **検索とのシームレスな切り替え**：検索ボックスに文字を入力すると即座に通常の検索結果一覧に切り替わり、`Escape` や Backspace で空にすると瞬時にストレージ分析へ戻ります。

## 2. 画面構成とビジュアル表示

左右の 2 ペイン連動レイアウトを採用しており、各階層のフォルダーやファイルの容量割合を一目で把握できます。

### 左ペイン：ツリーマップ（Treemap）表示

- **面積による直感的な表現**：占有容量が大きいフォルダーやファイルほど、大きな四角形として描画されます。
- **濃淡と境界線**：現在のフォルダー内における相対的な容量の重みを濃淡で表現し、専用の枠線スタイルでフォルダーと通常ファイルを明確に区別します。

### 右ペイン：サイズ降順一覧

- **サイズ降順ソート**：現在の階層のアイテムを大きい順にリストアップし、容量を圧迫している原因を素早く特定できます。
- **割合プログレスバー**：各行の下部にバーが表示され、現在の総容量に対する割合を直感的に確認できます。
- **双方向連動ハイライト**：左側のツリーマップまたは右側の一覧で項目を選択すると、もう一方のペインでも連動してハイライトされます。
- **長いファイル名の自動スクロール**：枠内に収まらない長いファイル名は、ホバー時や選択時にスムーズに自動スクロール表示されます。

## 3. ナビゲーションと操作方法

- **階層の移動**：
  - **フォルダーに入る**：ツリーマップのカードまたは右側の一覧項目を左ダブルクリックして、そのフォルダーの内部構造を展開。
  - **親フォルダーに戻る**：上部バーの「上へ」矢印をクリックするか、パンくずリストの任意の親フォルダーをクリック。
- **コンテキストアクションメニュー**：任意のカードや一覧項目で右クリックすると、通常の検索結果と同じ **アクションメニュー**（開く、フルパスのコピー、エクスプローラーで表示、ごみ箱へ移動、完全削除）が展開されます。
- **中クリックでの場所表示**：中クリックすると、設定されたファイラーでその項目の場所が即座に開きます。
- **QuickLook プレビューの連動**：項目を選択して `Alt+P` を押すとプレビューパネルが展開され、選択した項目に合わせてリアルタイムに更新されます。

## 4. 集計基準とリアルタイム同期

### 集計の範囲と基準

- **既存インデックスの活用**：Lertaro で有効化されているインデックス内の項目のみを集計し、追加のディスク I/O 走査は行いません。除外ルールに該当するファイルは集計対象外です。
- **論理サイズでの集計**：ファイルの実際の論理サイズを集計し、ハードリンクデータは 1 回のみカウントして重複を防ぎます。
- **隠しファイルとシステムファイル**：隠しファイルは通常どおり集計・表示されます。システムファイルは親フォルダーの合計容量に合算されます。

### リアルタイム同期と自動復帰

- **変更のリアルタイム反映**：ファイルの追加・変更・削除が発生すると、インデックスの更新通知を受け取って自動的かつスムーズに画面を更新します。
- **パスの自動復帰**：閲覧中のフォルダーが外部から削除・名前変更された場合でも、ストレージ分析はアクセス可能な親フォルダーへ自動的かつ安全に戻ります。
