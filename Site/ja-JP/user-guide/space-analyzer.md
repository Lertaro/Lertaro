# 容量分析

容量分析は、Lertaro の既存のファイルインデックスを SpaceSniffer のような高速な視覚表示に変換します。ディスクを走査しないため、複数のドライブに数百万件の項目があってもすばやく開けます。

## 容量分析を開く

Lertaro の完全検索ウィンドウを開き、検索ボックスを空のままにします。容量分析がウィンドウのホームページとして自動的に表示され、Lertaro が現在読み込んでいるすべてのインデックスが示されます。検索語を入力すると直ちに検索結果へ切り替わり、検索語を消すと容量分析のルートへ戻ります。ドライブまたはフォルダーをマウスの左ボタンでダブルクリックするとその中に移動でき、上矢印またはパンくずリストの任意の項目で上の階層に戻れます。

## 表示と操作

- 左側のツリーマップでは、大きな項目ほど広い面積を占めます。明暗は相対的なサイズを表し、枠線の違いでフォルダーとファイルを区別します。
- 右側のリストには同じ項目がサイズの降順で表示され、各行の下にある細いバーが現在の場所で表示されている合計サイズに対する割合を示します。どちらかで項目を選択すると、もう一方でも同期して強調表示されます。
- カードまたはリスト行を右クリックすると、検索結果と同じアクションメニューが開きます。開く、場所を表示、コピー、および該当するプラグインアクションを利用できます。
- カードまたはリスト行を選択し、設定済みのプレビューショートカットを使うと、完全検索ウィンドウのプレビューを開けます。開いたプレビューは、その後の選択に追従します。
- 右側のリストで収まらない名前は、行が選択またはホバーされている間、ツールチップの代わりにスクロール表示されます。

## 集計対象

Lertaro で有効になっているインデックスにすでに存在する項目だけが集計され、容量分析がファイルシステムを走査して不足分を補うことはありません。除外対象と未インデックスの内容は集計されません。隠し項目は通常どおり表示され、システム項目は個別には表示されませんが、そのサイズは表示中の上位フォルダーの合計に含まれる場合があります。

表示されるのはファイルの論理サイズであり、ディスク上の割り当て済み容量ではありません。フォルダーの合計にはインデックス済みの子孫が含まれ、ハードリンクされたデータは一度だけ数えられるため、Windows エクスプローラーやセクターレベルのディスク分析ツールとは結果が異なる場合があります。

容量分析ページが表示されている間は、関連するメモリ内インデックスの変更イベントを自動的に追跡し、連続する通知をまとめてから更新します。ローカルインデックスまたはフォルダーインデックスを有効化、無効化、削除すると、ルート表示は直ちに同期されます。あるディレクトリ内では、そのディレクトリまたは子孫の変更だけが表示を再構築し、上位ディレクトリの変更では現在のパスが引き続き有効かどうかだけを確認します。現在のディレクトリまたはその上位が名前変更、削除、あるいは有効なインデックスから除外された場合は、利用可能な最も近い上位ディレクトリへ自動的に戻ります。インデックスキャッシュファイルを開いたり再読み込みしたりすることはありません。検索を開始すると容量分析の更新は一時停止し、完全検索ウィンドウを閉じると描画済みの項目と共有 UI キャッシュが解放されます。
