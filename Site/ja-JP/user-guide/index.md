# ユーザーマニュアル

Lertaro は、キーボード操作を中心とした Windows 向けの高速ファイル検索ランチャーです。ローカルドライブ (NTFS と ReFS はそれぞれの変更ジャーナル経由、それ以外のファイルシステムは直接監視) とネットワーク共有をバックグラウンドでインデックス化し、任意のファイル・フォルダー・アプリケーションに一瞬でジャンプできるようにします。

このマニュアルでは、日常的に使うユーザーに必要なことをすべて扱います:

- **[はじめに](./getting-started)** — Lertaro のインストール方法と、3 つの検索ウィンドウ (メイン、クイック、インライン) の理解。
- **[検索構文](./search-syntax)** — あいまい検索、除外/完全一致/前方一致/後方一致演算子、OR グループ、ドライブ指定、パスモード、中国語ファイル名向けのピンインエイリアス。
- **[ホットキー](./hotkeys)** — 設定可能なすべてのショートカットとハードコードされたキー、既定の割り当て。
- **[アクションメニューとプレビュー](./actions-and-preview)** — 右クリック風のアクションリストと QuickLook プレビューパネル。
- **[インスタントアンサーとキーワードショートカット](./instant-answers)** — 電卓、環境変数、コマンド実行ショートカット、そしてプロセスマネージャー・ウィンドウ切り替え・ブラウザデータ・設定検索・ウェブ検索といったキーワードで起動するプラグイン。
- **[コマンドライン検索 (lff)](./cli)** — ターミナルから検索するための fzf スタイルの CLI コンパニオン。
- **[URI プロトコル (lertaro://)](./uri-protocol)** — リンク、別のアプリ、またはスクリプトから、検索や特定の設定に直接ジャンプする方法。
- **[対応ファイルマネージャー](./file-manager-support)** — Lertaro がドッキングできる、クイックナビゲーションを起動できる、または現在のフォルダーを検出できるファイルマネージャーとファイル選択ダイアログ。
- **[設定リファレンス](./settings/)** — すべての設定ページ、タブ、オプションの一覧。
- **[トラブルシューティング](./troubleshooting)** — よくある問題とその解決方法。
- **[寄付](./donate)** — Lertaro が役に立ったと感じていただけたなら。

Lertaro を初めてセットアップする場合は、**はじめに** から始めてください。
