# インスタント機能とキーワード拡張

Lertaro はローカルファイルの検索だけでなく、即座に計算結果を返す機能や各種システムツール、キーワード連動型の拡張プラグインを標準搭載しています。ファイル検索の完了を待つことなく、コマンドを入力するだけで即座に結果を得られます。

## 1. プレフィックス不要の即時機能

キーワードを入力しなくても、入力した文字列が特定のパターンに一致すると自動的に起動します。

### 計算機と基数変換

検索ボックスに計算式を直接入力すると、計算結果が 1 行目にリアルタイムで表示されます。`Enter` キーを押すと計算結果がクリップボードにコピーされます。

```text
12 * (4 + 3)
100 * (1 - 0.15)
```

進数変換にも標準で対応しています。

```text
255 to hex
0xFF to dec
101010 to bin
```

### 環境変数の展開と検索

- **変数の展開**：`%NAME%`（例: `%PATH%`、`%APPDATA%`）を入力すると、変数の実際の値が表示されます。`PATH` などの複数のパスを含む変数は、見やすいリスト形式に自動展開されます。
- **変数のあいまい検索**：`%` に続けてキーワードを入力する（例: `%temp`）と、名前にその文字を含むシステム/ユーザー環境変数を検索できます。

### コマンドの直接実行

ターミナルを開かずに検索ボックスから直接コマンドを実行できます。

- `#<コマンド>`：コマンドプロンプトを開き、**管理者権限で実行**します（例: `#sfc /scannow` や `#net start Lertaro.Service`）。
- `$<コマンド>`：コマンドプロンプトを開き、**通常のユーザー権限で実行**します（例: `$ping 1.1.1.1` や `$ipconfig /all`）。

### Web サイトの URL 直開き

`http://` または `https://` で始まる URL を入力または貼り付けて `Enter` を押すと、既定のブラウザでそのページが即座に開きます。検索結果がなく入力が裸のドメイン名で始まる場合、クイック検索ウィンドウは自動的に `https://` を補い、キャレットを末尾へ移動します。すでにプロトコルを含む入力は変更しません。

### クイック検索ウィンドウへのクリップボード文字列の取り込み

入力が事前設定されていない状態でクイック検索ウィンドウを呼び出すと、クリップボードが空でなく、同じウィンドウで直前に取り込んだ値と異なる場合に自動入力して全選択します。同じ値は繰り返し取り込まず、URI やフル検索ウィンドウから戻った際の事前入力も上書きしません。

## 2. キーワード起動機能（内蔵プラグイン）

短い **トリガーキーワード + スペース** の後にクエリを入力することで、専用プラグインの機能を呼び出せます。各キーワードは [**設定 → プラグイン**](./settings/plugins) で自由に変更可能です。

| 既定のキーワード | プラグイン名 | 機能概要と活用シーン | 入力例 |
| :--- | :--- | :--- | :--- |
| `ps` | **プロセス管理** | 実行中のプロセスを名前、PID、ウィンドウタイトル（ピンイン対応）で検索し、Enter キーで即座に終了。 | `ps chrome` や `ps 1234` |
| `win` | **ウィンドウ切り替え** | 開いているウィンドウを検索して切り替え。バックグラウンドでのリアルタイムサムネイル取得に対応。 | `win code` や `win ブラウザ` |
| `bm` | **ブラウザーデータ** | Chrome、Edge、Firefox などのブックマークや閲覧履歴を検索（履歴とブックマークは個別に有効化可能）。 | `bm github` |
| `set` | **設定検索** | Lertaro 内部のすべての設定項目をあいまい検索。選択すると該当する設定画面へ直接ジャンプしてハイライト。 | `set ホットキー` や `set あいまい` |
| `flow` | **Flow プラグインブリッジ** | 読み込まれている Flow.Launcher プラグインとそのトリガーワードを一覧表示。 | `flow` |
| `cs` | **コンテンツ検索** | インデックス済みローカル文書の本文を検索し、スニペット付きでファイルを表示。 | `cs プロジェクト計画` |

## 3. Web 検索エンジン連携

Web 検索プラグインには主要な検索エンジンのショートカットが組み込まれており、プレフィックスに続けて検索語を入力するとブラウザで検索を実行できます。

| キーワード | 検索エンジン | 入力例 | 説明 |
| :--- | :--- | :--- | :--- |
| `bd` | 百度 (Baidu) | `bd 深度学習` | Baidu で検索 |
| `g` | Google | `g lertaro github` | Google で検索 |
| `bing` | Bing | `bing マイクロソフト ドキュメント` | Bing で検索 |
| `gh` | GitHub | `gh Lertaro` | GitHub リポジトリを直接検索 |
| `wiki` | Wikipedia | `wiki 量子力学` | Wikipedia の項目を検索 |
| `yt` | YouTube | `yt lofi hip hop` | YouTube 動画を検索 |

**設定 → プラグイン → Web 検索 → 設定** で検索エンジンの追加、編集、削除、URL テンプレートの変更が可能です。

## 4. インスタント翻訳

既定のトリガーワード `tr` の後にテキストを入力すると、Lertaro で現在選択されている UI 言語に自動翻訳されます。

```text
tr Hello, how are you today?
```

- 入力中に非同期で翻訳結果が表示され、`Enter` キーで訳文をコピーできます。
- **設定 → プラグイン → 翻訳 → 設定** でトリガーワードの変更が可能です。

## 5. ファイルフィルター

**設定 → プラグイン → ファイルフィルター → 設定** で、特定のフォルダーや拡張子に限定した専用の検索スコープを作成できます。

- **対象フォルダーの指定**：特定の作業ディレクトリ（例: `D:\Engineering\Drawings`）を再帰的にスキャン。
- **拡張子ルールの指定**：`*.dwg;*.dxf` や `*.pdf;*.docx` などのパターンを指定。
- **トリガーキーワードの割り当て**：専用のプレフィックス（例: `cad`）を割り当て、`cad パーツ図` のように特定の業務ファイルだけを切り離して検索可能。

## 6. カスタムコマンド

**設定 → プラグイン → カスタムコマンド → 設定** で、よく使うスクリプトやツール、外部アプリを簡単なコマンドとして登録できます。

- **パラメータプレースホルダー**：位置プレースホルダー `%s1`、`%s2`... や、キーワード以降の全文を受け取る `%s` に対応。
- **クイックナビゲーションへの登録**：「クイックナビゲーションに表示」を有効にすると、[**クイックナビゲーション**](./hotkeys#3-クイックナビゲーションマウス操作) メニューにピン留めされ、`/` を使った多階層分類（例: `開発ツール/サービス再起動`）も可能です。
