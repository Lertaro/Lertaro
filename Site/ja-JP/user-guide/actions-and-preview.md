# アクションメニューと即時プレビュー

Lertaro は超高速なファイル検索だけでなく、充実したコンテキストアクション機能と強力なプレビューパネルを統合しており、エクスプローラーを開くことなくファイルの確認、管理、共有を行えます。

## 1. アクションメニューの詳細

クイックウィンドウでは、選択中の結果に対して `Ctrl+O` または方向キー `→` を押すとコンテキストアクションメニューが展開されます。ただし `→` はキャレットがすでに検索語の末尾にあるときだけ機能するため、文章の途中を編集中にカーソル移動が奪われることはありません。同じキーはファイルダイアログ**外**のインラインウィンドウでも使えますが、「開く/保存/フォルダーの参照」ダイアログにドッキングしたウィンドウにはアクションメニュー自体がありません。メイン検索ウィンドウではどちらのキーにも割り当てられておらず、結果を右クリックするか `Apps` キー（`Shift+F10`）を押すと同じメニューが開きます。

すべての行にメニューがあるわけではありません。**さらに表示** 行、プラグインが提供した結果、URL のお気に入り、どのプロバイダーも引き受けなかったインスタント結果、クイックウィンドウ以外でのアプリ、そしてすべてのファイルダイアログではメニューを表示しません。そうした行では、空のパネルを開く代わりにメニューキーは何もしません。

### 標準アクション一覧

| アクション名 | 既定のキー | 機能説明 |
| :--- | :--- | :--- |
| **開く** | `Enter` | システムの既定プログラムでファイルを開くか、アプリを起動します。メイン検索ウィンドウでは、`Enter` もダブルクリックも**選択したすべての行**に適用されます。 |
| **エクスプローラーで表示** | `Ctrl+Enter` | 親フォルダーを開き、エクスプローラー上で対象ファイルを選択した状態で表示します。 |
| **管理者として実行** | `Ctrl+Shift+Enter` | 管理者権限でプログラムを実行します（実行可能ファイル、ショートカット、バッチ等に対応）。 |
| **フルパスをコピー** | `Ctrl+Shift+C` | 絶対パス（例: `D:\Projects\app.exe`）をクリップボードにコピーします。 |
| **名前をコピー** | `Shift+C` | 選択したファイルやフォルダーの名前を、パスなしでクリップボードにコピーします。 |
| **ファイルのコピー** | `Ctrl+C` | ファイル自体をクリップボードに格納し、エクスプローラーや別フォルダーに直接貼り付け可能にします。 |
| **切り取り / ファイルのコピー** | `Ctrl+X` / `Ctrl+C` | ファイル自体をクリップボードに格納し、エクスプローラーや別フォルダーに直接貼り付け可能にします。検索ボックス内でテキストが選択されている間は、これらはテキストに対する操作のままです。 |
| **ここへ貼り付け** | `Ctrl+V` | フォルダーが選択されているとき、クリップボード上のファイルをそのディレクトリへ直接貼り付けます。実行には実体のファイル一覧がクリップボードに必要なので、検索語へテキストを貼り付ける操作は影響を受けません。 |
| **削除（ごみ箱へ移動）** | `Delete` | 選択したファイルやフォルダーをごみ箱へ安全に移動します。修飾キーのないこのキーがアクションに届くのは、キャレットがすでに検索語の末尾にあるときだけであり、その後にごみ箱への移動を問うネイティブの確認ダイアログが表示されます。 |
| **完全に削除** | `Shift+Delete` | 選択項目を完全に削除します（ネイティブの「完全に削除しますか」の確認ダイアログが表示され、そのあとでは復元できません）。 |
| **名前を変更** | — | Windows Shell を使って、存在するファイルまたはフォルダー 1 件の名前を変更します。ダイアログでは名前部分があらかじめ選択されます。 |
| **Windows 右クリックメニュー** | — | Windows エクスプローラーの標準コンテキストメニュー（送る、サードパーティ製ツールの項目を含む）を展開します。 |

### アクションメニューの操作と絞り込み

- **入力して即時絞り込み**：アクションメニューが開いた状態で文字を入力すると、アクション名で素早く絞り込めます（例: `copy` と入力してコピー関連の操作を即座に抽出）。絞り込みボックスがキーボードを受け持つため、ほかへ移動しても元の検索語には一切触れません。
- **アクセスキー文字**：アクションには強調表示された 1 文字が付くことがあります。そのキーを押すと**即座にアクションが実行されます**（ハイライトされるだけではありません）。ただしそれは絞り込みボックスがまだ空のあいだだけで、絞り込みのために打った 1 文字目が奪われることはありません。
- **独立した検索ボックス**：アクションメニューには独立した検索ボックスがあり、開くと自動的にフォーカスされます。アクションの絞り込みはメインの検索語を変更しません。階層を切り替えると絞り込み文字列が消去され、新しい階層の検索ボックスにフォーカスが移ります。
- **フローティングアクションパネル**：クイックウィンドウ、クイック起動パネル、メイン検索ウィンドウでは、アクションが対象項目の近くにフローティングパネルとして表示されます。クイック起動パネルは一時的にアクション一覧の最大作業高さへ広がり、閉じると元のコンパクトな高さに戻ります。
- **階層ナビゲーション**：サブメニューを持つ項目（「送る」など）で `→`、`Tab` または `Enter` を押して下の階層に進み、`←` またはテキストが空の状態で `Backspace` を押すと親階層に戻ります。入れ子のメニューでは `Escape` または右クリックで親階層に戻り、ルートではアクションメニューを閉じます。
- **ナビゲーションキーが引き続き動作する**：設定済みの次/前の項目のホットキー（既定は `Ctrl+N` / `Ctrl+P`）は、アクション一覧の中でもハイライトを移動します。先頭と末尾をまたいでループ移動し、区切り線・見出し・無効化されたアクションはスキップします。`Tab` は、それらのキーのいずれかに割り当てていない場合に限りサブメニューへ入ります。
- **外側をクリックして閉じる**：フローティングパネルの外側をクリックするとパネルが閉じます。ホストが対応している場合、パネルを開いたまま別の結果を右クリックすると対象だけがその場で置き換わります。
- **アクションのショートカット**：パネルにフォーカスがある間は、プロバイダーが定義したアクションショートカットを使用できます。実行後はフローティングパネルだけが閉じ、メイン検索ウィンドウまたはクイック起動パネルは開いたままになります。

## 2. メインウィンドウの一覧機能

メイン検索ウィンドウ（`Ctrl+F`）は、大量のファイル管理と詳細なブラウジングのために設計されています。

- **パス列のダブルクリック移動**：結果一覧の **名前** 列をダブルクリックするとファイルが開き、**パス** 列をダブルクリックするとそのファイルが存在する親フォルダーが直接開きます。ダブルクリックは*左*ボタンに限られ、列ヘッダーをダブルクリックした場合は代わりにウィンドウの最大化と元への復帰が行われます。
- **複数選択**：グリッドは通常の Windows リストとして振る舞います。`Ctrl`+クリックで行を追加または解除し、`Shift`+クリックで範囲を選択し、そのあとの `Enter` またはダブルクリックは**選択したすべての行**へ一括で作用します。すでに選択の一部である行を右クリックすると、その 1 行だけに縮めず選択全体を保ちます。
- **ストリーミング結果表示**：数百万件のファイルをスキャンする際も、インデックスエンジンから届いた結果がリアルタイムに順次一覧へ追加されます。検索全体の完了を待つことなく即座に操作が可能で、行が追加されても選択とスクロール位置は保たれます。まったく新しい結果セットのときだけ先頭からやり直します。
- **ループナビゲーション**：先頭行で `↑` を押すと末尾行へ、末尾行で `↓` を押すと先頭行へループ移動します。同じループはクイックウィンドウとインラインウィンドウでも適用され、まだ何も選択していない状態で `↑` を押すと末尾行へ、`↓` を押すと先頭行へ移動します。グループを 1 続きのリストとして**ループせずに**辿るのはクイックパネルだけです。
- **横スクロール**：グリッドの上で `Shift` + ホイールを回すと 1 目盛りにつき 3 列分スクロールします。狭いウィンドウで端の列まで届くための方法です。
- **ファイルのドラッグアウト**：任意の行を実際のファイルドロップとしてエクスプローラー、ダイアログ、チャットウィンドウへ直接ドラッグできます。複数選択中のいずれかをドラッグすると**選択全体**が一緒に運ばれます。Lertaro の外へドロップするとウィンドウは隠れますが、ドラッグ中はクローズが待たされるため、ドラッグカーソルが残り込むことはありません。
- **選択数の表示**：複数の行を選択すると、ステータスバーに結果総数とともに現在の選択数が表示されます。
- **ホバープレビュー**：プレビューパネルが開いた状態で行にポインターを動かすと、選択を変えずにプレビュー対象だけ切り替わります。候補を次々となぞってから、戻ってきた行で `Enter` を押すことができます。
- **ウィンドウのドラッグ移動とサイズ記憶**：ウィンドウ上部の余白部分はドラッグバーとして機能し、手動で調整したウィンドウサイズは次回起動時にも自動的に保持されます。

## 3. QuickLook 即時プレビュー機能

プレビュー可能な結果で `Alt+P` を押すと、検索ウィンドウの横にドッキングされたプレビューパネルが表示されます。**行を中クリック**しても同じパネルを開閉できます。ファイルダイアログのインラインウィンドウではどちらも用意されておらず、クイックパネルでは両方使えます。

### プレビューにキーボード操作はない

このパネルは意図的にアクティブ化されません。検索ウィンドウからフォーカスを奪うことはないため、入力する先は存在せず、`Escape` でも閉じません。`Alt+P` で切り替えるか、ドッキング元のウィンドウを閉じて隠してください。メディア再生バー、スクロールバー、プラグインカードなど、パネルの操作要素はすべてマウス専用で、キーボードのフォーカスはあった場所にそのまま残ります。

### 多彩なファイル形式に対応

- **画像とベクター形式**：JPG、PNG、GIF（アニメーション自動再生）、BMP、WebP、ICO、SVG などの高解像度プレビュー。
- **ドキュメントとコード構文**：TXT、Markdown、JSON、XML、YAML、C#、Python、JS、HTML などのシンタックスハイライト表示。
- **音声・動画の即時再生**：MP4、MKV、AVI、MOV、WMV、MP3、WAV、FLAC、WMA などのメディアファイルはプレビューを開くと**自動的に再生が開始**され、テーマ連動のミニ再生バー（再生/一時停止、シークバー、再生時間、ミュート）が表示されます。項目の切り替えで即座に停止します。
- **フォルダー構造の確認**：フォルダーを選択すると、直下のアイテム上位 30 件がアイコン・サイズ付きで表示されます（隠しファイルやシステムファイルは除外）。

### レイアウトとダイアログの自動回避

- **画面範囲の自動調整**：プレビューサイズは [**設定 → 一般 → プレビュー**](./settings/general#プレビュー) で変更可能で、画面外にはみ出さないよう自動制御されます。
- **ドッキングする側**：パネルは検索ウィンドウの**右**側にドッキングし、右に収まらないときだけ左へ反転します。広い側を追いかけて移動することはしないため、広いウィンドウをスクロールしても同じ位置に留まります。以降はオーナーのウィンドウを移動・サイズ変更するとついていきます。
- **サイズ記憶はセッション単位**：リサイズグリップのドラッグやパネルの移動は、プレビューを使い続けているあいだは記憶されますが、検索ウィンドウが次に隠れるか閉じられた時点で、設定済みのサイズとドッキング側に戻ります。
- **ネイティブダイアログの自動回避**：パスワード保護された Office 文書などをプレビューする際、パスワード入力ダイアログが表示されると Lertaro は一時的にウィンドウを隠し、操作完了後に自動復帰します。
- **プレビューからのドラッグ＆ドロップ**：プレビューパネルの上部をドラッグすることで、プレビュー中のファイルを外部アプリやエクスプローラーへ直接ドロップできます。フッターバーをドラッグするとパネル自体が移動します。

## 4. プラグインのリッチテキスト・対話型プレビュー

QuickLook はローカルファイルだけでなく、プラグインによる対話型プレビューにも対応しています。

- **テーマ適応型リッチテキスト**：WebView2 およびネイティブコンポーネントで描画され、ダーク/ライトテーマに自動追従し、高コントラストフォントと半透明スクロールバーで美しく表示されます。
- **多彩なプラグインカード**：辞書検索カード、リアルタイム天気予報、Web スナップショット、API レスポンス確認などの対話型パネルをサポートします。

## 5. サードパーティ製 QuickLook との連携（任意）

独立したオープンソースツール **QuickLook**（[GitHub の QL-Win/QuickLook](https://github.com/QL-Win/QuickLook)）をお使いの場合、[**設定 → プラグイン**](./settings/plugins) で **QuickLook ブリッジ** プラグインを有効化できます。

- **プレビューの委譲**：ローカルの名前付きパイプ経由で外部の QuickLook プロセスに接続し、プレビューウィンドウを Lertaro の横に吸着表示します。
- **自動フォールバック**：外部の QuickLook が起動していない場合は、Lertaro 内蔵のプレビューエンジンへ自動的に切り替わります。

## 6. ファイル占有の解除

公式の**ファイル占有解除**プラグインは、存在するファイルを 1 件だけ選択したときにアクションを追加します。ファイルを使用中のプロセス、その PID、実行ファイルのパスを一覧表示し、プロセスにファイルの解放を要求できます。フォルダー、存在しないファイル、複数選択ではアクションを実行できず、占有プロセスがない場合は解放要求ボタンも無効になります。ダイアログはホストのテーマに従い、検索ウィンドウより手前に表示され、Alt+Tab には表示されません。再読み込みにも対応しています。

## 7. お気に入りに追加

CoreExtensions には、存在するファイルまたはフォルダーを 1 件だけ追加できる**お気に入りに追加**アクションがあります。テーマ対応ダイアログで表示名を入力でき、同じパスがすでにお気に入りの場合はアクションを表示しません。

## 8. 名前を変更

CoreExtensions には、存在するファイルまたはフォルダーを 1 件だけ変更できる**名前を変更**アクションがあります。テーマ対応ダイアログには現在の完全な名前が表示され、名前部分があらかじめ選択されます。たとえば `report.pdf` では `report` のみが選択され、フォルダーや拡張子のない名前では名前全体が選択されます。`Enter` で確定し、`Esc` でキャンセルできます。確定後の名前変更は Windows Shell に委譲されます。
