# アクションメニューとプレビュー

## アクションメニュー

ファイル、フォルダー、アプリのすべての検索結果には、「直接開く」以外にも一連のアクションが用意されています：エクスプローラーで表示、パスをコピー、管理者として実行、ファイルの切り取り/コピー/貼り付け、削除（ごみ箱へ移動）または完全削除、およびプラグインによって追加されたアクション（カスケードサブメニューを含む完全な Windows 右クリックメニューなど）。

**アクションメニューを開く**ショートカット（デフォルトは `Ctrl+O`）を押すか、選択した結果上で右矢印キーを押すと開きます。メニュー内での操作：

- **次/前の項目** — 矢印キー、または設定した[次/前の項目ショートカット](./hotkeys)で強調表示を移動できます。単体の `Tab` キーなどのカスタム割り当てであっても、メインの検索結果リストとまったく同様に動作します。
- サブメニューを持つ項目（「送る」などのカスケードメニュー）で**右矢印キー / Enter**を押すとサブメニューに入ります。**左矢印キー**または（検索ボックスが空の場合の）**Backspace**で 1 階層戻ります。
- **Escape** でアクションメニューを終了します。アクションリストを絞り込むために文字を入力していた場合は、まず検索ボックスがクリアされます。
- 文字を入力すると、検索結果の絞り込みと同様に、現在表示されているアクションを名前で絞り込めます。

## フルウィンドウの結果グリッド

結果をダブルクリックすると通常は Enter を押したときと同様に開きますが、1 つだけ例外があります：**パス**列をダブルクリックすると、その行の他の場所で `Ctrl`+Enter を押したときと同様に、その項目を含むフォルダーがエクスプローラーで開きます。プラグインのカスタム列でも同様のダブルクリック動作を独自に定義できます。

グリッドには固定ページへの切り捨てではなくすべての検索結果が保持され、検索が完了するのを待って一度に表示されるのではなく、結果が届くにつれて順次追加されます。大容量ドライブでの広範な検索には数秒かかる場合がありますが、その間も各行は常に操作可能です。矢印キーによる移動は両端で循環します：先頭行で ↑ を押すと末尾行に移動し、末尾行で ↓ を押すと先頭行に戻ります。

このウィンドウにはタイトルバーがなく、上部領域がドラッグ領域となっています：検索ボックスやウィンドウボタン以外の場所を押してドラッグすると、ウィンドウを移動できます。ポインターが上部領域にあるときは、上部にグラブ可能な位置を示すバーがフェードインします。

## QuickLook プレビュー

選択した結果上で **QuickLook** ショートカット（デフォルトは `Alt+P`）を押すと、検索ウィンドウの横に固定されたプレビュー パネルが開き、画像やドキュメントなどのプレビュー可能なファイルタイプを Lertaro を離れることなく確認できます。もう一度押す（または QuickLook でプレビューできない結果に切り替える）と閉じます。

フォルダーのプレビューでは、最大 30 個の直下の子項目がファイルまたはフォルダーのアイコンとともに一覧表示されます。Windows エクスプローラーが隠し項目を表示するように設定されている場合でも、プレビューでは隠し項目とシステム項目が除外されます。

オーディオおよびビデオ ファイル（WPF の組み込み再生機能により追加のコーデックなしでサポートされる形式：MP4、WMV、AVI、MOV、MP3、WAV、WMA など）は、プレビューを開くとすぐに自動再生され、静止画サムネイルではなくテーマに合わせた小さな再生コントロール（再生/一時停止、シーク、現在/合計時間、ミュート）が表示されます。別の結果に切り替えるかプレビューを閉じると、再生は直ちに停止します。特定のファイルのコーデックをデコードできない場合は、静止画サムネイルの表示にフォールバックします。

プレビュー ウィンドウのサイズは固定されており、ユーザーが設定可能です（[設定 → 一般 → プレビュー](./settings/general#プレビュー)を参照）。現在表示されている結果の数には影響されません。どのようなサイズに設定しても、Lertaro はプレビュー ウィンドウが画面内に収まるように自動的に調整します：設定したサイズが検索ウィンドウと並んで画面に収まらない場合は、スペースのある側に自動的に固定されます。設定したサイズ自体がディスプレイの有効領域よりも大きい場合は、画面外にはみ出すことなく収まるように縮小されます。

プレビュー中のファイルが独自のネイティブ ハンドラーによるポップアップを必要とする場合（暗号化されたドキュメントのパスワードを求める Word や Excel など）、そのポップアップが開いている間、クイック ウィンドウとプレビュー パネルの両方が自動的に非表示になります。ポップアップを処理（パスワードを入力して閉じるなど）すると、検索テキストと選択状態を保持したまま両方のウィンドウが元の状態に復元されます。

プレビュー ウィンドウのヘッダー自体がプレビュー中ファイルのドラッグ ソースとなっており、エクスプローラー、エディター、またはその他のドロップ先にドラッグすると、検索ウィンドウから結果行をドラッグしたときとまったく同じように動作します。

### プラグインとインタラクティブプレビュー

ローカルファイルやフォルダーに加えて、QuickLook はプラグインが提供するカスタム インタラクティブ プレビュー パネル（MDict 辞書定義、天気カード、API インスペクター、Web プレビューなどの Flow Launcher プラグイン）もサポートしています。

インスタントプレビュー機能を持つプラグインの検索結果を選択すると、QuickLook が自動的にプレビュー パネルを展開し、結果間を移動してもポップイン アニメーションを繰り返すことなくコンテンツをスムーズに更新します。WebView2/HTML ベースのプレビューでは、Lertaro がテーマに応じたタイポグラフィ（Segoe UI、メイリオ）、高コントラストなダーク/ライトスタイル、スリムな半透明スクロールバーを自動的に適用します。

クイック ウィンドウからフル ウィンドウを開くとプレビューの開閉状態が引き継がれるため、すでに開いていたプレビューは開いたままになります。

### QuickLook による外部プレビュー（オプション）

同じ名前ですが、これは上記の組み込みプレビュー パネルとは別のものです：ご自身でインストールしていただく別のサードパーティ製アプリケーション **QuickLook**（[GitHub の QL-Win/QuickLook](https://github.com/QL-Win/QuickLook)、GPL ライセンス）を指します。Lertaro には同梱されていません。

インストールされて実行されている場合、付属の（実験的）**QuickLook Bridge** プラグイン（[設定 → プラグイン](./settings/plugins)で表示・切り替え可能）が専用の名前付きパイプを介して接続し、上記のすべての組み込みプレビュー タイプよりも優先してプレビュー処理を引き継ぎます。この間、Lertaro 自身のプレビュー パネルは非表示になり、QuickLook の独立したフローティング ウィンドウがプレビュー パネルの表示位置に移動されます。

アクションメニューの **QuickLook でプレビュー** を使用すると、他の組み込みプレビュー タイプが優先される場合でも、結果を手動で QuickLook に送信してプレビューできます。

これは公開された統合 API ではなく、QuickLook 独自の非公開なプロセス間通信プロトコルに完全に依存しているため、今後の QuickLook の更新によってプロトコルが変更され、機能しなくなる可能性があります。QuickLook をアンインストールまたは終了しても他の機能には影響せず、Lertaro は自身の組み込みプレビュー タイプにフォールバックします。
