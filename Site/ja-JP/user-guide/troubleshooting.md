# トラブルシューティング

Lertaro の使用中に問題が発生した場合は、以下の手順に従って原因を確認・解決してください。

## 1. グローバルホットキーが反応しない

- **バックグラウンドサービスの状態確認**：[**設定 → サービス状態**](./settings/service-status) を開き、`Lertaro.Service` が「実行中」であることを確認してください。通常のホットキーは App が処理しますが、昇格フックの常駐はサービスに依存しています。
- **管理者権限の分離（UIPI）**：フォアグラウンドのアプリが管理者権限で実行されている場合（例: 管理者コマンドプロンプトやタスクマネージャー）、Windows のセキュリティ機能（UIPI）により低権限プロセスからのキー入力がブロックされます。Lertaro はサービス経由でフックを自動昇格させますので、サービスが実行中であることを確認してください。
- **プロセスブラックリストの確認**：[**設定 → ホットキー**](./settings/hotkeys-page#プロセスブラックリスト) で、操作中のアプリが「プロセスブラックリスト」に含まれていないか確認してください。リスト内のアプリがアクティブな場合、Lertaro はホットキーを意図的にスルーします。
- **全画面アプリでの自動バイパス**：フルスクリーンのゲームや動画プレイヤーがアクティブな場合、操作を妨げないようホットキーは既定で無効化されます。全画面時も呼び出したい場合は、**設定 → ホットキー** で **全画面アプリフォーカス時も応答する** を有効にしてください。

## 2. 検索結果が更新されない・古い

- **NTFS / ReFS ドライブ**：ファイルシステムの USN 変更ジャーナルを読み取ることで、遅延ゼロのミリ秒単位でリアルタイム更新されます。
- **FAT32 / exFAT ドライブ**：ファイルシステムの変更イベントにより継続的に監視されます。
- **手動でのインデックス再構築**：PC の強制終了等でインデックスの整合性が崩れた場合は、[**設定 → インデックス → ローカルドライブ**](./settings/index-drives) で該当ドライブの **インデックス再構築** を実行してください。

## 3. ネットワークドライブが自動更新されない

- **定期スキャンの仕組み**：ネットワーク共有（SMB / NAS）にはローカルの変更ジャーナルが存在しないため、定期ポーリングに依存します。
- **更新モードの確認**：[**設定 → インデックス → ネットワークドライブ**](./settings/index-drives#ネットワークドライブ) で、更新モードが「手動」になっていないか確認してください。手動の場合は定期更新に切り替えるか、「インデックス再構築」をクリックしてください。
- **シンボリックリンク循環保護**：NAS 上の循環シンボリックリンクによる無限ループを防ぐため、ループ検知機能が自動で重複パスをスキップします。

## 4. 特定のファイルやフォルダーが見つからない

- **除外ルールの確認**：[**設定 → インデックス → 除外ルール**](./settings/index-drives#除外ルール) を確認し、完全パス、ワイルドカード、正規表現によって誤って除外されていないか確認してください。
- **ドライブの有効化確認**：[**設定 → インデックス → ローカルドライブ**](./settings/index-drives) で、対象のドライブが有効になっていることを確認してください。

## 5. インラインウィンドウで日本語 IME の候補窓が出ない

- **非フォーカス設計の特性**：[インラインウィンドウ](./getting-started#3-3-つのウィンドウ形態) は、閉じた後に元のアプリへ瞬時に操作を戻すため、キーボードフォーカスを奪わない設計になっています。IME の候補窓は Windows の正規フォーカスを必要とするため、インラインでは表示されない場合があります。
- **推奨する対処法**：
  1. **クイックウィンドウを利用**：`Ctrl` 2 回連打で開くクイックウィンドウは完全なフォーカスを持つため、すべての IME が正常に動作します。

## 6. ログの確認と Issue の報告

上記の手順で解決しない場合は、[**設定 → サービス状態**](./settings/service-status) でログを確認してください。

- **Service ログ**：インデックス作成、USN ジャーナル、ネットワークスキャン、IPC 通信のログ。
- **App ログ**：UI 描画、プラグイン、ホットキー、設定変更のログ。
- **Hook ログ**：グローバルキーフックおよびマウス操作イベントのログ。

検索ボックスや重要度フィルター（Info / Warn / Error）を活用してエラーを特定し、GitHub Issue を報告する際にログを添付してください。
