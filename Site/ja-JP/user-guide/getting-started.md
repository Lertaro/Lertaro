# はじめに

## インストール

ホームページの[ダウンロードボタン](../)から最新リリースを入手してください。各リリースでは 2 種類の形式が公開されています:

- **インストーラー** (`Lertaro-Setup.exe`) — 推奨。バックグラウンドのインデックスサービスを登録し、Lertaro を Windows と共に起動できるようにします。
- **ポータブル版** (`Lertaro-Portable.zip`) — 解凍して実行するだけで、インストールは不要です。バックグラウンドサービスは後から **設定 → サービスの状態** でインストールすることもできます。お使いのマシンに Lertaro が必要とする .NET Desktop Runtime がまだ入っていない場合は、同梱されている `install-dotnet-runtime.bat` を一度実行してください — インストーラー版ではこの手順は自動的に行われますが、ポータブル版では自動化されていません。ポータブル版の利用を終える際には、後片付けをしてくれるアンインストーラーがありません。フォルダーを削除する前に、同梱の `portable-cleanup.bat` を実行してください。サービスがインストールされている場合は Lertaro のバックグラウンドサービスを停止・削除し、現在のユーザーに登録された `lertaro://` URI プロトコルと「Windows と共に起動する」項目も削除します。サービスの削除では管理者権限の確認が表示される場合がありますが、それ以外の処理は現在のユーザーに対して行われます。

このいずれもが **x64** 版と **ARM64** 版として公開されています。上記の名前は x64 版で、最近の PC であればどれでも動作します — Windows on ARM でもエミュレーションで動作します。ARM のマシンでは、ネイティブに動作する `Lertaro-Setup-arm64.exe` または `Lertaro-Portable-arm64.zip` をお使いください。自動更新はインストールした際のアーキテクチャを維持するため、もう一方に移行するには自分でダウンロードする必要があります。

## ポータブル データ

ポータブル版は、アプリケーションの横にある `Data\Machine` にマシン データを、`Data\Users\<SID hash>` に各ユーザーのプライベート データを保存します。`Data` フォルダーがまだ作成されていない場合は、互換性のため既存の `%ProgramData%\Lertaro` と `%LocalAppData%\Lertaro` のデータを再利用します。`Data` を作成すると、このポータブル版が自身のデータを優先して自己完結したコピーになります。

初回起動時、Lertaro はファイルのインデックス化を担う Windows サービス (`Lertaro.Service`) をインストールして起動します。この分離構成は意図的なものです — 理由が気になる方は[アーキテクチャ](../dev-guide/architecture)を参照してください — が、ユーザーとして知っておく必要があるのは、**設定 → サービスの状態** でサービスがインストール済みかどうか、実行中かどうかを確認でき、インストールされていなければそこからインストールできる、ということだけです。

## 3 つのウィンドウ

Lertaro には検索ウィンドウが 1 つだけではなく、使い方に応じて適応する複数のウィンドウがあります:

- **メインウィンドウ** — タスクバーやスタートメニューのショートカットから開くフルサイズのウィンドウで、最も大きな検索結果リストと、ウィンドウ内のアクションパネルを備えています。
- **クイックウィンドウ** — グローバルなトグルホットキー (既定では `Ctrl` のダブルタップ) で呼び出す、コンパクトで常に最前面に表示されるポップアップです。「ホットキーを押す → 入力する → Enter」という一連の動作を素早く行えるように作られています。
- **インラインウィンドウ** — 対応するネイティブのファイルダイアログやエクスプローラーのウィンドウに Lertaro の検索バーを直接埋め込みます。すでに開いているダイアログから離れることなく検索できます。

3 つのウィンドウはいずれも同じ検索エンジン、ホットキーシステム、アクションメニューを共有しています。違いは、どこに、どのように表示されるかだけです。

## 基本的な検索

最近使ったファイル・お気に入り・履歴は、何も入力せずに取り出せます — これらは[クイックパネル](./settings/quick-panel)のタブで、このパネルは検索ウィンドウの中ではなく、前面にあるウィンドウに重ねて開きます。

そのまま入力を始めてください。検索結果は入力するたびに更新され、関連性に基づいて並び替えられます (マッチングとランキングの仕組みについては[検索構文](./search-syntax)を参照)。選択を移動するには[設定可能な次/前のアイテム用ホットキー](./hotkeys) (既定では矢印キー) を使用し、Enter でハイライトされている検索結果を開きます。

次は [検索構文](./search-syntax) で、クエリボックスを最大限に活用する方法を確認しましょう。
