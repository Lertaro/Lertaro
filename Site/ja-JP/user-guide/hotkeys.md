# ホットキーとマウス操作

Lertaro はキーボード優先の操作設計を採用しつつ、多彩なマウスジェスチャーと階層型クイックナビゲーションを提供します。固定キーを除き、すべてのグローバルおよびアプリ内ホットキーは [**設定 → ホットキー**](./settings/hotkeys-page) で自由にカスタマイズできます。

## 1. グローバルホットキー一覧

| 機能・アクション | 既定のキー | 機能説明と操作の詳細 |
| :--- | :--- | :--- |
| **クイックウィンドウの表示/非表示** | `Ctrl` の 2 回連打 | 連打方式または通常の修飾キー組み合わせ（例: `Alt+Space` など）に変更可能です。連打は**同じ**修飾キーを 2 回押して **100〜300 ms** をおいて離す操作を指します。左右の `Ctrl` は別のキーであり、その間に他のキーを押すとカウントはやり直しになります。連打方式では修飾キー自体が吸収されないため、通常の `Ctrl`+`C` 系のショートカットはそのまま動作します。**既定でメインウィンドウを開く**を有効にすると、このキーでメインウィンドウを開き、初回表示時は一度だけ前面とフォーカスを処理します。表示中で非アクティブなら再アクティブ化し、すでにアクティブならもう一度押すと既定ではクイックウィンドウへ戻り、**ショートカットの再入力でフルウィンドウを閉じる**を有効にした場合はそのまま閉じます。自動的に最前面へ固定されることはありません。 |
| **クイックジャンプ（Quick Jump）** | `Ctrl+G` | ファイルダイアログ内で、直前にエクスプローラー、対応するファイラー、またはファイルダイアログで開いていたフォルダーへ移動。 |
| **クイックナビゲーションメニュー** | 既定値なし | 任意のグローバルショートカットで階層型クイックナビゲーションメニューを開けます。デスクトップや通常のアプリではデスクトップのコンテキストを使い、エクスプローラーやネイティブのファイルダイアログではアクティブなウィンドウのコンテキストを使います。通常の前景保護でグローバルホットキーが抑止される場合でも、ファイラーとファイルダイアログは許可されます。 |
| **次の項目を選択** | `Ctrl+N` または `↓` | 一覧の選択を下に移動。クイックパネルではグループをまたいで連続して移動できます。クイック起動パネルでは方向キーが見た目のグリッドに沿って動き、左右は読む順序で行の境界を越え、上下は現在の列を保ったまま隣接行間のみを移動し、対象行のその列に項目がなければ現在の位置に留まります。クイック起動パネルが表示され検索語が空の場合、`Ctrl+N` で次のソースへ循環します。 |
| **前の項目を選択** | `Ctrl+P` または `↑` | 一覧の選択を上に移動。クイックパネルでもグループをまたいで連続して移動できます。クイック起動パネルでは方向キーが見た目のグリッドに沿って動き、左右は読む順序で行の境界を越え、上下は現在の列を保ったまま隣接行間のみを移動し、対象行のその列に項目がなければ現在の位置に留まります。クイック起動パネルが表示され検索語が空の場合、`Ctrl+P` で前のソースへ循環します。 |
| **1〜9 番目の結果を開く** | `Ctrl` + `1`〜`9` | 修飾キーは変更可能。クイックウィンドウの結果横に数字バッジが表示され、押すと対象項目を開ける。数字は**最初に見えている行からの** N 番目の選択可能な行を意味するため、スクロールするとバッジの番号は振り直されます。`0` は割り当てられていません。クイック起動パネルだけが例外で、`1`〜`9`、`0`、`A`〜`Z` まで最大 36 タイルに割り当てられます。 |
| **アクションメニューを開く** | `Ctrl+O` または `→` | 選択中の項目のコンテキストアクション（パスのコピー、プロパティ、管理者実行、ファイル操作等）を展開。クイックウィンドウと、ファイルダイアログ**外**のインラインウィンドウで使えます。メインウィンドウでは同じメニューを右クリックまたは `Apps` キー（`Shift+F10`）で開きます。 |
| **選択項目で検索語を補完** | `Ctrl+Tab` | 選択項目の名前またはフルパスを検索ボックスに入力し、追加の絞り込みを容易にする。 |
| **QuickLook 即時プレビュー** | `Alt+P` | プレビューパネルの開閉（画像、文書、音声・動画の即時再生、フォルダーツリー構造）。クイックウィンドウ・メインウィンドウ・クイックパネルで使え、インラインウィンドウでは使えません。プレビュー可能な行の中クリックでも同じパネルを開閉できます。 |
| **前の検索履歴語** | `Alt+Up` | 最近入力した検索キーワードを前に遡って表示。 |
| **次の検索履歴語** | `Alt+Down` | 最近入力した検索キーワードを後ろに進んで表示。 |
| **現在の履歴語を削除** | `Ctrl+Delete` | 現在表示されている検索キーワードを検索履歴から削除。 |
| **メインウィンドウを開く** | `Ctrl+F` | 現在入力中の検索キーワードを引き継いだまま、大画面のメイン検索ウィンドウを開く。 |
| **LocalSend 画面を開く** | `Ctrl+S` | LocalSend 経由で他デバイスにファイルやテキストを送信する画面を開く。 |
| **ウィンドウを固定（ピン留め）** | `Ctrl+T` | フォーカスを失ってもウィンドウを閉じずに維持（他アプリから文字をコピーして貼り付ける際に便利）。 |
| **クイックパネルの表示/非表示** | `Ctrl+F2` | 現在のアクティブウィンドウの横に、最近のファイル・お気に入り・ワークスペースを含むパネルを表示。 |

### ファイルダイアログで検索欄が空の場合

ネイティブのファイルダイアログにインライン検索ボックスが埋め込まれていて検索欄が空の場合、一覧にはまず「前回のディレクトリ」グループが表示されます。「インライン検索に現在開いているフォルダーを表示」が有効なら、対応ファイラーで現在開いているフォルダーをまとめた「現在開いているフォルダー」グループも表示され、ここにはダイアログ自身が現在開いているフォルダーも意図的に含まれます。重複するパスは統合され、空のグループは表示されません。グループ見出しにはショートカットバッジも表示されません。この設定は既定で有効で、[**設定 → 一般 → システム**](./settings/general) から変更できます。この動作はファイルダイアログ内のインライン検索だけに適用され、クイックウィンドウとフルウィンドウには影響しません。

### インラインウィンドウの呼び出しとフォーカスの引き継ぎ

ネイティブのファイルダイアログにドッキングしたウィンドウは、意図的に**キーボードを奪いません**。フォーカスはダイアログに残るので、ダイアログ自身のファイル名欄へそのまま入力を続けられ、ウィンドウ側は検索語を反映します。キャレットを動かせる操作は次のとおりです。

| 操作 | 効果 | 条件 |
| :--- | :--- | :--- |
| **英数字を入力** | ウィンドウが呼び出され、最初に入力した 1 文字が検索ボックスに引き継がれ、その後のキー入力もそのまま流れ込みます | 実際のキー入力のみが対象です。自動化ツールによる合成入力はそのまま素通しされ、コンテキストメニューやシステムメニューが開いている間は何も捕捉しません |
| **`Ctrl` の 2 回連打**（または設定済みの呼び出しホットキー） | キャレットをウィンドウ自身の検索ボックスへ入れます。検索ボックスがすでにキャレットを持っていて検索語が空の場合は、代わりに検索語をクリアし、ウィンドウを開いたままフォーカスをダイアログの欄へ返します | 他の場所と同じホットキーです。[**設定 → ホットキー**](./settings/hotkeys-page) で割り当てを変えれば、この引き継ぎも一緒に変わります。ブラックリストや全画面で通常ならグローバルホットキーが抑止される場合でも、ファイルダイアログは許可されたままです |
| **`Escape`** | **ダイアログ**がキーボードを持っている間はウィンドウを閉じます。**ウィンドウ**が持っている間は検索語をクリアし、フォーカスをダイアログへ戻します（ファイルダイアログの場合）か、ウィンドウを閉じます（通常のエクスプローラー上にドッキングしている場合） | |
| 空の欄で **`Backspace`** | `Escape` とまったく同じように検索を終了します | ウィンドウがキャレットを持っている場合のみ。ダイアログがキーボードを持っている間は、このキーはウィンドウの検索語を編集するだけにとどまります |
| 空の欄で **`Enter`** | `Escape` と同じように検索を終了します | ウィンドウがキャレットを持っている場合のみ。ダイアログがキーボードを持っている間は、`Enter` は選択中のブラウズ行を開きます |
| **`Tab`** | ダイアログ自身のコントロール移動に残り続けるため、ウィンドウへは呼び出しホットキーで移動してください | |

> [!NOTE]
> ファイルダイアログ内では、ウィンドウのアクションメニューを利用できません（`Ctrl+O`、`→`、右クリックはいずれも効かず、`Alt+P` のプレビューも提供されません）。マウスは行に対してそのまま使えます。**左クリック**で選択中の結果を開き、**`Ctrl`+クリック**で管理者として開き、行を**ドラッグアウト**してダイアログ側に落とせ、**ホバーするだけ**で選択が動きます（ホストのファイラー側にも同じ選択が反映されます）。

## 2. 検索ボックスのロゴとマウス操作

検索ボックス内の小さなロゴアイコンには、実用的なマウス操作が割り当てられています。

### クイックウィンドウでのロゴ操作

- **左クリック**：カーソル位置にコンテキストメニューを表示（メインウィンドウの表示、他のデバイスへ送信、ホットキーの有効化/無効化、設定、バージョン情報、クリーン終了、終了。トレイアイコンと同じメニューです）。「メインウィンドウの表示」は現在の検索語を引き継ぎます。
- **左ドラッグ**：画面上の検索バーの位置を自由に移動。**`Ctrl` キーを押しながらドラッグ**すると、移動方向が**垂直方向のみ**に固定され、横位置のズレを防げます。
- **右クリック**：設定されたサイズを維持したまま、クイックウィンドウを画面中央の既定位置にリセット。
- **中クリック**：ウィンドウの「固定（ピン留め）」を切り替え。固定中はロゴが点灯します。

> [!NOTE]
> クイックウィンドウが記憶する座標は、表示中のモニターに対する**相対比率座標**です。解像度や DPI スケーリングが異なる別のモニターに移動した際も、自動的に画面内に収まるよう比率計算されます。

### インラインウィンドウおよびメインウィンドウでのロゴ

- **インラインウィンドウ**：ファイルダイアログ（開く/保存/参照）に埋め込まれている場合、左クリックで [**クイックナビゲーション**](#_3-クイックナビゲーション-マウス操作) を表示。通常のエクスプローラーでは装飾表示のみです。ロゴをドラッグするとウィンドウ自体が移動し、そのオフセットは次回以降ドッキングするたびに再適用されます。
- **メインウィンドウ**：ロゴを左クリックするとコンテキストメニューを開きます。すでにメインウィンドウを開いているため、メニューでは**メインウィンドウを表示**は非表示になります。中クリックでウィンドウの固定状態を切り替えます。

### 検索ボックスのマウス操作（クイックウィンドウ）

- **ボックス上でホイールを回す**：過去の検索語を後ろ・前へ遡ります。`Alt+Up` / `Alt+Down` と同じ移動を、マウスから手を離さずにできます。
- **ボックスを中クリック**：現在表示されている履歴項目を削除します。このジェスチャーは固定で、変更可能な `Ctrl+Delete` の割り当てとは別のものです。
- **いつでも文字を入力すると**履歴セッションが終わるため、次のホイール操作は現在の検索語からやり直しになります。履歴はループしません。最も古い語で停止し、最も新しい語まで戻ると最初に始めていた検索語が返ります。

### トレイアイコン

- **左クリック**：クイックウィンドウを表示/非表示します。呼び出しホットキーとまったく同じ動作です。
- **右クリック**（ダブルクリック用のハンドラがないため、2 回目のクリックでも開きます）：カーソル位置でメニューを開きます。内容はメインウィンドウの表示、他のデバイスへ送信（LocalSend が有効な間のみ）、ホットキーの有効化/無効化、設定、バージョン情報、クリーン終了（Lertaro だけが実行中のプロセスである場合のみ）、終了です。
- **トレイアイコンを隠す**（[**設定 → 一般 → システム**](./settings/general)）を使うとアイコンは消えますが、ウィンドウ内ロゴのメニューまでは消えません。このメニューからホットキーを無効にしている間は、自分で閉じ出せないようアイコンが強制復帰します。

## 3. クイックナビゲーション（マウス操作）

キーボード入力を行わずに、マウス操作だけで頻繁に使うフォルダーや最近のファイルにアクセスできます。

[**設定 → ホットキー**](./settings/hotkeys-page) で、任意のグローバルキーボードショートカットを割り当てることもできます。デスクトップや通常のアプリではデスクトップのコンテキストでメニューを開き、エクスプローラーやネイティブのファイルダイアログではアクティブなウィンドウのコンテキストを使います。

### 呼び出し環境

- **デスクトップの余白**：中クリック（または左ダブルクリック）でメニューを開き、フォルダーやファイルをクリックして直接開く。
- **エクスプローラー**：余白部分を中クリックして開き、クリックしたフォルダーへ現在のウィンドウが即座に移動。
- **対応ファイラー**：Directory Opus、Total Commander、XYplorer、Files、One Commander などのファイル一覧部分を中クリック（詳細は [**対応ファイルマネージャー**](./file-manager-support) を参照）。
- **ファイルダイアログ**：各種アプリの「開く/保存/フォルダーの参照」ダイアログ内で中クリックまたはロゴをクリック。対象フォルダーへ安全に移動します。

### メニュー構成と管理

**階層型フォルダーブラウザー（Folder Cascader）** プラグインによって提供され、内容は 4 種類に分かれています：

1. **現在開いているフォルダー**：サポートされているすべてのファイラーで現在開かれているフォルダーを自動集約・重複排除して一覧表示。
2. **お気に入り・履歴**：スター付きのお気に入りと最近のアクセス履歴を分類表示。
3. **カスタム階層フォルダー**：**設定 → プラグイン → Folder Cascader** で独自の階層メニューを作成可能（例: `仕事/プロジェクトA`）。
4. **クイックフォルダー登録（`+` ボタン）**：メニューの各階層ヘッダーにある `+` ボタンをクリックするだけで、現在開いているフォルダーをそのカテゴリに直接追加可能。

## 4. 固定キー（変更不可）

直感的な操作の一貫性を保つため、以下のキー操作はすべての設定で固定されています。

| キー | 状況 | 動作 |
| :--- | :--- | :--- |
| `Enter` | 結果一覧 | 選択中の項目（ファイル/フォルダー/アプリ/アクション）を開く。メインウィンドウでは**選択したすべての行**を開く。検索欄が空のインラインウィンドウでは、代わりに検索を終了する（開くべき筆頭結果が存在しないため）。 |
| `Ctrl+Enter` | 結果一覧 | エクスプローラーで選択項目の場所を開いてフォーカス。 |
| `Ctrl+Shift+Enter` | 結果一覧 | 選択した項目を管理者権限で実行。 |
| `Escape` | クイックウィンドウ | ウィンドウを隠す。この 1 回で検索欄が空になることはない。検索語を保持するか捨てるかは、**閉じた後も検索ボックスの内容を保持する** の設定側で決まる。 |
| `Escape` | メインウィンドウ | 検索語をクリアして検索ボックスに再びフォーカスを当てる。検索欄がすでに空ならウィンドウを閉じ、**閉じた後も検索ボックスの内容を保持する** が有効な場合は即座に閉じる（無駄に 2 回押すことはない）。 |
| `Escape` | インラインウィンドウ | 上記の「**インラインウィンドウの呼び出しとフォーカスの引き継ぎ**」を参照。ダイアログがキーボードを持っている間はウィンドウを閉じ、ウィンドウが持っている間はフォーカスを返す。 |
| `Escape` | アクションメニュー | 1 回につき 1 階層。まずアクションの絞り込みをクリアし、次にサブメニューから外へ戻り、最後にメニューを出て元の検索語を復元する。 |
| `Backspace` | アクションメニュー | 絞り込みテキストが空の状態で押すと、アクションメニューを閉じて結果一覧に戻る。 |
| `←` / `→` 方向キー | アクションメニュー | 左キーで親メニューに戻り、右キーでサブメニューに入る。`Tab` でもサブメニューに入るが、次の項目/前の項目のホットキーに割り当てている場合はそちらが優先される。 |
| `Tab` | インラインウィンドウ | 検索ボックスからフォーカスが逃げないよう吸収される。一方、ダイアログ側で押した `Tab` は従来どおりダイアログ自身のコントロールを順に移動する。 |
| `Tab` | アクションメニュー | 選択中のサブメニューに入る。ただし `Tab` を次の項目/前の項目のホットキーに割り当てている場合はそちらが優先される。 |
| `Apps` / `Shift+F10` | メインウィンドウ | 右クリックとまったく同じく、現在の選択に対するアクションメニューを開く。 |
| `Alt+Space` | Lertaro の全ウィンドウ | 誤動作を防ぐため、システムタイトルバーメニューを無効化。 |
| `Alt+F4` | メイン / 設定ウィンドウ | ウィンドウを通常どおり閉じる。クイックウィンドウ・インラインウィンドウ・クイックパネル・プレビュー・LocalSend・アプリ内ダイアログでは無効化。 |

## 5. プラグインアクションとプロセスブラックリスト

### プラグインアクションのホットキー

内蔵のファイル操作には次の既定キーが用意されています：切り取り `Ctrl+X`、ファイルのコピー `Ctrl+C`、貼り付け `Ctrl+V`、削除 `Delete`、完全削除 `Shift+Delete`、パスコピー `Ctrl+Shift+C`、名前をコピー `Shift+C`、エクスプローラーで表示 `Ctrl+Enter`、管理者として実行 `Ctrl+Shift+Enter`。

破壊的なキーを検索ボックスの下で安全に扱うため、2 つの歯止めを設けています。組み合わせキーがアクションに届くのは、検索ボックスに**テキストが選択されていない**ときだけなので、`Ctrl+X` / `Ctrl+C` / `Ctrl+V` はこれまでどおり検索語の切り取り・コピー・貼り付けに使えます。`Delete` のような修飾キーなしのキーがアクションに届くのは、キャレットが**すでに検索語の末尾**にあるときだけです。そこでは削除すべき文字が残っていませんから、テキストのそれ以外の位置ではこのキーは入力用のキーのままです。さらに、どちらの削除アクションも Shell 自身の `IFileOperation` を通るため、キーとファイルの間にはネイティブの「ごみ箱へ移動しますか」/「完全に削除しますか」の確認が立ちはだかります。いずれも **設定 → ホットキー → プラグインアクション** で再登録したりクリアしたりできます。

### プロセスブラックリストと全画面自動バイパス

- **全画面アプリの自動バイパス**：フルスクリーンで動作する 3D ゲームや動画プレイヤーを検知すると、Lertaro は自動的にすべてのグローバルホットキーを通過させ、ゲームの操作を妨げません。
- **カスタムプロセスブラックリスト**：[**設定 → ホットキー**](./settings/hotkeys-page#_3-プロセスブラックリスト-process-blacklist) に特定のプロセス名（例: `game.exe`）を登録すると、そのアプリがフォアグラウンドにある間はホットキーを完全に無効化します。
