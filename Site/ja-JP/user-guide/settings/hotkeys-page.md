# ホットキー設定

ホットキー設定画面では、Lertaro の全グローバル呼び出しキー、アプリ内ナビゲーションキー、プラグインアクションショートカット、およびプロセスブラックリストを一元管理します。画面上部には **グローバル**、**プラグインアクション**、**プロセスブラックリスト** の 3 つのタブが配置されています。

## 1. グローバル（Global）

### グローバルショートカット

- **クイック検索の表示/非表示**：専用のキー登録欄。**修飾キーの 2 回連打モード**（既定は `Ctrl` の 2 回連打、`Alt` や `Shift` にも設定可能）または **通常のキー組み合わせ**（例: `Alt+Space` など）に対応。
- **既定でメインウィンドウを開く**：チェックボックス（既定は無効）。有効にすると、グローバル呼び出しキーでクイックウィンドウではなくメインウィンドウを開きます。初回表示時は一度だけ前面とフォーカスを処理し、表示中で非アクティブなら再アクティブ化、すでにアクティブならもう一度押すと既定ではクイックウィンドウへ戻り、**ショートカットの再入力でフルウィンドウを閉じる**を有効にした場合はそのまま閉じます。自動的に最前面へ固定されることはありません。
- **全画面アプリフォーカス時も応答する**：チェックボックス（既定は無効）。有効にすると、フルスクリーンのゲームや動画プレイヤーがアクティブな場合でもホットキーに応答します。無効のときはゲーム操作を保護するためにキーをスルーします。
- **クイックジャンプ（Quick Jump）**：既定は `Ctrl+G`。ファイルダイアログ内で直前にファイラーで開いていたフォルダーへ移動します。
- **クイックナビゲーションメニュー**：既定ではショートカットなし。任意のグローバルショートカットを割り当てて階層型メニューを開けます。デスクトップや通常のアプリではデスクトップのコンテキストを使い、エクスプローラーやネイティブのファイルダイアログでは現在のウィンドウのコンテキストを使います。通常の前景保護でグローバルホットキーが抑止される場合でも、ファイラーとファイルダイアログは許可されます。

### 機能キー

カスタムの単一キーまたは組み合わせキーを登録できるコントロール群です。

- **次の項目 / 前の項目を選択**：既定 `Ctrl+N` / `Ctrl+P`（方向キー `↓` / `↑` と同等）。
- **結果ジャンプ修饰キー**：既定 `Ctrl`、数字キー `1`–`9` と組み合わせて直接起動。
- **アクションメニューを開く**：既定 `Ctrl+O`（方向キー `→` と同等）。この 2 つはいずれもクイックウィンドウと、ファイルダイアログ外のインラインウィンドウで使えます。メインウィンドウでは同じメニューを右クリックまたは `Apps` キーで開きます。
- **選択項目で検索語を補完**：既定 `Ctrl+Tab`。
- **QuickLook 即時プレビュー**：既定 `Alt+P`。
- **前 / 次の検索履歴語**：既定 `Alt+Up` / `Alt+Down`。
- **現在の履歴語を削除**：既定 `Ctrl+Delete`。
- **メインウィンドウを開く**：既定 `Ctrl+F`。
- **LocalSend 画面を開く**：既定 `Ctrl+S`。
- **ウィンドウを固定（ピン留め）**：既定 `Ctrl+T`。
- **クイックパネルの表示/非表示**：既定 `Ctrl+F2`。

### クイックナビゲーション（マウス操作）

- **余白部分で左ダブルクリック**：チェックボックス（**既定は無効**）。デスクトップやエクスプローラーの余白ダブルクリックでメニューを表示。
- **余白部分で中クリック**：チェックボックス（既定で有効）。デスクトップやエクスプローラー、ファイルダイアログで中クリックしてメニューを表示。

左ダブルクリックの形を受け付けるのはデスクトップとエクスプローラーだけで、サードパーティ製ファイラーは中クリックのみです。どちらのトリガーも、ポインターが Lertaro 自身のウィンドウ上にある間はスキップされます。また、ブラックリストや全画面によって通常ならグローバルなトリガーが無効化される状況でも、ファイラーとダイアログに対してはどちらも生きたまま維持されます。

### ホットキーを登録する

キー入力は背後のアプリではなく登録欄へ送られます。そのため登録控件そのものが一連のジェスチャーになっています。

- **`Escape`**：登録を中止して値をクリアします。「破棄して元に戻す」は存在せず、押した瞬間に欄は空になります。
- **`✕`**：欄をクリアします。**`↺`**：その行の出荷時既定値を復元します。2 つのうち表示されるのは常にどちらか 1 つだけで、組み合わせが設定されている間はクリア、空になったあとは復元になります。
- **修飾キー単体**（`Ctrl`、`Alt`、`Shift`）は、単体で意味を持つ行でのみ受理されます。それは呼び出しホットキー（2 回連打方式になるもの）と結果ジャンプの修飾キーです。通常の組み合わせ用の行で修飾キーだけを押して離すと、発火のしようのない値を保存する代わりに、その行は**クリア**されます。
- **Windows 予約の組み合わせ**（`Win+E`、`Win+D` など）は拒否されます。値は空へ強制変換されるため、欄は単に空白になります。
- **重複の検出はありません。** 2 つの行に同じ組み合わせを登録しても警告は何も出ません。お気に入り項目のホットキーだけが重複または OS に拒否された組み合わせを報告しますが、それも適用したあとになってからです。

### お気に入りごとのホットキー

すべてのお気に入り（[**設定 → お気に入り**](./favorites)）には、それぞれ専用の **OS レベルのグローバル**ホットキーを登録できます。Lertaro にウィンドウが 1 つも開かれていないときでも機能し、フォアグラウンドのファイラーをそのフォルダーへ移動させます。上の登録欄と異なり、修飾キーが必須で、修飾キー単体は拒否され、`F12` は使えません。

## 2. プラグインアクション（Plugin Actions）

各プラグインが登録したアクションショートカット（例: パスコピー `Ctrl+Shift+C`、名前をコピー `Shift+C`、切り取り `Ctrl+X`、コピー `Ctrl+C`、貼り付け `Ctrl+V`、削除 `Delete`、完全削除 `Shift+Delete` など）が一覧表示されます。

- **プラグインごとのグループ分け**：提供元のプラグインごとに整理されています。
- **個別の再登録**：各アクションに専用の登録欄があり、新しいキーを押すだけで変更可能です。

## 3. プロセスブラックリスト（Process Blacklist）

特定のアプリがフォアグラウンドにある際、Lertaro のホットキーやマウス操作を無効化するリストです。

- **大文字小文字の区別なし**：`game.exe` または `game` のどちらでも一致します。
- **個別追加**：プロセス名を入力して **プロセスを追加** をクリック。
- **テキストでの一括管理**：**テキスト生成** で現在のリストを複数行テキストとしてエクスポートしたり、貼り付けて **リストに適用** で一括更新できます。
- **ファイルダイアログの自動除外**：ブラックリスト内のアプリであっても、Windows 標準のファイルダイアログが表示されているときはインライン検索やクイックナビゲーションが正常に動作します。
