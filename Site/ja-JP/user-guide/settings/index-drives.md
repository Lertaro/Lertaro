# インデックス管理

インデックス設定画面では、ローカルドライブ、ネットワーク共有、WSL、個別フォルダーに対するインデックス作成範囲、更新スケジュール、および除外ルールを細かく制御します。画面上部には **ローカルドライブ**、**ネットワークドライブ**、**WSL**（該当環境検出時のみ）、**フォルダー**、**除外ルール** の 5 つのタブが配置されています。

## 1. ローカルドライブ（Local Drives）

- **ステータスサマリー**：現在インデックス化されている物理ドライブ数と総アイテム数が表示され、全ドライブの一括再構築を行う **インデックス再構築** ボタンが配置されています。
- **ドライブ一覧行**：
  - **有効/無効チェックボックス**：パーティションごとにインデックス作成を個別に切り替え。
  - **ファイルシステムと状態**：ファイルシステムの種類（NTFS、ReFS、FAT32、exFAT 等）、稼働状態、インデックス済みアイテム数を表示。
  - **個別ドライブ操作**：**再構築** と **削除** ボタン。スキャン実行中は動的に **停止** ボタンが表示されます。
- **リアルタイム監視**：NTFS / ReFS は Windows の USN 変更ジャーナルを読み取ってミリ秒単位で同期し、FAT32 / exFAT はファイル変更イベントを監視します。
- **無停止での再構築**：ドライブの再構築中も、新規インデックスが完成するまでは既存のインデックスが検索に応答し続けるため、検索が途切れることはありません。再起動等で中断されても次回起動時に続きから再開されます。

## 2. ネットワークドライブ（Network Drives）

- **ネットワーク共有の対応**：マウント済みの Windows ネットワークドライブ（SMB / NAS）を一覧表示。
- **更新モード（Refresh Mode）**：ローカルの変更ジャーナルが存在しないため、定期スキャン周期を設定可能：
  - **手動** —— 「インデックス再構築」クリック時のみスキャン。
  - **15 分ごと** —— 頻繁に更新される共有向け。
  - **1 時間ごと** —— 標準的な定期更新。
  - **毎日** —— アーカイブ用ストレージ向け。
- **シンボリックリンク循環保護**：NAS 上の循環シンボリックリンクやジャンクションによる無限ループを防ぐため、ループ検知エンジンが重複パスを自動スキップします。

## 3. WSL（Linux 用 Windows サブシステム）

WSL ディストリビューションがインストールされている場合に自動的に表示されます。

- **自動検出**：Ubuntu、Debian、Arch などのインストール済みディストリビューションを自動認識。
- **状態と更新**：ネットワークドライブと同様のステータス管理と更新モード（手動 / 15 分ごと / 1 時間ごと / 毎日）を提供。
- **ゼロ I/O 検索**：WSL ファイルの検索時はメモリインデックスを直接参照し、Linux サブシステムを起動させたり負荷をかけたりしません。

## 4. フォルダー（Folders）

ドライブ全体ではなく、特定の作業フォルダーのみを対象にしたい場合に利用します。

- **複数選択での追加**：**フォルダーを追加** をクリックしてピッカーを開き、`Ctrl` または `Shift` キーを押しながら複数のフォルダーを一括追加可能。
- **UNC パスのサポート**：`\\server\share\projects` のようなネットワーク UNC パスも直接登録可能。
- **個別更新スケジュール**：各フォルダーごとに独立した有効スイッチ、アイテム数、更新モード（手動 / 15 分ごと / 1 時間ごと / 毎日）を設定できます。

## 5. 除外ルール（Exclusions）

ローカル、ネットワーク、フォルダー全体に適用される除外設定で、3 つのサブタブに分かれています。

### パス除外（Path Exclusions）

- **完全プレフィックス一致**：`D:\Cache` や環境変数（`%ProgramData%`、`%APPDATA%`）を指定して除外。

### Glob ルール（Glob Rules）

- **ワイルドカード構文**：
  - `*`：フォルダー単一階層内の任意文字（例: `*.tmp`、`*.log`）。
  - `**`：再帰的なサブディレクトリ一致（例: `**/node_modules/**`、`**/bin/**`、`**/obj/**`）。

### 正規表現ルール（Regex Rules）

- **高度な正規表現一致**：ドットファイル（`^\.`）や Office の一時ファイル（`~\$`）などを柔軟に除外。

> [!TIP]
> 除外ルールは **個別追加** と **テキストによる一括インポート/エクスポート** の両方に対応しています。**リストからテキストを生成** でルールをエクスポートし、編集後に **リストに適用** をクリックして一括反映できます。
