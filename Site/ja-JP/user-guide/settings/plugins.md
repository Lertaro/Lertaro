# プラグイン

インストール済みのすべてのプラグインを一覧表示し、現在読み込まれているプラグイン SDK のバージョンをページヘッダーにバッジとして表示します。クリックすると[開発者ガイド](../../dev-guide/)が開きます。このバージョン番号は、まさにガイドと照らし合わせるためのものです。

ページは左右2つのペインに分かれています。左がインストール済みのプラグイン、右が選択中のプラグインの詳細です。2つは別々にスクロールするため、長いプラグイン一覧と長い設定フォームが互いを引きずることはありません。

プラグインが1つもインストールされていない場合、代わりに空の状態メッセージが表示されます。

## プラグイン一覧

インストール済みのプラグインごとに1行、名前とその下にバージョンが表示されます。行を選択すると、そのプラグインが右のペインに開きます。

一覧は操作できるものから並びます。まず独自の設定を持つプラグイン、次に切り替えられるコンポーネントを持つもの、最後にそれ以外。各グループ内は名前順です。

## 選択中のプラグイン

ペインの先頭には、プラグインのアイコン、名前、**全体的な機能の説明** が表示されます。

その下に、独自の設定(単純な有効/無効を超えたカスタム設定)を公開しているプラグインであれば **詳細** と **設定** の2つのタブが表示されます。設定が何もないプラグインにはタブ自体が表示されず、ペイン全体がその詳細になります。

### 詳細

このプラグインが登録するコンポーネントが、種類(検索プロバイダー、動的メニュープロバイダーなど)ごとにグループ化されて表示されます。切り替え可能な各コンポーネントには専用の **有効/無効チェックボックス** があります。必須とマークされたコンポーネントは代わりに鍵アイコンが表示され、オフにできません。コンポーネントの横の **(!)** にカーソルを合わせると、詳細な機能の説明が表示されます。

グループ(またはプラグイン全体)に切り替え可能なコンポーネントが2つ以上ある場合、そのヘッダーの横に **すべて選択/すべて選択解除** リンクが表示され、そのスコープ内のすべてのチェックボックスを1つずつではなく一括で切り替えられます。

### 設定

プラグイン独自の設定を、別のダイアログではなくこの場で編集します。設定を2つ以上のグループに分けているプラグインには、グループごとに1つ、専用のタブ列が追加されます。

**OK** を押すまで何も書き込まれません。このタブを離れる(詳細に戻る、または別のプラグインを選ぶ)と、各項目は保存済みの値に戻ります。放置した編集が後から誤って確定されることはありません。

プラグインの設定が実際にどのようなものかの具体例(トリガーキーワードの変更など)については、[インスタントアンサーとキーワードショートカット](../instant-answers)を参照してください。

## Flow Launcher プラグイン エコシステムのサポート

`Lertaro.PluginSdk` に基づくネイティブな C# プラグインに加えて、Lertaro は組み込みの Flow Launcher Bridge を通じて、広範な Flow Launcher コミュニティ プラグイン エコシステムとのネイティブ互換性を提供します。

- **サポートされているプラグインの種類**: **C# (.NET)**、**Python 3.12**（`requirements.txt` に基づくバックグラウンドでの `pip` 依存関係の自動インストールをサポート）、**Node.js v20 LTS**（`package.json` に基づくバックグラウンドでの `npm` 依存関係の自動インストールをサポート）、および独立した **実行可能ファイル**（`.exe`）で記述された Flow Launcher プラグインに対応しています。
- **インストール方法**: サードパーティ製の Flow Launcher プラグイン フォルダーを `<ユーザー データ ディレクトリ>\FlowData\Plugins\` に配置するだけで、Lertaro が自動的に検出、読み込み、検索キーワードおよびアクションを登録します。
- **完全に分離されたランタイム環境**: Python（`FlowData\PythonEmbeded-{arch}`）と Node.js（`FlowData\NodeEmbeded-{arch}`）のランタイムは、Lertaro のユーザー データ ディレクトリ内に完全に自己完結してオンデマンドで自動ダウンロード・展開され、システムのグローバル環境変数や PATH を変更または汚染することはありません。
- **一元管理と個別スイッチ**: **設定 → プラグイン → Flow Launcher Bridge** の **設定** タブで、読み込まれたすべての Flow プラグインがタブごとに一覧表示されます。各プラグインの先頭には専用の **このプラグインを有効化** スイッチがあり、個別に有効・無効を切り替えられます。
- **カスタム トリガー キーワードと状態の分離**: 各 Flow プラグインの **トリガー キーワード（ActionKeyword）** を自由にカスタマイズできます。設定と有効化状態は `FlowData\Settings\Plugins.json` に一括保存されるため、プラグイン内部の設定を汚染せず、プラグインの更新や再起動後も保持されます。
- **ネイティブ組み込み設定と多言語対応 (i18n)**: YAML/JSON テンプレート（`SettingsTemplate.yaml`/`.json`）および C# WPF カスタム設定パネル（`ISettingProvider`）に基づくプラグイン設定 UI にシームレスに対応し、アプリのテーマに自動調和して多言語 i18n ローカライゼーションを完全にサポートします。
- **カスタム インタラクティブ プレビューと WebView2 美化**: Flow Launcher プラグインから返されるカスタム プレビュー パネル（MDict 辞書定義、天気カード、API インスペクター、Web プレビューなど）をサポートし、結果を選択するだけで QuickLook プレビュー パネルで追加のキー操作なしにスムーズに展開・切り替え可能です。WebView2/HTML ベースのプレビューでは、Lertaro がテーマに適応したタイポグラフィ（Segoe UI、メイリオ）、高コントラスト スタイル、およびスリムな半透明スクロールバーを自動的に注入します。
- **クイック検索と呼び出し**: 検索バーに `flow` キーワードを入力すると、読み込まれたすべての Flow プラグインの一覧、トリガー キーワード、およびステータスが表示されます。各プラグインのトリガー キーワード（`md`、`tr` など）を直接入力すると、即座に検索を実行できます。
