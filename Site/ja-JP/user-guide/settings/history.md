# 検索履歴

履歴設定画面では、パスごとの利用頻度、入力した検索語、および確定済みのクエリ関連付けを **検索履歴**・**キーワード履歴**・**クエリ関連付け** の 3 つの独立したタブで管理します。

## 1. 検索履歴（Search History）

実際に開いたファイル・フォルダー・アプリの利用頻度と最終起動日時を記録し、同程度の一致度を持つ候補同士の並び順を微調整します。

- **減衰付き利用頻度による微調整**：よく使う項目は 90 日半減期のスコアで **同じ一致グレード内** で優先されますが、完全一致や明確な直接一致を追い越すことはありません。
- **インラインウィンドウでの自動分類**：ファイルダイアログのインライン検索時、現在のフォルダー内の一致項目は「現在のフォルダー」、それ以外は「全体検索」に分類されます。
- **無効パスの自動除外**：削除または移動されたパスは検索結果から自動的に除外されます。
- **管理操作**：
  - **履歴を有効化**：全体の記録スイッチ。無効時も既存の記録は保持されます。
  - **検索絞り込み・削除**：絞り込み検索、**N 回以下をクリア**、個別削除、**すべての履歴を消去**を利用できます。
  - **リアルタイム更新**：別の検索ウィンドウで項目を開くと一覧の回数が自動更新されます。

## 2. キーワード履歴（Keyword History）

結果やアクションを実行したとき、またはその検索語でメインウィンドウを開いたときに実際に使用された **検索文字列そのもの** を記憶します。

- **ホットキーによる履歴呼び出し**：クイックウィンドウで **`Alt+Up`**（前へ）/ **`Alt+Down`**（次へ）を押して過去の検索語を呼び出せます。**`Ctrl+Delete`** で表示中の履歴語を削除できます。
- **使用回数と削除**：**N 回以下をクリア**、個別削除、**すべての履歴を消去**を個別に実行できます。

## 3. クエリ関連付け（Query Associations）

パスごとの利用頻度とは別に、確定した **検索クエリ → 対象パス** の学習済み関連付けを管理します。

- **3 回の手動起動による確定条件**：正規化された同一クエリで **3 回以上** 直接選択して開いた項目のみが学習済み候補として補完され、一度きりの誤クリックによる汚染を防ぎます。
- **自己強化ループの防止**：学習補完から開いた操作は未確定カウントを増やさず、常に直接一致の後に表示されます。
- **個別の整理・消去**：パスの利用頻度を維持したまま、不要な関連付けだけを個別削除または一括消去できます。
