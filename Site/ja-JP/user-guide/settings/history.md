# 検索履歴

履歴設定画面では、Lertaro の利用履歴と関連付けによる優先表示を管理します。画面上部には **検索履歴** と **キーワード履歴** の 2 つのタブが配置されています。

## 1. 検索履歴（Search History）

検索結果から実際に起動したアイテムと、そのときに使用した検索クエリを紐付けて記憶します。

- **スマート優先表示**：過去の検索クエリと類似するキーワードを入力した際、以前開いたアイテムが結果一覧の上位に自動的に優先表示されます（例: `bcomp` で `BCompare.exe` を起動したことがある場合、次回 `bc` と入力しても上位に表示）。
- **インラインウィンドウでの自動分類**：ファイルダイアログのインライン検索時、現在のフォルダー内の一致項目は「現在のフォルダー」、それ以外は「全体検索」に自動分類されます。
- **無効パスの自動除外**：ファイルが削除または移動された場合、存在しないリンクは検索結果から自動的に除外され、重複表示も防がれます。
- **管理操作**：
  - **履歴を有効化**：記録機能の全体スイッチ。無効にしても既存の記録は保持されます。新しい項目は追加されませんが、既存の項目を開くと使用回数は引き続き加算されます。
  - **検索絞り込み**：上部の検索バーで履歴項目を絞り込み。
  - **使用回数と削除**：各項目には開いた回数が表示されます。回数のしきい値を選び、**N 回以下をクリア** を押すと使用頻度の低い項目を削除できます。個別削除や**すべての履歴を消去**も利用できます。
  - **リアルタイム更新**：別の検索ウィンドウで新しい項目を開くと、一覧の使用回数が自動更新されます。

## 2. キーワード履歴（Keyword History）

結果やアクションを実行したとき、またはその検索語でメインウィンドウを開いたときに実際に使用された **検索文字列そのもの** を記憶します。入力しただけでクイック検索ウィンドウを閉じたり、フォーカスを失ったりした場合は追加されません。

- **ホットキーによる履歴呼び出し**：クイックウィンドウで **`Alt+Up`**（前へ）/ **`Alt+Down`**（次へ）を押して過去の検索語を順に呼び出せます。**`Ctrl+Delete`** で現在表示中の履歴語を削除できます。
- **使用回数と削除**：各キーワードには使用回数が表示されます。回数のしきい値を選び、**N 回以下をクリア** を押すと使用頻度の低いキーワードを削除できます。
- **個別管理**：検索履歴と同様に **履歴を有効化** スイッチ、絞り込み、個別削除、**すべての履歴を消去** ボタンが用意されています。無効時も既存のキーワードの使用回数は加算されますが、新しいキーワードは追加されません。
