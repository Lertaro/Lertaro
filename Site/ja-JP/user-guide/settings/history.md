# 検索履歴

3つのタブで、開いた項目、検索語、クエリ関連をそれぞれ管理します。

## 1. 検索履歴（Search History）

検索結果から開いたファイル、フォルダー、アプリの回数と日時を記録します。

- **順位への反映**：開くたびに1点を加え、上限は10点です。スコアは90日で半減します。有効スコア3でH3、5でH5の対象になります。クイック検索の枠はH5が3件、H3が10件、インライン検索は1件と3件です。フルウィンドウには件数枠がありません。
- **順位を上げられる範囲**：有効な一致等級と優先度が同じ結果の中で使用履歴を比較します。クイック検索の種類設定はファイル・フォルダーの完全一致等級にも影響します。[検索構文](../search-syntax)を参照してください。
- **インライン表示**：現在のフォルダーと全体の結果を分けて表示し、存在しないパスは省きます。
- **管理**：キーワードで絞り込み、個別削除、使用回数N以下の削除、全消去ができます。別のウィンドウから開くと一覧も更新されます。記録を無効にすると新規項目は追加されませんが、既存項目の回数と日時は更新されます。

## 2. キーワード履歴（Keyword History）

結果やアクションの実行時、またはフルウィンドウを開くときの元の検索語を保存します。入力してクイック検索を閉じるだけでは記録されません。

- **Alt+Up / Alt+Down**で履歴を移動し、**Ctrl+Delete**で現在の項目を削除します。
- 絞り込み、個別削除、全消去、使用回数による削除ができます。独立した記録スイッチを無効にすると、新しい語は追加されず、既存語の回数だけが更新されます。

## 3. クエリ関連付け（Query Associations）

**クエリ → 対象パス**の関連を使用スコアとは別に保存します。

- 同じ正規化クエリの通常の検索結果から対象を**3回以上**開くと、関連による補完が有効になります。学習した関連だけで表示された結果を開いても、この確認回数は増えません。
- 1回の検索で補完する関連は最大**1件**です。低優先度の対象は除外し、関連だけで見つかった結果は直接一致の後に表示します。
- 関連の絞り込み、個別削除、全消去をしても、パスの使用スコアは維持されます。
