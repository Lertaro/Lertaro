# 履歴

**検索履歴** と **キーワード履歴** の 2 つの独立したタブがあります。

## 検索履歴

実際に開いた結果を記録し、次回似たような検索をしたときに優先的に表示できるようにします。

検索履歴には、開いたパスとそこへ至った検索語の両方が記録されます。後でその検索語にあいまい一致するクエリを入力すると、クイック検索、インライン検索、完全検索の各ウィンドウで、現在も存在するパスを再度呼び出して優先表示できます。たとえば、`bcomp` で `BCompare.exe` を開いた後は、`bc` でも上位に戻せます。インライン検索では、アクティブなフォルダー内の一致項目は **現在のフォルダー**、それ以外は **グローバル検索** に表示されます。存在しないパスは無視され、同じパスが重複して表示されることはありません。

- **履歴を有効にする** チェックボックス — 記録のオン/オフを切り替えます。オフにしても既存のエントリはそのまま残り、単に新しく追加されなくなるだけです。
- **検索ボックス** — 表示中の履歴リストをキーワードで絞り込みます。
- 各エントリは個別に削除できるほか、**すべての履歴を消去** で一括削除もできます。

## キーワード履歴

クイックウィンドウの検索ボックスに実際に入力した生のテキストを記録します(開いた結果ではありません)。これにより、[キーワード履歴のホットキー](../hotkeys#グローバルホットキー)(デフォルトは `Alt+Up` / `Alt+Down`)で最近のクエリを順にたどることができます。

- 開いた結果ではなくキーワードを対象にした、同じ **履歴を有効にする** トグル、検索フィルター、個別削除、**すべての履歴を消去** ボタンがあります。
