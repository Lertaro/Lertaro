# バージョン情報

App、Core、Service、CLI 各コンポーネントのバージョン番号(サービスが現在正常かどうかを反映して色分けされます)、Lertaro の簡単な説明、プロジェクトのホームページとオンラインユーザーガイドへのリンクを表示します。

## データ フォルダー

その下にはさらに 2 つのリンクがあり、Lertaro が自身の設定を読み書きしているフォルダーを開きます。それぞれ実際のパスがクリック可能なリンクテキストとして表示され、フォルダーがまだ存在しない場合は先に作成されます。

- **ユーザー データ フォルダー** — `user-settings.json` を保持するユーザーごとのフォルダーです。設定が保存されるたびに、新しいファイルが書き込まれる前に以前のファイルが `user-settings.json.bak.1` にローテーションされ(古いバックアップは `.bak.5` まで繰り下げられます)、誤った編集や保存中のクラッシュがあっても、常に直近のコピーから復元できるようになっています。履歴、証明書、ユーザー固有のキャッシュもここに保存されます。
- **マシン データ フォルダー** — バックグラウンドサービスが使用するマシン全体のフォルダーです(`machine-settings.json`、ローカル ドライブのインデックス キャッシュ、サービス側のログなど)。

インストーラー版では `%LocalAppData%\Lertaro` と `%ProgramData%\Lertaro` を使用します。ポータブル版ではアプリケーションの横にある `Data\Users\<SID hash>` と `Data\Machine` を使用します。ポータブル版の `Data` フォルダーがまだ作成されていない場合は、互換性のため既存のインストーラー版データを再利用します。優先順位は[ポータブル データ](../getting-started#ポータブル-データ)を参照してください。

## アップデートの確認

- **アップデートを確認** ボタン — 新しいリリースがないか問い合わせます。ボタン自体のラベルが進行状況を反映します(「確認中...」の後、「最新です」または見つかった新しいバージョン番号のいずれかになります)。
- 非管理者アカウントがその場でアップデートをインストールするためにバックグラウンドサービスを停止できない場合、警告バナーがその旨を説明し、代わりに手動ダウンロードページへ誘導します。
- 新しいバージョンが見つかると:
  - **サイレント自動更新** — バックグラウンドでダウンロードとインストールを行い、進行状況バーを表示した後、Lertaro を自動的に再起動します。
  - **ダウンロードページへ移動** — 手動インストール用に、ブラウザで GitHub のリリースページを開きます。

これは [一般 → システム](./general#システム) にある **アップデートの自動確認** / **サイレント自動更新** チェックボックスと連動しています。それらは起動時にこの確認を自動的に行うかどうかを制御するもので、このページではいつでも手動でトリガーできます。
