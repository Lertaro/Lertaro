# お気に入り

よく使うフォルダー、ファイル、URL をピン留めして、いつでもワンキーでアクセスできるようにします。

## お気に入りの追加

- **表示名** — 任意。空欄のままで対象がローカルパスの場合、パスのファイル名から自動入力されます。
- **対象パス** — ローカルパス、または `http://`/`https://` の URL。
- **フォルダーを参照** / **ファイルを参照** ボタン — パスを入力する代わりにネイティブのピッカーを開きます。
- **追加** ボタン — パスが入力されると有効になります。

## リストの管理

リスト内の各お気に入りには名前と対象パスが表示され、行ごとに次の操作があります:

- **上へ移動** / **下へ移動** — リストの並び順を変更します。これは他の検索結果に対するお気に入りの順位にも影響します。各行は左端の 6 点ハンドルを直接ドラッグしても並べ替えられます。これは Settings 内の他のすべての並べ替え可能なリスト(結果タイプの優先順位、クイックナビゲーションの順序、サイドバーフィルターの順序、結果グリッドの列順序)で使われているのと同じドラッグ並べ替えハンドルです。
- **編集** — 項目を上のフィールドに読み込み直し、変更できるようにします。
- **削除** — 削除します。

## 検索結果への表示

一致するお気に入りは、フォルダー/パスのラベルの横に **★** マーカー付きで検索結果に表示され、他の検索結果と同様、表示名で検索できます(名前に漢字が含まれる場合はピンインでも検索可能)。これは Lertaro においてカスタム検索エイリアスに最も近いものです。詳しくは [検索構文](../search-syntax#お気に入り、カスタムエイリアスではない) を参照してください。
