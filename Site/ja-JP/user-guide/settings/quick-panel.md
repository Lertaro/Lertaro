# クイックパネル

パネルを開いている間、現在選択しているグループの見出しに表示されたフォルダーも現在のディレクトリとして扱われます。選択項目がファイルかフォルダーかは関係ありません。見出しのパスが空でなければ、対応するファイルダイアログでクイック切り替え（既定は `Ctrl+G`）を使ってその場所へ移動できます。

ホットキーで呼び出し、前面にあるウィンドウの右下隅に、その高さと幅のちょうど半分のサイズでドッキングするフローティングパネルです。指定したフォルダーの中身と、プラグインが提供する一覧を、サムネイルタイルまたは一覧で表示するので、作業中のウィンドウを離れずにファイルを取り出したり、ドラッグして持ち出したり、逆にドロップして入れたりできます。上端をドラッグすれば、今回の呼び出しの間だけ別の場所へ移動できます。

- **クイックパネルを有効にする** — マスタースイッチ。オフにするとホットキーを押しても何も起きません。

呼び出すキーは[ホットキー](./hotkeys-page)ページにあります(既定は `Ctrl+F2`)。

## ワークスペース

パネルは一度に1つのタブを表示し、**ワークスペース**はそのうちの1種類です。ワークスペースとは、ある種類の作業のために集めたソースの組です — あるプロジェクトのフォルダー群、参考資料を置いている場所、ものを放り込むための受け皿など。

左側のリストがワークスペースそのもので、**新しいワークスペース**、**ワークスペースを複製**、**ワークスペースを削除**のボタンと、設定の他の場所と同じ上下矢印(またはドラッグ)による並べ替えリスト([お気に入り](./favorites)を参照)が付いています。ここでの上から下が、パネルのタブストリップでの左から右になります。

- **名前** — タブに表示される文字。空のままにすると翻訳済みの既定名にフォールバックするので、一度も名前を変えていないワークスペースは UI 言語に追従します。
- **有効** — 各ワークスペースの横のチェックボックス。オフにすると設定は残したままタブだけがなくなります。今月は使わないが、削除するとソース一覧を組み直す羽目になるワークスペース向けです。ライブパネルのタブにある **×** はまさにこれを行うので、戻すのはここからになります。

選択中のワークスペースは2つのサブタブで編集します:**ソース**と**アプリ**。

## ソース

各ソースがパネルの1つのグループになり、このリストの順序で表示されます。**フォルダーを追加**で追加します。各行のチェックボックスはそのグループを削除せずに非表示にし、名前のボックスはグループの見出しを上書きします(空ならフォルダー自身の名前)。**その他のオプション**に残りの設定があります:

- **表示** — そのグループがフォルダーから何を取り出すか:
  - **最近変更されたファイル** — 最近変更されたものだけを新しい順に。フォルダーを走査するのではなくインデックスが答えます。
  - **すべて、新しい順** — 古いという理由でファイルを隠すことはなく、何を先に出すかだけを決めます。
  - **すべて、名前順** — フォルダーをショートカットバーとして使う場合。
- **フォルダー** — フォルダーそのもの。隣の **…** ボタンで参照できます。
- **サブフォルダーを含む** — 既定はオフ。
- **ドロップされたファイルを受け入れる** — このグループにドラッグしたファイルやフォルダーを、Windows 自身のファイルコピー(その進行状況ダイアログ、競合の確認、元に戻す操作)でこのフォルダーへコピーします。常にコピーで、移動になることはありません。既定はオフで、ソースごとに個別に指定します:受け皿として使うフォルダーには必要で、読むだけのフォルダーには不要だからです。
- **フィルター** — `;` または `,` で区切った1つ以上のパターン(例:`*.mp4;*.mkv`)で、このソースに表示する内容を任意に絞り込みます。既定の空欄はフィルターなしです。
- **最大** — このグループが表示する最大件数。0 はソースにあるものすべて。
- **変更が次の時間内(分)** — この時間内に変更されたものだけが対象になります。0 は期間制限なし。
- **一覧で表示** — このグループをサムネイルタイルではなく詳細一覧で開きます。どちらが合うかはフォルダーの性質次第です:画像はタイル、文書は名前と日付。タイルは1行を5つで**等分**します — 広いウィンドウにドッキングしたパネルでは、数が増えるのではなく見るに値する大きさのサムネイルになります。5は固定ではありません:5つでもサムネイルが埋められる幅を超えるほど広ければ数が増え、5つでは判別できないほど狭ければ数が減ります。いくつになっても1行は固定サイズを並べるのではなく**等分**するので、行末に隙間が残ることはありません。絵はそれぞれの比率のままなので、16:9の動画ばかりのフォルダーが、上下に余白の帯を抱えた縦長の箱の並びになることもありません。

ここで追加したフォルダーは既定で**すべて、名前順**です — 手で選んだフォルダーは、たいてい物が置いてある場所だからです。新規インストール時のワークスペースだけは例外で、それも意図的です:デスクトップ、ダウンロード、ドキュメントは物が届く場所なので、最近変更されたファイルで始まります。

## プラグインタブ

プラグインが提供するタブで、どれかのワークスペースの中ではなく、ページ自身の2つめのタブに並びます:プラグインが差し出すのは一揃いのコレクションであり、このワークスペースのフォルダーとも、あのワークスペースのフォルダーとも、特に近しいわけではないからです。各タブはパネル全体に対して一度チェックすればストリップに入り、外せば出ていきます。

CoreExtensions には5つ同梱されています:

| タブ | 何が並ぶか |
|---|---|
| **お気に入り** | あなたの[お気に入り](./favorites)を、並べた順のまま。中の URL はブラウザーで開きます。 |
| **履歴** | Lertaro 自身から開いたもの。新しい順 — この中でアプリケーションを含むのはこれだけです。 |
| **Windows の最近使った項目** | シェル自身の最近使ったドキュメントの一覧を、指し示す実ファイルへ解決したもの。新しい順。 |
| **最後のフォルダー** | 最後に見ていたフォルダー — エクスプローラーでも、どのアプリのファイルダイアログでも構いません。直前まで居た場所をそのまま差し出せます。 |
| **最近使ったファイル** | パネルが見るように設定されたフォルダー群の中で最も新しいファイル。フォルダーを歩き回るのではなくインデックスが答えます。ファイルのみ。 |

- チェックボックスはそのタブをストリップに入れるか外すかを決めます。パネル上のタブの **×** も同じことなので、戻すのはここです。
- **一覧で表示** — そのタブをサムネイルタイルではなく詳細一覧で開きます。フォルダーソースと同じ選択肢で、ここで訊いているのは、プラグインタブにはソースリストの中に自分の行がないからです。パネル側の見出しの表示切り替えは、開いている間に限りこれを上書きします。
- リストに載るのは[プラグイン](./plugins)ページでコンポーネントが有効になっているタブだけですが、それは別の問いです:ここでチェックを外すのはストリップから外すだけ、あちらで無効にするのはそもそも動かさないということ。プラグインをオフにしている間に閉じたタブは、プラグインが戻ってきても閉じたままです — この状態はコンポーネントに対して保存されており、そのとき読み込まれているものから組み立て直しているわけではありません。

プラグインタブは一覧を1つだけ持ち、グループの見出しは付きません — タブ自体がすでにその名前だからです。ファイルのドロップは受け付けず、何も返さなかったプラグインにはタブ自体ができません。

## アプリ

このワークスペースが属するアプリケーションを、1行につき1つのプロセス名で指定します(`chrome` でも `chrome.exe` でも構いません)。そのいずれかの上でパネルを呼び出すと、前回の状態ではなくこのワークスペースで開きます — 今いるアプリ自体が、どのフォルダー群のことなのかを語っているからです。空にすると、このワークスペースは手動でしか開けません。

## クイックパネルのみ

パネルが立ち入らないアプリケーションを、1行につき1つのプロセス名で指定します。グローバルな[プロセスのブラックリスト](./hotkeys-page#process-blacklist)を置き換えるのではなく、その上に**追加**されます:グローバルでブロックされているものはここでもブロックされます。このリストは、このパネルだけが避ける理由を持つアプリのためのものです — 前面のウィンドウに自分を貼り付けるので、全画面のプレーヤーやゲームは台無しになりますが、だからといってグローバルなブロックに値するわけではありません。

## パネルの使い方

- **フィルターボックス** — タブストリップの右にあり、パネルが開いた瞬間にフォーカスが入ります。あいまい検索(検索ウィンドウと同じ fzf 方式のマッチング、ピンインエイリアスを含む)で、対象は現在のワークスペースだけです。フィルター中に一致が1件もなくなったグループは非表示になります。
- **Enter** は選択中の項目を開きます。ダブルクリックと同じです。最初の項目が初めから選択されているので、呼び出してからフィルターボックスを離れることなく「入力して Enter」だけで完結します。
- **上下キー**は選択を動かし、グループの最後の行で止まらずに次のグループへ入っていきます — 全グループが上から下へひと続きのリストとして扱われます。フィルターボックスからも使え、キーボードがボックスから離れることはないので、絞り込みと選択がひと続きの操作になります。タイル表示のグループの中では、これまでどおりグリッドの行単位で移動します。設定の「次/前の項目を選択」ホットキー(既定は `Ctrl+N`/`Ctrl+P`)も同じ動作です。ただし同じキーにプラグインのアクションが割り当てられている場合は、そちらが優先されます。
- **タブの切り替え** — 「N番目の結果へジャンプ」の修飾キー(既定は `Ctrl`、[ホットキー](../hotkeys)参照)を押しながら 1〜9、またはタブをクリック。ワークスペースとプラグインタブは1本のタブストリップと1つの並び順を共有します。タブはドラッグで並べ替えられ、それぞれの **×** はそのタブをストリップから外します(ワークスペースはオフに、プラグインタブは閉じた状態に — どちらも上の設定で戻せます)。最後の1つを閉じるとパネル自体が閉じます。
- **グループの見出し**には並べ替えの切り替え(名前順/更新日時順)、表示の切り替え(タイル/一覧)、折りたたみの矢印があります。見出し本体または矢印をクリックすると、標準的な Windows のグループ見出しのように開閉できます。並べ替えと表示のコントロールはそれぞれの操作を続けます。ここでの操作はパネルが開いている間だけ有効で、初期状態は上の設定が決めます。
- **行番号** — すべてのグループで左側の余白を共有します。リスト表示では項目、タイル表示では視覚上の行に番号を付けます。余白の幅は表示中のグループで最大の番号に合わせるため、番号は常に揃います。グループの開閉は折りたたみの矢印を操作したときだけで、スクロールでは変わりません。
- **複数選択** — タイル表示では、空いている場所をドラッグして矩形選択できます。選択は1つのグループに属します(グループごとに独立したリストを描画しているため)。空白をクリックすると選択が解除されます。
- **ファイルのドロップ** — ファイル、フォルダー、あるいは Web ページから直接ドラッグした画像を、ドロップを受け入れるグループへ落とします。ドラッグがファイルとして提供できるものはすべて受け取り、画像に限りません。コピーが終わるとそのグループは自動で読み込み直します。
- **プレビュー** — QuickLook のキー(既定は `Alt+P`。他のホットキーと同じく[ホットキー](./hotkeys-page)ページで変更できます)で、選択中のファイルのプレビューウィンドウが開き、以後は選択に追従します。ドッキングするのはパネルの右側で、画面の端に阻まれて収まらないときだけ左側に回ります — 最大化したウィンドウの右下隅にいるパネルがまさにその場合です。プレビューをクリックしてもパネルは消えず、その両方から離れたときに消えます。パネルを閉じると一緒に閉じます。
- **閉じないようにする** — パネルはフォーカスを失うと閉じます。ピン留めボタン、または「ウィンドウを閉じない」ホットキー(既定は `Ctrl+T`、クイックウィンドウと同じキー)で、今回の呼び出しの間だけそれを止められます。
- **Esc** はフィルターボックスに文字があればそれを消し、なければパネルを閉じます。
- パネルは自身を最新に保ちます:表示中のフォルダーがディスク上で変化すると読み込み直します。独自のスキャンではなく、アプリ全体で使っているインデックスベースの監視を通じて行われます。
