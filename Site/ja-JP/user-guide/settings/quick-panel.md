# クイックパネル設定

**クイックパネル（Quick Panel）** は、頻繁に使用するファイルの呼び出し、プロジェクトのコンテキスト管理、デスクトップ上でのドラッグ＆ドロップ操作のために設計されたフローティングワークスペースです。ホットキーを押すとアクティブウィンドウの右下に吸着表示され、作業中の画面を離れずにファイルを参照・整理できます。

## 1. コア機能とメインスイッチ

- **クイックパネルを有効化**：全体の有効化スイッチ。無効にするとホットキーは反応しなくなります。
- **呼び出しホットキー**：既定は **`Ctrl+F2`**（[**設定 → ホットキー**](./hotkeys-page) で変更可能）。
- **スマートドッキングとサイズ制御**：親ウィンドウの幅・高さのそれぞれ 1/2 のサイズで表示されます（視認性と操作性を保つため最小サイズは `280 × 200px` に制限）。Lertaro のウィンドウがアクティブな場合は誤動作防止のためホットキーは無視され、パネルが開いている状態で同じホットキーを押すと閉じます。
- **クイックジャンプとの連動**：パネルが開いている間、現在選択中のグループのフォルダーが作業ディレクトリとして記録されます。ファイルダイアログで `Ctrl+G` を押すとそのフォルダーへ即座に移動できます。

## 2. ワークスペース（Workspaces）

プロジェクトやタスクごとにフォルダーの組み合わせを整理できます。

- **ワークスペース管理**：左側の一覧で **新規作成**、**複製**、**削除** を行え、ドラッグでタブバー上の表示順序を並び替えられます。
- **プロパティ**：
  - **名前**：タブに表示されるテキスト（空欄の場合は言語設定に応じた既定名になります）。
  - **有効スイッチ**：タブバーに表示するかどうかを制御します。パネル上でタブの **×** ボタンを押して非表示にした場合も、ここで再度有効化できます。

選択したワークスペースは、右側の **ソース** と **アプリケーション** の 2 つのタブで設定します。

## 3. ソース設定（Sources）

ワークスペース内の独立したフォルダーグループを定義します。

- **フォルダーを追加**：対象となる物理ディレクトリを選択します。
- **表示モード（Display Mode）**：
  - **最近変更されたファイル** —— インメモリインデックスからミリ秒未満で最近更新されたファイルを抽出（新しい順）。
  - **すべてのファイル（新しい順）** —— すべてのファイルを更新日時の降順で表示。
  - **すべてのファイル（名前順）** —— 定番ファイルのショートカットバーとして利用。
- **サブフォルダーを含める**：配下のファイルを再帰的に含めます。
- **ドロップされたファイルを受け入れる**：有効にすると、外部からファイルやフォルダー、Web 画像をこのグループにドラッグ＆ドロップしてコピーできます（Windows 標準のコピー機能を使用し、衝突確認や取り消しに対応）。
- **フィルタールール**：ワイルドカードまたは検索構文の `@` フィルターで表示する拡張子を限定（例: `*.mp4;*.mkv`、`*.lnk;:@doc;:@img`、`*.lnk;:@doc|img`）。
- **最大表示件数と時間制限**：表示件数の上限（0 で無制限）や、N 分以内に更新されたファイルのみに絞り込む設定。
- **詳細リスト vs サムネイルタイル**：グループごとにリスト表示かグリッドタイル表示かを選択可能（タイルは縦横比を維持したまま均等に拡大縮小）。

## 4. プラグイン動的タブ（Plugin Tabs）

プラグインが提供する動的リストをクイックパネルに表示できます。CoreExtensions には 5 つの標準タブが含まれています。

| プラグインタブ | 内容 |
| :--- | :--- |
| **お気に入り** | スターを付けた登録アイテム（URL はブラウザーで開きます）。 |
| **履歴** | Lertaro 経由で開いた最近のアイテムやアプリ。 |
| **Windows 履歴** | Windows の「最近使った項目」を実ファイルとして展開。 |
| **前回のフォルダー** | エクスプローラーやダイアログで直前に開いていたフォルダーを追跡。 |
| **最近のファイル** | インデックスを利用して設定済みフォルダー内の最新ファイルを一覧表示。 |

各タブの有効/無効や、リスト/タイルの初期表示形式を個別に設定できます。

## 5. アプリ連携と専用ブラックリスト

- **アプリケーション連携（Applications）**：特定のプロセス名（例: `chrome.exe` や `devenv.exe`）を登録すると、そのアプリ上でクイックパネルを呼び出した際に該当するワークスペースが自動で開きます。
- **クイックパネル専用ブラックリスト**：パネルの表示を抑制したいアプリを登録します。グローバルブラックリストに**上乗せ**して適用されます。

## 6. パネルの操作ガイド

- **リアルタイムあいまい絞り込み**：右上の検索ボックスであいまい一致とピンイン検索による絞り込みが可能。
- **キーボードナビゲーション**：上下キーでグループをまたいでスムーズに選択移動し、`Enter` で実行。
- **タブ切り替え**：`Ctrl` + `1`–`9` で各タブ間をすばやく切り替え。
- **QuickLook プレビューとピン留め**：項目を選択して `Alt+P` でプレビューを表示、`Ctrl+T` でフォーカス喪失時も閉じないように固定。
