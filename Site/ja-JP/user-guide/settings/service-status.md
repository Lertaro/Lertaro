# サービス状態

サービス状態画面では、Lertaro のバックグラウンドインデックスサービスの稼働状況を一元監視し、Service、App、Hook の 3 大プロセスのリアルタイムログを閲覧できます。設定画面は **設定 → サービス状態** です。

## 1. サービス状態とコントロール

上部のステータスカードには、バックグラウンドインデックスサービスの稼働状況がリアルタイムに表示されます。

- **状態表示**：
  - **準備完了（Ready）**：サービスが正常稼働しており、インデックス済みのファイルおよびフォルダーの総数が表示されます。
  - **インデックス作成中（Indexing）**：初期構築または増分スキャンの実行中（スピナーが表示されます）。
  - **インストール中（Installing）**：Windows サービスの登録および起動処理中。
  - **エラー（Error）**：サービスが停止中または異常終了している状態（エラー内容と警告マークを表示）。
- **サービスの自己修復とインストール**：サービスが未インストールまたはエラーの場合にのみ **サービスをインストールして起動** ボタンが表示されます。正常稼働時は意図しない中断を防ぐため常時バックグラウンドで稼働し続けます。

## 2. 3 プロセス統合リアルタイムログビューアー

下部のログビューアーは、Lertaro を構成する 3 つのプロセスに対応するタブに分かれています。

- **App タブ**：フロントエンド WPF UI、検索インタラクション、ホットキー応答、描画に関するログ。
- **Hook タブ**：低レベルキーボードフックプロセス（`Lertaro.Hook.exe`）のキー監視と隔離状態に関するログ。
- **Service タブ**：管理者権限バックグラウンドサービス（`Lertaro.Service.exe`）の USN ジャーナル解析、ディスクスキャン、インメモリツリー構築、IPC 通信ログ。

### 絞り込みとログ消去

- **ログレベルフィルター**：「すべて / エラー / 警告 / 情報 / デバッグ」から選択でき、重大度に応じて色分け表示されます。
- **リアルタイム検索**：キーワードを入力してログ行を即座に絞り込み可能。
- **ログの安全な消去**：**ログを消去** をクリックすると表示中のタブのログを消去します。Service タブのログは IPC 経由で安全に切り詰められます。
