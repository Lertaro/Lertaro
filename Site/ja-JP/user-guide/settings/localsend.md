# LocalSend ローカル転送設定

Lertaro には、公式の [LocalSend](https://localsend.org) プロトコルと互換性のあるローカルネットワーク転送機能が統合されています。同一 LAN 内のスマートフォンや PC とファイル、フォルダ、プレーンテキストを相互に転送できます。設定のパスは**設定 → LocalSend**です。

## 基本設定

- **LocalSend ローカル転送を有効化** —— LocalSend 転送サービスのオン/オフを切り替えます。有効化するとトレイメニューに「LocalSend で送信...」項目が表示され、グローバルショートカットにも反応します。
- **デバイス名** —— LAN 内の他の LocalSend クライアントから識別されるエイリアス名。デフォルトではマシン名から自動生成されます。
- **サービスポート** —— 受信要求を待機する HTTP/HTTPS ポート（既定値は `53317`）。

## セキュリティと暗号化

- **暗号化転送 (HTTPS)** —— 有効にすると HTTPS 暗号化接続を使用してデータを転送します（相手デバイスの暗号化サポートが必要です）。
- **受信 PIN コード** —— 転送要求時に必要な PIN コード（空欄で無効化）。

## 受信と保存

- **ファイルを自動保存** —— 信頼できるクライアントからのファイルを自動的に受信・保存します。
- **保存先フォルダ** —— 受信したファイルの既定の保存先ディレクトリ。

## 呼び出しと送信モード

- **ショートカットの呼び出し** —— 既定では **`Ctrl+S`**（[ショートカット設定](./hotkeys-page)で変更可能）またはトレイメニューの「LocalSend で送信...」から呼び出します。
- **モード切り替え** —— 送信ウィンドウで [ ファイル / フォルダ送信 ] と [ テキスト送信 ] を切り替えられます。
