# LocalSend 設定

Lertaro は、オープンソースの [LocalSend](https://localsend.org) プロトコルとネイティブ互換性を持つ LAN 内ファイル転送エンジンを内蔵しています。外部のインターネットやケーブルを必要とせず、同一 LAN 内にある Windows、Mac、Linux、iPhone、iPad、Android デバイス間でファイル、フォルダー、テキストを即座に送受信できます。設定画面は **設定 → LocalSend** です。

## 1. 基本サービス設定

- **LocalSend 転送サービスを有効化**：全体のスイッチ。有効にするとバックグラウンドで待受サービスが起動し、トレイメニューに「他のデバイスへ送信...」項目が追加されます。
- **デバイス名**：LAN 内の他デバイスに表示される名前。初期設定ではコンピューター名が使用されますが、自由に変更可能です（例: `作業用ノートPC`）。
- **サービスポート**：HTTP / HTTPS 待受ポート（LocalSend 標準の `53317` が既定）。競合がある場合は変更できます。

## 2. セキュリティ・暗号化・保存先

- **暗号化転送 (HTTPS)**：既定で有効。デバイス間の通信を TLS で暗号化し、LAN 内の盗聴を防ぎます。
- **受信 PIN コード**：4〜6 桁の数字 PIN を設定可能。設定時は送信側で一致する PIN の入力が必要になります（空欄で無効）。
- **ファイルの自動保存**：有効にすると、信頼できるクライアントからの転送要求を手動の確認なしで自動承認・保存します。
- **保存先ディレクトリ**：受信したファイルの保存先（既定は `Downloads\LocalSend`）。参照ボタンから変更可能です。

## 3. 送信画面と操作方法

- **ホットキーによる起動**：グローバルホットキー **`Ctrl+S`**（[**設定 → ホットキー**](./hotkeys-page) で変更可能）で送信画面を瞬時に呼び出せます。
- **送信モードの切り替え**：送信画面上部で **[ファイル / フォルダー送信]** と **[テキスト送信]** を切り替え可能。
- **ドラッグ＆ドロップでのファイル追加**：Lertaro の検索結果、クイックパネル、エクスプローラーからファイルを送信ウィンドウへ直接ドラッグして追加可能。レーダーで検出されたデバイスをクリックするだけで高速転送されます。
