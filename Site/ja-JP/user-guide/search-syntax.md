# 検索構文

Lertaro の検索ボックスは、単なる文字列の一致検索にとどまりません。超高速な検索アルゴリズムを搭載し、あいまいな文字飛び一致、論理演算子、単語境界修飾子、ドライブやパスの絞り込み、クエリトークンによる二次フィルター、多言語スマートエイリアスに対応しており、すべての構文を同一のクエリ内で自由に組み合わせて使用できます。

## 1. 基本一致モードと大文字小文字の区別

### あいまい検索（既定）

Lertaro では既定であいまい一致（Fuzzy Matching）が有効になっています。検索語の任意の文字を順番どおりに入力するだけで、ファイル名やフォルダー名の中で文字が離れていても正確にヒットします。

| 入力例 | 一致結果の例 | 説明 |
| :--- | :--- | :--- |
| `ltro` | `Lertaro.exe` | `l` → `t` → `r` → `o` の順序で飛び飛びに一致（**L**er**t**a**ro**.exe） |
| `vsc` | `Visual Studio Code.lnk` | 各単語の頭文字に一致（**V**isual **S**tudio **C**ode） |
| `rep` | `Q3-report-final.docx` | 連続する部分文字列に一致（Q3-**rep**ort-final.docx） |

**設定 → 一般 → システム → あいまい一致を有効化** をオフにすると、通常の検索語（演算子なし）は連続した部分文字列として一致する必要があります（`abc` は `a-b-c` に一致しなくなります）。この設定は修飾子のない通常の検索語にのみ影響し、後述するすべての演算子の動作は変わりません。

### スマートな大文字小文字の区別（Smart Case）

- **すべて小文字の検索**：既定で大文字と小文字を区別しません。例えば `myfile` は `myfile`、`MyFile`、`MYFILE` などに一致します。
- **大文字が含まれる検索**：検索語に大文字が 1 つでも含まれている場合、その単語は自動的に**大文字小文字を区別**するようになります。例えば `MyFile` は `MyFile` のみに一致し、小文字の `myfile` には一致しません。

## 2. 複数キーワードと論理演算

### スペース：AND（論理積）

複数の検索語をスペースで区切ると、すべての条件を満たす必要があります。ファイル名内に出現する順序は**問いません**。

```text
report final 2024
```

上記の入力は、`2024-Q3-report-final.docx` と `final_report_2024.pdf` の両方に一致します。

### パイプ `|`：OR（論理和）

パイプ記号 `|` でキーワードを区切ると、いずれかの条件に一致すればヒットします。

```text
png | jpg | gif
```

AND と OR を自由に組み合わせることができます。

```text
report | summary 2024
```

これは `report` または `summary` を含み、かつ `2024` も含むファイルを検索します。OR 検索では、条件を満たしたすべてのキーワードが結果の名前の中で同時にハイライト表示されます。

### 単語内のスペースとフレーズの引用符

スペースを含むフレーズを 1 つの単語として検索したい場合は、バックスラッシュでスペースをエスケープ（`\ `）するか、単一引用符 `'...'` または二重引用符 `"..."` で囲みます。

```text
final\ report
'final report'
```

どちらの書き方も、2 つの独立した AND キーワードではなく、スペースを含んだ 1 つの完全なフレーズとして `final report` を検索します。

### 複数行テキストの貼り付け（自動で OR に折りたたみ）

スプレッドシートやテキストファイル、ログなどから複数行のテキスト（1 行に 1 ファイル名）をコピーして検索ボックスに直接貼り付けると、Lertaro は各行を `|` で連結し、1 つの OR クエリとして自動的に折りたたみます（空白行はスキップされます）。

```text
123
456
678
```

貼り付けると次のように自動変換されます。

```text
123 | 456 | 678
```

## 3. 検索演算子一覧

### 演算子クイックリファレンス

| 演算子 / 構文 | タイプ | 効果 | 入力例 | 一致結果の例 |
| :--- | :--- | :--- | :--- | :--- |
| *(なし)* | 既定のあいまい一致 | 文字が順番どおりに含まれていれば一致（あいまい検索オン時） | `report` | `Q3-report-final.docx` |
| `!` | 除外 | 名前に対象の文字列が正確に含まれる項目をすべて除外 | `!temp` | `temp` を含むファイルを除外 |
| `'` | 完全一致の反転 | あいまいオン時は完全一致へ、オフ時はあいまい一致へ切り替え | `'report` | 連続する部分文字列 `report` が必須 |
| `'...'` | 単語境界一致 | 単語の境界に位置する完全一致（単語内部の誤一致を防止） | `'app'` | `app.exe` や `my-app.log` に一致、`whatsapp.exe` には不一致 |
| `^` | 前方一致 | ファイル名/フォルダー名が指定の文字で始まる | `^IMG` | `IMG_20240101.jpg`（`MY_IMG.jpg` には不一致） |
| `$` | 後方一致 | ファイル名/フォルダー名が指定の文字で終わる | `.pdf$` | `document.pdf`（`document.pdf.bak` には不一致） |
| `^...$` | 完全一致 | 名前全体が指定の文字列と完全に一致 | `^readme.md$` | `readme.md` のみに一致 |
| `\|` | OR（論理和） | パイプのいずれかの側の条件に一致 | `doc \| pdf` | `doc` または `pdf` を含む名前に一致 |

### 演算子の詳細説明と組み合わせ実例

1. **除外修飾子 `!`**：`!term` は `term` という部分文字列を含む結果を完全に除外します。不要な除外を防ぐため、除外語句にはピンイン展開などのエイリアスは適用されません。
2. **完全一致の反転 `'`**：全体であいまい一致が有効なとき、先頭に `'` を付けると特定の検索語のみを一時的に完全一致（連続した部分文字列）にできます。例えば `lertaro 'v1.2` と入力すると、`lertaro` はあいまい一致、`v1.2` は連続一致になります。
3. **単語境界一致 `'...'`**：単語を引用符で囲むと（例: `'app'`）、前後の境界（空白、記号、ハイフン、アンダースコア、文字列の端）をチェックし、長い単語の途中への意図しない一致を防ぎます。
4. **完全一致 `^...$`**：`^` と `$` が**同一の単語**を囲んでいる場合にのみ機能します。別々の単語に指定した場合（例: `^src md$`）は、それぞれ独立した前方一致と後方一致として扱われます。

**複数演算子の組み合わせ例**：

- `^IMG !.png$ 2024`：`IMG` で始まり、`2024` を含み、拡張子が `.png` **ではない** ファイルを検索。
- `'data | 'backup ^2024 .zip$`：`2024` で始まり、`.zip` で終わり、かつ名前に `data` または `backup` が正確に含まれるアーカイブを検索。

## 4. パスモードとドライブの絞り込み

### ドライブの指定

検索ボックスの先頭にドライブ文字とコロンを入力すると、検索範囲を特定のドライブに限定できます。

```text
d: report
```

スペースは省略可能で、`d:report` と `d: report` は同等です。

### フルパスモード

検索文字列にパス区切り文字（`\` または `/`）が含まれている場合、Lertaro は自動的にフルパス一致モードに切り替わります。

```text
D:\Projects\Lertaro
```

末尾をパス区切り文字で終えた場合（例: `D:\Projects\`）、そのフォルダーの**直下および内部**にある項目を検索します。

### 親フォルダー名のフォールバック一致（Folder Matching）

ファイル名単体での検索結果が上限件数に達しない場合、Lertaro は検索語のうちファイル名に一致しなかった部分を使って親フォルダー名との一致を自動的に補完します。特別な構文は不要です。

```text
d01j dcj
```

`dcj` という文字列がファイル名自体に含まれていなくても、`dcj` という名前（またはエイリアス）のフォルダー内にある `d01j.txt` を見つけることができます。

> [!NOTE]
> 少なくとも 1 つの単語がファイル名自体に一致している必要があり、ファイル名単体での一致で結果が埋まらなかった場合にのみ動作します。補完された結果は常に通常の検索結果の後ろに並び、通常の検索結果の順序を乱すことはありません。

## 5. クエリトークンと二次フィルター（Query Tokens）

Lertaro では、メインの検索語の後ろにコロン `:`（**設定 → 一般 → システム → クエリトークン総前置文字** で変更可能）で始まる**クエリトークン（Query Tokens）**を追加し、結果の二次フィルターや並べ替えを行えます。

1 つの `:` の後ろにカンマ `,` で区切って複数のトークンを連結できます（例: `report :@doc,M-,:-F`）。

### ファイルカテゴリフィルター（`:@<カテゴリ名>`）

定義済みの拡張子カテゴリを素早く適用できます。`|` による複数指定も可能です。

- `:@doc`：ドキュメント類（`*.doc; *.docx; *.pdf; *.txt; *.ppt; *.pptx; *.xls; *.xlsx; *.csv; *.rtf; *.md; *.wps`）
- `:@img`：画像類（`*.jpg; *.jpeg; *.png; *.gif; *.bmp; *.webp; *.ico; *.svg; *.tif; *.tiff; *.psd; *.ai`）
- `:@video`：動画類（`*.mp4; *.mkv; *.avi; *.mov; *.wmv; *.flv; *.m4v; *.webm; *.3gp; *.rmvb; *.ts`）
- `:@audio`：音声類（`*.mp3; *.wav; *.flac; *.aac; *.ogg; *.m4a; *.wma; *.ape`）
- `:@zip`：圧縮ファイル類（`*.zip; *.rar; *.7z; *.tar; *.gz; *.bz2; *.xz; *.iso`）

**例**：

- `財務 :@doc`：ドキュメント類から「財務」を検索。
- `壁紙 :@img`：画像ファイルから「壁紙」を検索。
- `clip :@video|audio`：動画または音声ファイルから「clip」を検索。

**設定 → プラグイン → CoreExtensions** でカテゴリのルール編集や新規追加が可能です。

### 拡張子の直接指定フィルター（`:.ext` または `:.ext1.ext2`）

ドットで始まる拡張子を直接指定します（フォルダーは自動的に除外されます）。

- `report :.pdf`：`.pdf` ファイルのみに限定。
- `data :.csv.xlsx`：`.csv` または `.xlsx` ファイルのみに限定。

### 並べ替えとファイル/フォルダーの絞り込み（`:[SCMAF]`）

1 文字のアルファベットで属性を指定します：`S`（サイズ）、`C`（作成日時）、`M`（更新日時）、`A`（アクセス日時）、`F`（フォルダー/ファイルの絞り込み）。

文字単体は**昇順**（小さい順 / 古い順）を表し、マイナス記号 `-`（プレフィックスまたはサフィックス、例: `M-` や `:-M`）を付けると**降順**（大きい順 / 新しい順）または反転フィルターになります。

| トークン構文 | 効果 | 主な使用シナリオ |
| :--- | :--- | :--- |
| `:S` | サイズの昇順（小さいファイルが先頭） | 空ファイルや微小ファイルの探索 |
| `:S-` または `:-S` | サイズの降順（大きいファイルが先頭） | `log :S-`（容量を圧迫しているログファイルの調査） |
| `:M` | 更新日時の昇順（古いファイルが先頭） | 長期間更新されていないファイルの確認 |
| `:M-` または `:-M` | 更新日時の降順（最新の更新が先頭） | `report :M-`（直近で編集したドキュメントの検索） |
| `:C` / `:C-` | 作成日時の昇順 / 降順 | `build :C-`（最新のビルド成果物の確認） |
| `:A` / `:A-` | アクセス日時の昇順 / 降順 | `project :A-`（最近開いたプロジェクトの検索） |
| `:F` | **フォルダーのみ**（通常ファイルを除外） | `config :F`（config という名前のフォルダーのみ検索） |
| `:-F` または `:F-` | **ファイルのみ**（フォルダーを除外） | `config :-F`（config という名前のファイルのみ検索） |

### ワイルドカードによる二次フィルター（`:?<式>` または `?<式>`）

標準的な Windows ワイルドカード（`?` は任意の 1 文字、`*` は任意の文字列）を使用して結果を絞り込みます。`|` や `;` で複数の OR 条件を指定できます。

- `mp4 :?(2026???????????)`：`2026` とそれに続く 11 桁のタイムスタンプを含む動画に一致。
- `photo :?IMG_????.jpg|DSC_????.jpg`：特定の形式の写真番号に一致。

### パス文字列による二次フィルター（`::<パス式>`）

結果の親フォルダー階層またはファイル名自体に、指定されたあいまいキーワードが含まれていることを要求します。

- `report ::2024`：ファイルが存在するパスのどこかに `2024` が含まれている必要があります。
- `main ::"src\core"`：`src\core` 配下に存在するファイルに限定。

### 連結トークンの組み合わせ例

複数のトークンを 1 つの `:` の後ろに連結して指定できます。

- `財務レポート :@doc,M-`：「財務レポート」を検索し、ドキュメント類に限定し、更新日時の新しい順にソート。
- `backup :.zip,S-,:-F`：「backup」を検索し、`.zip` 形式に限定し、ファイルサイズが大きい順にソート、ファイルのみを表示。
- `icon ::assets,?*128*`：「icon」を検索し、パスに `assets` を含み、名前に `128` が含まれる項目に限定。

## 6. 特殊な検索機能

### 単一検索での除外ルールの一時的なバイパス

検索クエリの先頭に `*` を付けると、[**除外ルール**](./settings/index-drives#除外ルール) で設定したパス除外、Glob、正規表現をその回の検索に限り一時的に無効化して検索できます。

```text
*node_modules
```

先頭の `*` は検索前に自動で除去され、テキストの一致判定には含まれません。すでにインデックス済みの項目のみが対象となります（ネットワークドライブや WSL で最初からインデックスされていないフォルダーは表示されません）。システムの隠しファイル除外などは維持されます。

### 検索結果種別トリガー

**設定 → 一般 → クイック検索ウィンドウ → 結果タイプ優先度** で、特定の結果タイプ（アプリケーション、システム設定、ファイルカテゴリ、プラグイン項目、ファイルなど）に 1 文字の**トリガー**を割り当てることができます。

クイック検索バーの先頭にそのトリガー文字を入力すると、そのタイプの結果のみが表示され、他のタイプはすべて非表示になります。

```text
;vs
```

例えば `;` が「アプリケーション」に割り当てられている場合、上記のように入力するとアプリケーション内の Visual Studio のみが検索されます。クイックウィンドウおよびインラインウィンドウでは、トリガーの有無にかかわらず履歴とお気に入りは常に最上位に固定表示されます。

## 7. 多言語スマートエイリアス

### 中国語ファイル名：ピンインエイリアス

標準搭載のピンインエイリアスプラグイン（`PinyinAlias`）により、設定なしでピンイン（ローマ字）による中国語ファイル名の検索が可能です。

- **全ピンイン（Full Pinyin）**：`chongqing` と入力して `重庆.docx` に一致。
- **頭文字（Initials）**：`cq` と入力しても `重庆.docx` に一致、`wzry` で `王者荣耀.exe` に一致。
- **多音字のサポート**：複数の読み方を持つ漢字も自動的にインデックスされます（例: `重庆` は `chongqing` と `zhongqing` の両方でヒット）。

**設定 → プラグイン** で `PinyinAlias` プラグインの状態を確認できます。

### スペイン語ファイル名：アクセント記号エイリアス

標準搭載の `SpanishAlias` プラグインにより、アクセント記号付き文字（`á`, `é`, `í`, `ó`, `ú`, `ü`, `ñ`）を含むファイル名を、通常の ASCII 文字でそのまま検索できます。

- `cancion` で `Canción.mp3` に一致。
- `nino` で `Niño.txt` に一致。
- `ciguena` で `Cigüeña.png` に一致。

一致した文字（元のファイル名に含まれるアクセント記号付き文字を含む）は正確にハイライトされます。

## 8. よくある質問とお気に入り

### お気に入り、カスタムエイリアスではない

Lertaro には一般的な「カスタム検索エイリアス/マクロ」機能はありません。最も近い代替手段は [**お気に入り**](./settings/favorites) です。任意のファイル、フォルダー、または URL をカスタム表示名でお気に入りに登録すると、その表示名で直接検索できるようになります（検索結果に ★ アイコンが表示されます）。

特定のキーワードで外部プログラムを起動したりスクリプトを実行したい場合は、[**カスタムコマンド**](./instant-answers#カスタムコマンド) を参照してください。
