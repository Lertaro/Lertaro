# 開発者ガイド

Lertaro は、サードパーティ製アセンブリが検索動作の拡張、コンテキストメニューアクションの追加、他のウィンドウとの統合、UI のカスタマイズを行うためにターゲットできる、オープンなプラグイン SDK
(`Lertaro.PluginSdk`)を提供しています。本ガイドではこの SDK の全体を解説します。

- **[アーキテクチャ](./architecture)** — App、バックグラウンドの Service、プラグインがどのように組み合わさっているか。
- **[はじめに](./getting-started)** — プラグインプロジェクトの雛形作成と読み込み。
- **プラグイン SDK リファレンス**:
  - **[コア検索とアクション](./sdk/core-search-actions)** — 検索結果と結果アクションの提供。
  - **[システム / ダイアログアダプター](./sdk/system-adapters)** — File Explorer、ネイティブファイルダイアログ、その他のフォアグラウンドウィンドウとの統合。
  - **[UI とプレビューの拡張](./sdk/ui-extensions)** — サイドバーフィルター、結果列、ファイルプレビュー、サムネイル、テーマ、翻訳。
  - **[共有抽象化](./sdk/abstractions)** — プラグインが受け取る読み取り専用モデル(`ISearchResult`、
    `IPluginSearchWindow`)と設定スキーマ(`IConfigurable`)。
  - **[ホストサービス](./sdk/services)** — ホストがプラグインに公開する静的サービス(アイコン、お気に入り、履歴、ファイルメタデータ、ディレクトリインデックス作成、プラグインごとの設定、ログ)。
- **[サンプルプラグイン](./examples)** — 実際に同梱されている2つのプラグインのケーススタディ。
- **[パッケージングと配布](./packaging)** — ビルドされたプラグイン DLL がどのように発見され、読み込まれるか。

ここに記載されているすべてのインターフェースシグネチャは、現在の `PluginSdk` ソースと直接照合して検証済みです——もし食い違いを見つけた場合は、コードの方が正となります。
