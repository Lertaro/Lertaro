# 즉시 답변 및 키워드 단축 명령

일부 결과는 파일 검색을 기다리지 않고 입력하는 즉시 나타납니다 — 항상 활성화되어 있거나, 실제 쿼리를
입력하기 전에 짧은 키워드로 게이트되어 있습니다(브라우저 기록 검색처럼 큰 기능이 관련 없는 모든 키
입력마다 주목을 끌지 않도록 하기 위함입니다). 키워드로 게이트된 대부분의 기능은
**설정 → 플러그인 → 구성**에서 키워드를 설정할 수 있습니다.

## 항상 활성화

이들은 키워드가 필요 없습니다 — 입력한 내용이 각자의 패턴과 일치하면 즉시 활성화됩니다.

### 계산기

수식을 직접 입력하면 결과가 실시간으로 나타나며, **Enter**를 누르면 클립보드로 복사됩니다.

```
12 * (4 + 3)
```

명시적인 진법 변환도 지원됩니다.

```
255 to hex
0xFF to dec
```

### 환경 변수

- `%NAME%`은 특정 변수를 펼쳐 보여줍니다(`%PATH%` 같은 다중 경로 변수는 경로별로 하나씩 항목이
  나뉩니다).
- `%partial`은 `partial`과 일치하는 모든 변수 이름을 퍼지 매칭으로 나열합니다.

### 명령 실행하기

- `#<command>`는 명령 프롬프트 창을 열고 `<command>`를 **관리자 권한으로** 실행합니다.
- `$<command>`는 명령 프롬프트 창을 열고 `<command>`를 일반적으로 실행합니다.

### 순수 URL

`http://`/`https://` 주소를 입력하거나 붙여넣으면 Lertaro가 이를 바로 열도록 제안합니다.

## 키워드로 트리거 (내장, 설정 가능한 접두사)

키워드, 공백, 그다음 쿼리를 입력하세요. 각 키워드는 기본적으로 짧은 접두사로 설정되어 있지만, 자주
입력하는 다른 무언가와 충돌한다면 해당 플러그인 자체의 **구성** 대화상자에서 독립적으로 변경할 수
있습니다.

| 키워드 (기본값) | 플러그인 | 검색 대상 |
|---|---|---|
| `ps` | Process Manager | 이름, PID, 창 제목으로 실행 중인 프로세스를 검색합니다(퍼지/병음 매칭도 지원) — 하나를 선택하면 종료합니다. |
| `win` | Window Switcher | 현재 열려 있고 전환 가능한 창(Alt+Tab이 보여주는 것과 동일한 집합)을 제목, 프로세스 이름, PID로 검색합니다. 하나를 선택하면 전면으로 가져옵니다. |
| `bm` | Browser Data | 해당 플러그인 자체 설정에서 추가한 Chrome/Chromium 계열 및 Firefox 계열 브라우저 프로필의 북마크와 기록입니다. |
| `set` | Core Extensions | 앱의 모든 설정을 이름으로 퍼지 매칭합니다 — 하나를 선택하면 강조 표시된 상태로 설정의 해당 항목으로 바로 이동합니다. `set`만 입력하면(뒤에 아무것도 없이) 모든 설정을 나열합니다. |

Window Switcher는 기본적으로 각 창의 실제 콘텐츠 실시간 썸네일을 아이콘으로 보여주며, 이는 백그라운드에서
캡처되므로 입력 속도가 느려지지 않습니다 — 일반 앱 아이콘이 먼저 즉시 표시되고, 준비되면 썸네일이 서서히
나타납니다. **설정 → 플러그인 → Window Switcher → 구성**에서 **창 콘텐츠를 아이콘으로 표시**를 끄면 이
캡처를 완전히 건너뛰고 항상 앱 아이콘을 사용합니다. 진짜 배타적 전체 화면으로 실행 중인 창(대부분의
게임은 기본적으로 이 대신 테두리 없는 창 모드를 사용하며, 이는 문제없이 처리됩니다)은 이 방식으로 캡처할
수 없으며 항상 앱 아이콘으로 대체됩니다.

Browser Data는 북마크와 기록을 독립적으로 인덱싱합니다 — **북마크 인덱싱**과 **기록 인덱싱**은
**설정 → 플러그인 → Browser Data → 구성**에서 별도의 토글이므로, 북마크는 계속 검색하면서 기록만
끄거나(기록은 북마크보다 훨씬 커지는 경향이 있습니다) 그 반대로 할 수 있습니다.

## 웹 검색

Web Search는 여러 검색 엔진/사이트에 대한 기본 키워드를 함께 제공합니다 — `bd`(바이두), `g`(Google),
`bing`(Bing), `gh`(GitHub), `wiki`(위키백과), `yt`(YouTube) — 그리고
**설정 → 플러그인 → Web Search → 구성**에서 각각 이름, 키워드, 아이콘, URL 템플릿을 지정하여 항목을
추가, 편집, 완전히 삭제할 수 있습니다.

```
g lertaro github
```

는 브라우저에서 "lertaro github"에 대한 Google 검색을 엽니다.

## 번역

번역 플러그인의 기본 키워드는 `tr`입니다. 뒤에 텍스트를 입력하면 현재 Lertaro 인터페이스에서 선택한 언어로 번역합니다.

```
tr hello
```

결과는 비동기로 표시됩니다. **Enter** 키를 누르거나 클릭하면 복사할 수 있습니다. 번역할 텍스트는 Microsoft Translator로 전송되므로 인터넷 연결이 필요합니다. 대상 언어는 App의 현재 언어 설정입니다. 키워드는 **설정 → 플러그인 → 번역 → 구성**에서 변경할 수 있습니다.

## File Filters

**설정 → 플러그인 → File Filters → 구성**에서 완전히 구성되는, 자체 규칙 아래 특정 폴더를
인덱싱합니다. 각 규칙은 자체 **대상 폴더** 목록(재귀적으로 스캔), **확장자 / 패턴** 필드(예:
`*.exe;*.lnk` — `;` 또는 `,`로 구분된 여러 패턴이 모두 매칭됩니다. 기본값 `*`는 모든 파일과
일치합니다), 결과 설명에 표시되는 선택적인 **필터 이름**을 가집니다. 하위 폴더는 패턴과 무관하게 항상
포함됩니다 — 패턴으로 필터링되는 것은 파일뿐입니다.

**바로가기 키워드**를 추가하면 위의 내장 키워드와 마찬가지로, 일반 인덱스에 항상 섞어 넣는 대신 규칙의
매칭 결과를 접두사 뒤로 게이트할 수 있습니다.

## 완전히 커스텀 (직접 키워드 정의)

### 커스텀 명령

**설정 → 플러그인 → Custom Commands → 구성**에서 완전히 구성되는, 외부 프로그램을 실행하는 여러분만의
`<keyword> <args>` 명령을 정의합니다. 명령의 매개변수 템플릿은 위치 기반 플레이스홀더(공백으로 구분된
각 인수에 대한 `%s1`, `%s2`, ...)와 전체 나머지 플레이스홀더(키워드 뒤에 입력한 모든 것에 대한 `%s`)를
지원합니다.

각 명령에는 **빠른 탐색에 표시** 체크박스도 있습니다(기본값 꺼짐) — 켜면 해당 명령이
[빠른 탐색](./hotkeys#빠른-탐색-마우스) 메뉴의 루트에도 자체 항목으로 나열되어, 키워드를 전혀
입력하지 않고도 클릭할 수 있습니다. **빠른 탐색 하위 메뉴** 필드는 루트 대신 이름 붙은 하위 메뉴 아래에
중첩시킵니다 — 여러 단계로 중첩하려면 `/`를 사용하세요(예: 2단계 하위 메뉴를 위한 `Tools/Network`).
비워두면 명령이 최상위 레벨에 유지됩니다. 이 방식으로 표시된 명령은 여기서 `%s1`/`%s`에 대입할 입력된
인수 텍스트가 없으므로, 구성된 매개변수를 그대로 사용하여 실행됩니다.

---

이 페이지의 어떤 플러그인도 필수가 아닙니다 — 각각은 키보드 공간을 두고 경쟁하는 것을 원하지 않는다면
[설정 → 플러그인](./settings/plugins)에서 독립적으로 비활성화할 수 있으며, [검색 문법](./search-syntax)은
그 밖의 모든 것(파일, 폴더, 애플리케이션)에 사용되는, 별개로 항상 활성화되어 있는 퍼지 쿼리 언어를
다룹니다.
