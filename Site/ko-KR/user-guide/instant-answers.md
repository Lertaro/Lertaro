# 인스턴트 답변 및 키워드 확장 기능

Lertaro는 로컬 파일 검색 외에도 강력한 즉시 계산, 시스템 도구 및 키워드 기반 확장 플러그인을 제공합니다. 파일 검색 결과를 기다릴 필요 없이 해당 명령어를 입력하여 즉각적인 결과를 얻을 수 있습니다.

## 1. 상시 활성화된 인스턴트 기능

키워드 접두사 없이도 입력된 텍스트가 특정 패턴과 일치하면 즉시 실행됩니다.

### 계산기 및 진법 변환

검색창에 수학 수식을 직접 입력하면 첫 번째 줄에 결과가 실시간으로 표시됩니다. `Enter`를 누르면 계산 결과가 클립보드에 복사됩니다.

```text
12 * (4 + 3)
100 * (1 - 0.15)
```

진법 변환도 기본 지원합니다.

```text
255 to hex
0xFF to dec
101010 to bin
```

### 환경 변수 확장 및 검색

- **변수 값 확인**: `%NAME%`(예: `%PATH%`, `%APPDATA%`)을 입력하여 실제 경로 값을 확인합니다. `PATH`처럼 여러 경로가 포함된 변수는 줄바꿈 목록으로 깔끔하게 자동 전개됩니다.
- **환경 변수 퍼지 검색**: `%` 뒤에 키워드를 입력(예: `%temp`)하면 해당 단어가 포함된 시스템/사용자 환경 변수를 검색합니다.

### 명령어 즉시 실행

터미널을 따로 열지 않고 검색창에서 직접 명령을 실행할 수 있습니다.

- `#<명령어>`: 명령 프롬프트를 열고 **관리자 권한으로 실행**합니다(예: `#sfc /scannow` 또는 `#net start Lertaro.Service`).
- `$<명령어>`: 명령 프롬프트를 열고 **일반 사용자 권한으로 실행**합니다(예: `$ping 1.1.1.1` 또는 `$ipconfig /all`).

### 웹 URL 바로 열기

`http://` 또는 `https://`로 시작하는 URL을 입력하거나 붙여넣고 `Enter`를 누르면 기본 브라우저에서 즉시 열립니다. 검색 결과가 없고 입력이 프로토콜 없는 도메인으로 시작하면 빠른 검색 창이 자동으로 `https://`를 채우고 커서를 끝으로 이동합니다. 이미 프로토콜이 포함된 입력은 변경하지 않습니다.

### 빠른 검색 창의 클립보드 텍스트 가져오기

미리 입력된 내용 없이 빠른 검색 창을 호출하면 클립보드가 비어 있지 않고 같은 창에서 직전에 가져온 값과 다를 때 텍스트를 자동으로 입력하고 전체 선택합니다. 같은 값은 반복해서 가져오지 않으며 URI 또는 전체 검색 창에서 돌아올 때의 미리 입력된 내용도 덮어쓰지 않습니다.

## 2. 키워드 실행 기능 (내장 플러그인)

짧은 **트리거 키워드 + 공백** 뒤에 쿼리를 입력하여 전용 플러그인 기능을 호출할 수 있습니다. 모든 키워드는 [**설정 → 플러그인**](./settings/plugins)에서 변경할 수 있습니다.

| 기본 키워드 | 플러그인 이름 | 기능 설명 및 활용 | 사용 예시 |
| :--- | :--- | :--- | :--- |
| `ps` | **프로세스 관리** | 실행 중인 프로세스를 이름, PID, 창 제목으로 검색하고 Enter로 즉시 종료. | `ps chrome` 또는 `ps 1234` |
| `win` | **창 전환기** | 열려 있는 앱 창을 검색하고 실시간 백그라운드 썸네일과 함께 즉시 전환. | `win code` 또는 `win 브라우저` |
| `bm` | **브라우저 데이터** | Chrome, Edge, Firefox의 북마크 및 방문 기록 검색(북마크/기록 개별 토글 가능). | `bm github` |
| `set` | **설정 검색** | Lertaro 내부의 모든 설정을 퍼지 검색. 선택 시 해당 설정 페이지로 즉시 이동 및 하이라이트. | `set 단축키` 또는 `set 퍼지` |
| `flow` | **Flow 플러그인 브리지** | 로드된 Flow.Launcher 플러그인 및 트리거 목록을 확인하고 Flow 생태계 활용. | `flow` |

## 3. 웹 검색 엔진 바로가기

웹 검색 플러그인에는 주요 검색 엔진이 내장되어 있어 접두사 뒤에 검색어를 입력하면 브라우저에서 바로 검색할 수 있습니다.

| 단축어 | 검색 엔진 | 예시 | 설명 |
| :--- | :--- | :--- | :--- |
| `bd` | 바이두 (Baidu) | `bd 딥러닝` | Baidu에서 검색 |
| `g` | 구글 (Google) | `g lertaro github` | Google에서 검색 |
| `bing` | 빙 (Bing) | `bing 마이크로소프트 문서` | Bing에서 검색 |
| `gh` | 깃허브 (GitHub) | `gh Lertaro` | GitHub 저장소에서 바로 검색 |
| `wiki` | 위키백과 (Wikipedia) | `wiki 양자역학` | 위키백과 항목 검색 |
| `yt` | 유튜브 (YouTube) | `yt lofi hip hop` | YouTube 동영상 검색 |

**설정 → 플러그인 → 웹 검색 → 설정**에서 새 검색 엔진과 커스텀 URL 템플릿을 추가/편집/삭제할 수 있습니다.

## 4. 즉시 번역

기본 트리거 `tr` 뒤에 번역할 텍스트를 입력하면 Lertaro UI 언어로 자동 번역됩니다.

```text
tr Hello, how are you today?
```

- 타이핑 중 비동기적으로 번역 결과가 나타나며, `Enter`를 눌러 결과를 복사할 수 있습니다.
- **설정 → 플러그인 → 번역 → 설정**에서 트리거 단어를 변경할 수 있습니다.

## 5. 파일 필터

**설정 → 플러그인 → 파일 필터 → 설정**에서 특정 폴더 및 확장자에 국한된 전용 검색 범위를 만들 수 있습니다.

- **대상 폴더 지정**: 특정 작업 디렉토리(예: `D:\Engineering\Drawings`)를 재귀적으로 스캔.
- **확장자 규칙 지정**: `*.dwg;*.dxf` 또는 `*.pdf;*.docx` 패턴 설정.
- **트리거 키워드 할당**: 전용 키워드(예: `cad`)를 할당하여 `cad 부품도`와 같이 특정 업무 파일만 격리 검색.

## 6. 커스텀 명령어

**설정 → 플러그인 → 커스텀 명령어 → 설정**에서 복잡한 스크립트, CLI 도구, 외부 앱을 간단한 명령어로 래핑할 수 있습니다.

- **매개변수 플레이스홀더**: 위치 플레이스홀더 `%s1`, `%s2`... 및 전체 입력 캡처 `%s` 지원.
- **퀵 내비게이션 연동**: "퀵 내비게이션에 표시"를 체크하면 [**퀵 내비게이션**](./hotkeys#3-퀵-내비게이션-마우스-트리거) 메뉴에 등록되며, `/`를 이용한 다단계 서브메뉴(예: `개발도구/서비스재시작`) 분류도 지원합니다.
