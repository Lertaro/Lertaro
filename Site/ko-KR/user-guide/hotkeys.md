# 단축키

아래의 모든 전역 및 앱 내 단축키는 **설정 → 단축키**에서 다시 바인딩할 수 있습니다. 여기서는 기본값을
보여줍니다. 설정 UI 자체에 대해서는 [설정 → 단축키 페이지](./settings/hotkeys-page)를 참고하세요.

## 전역 단축키

| 동작 | 기본값 | 참고 |
|---|---|---|
| 퀵 창 전환 | `Ctrl` 두 번 누르기 | 두 번 누르기 대신 전체 조합(예: `Alt+Space`)으로 설정할 수도 있습니다. |
| 빠른 전환 | `Ctrl+G` | 지원되는 파일 대화 상자에서 지원 파일 관리자 또는 빠른 패널에서 마지막으로 수집한 폴더로 이동합니다. 인라인 검색이 비어 있으면 그 대상도 결과로 표시됩니다. |
| 다음 항목 선택 | `Ctrl+N` | 아래쪽 화살표 키로도 동작합니다. [빠른 패널](./settings/quick-panel)에서는 그룹 하나가 아니라 탭 전체를 훑으며, 현재 그룹의 끝에서 다음 그룹으로 이어집니다. |
| 이전 항목 선택 | `Ctrl+P` | 위쪽 화살표 키로도 동작합니다. 빠른 패널에서도 마찬가지로 그룹을 넘나들며 탭 전체를 훑습니다. |
| 결과 1~9로 이동 | `Ctrl` + 숫자 | 수정자 키는 설정 가능하며, 숫자는 항상 1~9입니다. 퀵 창은 각 표시된 결과 옆에 작은 배지로 단축키를 보여주므로 행을 셀 필요가 없습니다. |
| 동작 메뉴 열기 | `Ctrl+O` | 선택된 결과에서 오른쪽 화살표 키로도 동작합니다. |
| 선택 항목으로 완성 | `Ctrl+Tab` | 퀵 창에서, 선택된 결과의 이름/경로로 검색 상자를 채웁니다. |
| QuickLook 미리보기 | `Alt+P` | 선택된 결과의 미리보기 패널을 토글합니다. [빠른 패널](./settings/quick-panel)도 같은 키를 쓰며, 미리보기는 자기 좌우 중 자리가 있는 쪽에 도킹됩니다. |
| 이전 키워드 기록 | `Alt+Up` | 최근에 입력한 쿼리를 거슬러 순환합니다. |
| 다음 키워드 기록 | `Alt+Down` | 최근에 입력한 쿼리를 앞으로 순환합니다. |
| 키워드 기록 항목 삭제 | `Ctrl+Delete` | |
| 전체 창 열기 | *(없음)* | 현재 쿼리를 그대로 유지한 채 전체 창을 바로 엽니다 — [퀵 창 자체의 로고](#검색-상자-로고-아이콘)를 좌클릭하여 열리는 메뉴에서 메인 창 표시를 선택하는 것과 같은 효과지만, 그 추가 단계가 없습니다. 기본적으로 바인딩되어 있지 않으므로 **설정 → 단축키**에서 설정하세요. |
| 창 유지하기 | `Ctrl+T` | 포커스가 다른 곳으로 가도 창이 숨지 않게 합니다. 다른 창에서 복사한 텍스트를 모아 질의를 만들기 위한 것으로, 숨을 때마다 검색 상자가 비워지는 것을 막습니다. 이번 호출 동안만 유지되며 다음에 숨을 때 해제됩니다. 빠른 창에서는 로고를 가운데 버튼으로 클릭해도 같으며, 켜져 있는 동안 로고가 밝아집니다. 창이 떠 있지만 포커스가 없을 때 호출 단축키를 누르면 숨기지 않고 다시 포커스를 줍니다. [빠른 패널](./settings/quick-panel)도 같은 키를 쓰며, 자체 고정 버튼이 표시 역할을 합니다. |
| 빠른 패널 열기/닫기 | `Ctrl+F2` | [빠른 패널](./settings/quick-panel)을 앞에 있는 창의 오른쪽 아래 모서리에 도킹해 엽니다. 이미 떠 있으면 닫습니다. 열린 뒤에는 "1–9번째 결과로 이동" 수정 키를 누른 채 1–9를 누르면 워크스페이스를 전환합니다. |

## 검색 상자 로고 아이콘

검색 상자의 작은 로고 아이콘(창에 따라 왼쪽 또는 오른쪽에 위치)은
[세 가지 창](./getting-started#세-가지-창) 각각에서 다르게 동작합니다.

- **퀵 창** — 좌클릭(이동 없이)하면 트레이 아이콘 우클릭 시 나타나는 것과 같은 메뉴(메인 창 표시, 단축키
  전환, 설정, 정보, 완전히 종료, 종료)가 커서 위치에 나타납니다. 그 메뉴의 메인 창 표시 항목도 현재 입력된
  쿼리를 그대로 가져갑니다. 클릭 후 드래그하면 검색창의 다른 부분을 드래그하는 것과 동일하게 창이
  움직입니다 — 드래그 중(창 막대든 로고든, 그리고 드래그 도중 Ctrl을 켜고 끄는 것도 동작합니다) **Ctrl**을
  누르고 있으면 이동을 수직으로만 제한할 수 있어, 좌우로 흔들리지 않고 창을 위아래로 살짝 옮기는 데
  유용합니다. 우클릭하면 창을 기본 화면 위치(크기는 아님)로 되돌립니다 — 처음 실행했을 때 가운데로
  맞춰지는 것과 같은 위치입니다. 마우스를 올리면 세 가지 동작을 모두 설명하는 툴팁이 나타납니다.

  저장된 위치는 절대적인 화면 좌표가 아니라 창이 마지막으로 있었던 모니터를 기준으로 합니다 — 다른
  모니터(또는 해상도나 DPI 배율이 다른 모니터)에서 다시 불러오면, 화면 밖으로 벗어나거나 잘못된 디스플레이에
  나타나는 대신 그곳의 동일한 지점에서 다시 열립니다.
- **인라인 창** — 네이티브 열기/저장/폴더 찾아보기 대화상자에 도킹되어 있을 때만 클릭할 수 있습니다.
  좌클릭하면 [빠른 탐색](#빠른-탐색-마우스)이 열리며, 아래의 전용 트리거와 동일합니다. 일반
  탐색기 창이나 바탕 화면에 도킹되어 있을 때는 클릭할 수 없습니다. 그런 경우에는 탐색할 만한 유용한
  대상이 없기 때문입니다 — 호버 강조나 툴팁도 나타나지 않으므로, 클릭 가능한 것처럼 보이면서 아무 일도
  하지 않는 대신 조용히 있습니다.
- **메인 창** — 여기서는 로고가 순전히 장식용입니다. 클릭해도 아무 일도 일어나지 않습니다.

## 빠른 탐색 (마우스)

가운데 클릭은 기본적으로 활성화되어 있고 왼쪽 버튼 더블클릭은 기본적으로 꺼져 있습니다. 각 트리거는 설정에서 따로 켜고 끌 수 있습니다.

- 이 트리거를 켜면 바탕 화면이나 탐색기 창 안의 빈 공간을 **더블클릭**하여 빠른 탐색을 열 수 있습니다.
- 바탕 화면이나 탐색기 창 안의 빈 공간, 또는 지원되는 타사 파일 관리자(Directory Opus, Total
  Commander, XYplorer, Files 등)의 파일 목록, 또는 네이티브 열기/저장/폴더 찾아보기 대화상자를
  **미들클릭**하면 빠른 탐색이 트리거됩니다. 이 다른 창들은 미들클릭에만 반응합니다 — 그곳에서
  더블클릭은 이미 "이것을 열기"를 의미하므로, 더블클릭의 용도를 바꾸지 않습니다. 각 통합이 다루는
  범위는 [지원되는 파일 관리자](./file-manager-support)를 참고하세요.
- 인라인 검색창이 네이티브 열기/저장/폴더 찾아보기 대화상자에 도킹되어 있을 때는, 그 자체의 로고도
  빠른 탐색을 트리거합니다 — 위의 [검색 상자 로고 아이콘](#검색-상자-로고-아이콘) 참고.

이들 트리거 중 무엇이든 즐겨찾기, 기록, 구성된 빠른 접근 폴더의 계단식 메뉴를 띄웁니다(
[설정 → 즐겨찾기](./settings/favorites)와 [설정 → 기록](./settings/history) 참고) — 플러그인도 자체
항목을 기여할 수 있습니다. `wincmd.ini`에 설정해 두었다면 Total Commander 자체의 Directory Hotlist, Directory Opus 자체의 즐겨찾기 메뉴,
또는 "빠른 탐색에 표시"로 플래그된 [커스텀 명령](./instant-answers#커스텀-명령)(선택적으로 `/`로
구분된 경로를 지정해 하위 메뉴에 중첩 가능)이 그 예입니다. 기여하는 각 플러그인은 메뉴 루트에 자체
레이블이 붙은 섹션을 가지며, 그 섹션들이 나타나는 순서는 여러분이 직접 설정할 수 있습니다 — 자세한
내용은 [설정 → 일반 → 빠른 탐색](./settings/general#빠른-탐색)을 참고하세요. 폴더를 클릭하면
대상 창을 그곳으로 이동시키고, 파일을 클릭해도 마찬가지로 그곳으로 이동하되 파일을 여는 대신 그 파일이
담긴 폴더 안에서 해당 파일이 선택된 상태로 만듭니다 — 유일한 예외는 바탕 화면으로, 탐색할 기존 창
패널이 없으므로 더블클릭했을 때와 마찬가지로 폴더나 파일이 직접 열립니다. 파일 대화상자 안에서는
특히, 파일을 클릭하면 대신 대화상자가 그 파일의 폴더로 이동합니다 — 여러분을 대신해 열기/저장을
자동으로 확정하는 일은 의도적으로 절대 하지 않습니다.

이 메뉴를 실제로 구성하는 것은 **Folder Cascader** 플러그인입니다. 즐겨찾기와 기록(각각 독립적으로
켜고 끌 수 있음) 외에도, 자체적으로 설정 가능한 빠른 접근 폴더 목록을 갖고 있습니다 —
**설정 → 플러그인 → Folder Cascader → 구성**에서 폴더의 경로와 선택적인 표시 이름을 추가하고,
`Submenu` 값(예: 여러 단계로 중첩하려면 `/`로 구분한 `Tools/Network`)을 지정하면 루트 대신 특정
카테고리 아래에 중첩시킬 수 있습니다. 메뉴의 모든 레벨 — 루트와 중첩된 각 카테고리 — 은 자체 헤더에
작은 **+** 버튼도 갖고 있습니다. 이를 클릭하면 현재 탐색 중인 폴더를 그 자리에서 바로 추가할 수 있으며,
그 이름, 경로, 그리고 그 레벨 자체의 하위 메뉴 경로로 미리 채워집니다(확정 전까지 모두 수정 가능).
설정을 열기 위해 메뉴를 벗어날 필요가 없습니다.

## 하드코딩된 키 (설정 불가)

이 키들은 단축키 설정과 무관하게 항상 동일하게 동작합니다.

| 키 | 상황 | 동작 |
|---|---|---|
| `Escape` | 어디서든 | 검색 상자에 텍스트가 있으면 지웁니다. 그렇지 않으면 창을 닫습니다(또는 동작 메뉴를 종료합니다). |
| `Enter` | 결과 목록 | 선택된 결과를 엽니다. |
| `Ctrl+Enter` | 결과 목록 | 결과를 여는 대신 탐색기에서 위치를 찾습니다. |
| `Ctrl+Shift+Enter` | 결과 목록 | 결과를 상승된 권한으로 엽니다(관리자 권한으로 실행). |
| `Left` / `Right` 화살표 | 동작 메뉴 | 메뉴 한 단계 뒤로 가기 / 하위 메뉴로 들어가기. |
| `Backspace` | 동작 메뉴 | 검색 상자가 이미 비어 있을 때 동작 메뉴를 종료합니다. |
| `Alt+Space` / `Alt+F4` | Lertaro의 모든 창 | `Alt+Space`는 모든 창에서 억제됩니다. 어느 창도 Windows 시스템 메뉴가 속할 진짜 제목 표시줄을 갖고 있지 않기 때문입니다. `Alt+F4`는 메인 창과 설정 창에서는 평소처럼 창을 닫으며, 퀵 창·인라인 창·QuickLook·각종 대화상자에서는 계속 억제됩니다. 이들은 열고 닫는 창이 아니라 보이고 숨기는 창이기 때문입니다. |

## 플러그인 동작 단축키

플러그인은 자체적인 기본 단축키가 있는 동작을 등록할 수 있습니다(예: 경로 복사(`Ctrl+Shift+C`), 관리자
권한으로 실행, 또는 내장 파일 동작 — 잘라내기 `Ctrl+X`, 복사 `Ctrl+C`, 붙여넣기 `Ctrl+V`, 삭제
`Delete`, 영구 삭제 `Shift+Delete`). 이들은 **설정 → 단축키 → 플러그인 동작** 아래에, 등록한 플러그인별로
그룹화되어 나타나며, 내장 단축키와 동일한 방식으로 다시 바인딩할 수 있습니다.

## 프로세스 차단 목록

Lertaro의 전역 단축키가 다른 애플리케이션(예: 원시 키보드 입력을 가로채는 게임)과 충돌한다면, 그
프로세스를 **프로세스 차단 목록**에 추가하세요 — 자세한 내용은
[설정 → 단축키 페이지](./settings/hotkeys-page#process-blacklist)를 참고하세요. 차단 목록에 있는
프로세스가 포그라운드에 있는 동안에는, Lertaro의 전역 단축키, 키 입력 가로채기, 위의 빠른 탐색 마우스
트리거가 모두 손대지 않고 그대로 통과됩니다.

진짜로 전체 화면인 포그라운드 앱은 어떤 것이든 차단 목록 항목 없이도 자동으로 동일하게 처리됩니다.
어느 경우든 활성화된 파일 대화상자는 항상 예외이므로, 그곳에서는 빠른 탐색이 계속 동작합니다.
