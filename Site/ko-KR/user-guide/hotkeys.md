# 단축키 및 인터랙션 제스처

Lertaro는 키보드 우선 인터랙션 설계를 채택하면서도, 풍부한 마우스 제스처와 다단계 퀵 내비게이션을 제공합니다. 고정 키를 제외한 모든 전역 및 앱 내부 단축키는 [**설정 → 단축키**](./settings/hotkeys-page)에서 자유롭게 변경할 수 있습니다.

## 1. 전역 단축키 요약표

| 기능/액션 | 기본 단축키 | 기능 설명 및 상세 인터랙션 |
| :--- | :--- | :--- |
| **퀵 윈도우 표시/숨기기** | `Ctrl` 더블 클릭 | 더블 클릭 방식 또는 일반 조합키(예: `Alt+Space`)로 변경할 수 있습니다. 더블 클릭은 **같은** 수식키를 두 번 눌러 **100–300ms** 사이에 놓는 것을 뜻합니다. 왼쪽 `Ctrl`과 오른쪽 `Ctrl`은 서로 다른 키이고, 그 사이에 다른 키를 누르면 횟수가 처음부터 다시 세어집니다. 더블 클릭 방식에서는 수식키 자체가 가로채지지 않으므로 `Ctrl`+`C` 같은 일반 단축키가 계속 정상 동작합니다. **전체 패널을 기본으로 열기**를 켜면 이 단축키가 메인 윈도우를 엽니다. 처음 표시될 때는 한 번만 전경 및 포커스를 처리하고, 표시되어 있지만 비활성 상태이면 다시 활성화하며, 이미 활성 상태이면 기본적으로 다시 눌렀을 때 퀵 윈도우로 돌아가고 **단축키 재입력 시 전체 창 닫기**가 켜져 있을 때만 바로 닫습니다. 자동으로 항상 위에 유지하지는 않습니다. |
| **퀵 점프 (Quick Jump)** | `Ctrl+G` | 파일 대화상자를 탐색기, 지원 파일 관리자 또는 파일 대화상자에서 가장 최근에 탐색했던 폴더로 즉시 이동. |
| **퀵 내비게이션 메뉴** | 기본값 없음 | 선택한 전역 단축키로 계층형 퀵 내비게이션 메뉴를 엽니다. 바탕화면이나 일반 앱에서는 바탕화면 컨텍스트를 사용하고, 파일 탐색기와 네이티브 파일 대화상자에서는 활성 창 컨텍스트를 사용합니다. 일반 전경 보호로 전역 단축키가 억제되는 경우에도 파일 관리자와 파일 대화상자는 허용됩니다. |
| **다음 항목 선택** | `Ctrl+N` 또는 `↓` | 목록에서 강조 표시를 아래로 이동. 퀵 패널에서는 그룹을 건너뛰며 연속 탐색할 수 있습니다. 퀵 런치 패널에서는 방향키가 보이는 격자를 따라 이동하며 왼쪽과 오른쪽은 읽기 순서대로 행 경계를 넘고, 위와 아래는 현재 열을 유지한 채 인접한 행 사이에서만 이동하며 대상 행에 해당 열의 항목이 없으면 그 앞에서 멈춥니다. 퀵 런치 패널이 표시되고 검색어가 비어 있으면 `Ctrl+N`으로 다음 소스를 순환하며 마지막 다음에는 처음으로 돌아갑니다. |
| **이전 항목 선택** | `Ctrl+P` 또는 `↑` | 목록에서 강조 표시를 위로 이동. 퀵 패널에서도 그룹 간 이동을 지원합니다. 퀵 런치 패널에서는 방향키가 보이는 격자를 따라 이동하며 왼쪽과 오른쪽은 읽기 순서대로 행 경계를 넘고, 위와 아래는 현재 열을 유지한 채 인접한 행 사이에서만 이동하며 대상 행에 해당 열의 항목이 없으면 그 앞에서 멈춥니다. 퀵 런치 패널이 표시되고 검색어가 비어 있으면 `Ctrl+P`로 이전 소스를 순환하며 처음 이전에는 마지막으로 돌아갑니다. |
| **1~9번 결과로 이동** | `Ctrl` + `1`–`9` | 조합키 변경 가능. 퀵 윈도우 결과 옆에 번호 배지가 표시되어 실행 가능. 번호는 **첫 번째로 보이는 행**을 기준으로 선택 가능한 N번째 행을 뜻하므로, 스크롤하면 배지 번호가 다시 매겨집니다. `0`은 지정되어 있지 않습니다. 퀵 런치 패널은 예외로 `1`–`9`, `0`, `A`–`Z`까지 최대 36개 타일에 할당합니다. |
| **액션 메뉴 열기** | `Ctrl+O` 또는 `→` | 선택 항목의 컨텍스트 액션 패널 확장(경로 복사, 속성, 관리자 실행, 파일 조작 등). 퀵 윈도우와 파일 대화상자 **밖**의 인라인 카드에서 동작하며, 메인 윈도우에서는 대신 우클릭 또는 `Apps` 키(`Shift+F10`)로 같은 메뉴를 엽니다. |
| **선택 항목으로 검색어 자동완성** | `Ctrl+Tab` | 현재 선택된 항목의 이름 또는 전체 경로를 검색창에 채워 2차 필터링 수행. |
| **QuickLook 즉시 미리보기** | `Alt+P` | 사이드 미리보기 패널 열기/닫기(이미지, 문서, 오디오/비디오 즉시 재생, 폴더 구조). 퀵 윈도우와 메인 윈도우, 퀵 패널에서 사용할 수 있고 인라인 카드에서는 사용할 수 없습니다. 미리보기 가능한 행을 휠클릭하면 동일한 패널이 토글됩니다. |
| **이전 검색 기록어** | `Alt+Up` | 최근 입력했던 검색 키워드를 뒤로 탐색. |
| **다음 검색 기록어** | `Alt+Down` | 최근 입력했던 검색 키워드를 앞으로 탐색. |
| **현재 검색 기록어 삭제** | `Ctrl+Delete` | 현재 표시된 검색 키워드를 기록에서 제거. |
| **메인 윈도우 열기** | `Ctrl+F` | 현재 입력 중인 검색어를 유지한 채 대형 메인 검색창 열기. |
| **LocalSend 전송창 열기** | `Ctrl+S` | LocalSend 무선 LAN 전송창을 열어 다른 기기로 파일이나 텍스트를 빠르게 전송. |
| **창 고정 (항상 유지)** | `Ctrl+T` | 포커스를 잃어도 창이 닫히지 않도록 고정(다른 창에서 텍스트를 복사해 올 때 유용). |
| **퀵 패널 표시/숨기기** | `Ctrl+F2` | 현재 활성 창 옆에 최근 파일, 즐겨찾기, 워크스페이스가 포함된 패널 도킹. |

### 파일 대화상자에서 검색어가 비어 있을 때

네이티브 파일 대화상자에 인라인 검색창이 포함되어 있고 검색어가 비어 있으면 목록에 먼저 ‘마지막 디렉터리’ 그룹이 표시됩니다. ‘인라인 검색에 현재 열려 있는 폴더 표시’를 켜면 지원되는 파일 관리자에서 현재 열려 있는 폴더를 모은 ‘현재 열려 있는 폴더’ 그룹도 표시되며, 여기에는 대화상자가 현재 열려 있는 폴더가 의도적으로 포함됩니다. 중복 경로는 하나로 합치며, 비어 있는 그룹은 표시하지 않고 그룹 제목에도 단축키 배지를 표시하지 않습니다. 이 설정은 기본적으로 켜져 있으며 [**설정 → 일반 → 시스템**](./settings/general)에서 변경할 수 있습니다. 이 동작은 파일 대화상자의 인라인 검색에만 적용되며 퀵 윈도우와 전체 윈도우에는 영향을 주지 않습니다.

### 인라인 윈도우 호출 및 포커스 인계

네이티브 파일 대화상자에 도킹된 카드는 의도적으로 **키보드를 가로채지 않습니다**: 대화상자가 포커스를 유지하므로 사용자는 대화상자 자체의 파일 이름 입력창에 계속 타이핑하고, 카드는 그 검색어를 그대로 반영합니다. 캐럿을 옮기는 제스처는 다음과 같습니다.

| 제스처 | 효과 | 조건 |
| :--- | :--- | :--- |
| **글자나 숫자 입력** | 카드가 호출되면서 첫 글자가 카드의 검색창으로 들어가고, 이후 키 입력도 계속 카드로 전달됩니다 | 실제 키 입력만 해당하며, 자동화 도구가 만든 합성 입력은 그대로 통과됩니다. 컨텍스트 메뉴나 시스템 메뉴가 열려 있는 동안에는 아무것도 가로채지 않습니다 |
| **`Ctrl` 더블 클릭** (또는 설정해 둔 호출 단축키) | 카드 자체의 검색창에 캐럿을 놓습니다. 이미 검색창에 캐럿이 있고 검색어가 비어 있으면 대신 검색어를 지우고 포커스를 대화상자 입력창으로 돌려주며 카드는 열어 둡니다 | 다른 곳과 똑같은 호출 단축키이므로 [**설정 → 단축키**](./settings/hotkeys-page)에서 변경하면 이 동작도 함께 바뀝니다. 블랙리스트나 전체화면으로 전역 단축키가 억제되는 경우에도 파일 대화상자는 계속 허용됩니다 |
| **`Escape`** | **대화상자**가 키보드를 갖고 있을 때는 카드가 닫힙니다. **카드**가 갖고 있을 때는 검색어가 지워지고 포커스가 대화상자로 돌아갑니다(파일 대화상자인 경우) 또는 카드가 닫힙니다(일반 탐색기 창 위에 도킹된 경우) | |
| **검색창이 비어 있을 때 `Backspace`** | `Escape`와 똑같이 검색을 벗어납니다 | 카드에 캐럿이 있을 때만 해당합니다. 대화상자가 키보드를 갖고 있으면 이 키는 카드의 검색어만 편집합니다 |
| **검색창이 비어 있을 때 `Enter`** | `Escape`처럼 검색을 벗어납니다 | 카드에 캐럿이 있을 때만 해당합니다. 대화상자가 키보드를 갖고 있으면 `Enter`가 강조된 탐색 행을 엽니다 |
| **`Tab`** | 항상 대화상자 자체의 컨트롤 이동으로 남으므로, 카드는 설정해 둔 호출 단축키로 이동하세요 | |

> [!NOTE]
> 파일 대화상자 안에서는 카드의 액션 메뉴를 사용할 수 없고(`Ctrl+O`, `→`, 우클릭 모두 아무 동작을 하지 않음), `Alt+P` 미리보기도 제공되지 않습니다. 마우스는 행에서 계속 동작합니다: **좌클릭**으로 강조된 결과를 열고, **`Ctrl`+클릭**으로 관리자 권한으로 열며, 행을 **드래그해서** 대화상자 쪽으로 끌어낼 수 있고, 단순히 **마우스를 올리기만** 해도 선택이 이동하며 호스트 파일 관리자가 이를 그대로 반영합니다.

## 2. 검색창 아이콘 및 마우스 제스처

검색창 내부의 작은 로고 아이콘은 브랜드 표시뿐 아니라 실용적인 마우스 제스처를 제공합니다.

### 퀵 윈도우 로고 제스처

- **좌클릭**: 커서 위치에 메인 팝업 메뉴 표시(트레이 아이콘과 동일한 메뉴: 메인 창 표시, 다른 기기로 전송, 단축키 비활성화/활성화, 설정, 정보, 클린 종료, 종료). "메인 창 표시"는 현재 검색어를 유지합니다.
- **좌클릭 드래그**: 검색바 위치를 자유롭게 이동. **`Ctrl` 키를 누른 채 드래그**하면 이동 방향이 **수직 방향으로 고정**되어 수평 위치가 틀어지지 않습니다.
- **우클릭**: 설정된 창 크기를 유지한 채 퀵 윈도우를 화면 중앙 기본 위치로 즉시 리셋.
- **휠클릭 (중간 버튼)**: 창 "고정" 상태를 토글. 고정 중에는 로고가 밝게 점등됩니다.

> [!NOTE]
> 퀵 윈도우가 기억하는 좌표는 해당 모니터에 대한 **상대 비율 좌표**입니다. 해상도나 DPI 배율이 다른 모니터로 이동하더라도 화면 밖으로 벗어나지 않도록 자동 계산됩니다.

### 인라인 및 메인 윈도우 로고

- **인라인 윈도우**: 네이티브 파일 대화상자(열기/저장/찾아보기)에 임베드된 경우, 로고를 좌클릭하여 [**퀵 내비게이션**](#_3-퀵-내비게이션-마우스-트리거) 계단식 메뉴를 표시합니다. 로고를 드래그하면 카드 자체가 이동하고, 이후 도킹할 때마다 오프셋이 다시 적용됩니다.
- **메인 윈도우**: 로고를 좌클릭하면 컨텍스트 메뉴가 열립니다. 이미 메인 윈도우가 열려 있으므로 메뉴에서 **메인 창 표시** 항목은 숨겨집니다. 가운데 버튼을 클릭하면 창 고정 상태를 전환합니다.

### 검색창 마우스 제스처 (퀵 윈도우)

- **검색창 위에서 마우스 휠**: 최근 검색 기록어를 뒤로/앞으로 순회합니다. `Alt+Up` / `Alt+Down`과 같은 탐색을 마우스에서 손을 떼지 않고 수행합니다.
- **검색창 휠클릭(중간 버튼)**: 현재 표시된 기록 항목을 삭제합니다. 이 제스처는 고정 동작이며 설정 가능한 `Ctrl+Delete` 바인딩과는 별개입니다.
- **언제든 타이핑**하면 기록 탐색 세션이 끝나므로, 다음 휠 조작은 현재 검색어부터 다시 시작합니다. 기록은 순환하지 않습니다: 가장 오래된 항목에서 멈추고, 최신 항목을 지나면 처음에 시작했던 검색어로 돌아옵니다.

### 시스템 트레이 아이콘

- **좌클릭**: 호출 단축키와 똑같이 퀵 윈도우를 토글합니다.
- **우클릭** (더블클릭 처리가 없으므로 두 번째 클릭도 해당): 커서 위치에서 메뉴를 엽니다. 메인 창 표시, 다른 기기로 전송(LocalSend가 활성화된 동안에만), 단축키 비활성화/활성화, 설정, 정보, 클린 종료(Lertaro 하나만 실행 중일 때에만), 종료.
- **트레이 아이콘 숨기기** ([**설정 → 일반 → 시스템**](./settings/general))를 켜면 아이콘은 사라지지만 창 내부의 로고 메뉴는 그대로 남습니다. 그 메뉴에서 단축키를 비활성화한 동안에는 아이콘이 강제로 다시 표시되어, 스스로 접근을 막는 상황이 생기지 않습니다.

## 3. 퀵 내비게이션 (마우스 트리거)

타이핑 없이 마우스 클릭만으로 자주 쓰는 디렉토리에 바로 이동하거나 파일을 열 수 있습니다.

[**설정 → 단축키**](./settings/hotkeys-page)에서 선택한 전역 키보드 단축키를 지정할 수도 있습니다. 바탕화면이나 일반 앱에서는 바탕화면 컨텍스트로 메뉴를 열고, 파일 탐색기와 네이티브 파일 대화상자에서는 활성 창 컨텍스트를 사용합니다.

### 트리거 환경

- **바탕화면 빈 공간**: 휠클릭(또는 좌클릭 더블클릭)하여 메뉴 열기. 폴더나 파일을 클릭하여 즉시 실행.
- **파일 탐색기**: 탐색기 빈 공간을 휠클릭하여 열기. 클릭한 폴더로 현재 탐색기가 즉시 이동.
- **지원 파일 관리자**: Directory Opus, Total Commander, XYplorer, Files, One Commander 등의 목록 영역을 휠클릭([**지원 파일 관리자**](./file-manager-support) 참고).
- **파일 대화상자**: 열기/저장 대화상자에서 휠클릭 또는 로고 클릭하여 대상 폴더로 안전하게 이동.

### 계단식 메뉴 구성 및 관리

**Folder Cascader** 플러그인을 통해 구동됩니다.

1. **현재 열린 폴더**: 지원되는 모든 파일 관리자에서 현재 열려 있는 폴더를 자동 집계 및 중복 제거하여 표시.
2. **즐겨찾기 및 기록**: 별표 표시된 즐겨찾기와 최근 접근 기록 목록.
3. **사용자 지정 분류**: **설정 → 플러그인 → Folder Cascader**에서 다단계 서브메뉴 구성 가능(예: `업무/프로젝트A`).
4. **빠른 폴더 추가 (`+` 버튼)**: 메뉴 각 계층의 헤더에 있는 `+` 버튼을 클릭하여 현재 열린 폴더를 해당 분류에 즉시 저장.

## 4. 변경 불가능한 핵심 고정 키

일관된 조작성을 보장하기 위해 다음 키는 항상 고정 동작합니다.

| 키 | 상황 | 동작 |
| :--- | :--- | :--- |
| `Enter` | 결과 목록 | 선택한 항목(파일/폴더/앱/액션)을 엽니다. 메인 윈도우에서는 **선택된 모든** 행을 엽니다. 인라인 검색창이 비어 있으면 대신 검색을 벗어납니다. 열 상위 매칭 항목이 없기 때문입니다. |
| `Ctrl+Enter` | 결과 목록 | 파일 탐색기에서 해당 파일의 위치를 열고 선택합니다. |
| `Ctrl+Shift+Enter` | 결과 목록 | 관리자 권한으로 실행합니다. |
| `Escape` | 퀵 윈도우 | 창을 숨깁니다. 이 동작으로는 검색창을 비우지 않으며, 검색어는 **닫은 후 검색창 내용 유지** 설정에 따라 보존되거나 삭제됩니다. |
| `Escape` | 메인 윈도우 | 검색어를 지우고 검색창에 다시 포커스를 주며, 검색창이 이미 비어 있으면 창을 닫습니다. **닫은 후 검색창 내용 유지**가 켜져 있으면 한 번만 눌러도 바로 창을 닫습니다(헛되이 두 번 누르는 일이 없도록). |
| `Escape` | 인라인 카드 | 위의 **인라인 윈도우 호출 및 포커스 인계**를 참고하세요: 대화상자가 키보드를 갖고 있으면 카드가 닫히고, 카드가 갖고 있으면 포커스를 돌려줍니다. |
| `Escape` | 액션 메뉴 | 한 번 누를 때마다 한 단계씩: 먼저 액션 필터를 지우고, 다음 하위 메뉴에서 빠져나오고, 마지막으로 메뉴를 벗어나 원래 검색어를 복원합니다. |
| `Backspace` | 액션 메뉴 | 필터 검색어가 빈 상태에서 누르면 액션 메뉴를 닫고 검색 목록으로 돌아갑니다. |
| `←` / `→` 방향키 | 액션 메뉴 | 왼쪽 키는 상위 메뉴로, 오른쪽 키는 하위 메뉴로 진입합니다. `Tab`으로도 하위 메뉴에 진입할 수 있으며, 다음/이전 항목 단축키에 `Tab`을 지정한 경우에만 그 키가 우선합니다. |
| `Tab` | 인라인 카드 | 검색창에서 포커스가 빠져나가지 않도록 가로채며, 대화상자 내부의 `Tab`은 그대로 자체 컨트롤을 순회합니다. |
| `Tab` | 액션 메뉴 | 강조된 하위 메뉴로 진입합니다. 단, `Tab`을 다음/이전 항목 단축키에 지정했다면 그 지정이 우선합니다. |
| `Apps` / `Shift+F10` | 메인 윈도우 | 우클릭과 완전히 똑같이 현재 선택 항목의 액션 메뉴를 엽니다. |
| `Alt+Space` | Lertaro의 모든 창 | 오작동 방지를 위해 시스템 타이틀바 메뉴를 차단합니다. |
| `Alt+F4` | 메인 / 설정 창 | 창을 닫습니다. 퀵 윈도우, 인라인, 퀵 패널, 미리보기, LocalSend 창과 앱 내 대화상자에서는 차단됩니다. |

## 5. 플러그인 액션 단축키 및 프로세스 블랙리스트

### 플러그인 액션 단축키

내장 파일 액션은 다음 기본값으로 제공됩니다: 잘라내기 `Ctrl+X`, 파일 복사 `Ctrl+C`, 붙여넣기 `Ctrl+V`, 삭제 `Delete`, 영구 삭제 `Shift+Delete`, 경로 복사 `Ctrl+Shift+C`, 이름 복사 `Shift+C`, 탐색기에서 위치 확인 `Ctrl+Enter`, 관리자 권한으로 실행 `Ctrl+Shift+Enter`.

검색창 아래에서 위험한 키를 안전하게 막아 주는 장치가 두 가지 있습니다. 조합키가 액션에 도달하려면 검색창에 **선택된 텍스트가 없어야** 하므로, `Ctrl+X` / `Ctrl+C` / `Ctrl+V`는 검색어를 전과 똑같이 자르고 복사하고 붙여넣습니다. `Delete` 같은 단독 키가 액션에 도달하려면 캐럿이 **이미 검색어 끝**에 있어야 합니다. 그 위치에서는 더 지울 글자가 없기 때문입니다. 텍스트 중간 어디에 있든 그 키는 계속 타이핑 키로 남습니다. 그리고 두 삭제 액션은 모두 셸의 `IFileOperation`을 거치므로, 키와 파일 사이에 네이티브 "휴지통으로 이동하시겠습니까?" / "영구적으로 삭제하시겠습니까?" 확인 창이 그대로 서 있습니다. 각 키는 **설정 → 단축키 → 플러그인 액션**에서 다시 지정하거나 비울 수 있습니다.

### 프로세스 블랙리스트 및 전체화면 자동 무시

- **전체화면 앱 자동 무시**: 전체화면 3D 게임이나 비디오 플레이어가 감지되면 Lertaro는 전역 단축키를 자동으로 통과시켜 게임 조작을 방해하지 않습니다.
- **사용자 지정 프로세스 블랙리스트**: [**설정 → 단축키**](./settings/hotkeys-page#_3-프로세스-블랙리스트-process-blacklist)에 특정 프로세스(예: `game.exe`)를 등록하면 해당 앱 활성 시 단축키가 무음 처리됩니다.
