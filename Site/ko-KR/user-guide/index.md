# 사용자 매뉴얼

Lertaro는 Windows용의 빠르고 키보드 중심적인 파일 검색 런처입니다. 로컬 드라이브(NTFS와 ReFS는 변경
저널을 통해, 그 밖의 파일 시스템은 직접 감시하여)와 네트워크 공유를 백그라운드에서 인덱싱한 뒤, 순식간에
어떤 파일, 폴더, 애플리케이션으로도 바로 이동할 수 있게 해줍니다.

이 매뉴얼은 일상적인 사용자에게 필요한 모든 것을 다룹니다.

- **[시작하기](./getting-started)** — Lertaro를 설치하고, 세 가지 검색 창(메인, 퀵, 인라인)을
  이해합니다.
- **[검색 문법](./search-syntax)** — 퍼지 매칭, 제외/정확히 일치/접두사/접미사 연산자, OR 그룹, 드라이브
  타겟팅, 경로 모드, 중국어 파일명을 위한 병음 별칭입니다.
- **[단축키](./hotkeys)** — 설정 가능한 모든 단축키와 하드코딩된 키, 기본 바인딩과 함께 정리했습니다.
- **[동작 메뉴 및 미리보기](./actions-and-preview)** — 마우스 우클릭 스타일의 동작 목록과 QuickLook
  미리보기 패널입니다.
- **[즉시 답변 및 키워드 단축 명령](./instant-answers)** — 계산기, 환경 변수, 명령 실행 바로가기, 프로세스 관리자, 창 전환기, 브라우저 데이터, 설정 검색, 웹 검색, 번역 같은 키워드로 실행되는 플러그인입니다.
- **[명령줄 검색 (lff)](./cli)** — 터미널에서 검색하기 위한 fzf 스타일의 CLI 동반 도구입니다.
- **[URI 프로토콜 (lertaro://)](./uri-protocol)** — 링크, 다른 앱, 스크립트에서 특정 검색이나 특정
  설정으로 바로 이동합니다.
- **[지원되는 파일 관리자](./file-manager-support)** — Lertaro가 도킹하거나, 빠른 탐색을 트리거하거나,
  현재 폴더를 감지할 수 있는 파일 관리자와 파일 선택 대화상자 목록입니다.
- **[설정 참조](./settings/)** — 모든 설정 페이지, 탭, 옵션을 항목별로 정리했습니다.
- **[문제 해결](./troubleshooting)** — 흔한 문제와 해결 방법입니다.
- **[기부](./donate)** — Lertaro가 여러분에게 유용했다면요.

Lertaro를 처음 설정한다면 **시작하기**부터 확인하세요.
