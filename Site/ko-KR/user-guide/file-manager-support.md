# 지원되는 파일 관리자

Lertaro는 검색만 하는 것이 아니라, 현재 사용 중인 파일 관리자나 대화상자와도 통합될 수 있습니다.
대상에 따라 이 통합은 최대 세 가지를 의미할 수 있습니다.

- **인라인 검색 도킹** — Lertaro 검색창이 대상 창([인라인 창](./getting-started#세-가지-창))
  안에 직접 내장되어, 그곳을 벗어나지 않고도 검색할 수 있습니다.
- **빠른 탐색(Quick Navigation)** — 대상이 [빠른 탐색 마우스
  트리거](./hotkeys#빠른-탐색-마우스)(더블클릭/미들클릭, 또는 인라인 창 자체의 로고)에 반응하여
  즐겨찾기, 기록, 빠른 접근 폴더의 계단식 메뉴를 띄웁니다.
- **활성 경로 감지** — Lertaro가 대상에서 현재 열려 있는 폴더가 어디인지 파악하여, 검색 범위를 그
  폴더로 한정하고 (경로 복사 같은) 경로 상대적 동작을 그 폴더 기준으로 해석할 수 있습니다.

모든 통합이 세 가지를 다 제공하는 것은 아닙니다 — 아래 표를 참고하세요.

## 빠른 탐색의 열려 있는 폴더

Folder Cascader 플러그인에서 **열려 있는 폴더 표시**를 켜면(기본값: 켜짐), 빠른 탐색에 즐겨찾기와 기록보다 앞선 **열려 있는 폴더** 그룹이 추가됩니다. 지원되는 모든 파일 관리자에서 현재 열려 있는 실제 파일 시스템 폴더를 모으고 중복 경로는 자동으로 제거합니다. 가상 위치와 더 이상 존재하지 않는 폴더는 표시하지 않으므로 목록의 모든 항목으로 정상적으로 이동할 수 있습니다.

## 내장 지원 (추가 설치 불필요)

이들은 Lertaro의 핵심 확장 플러그인에 번들되어 있습니다 — 별도로 활성화할 것이 없습니다.

| 대상 | 인라인 검색 도킹 | 빠른 탐색 | 활성 경로 감지 |
|---|---|---|---|
| Windows 파일 탐색기 | 지원 | 더블클릭 또는 미들클릭 | 지원 |
| 최신 열기/저장 파일 대화상자 | 지원 (이 자체가 인라인 창입니다) | 미들클릭, 또는 인라인 창 자체의 로고 좌클릭 | — |
| 클래식 열기/저장 파일 대화상자 | 지원 | 미들클릭, 또는 인라인 창 자체의 로고 좌클릭 | — |
| 클래식 폴더 찾아보기 대화상자 | 지원 | 미들클릭, 또는 인라인 창 자체의 로고 좌클릭 | — |

활성 경로 감지는 대화상자 자체에는 적용되지 않습니다 — 이미 대화상자 안에 도킹된 상태에서는 Lertaro가
검색 범위를 한정할 "다른 창"이 존재하지 않기 때문입니다.

## 선택적 플러그인 (설정 → 플러그인)

다음 각각은 자체 플러그인으로 제공됩니다. [설정 → 플러그인](./settings/plugins)에서 설치/활성화한 뒤,
해당 플러그인 자체의 **구성** 대화상자에서 **인라인 검색 활성화**와 **빠른 탐색 활성화**를 각각 독립적으로
켜고 끌 수 있습니다 — 둘 다 기본값은 켜짐입니다.

| 대상 | 인라인 검색 도킹 | 빠른 탐색 | 활성 경로 감지 |
|---|---|---|---|
| Directory Opus | 지원 | 파일 목록 패널에서 미들클릭 | 지원 |
| Files | 지원 | 파일 목록 패널에서 미들클릭 | 지원 |
| One Commander | 지원 | 파일 목록 패널에서 미들클릭 | 지원 |
| Total Commander | 지원 | 파일 목록 패널에서 미들클릭 | 지원 |
| XYplorer | 지원 | 파일 목록 패널에서 미들클릭 | 지원 |

다섯 개 모두 실행 중인 프로세스를 매칭하여 대상을 감지합니다(Directory Opus와 Total Commander의 경우,
UI를 긁어오는 대신 각자가 문서화한 원격 제어 인터페이스와 `WM_COPYDATA`로 통신합니다). Files와 One
Commander는 원격 제어 프로토콜을 노출하지 않으므로 대신 UI 자동화를 사용합니다.

## 애플리케이션 자체 대화상자 (선택적 플러그인)

이들은 애플리케이션 전체가 아니라, 타사 애플리케이션 안의 특정 대화상자 하나를 대상으로 합니다 — 위의 내장
대화상자와 같은 방식입니다. [설정 → 플러그인](./settings/plugins)에서 설치/활성화하며, 각각 자체적인
켜기/끄기 스위치가 있는 단일 컴포넌트로 제공됩니다(전환할 것이 하나뿐이므로 별도의 구성 대화상자는
없습니다).

| 대상 | 인라인 검색 도킹 | 빠른 탐색 | 활성 경로 감지 |
|---|---|---|---|
| WPS Office의 열기/저장 대화상자 | 지원 | 미들클릭, 또는 인라인 창 자체의 로고 좌클릭 | — |
| WinRAR의 압축 풀기 대화상자 | 지원 | 미들클릭, 또는 인라인 창 자체의 로고 좌클릭 | — |
| Bandizip의 압축 풀기 대화상자 | 지원 | 미들클릭, 또는 인라인 창 자체의 로고 좌클릭 | — |
| Bandizip의 파일 추가 대화상자 | 지원 | 미들클릭, 또는 인라인 창 자체의 로고 좌클릭 | — |

창 제목이 아니라 컨트롤 구조로 감지하므로, 각 애플리케이션이 제공하는 모든 언어 팩에서 동작합니다. WPS
항목은 문서, 스프레드시트, 프레젠테이션, PDF 리더를 모두 포함하며 이들은 같은 대화상자를 사용합니다. WPS는
Windows 기본 대화상자가 아닌 자체 대화상자를 쓰기 때문에 별도의 플러그인이 필요하며, 대부분의 애플리케이션이
위의 내장 대화상자로 처리되는 것과 대비됩니다. 그것들과 마찬가지로 활성 경로 감지는 적용되지 않습니다 —
Lertaro가 이미 대화상자 자체 안에 도킹되어 있어, 검색 범위를 한정할 다른 창이 없기 때문입니다.
