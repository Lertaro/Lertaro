# 지원 파일 관리자 및 대화상자 연동

Lertaro는 단순한 독립형 실행기를 넘어, Windows 파일 탐색기, 서드파티 파일 관리자 및 각종 소프트웨어 대화상자에 깊숙이 내장되어 파일 열기, 저장 및 디렉토리 이동 효율을 극대화합니다.

## 1. 3대 핵심 연동 기능

대상 창의 특성에 따라 최대 세 가지 연동 기능이 제공됩니다.

- **인라인 검색 (Inline Search)**: 대상 창 상단이나 파일 대화상자 내부에 초고속 검색창이 직접 임베드되어 현재 작업 창을 벗어나지 않고 검색 수행.
- **퀵 내비게이션 (Quick Navigation)**: 빈 공간을 휠클릭(또는 좌클릭 더블클릭)하거나 임베드된 로고를 클릭하여 열린 폴더, 즐겨찾기, 최근 기록 및 사용자 지정 폴더의 계단식 메뉴 호출.
- **활성 경로 감지 (Active Path Detection)**: 대상 창에서 현재 열려 있는 실제 디렉토리를 실시간으로 감지하여 검색 범위를 해당 폴더로 자동 제한하거나 상대 경로 동작 수행.

## 2. 시스템 기본 컴포넌트 지원 (기본 탑재)

별도의 플러그인 설치 없이 Lertaro 코어 엔진에서 기본 지원합니다.

| 대상 창 유형 | 인라인 검색 | 퀵 내비게이션 호출 방식 | 활성 경로 감지 |
| :--- | :--- | :--- | :--- |
| **Windows 파일 탐색기** | 지원 | 빈 공간 더블클릭 또는 휠클릭 | 지원 |
| **모던 열기/저장 파일 대화상자** | 지원 (대화상자 내 직접 임베드) | 휠클릭 또는 임베드된 로고 좌클릭 | — |
| **클래식 열기/저장 파일 대화상자** | 지원 | 휠클릭 또는 임베드된 로고 좌클릭 | — |
| **클래식 폴더 찾아보기 대화상자** | 지원 | 휠클릭 또는 임베드된 로고 좌클릭 | — |

> [!NOTE]
> 파일 선택 대화상자의 경우 Lertaro가 창 내부에 직접 내장되어 있어 별도의 외부 경로 감지가 필요하지 않습니다. 퀵 내비게이션에서 항목을 클릭하면 대화상자가 해당 폴더로 안전하게 이동합니다.

## 3. 전문 서드파티 파일 관리자 지원 (선택 플러그인)

파워 유저를 위한 인기 파일 관리자 전용 플러그인을 제공합니다. [**설정 → 플러그인**](./settings/plugins)에서 활성화하고 인라인 검색과 퀵 내비게이션을 개별 설정할 수 있습니다.

| 파일 관리자 | 인라인 검색 | 퀵 내비게이션 호출 방식 | 활성 경로 감지 | 핵심 통신 기술 |
| :--- | :--- | :--- | :--- | :--- |
| **Directory Opus** | 지원 | 파일 목록 영역에서 휠클릭 | 지원 | `WM_COPYDATA` 공식 원격 제어 API |
| **Total Commander** | 지원 | 파일 목록 영역에서 휠클릭 | 지원 | `WM_COPYDATA` 메시지 프로토콜 |
| **XYplorer** | 지원 | 파일 목록 영역에서 휠클릭 | 지원 | 전용 프로세스 통신 |
| **Files** | 지원 | 파일 목록 영역에서 휠클릭 | 지원 | Windows UI Automation 프레임워크 |
| **One Commander** | 지원 | 파일 목록 영역에서 휠클릭 | 지원 | Windows UI Automation 프레임워크 |

### Directory Opus 전용 심층 연동

- **재귀 폴더 크기 열 (Lertaro 크기)**: Directory Opus 플러그인에서 "Lertaro 크기 열 활성화"를 켜면 커스텀 스크립트 열이 설치됩니다. Lertaro의 인메모리 인덱스에서 폴더 크기를 직접 읽어오므로 **디스크 I/O가 전혀 없이** 드라이브 전체 폴더 용량을 즉시 확인할 수 있습니다.
- **영구 서식 저장**: Directory Opus 열 선택기에서 "Lertaro 크기"를 추가한 후 **폴더 → 폴더 서식 → 저장 → 모든 폴더에 서식 저장**을 클릭합니다.

### Everything 호환 서비스 (IPC)

[**설정 → 일반 → 시스템**](./settings/general#시스템)에서 **Everything 호환 서비스 (IPC) 활성화**를 켜면 표준 Everything Win32 IPC 인터페이스를 에뮬레이트합니다. Directory Opus, Total Commander, Flow Launcher 등에서 Everything 없이도 Lertaro 인덱스를 직접 활용할 수 있습니다.

## 4. 자체 제작 대화상자 소프트웨어 지원 (전용 플러그인)

표준 Windows 대화상자를 쓰지 않는 주요 소프트웨어를 위한 전용 플러그인을 제공합니다.

| 소프트웨어 및 대화상자 유형 | 인라인 검색 | 퀵 내비게이션 호출 방식 | 연동 설명 |
| :--- | :--- | :--- | :--- |
| **WPS Office** 열기/저장 대화상자 | 지원 | 휠클릭 또는 로고 클릭 | WPS Writer, Spreadsheets, Presentation, PDF 지원 |
| **WinRAR** 압축 해제 대화상자 | 지원 | 휠클릭 또는 로고 클릭 | 압축 해제 대상 폴더 빠른 지정 |
| **Bandizip** 압축 해제 대화상자 | 지원 | 휠클릭 또는 로고 클릭 | 해제 대상 폴더 즉시 선택 |
| **Bandizip** 파일 추가 대화상자 | 지원 | 휠클릭 또는 로고 클릭 | 압축할 소스 파일 빠른 선택 |
| **AutoCAD** 열기/저장 대화상자 | 지원 | 휠클릭 또는 로고 클릭 | CAD 도면 파일의 신속한 저장 및 호출에 최적화 |

각 플러그인은 컨트롤 계층 구조와 핸들을 직접 감지하여 동작하므로 다국어 언어팩이나 테마 변경에 영향을 받지 않습니다.
