# 공간 분석

공간 분석은 Lertaro의 기존 파일 인덱스를 SpaceSniffer와 유사한 빠른 시각적 개요로 보여 줍니다. 디스크를 스캔하지 않으므로 여러 드라이브에 수백만 개의 항목이 있어도 빠르게 열립니다.

## 공간 분석 열기

Lertaro의 전체 검색 창을 열고 검색 상자를 비워 두세요. 공간 분석이 창의 홈 페이지로 자동 표시되며 현재 Lertaro에 로드된 모든 인덱스를 보여 줍니다. 검색어를 입력하면 즉시 검색 결과로 전환되고, 검색어를 지우면 공간 분석의 이전 위치로 돌아갑니다. 드라이브나 폴더를 마우스 왼쪽 버튼으로 두 번 클릭하면 안으로 이동하고, 위쪽 화살표나 이동 경로의 항목을 사용하면 상위 위치로 돌아갑니다.

## 보기 및 사용

- 왼쪽 트리맵에서는 큰 항목이 더 넓은 면적을 차지합니다. 밝고 어두운 색조는 상대적인 크기를 나타내며 테두리 차이로 폴더와 파일을 구분합니다.
- 오른쪽 목록에는 같은 항목이 크기 내림차순으로 표시됩니다. 각 행 아래의 가는 막대는 현재 위치에서 보이는 전체 크기에 대한 비율을 나타냅니다. 어느 한쪽에서 항목을 선택하면 다른 쪽에서도 함께 강조됩니다.
- 카드나 목록 행을 마우스 오른쪽 버튼으로 클릭하면 검색 결과와 같은 동작 메뉴가 열립니다. 열기, 위치 찾기, 복사 및 적용 가능한 플러그인 동작을 사용할 수 있습니다.
- 이름이나 크기가 잘린 경우에만 도구 설명이 표시됩니다.

## 집계 범위

Lertaro에서 활성화된 인덱스에 이미 있는 항목만 포함되며, 공간 분석이 파일 시스템을 탐색하여 누락된 내용을 채우지 않습니다. 제외되었거나 인덱싱되지 않은 내용은 집계되지 않습니다. 숨김 항목은 정상적으로 표시되고 시스템 항목은 개별적으로 표시되지 않지만, 시스템 항목의 크기가 표시되는 상위 폴더의 합계에는 포함될 수 있습니다.

표시되는 크기는 파일의 논리적 크기이며 디스크에 할당된 공간이 아닙니다. 폴더 합계에는 인덱싱된 하위 항목이 포함되고 하드 링크된 데이터는 한 번만 계산되므로 Windows 파일 탐색기나 섹터 수준 디스크 분석 도구와 결과가 다를 수 있습니다.

공간 분석 페이지가 표시되는 동안 관련 메모리 내 인덱스 변경 이벤트를 자동으로 추적하고 연속 알림을 모아 현재 보기를 갱신합니다. 인덱스 캐시 파일을 열거나 다시 읽지 않습니다. 검색을 시작하면 공간 분석 업데이트가 일시 중지되고, 전체 검색 창을 닫으면 렌더링된 항목과 공유 UI 캐시가 해제됩니다.
