# 설정 참조

설정 창은 다른 창과 마찬가지로 크기를 바꾸고 최대화할 수 있습니다. 가장자리를 끌거나, 제목 표시줄의 최대화
버튼을 누르거나, 제목 표시줄을 두 번 클릭하면 됩니다. 특히 플러그인 페이지에서 쓸모가 있는데, 플러그인
목록과 그 플러그인의 설정을 나란히 놓는 페이지라 넓이가 그대로 도움이 됩니다.

설정 창의 제목 표시줄에는 검색 상자가 있습니다. 이는 단순한 부분 문자열이 아니라 메인 검색 창이
사용하는 것과 동일한 fzf 스타일 매칭(병음 별칭 지원 포함)으로, 플러그인 아래의 항목별 항목, 단축키의
플러그인 동작 탭을 포함한 모든 섹션에 걸쳐 매칭됩니다. 각 결과는
브레드크럼(예: "인덱스 > 네트워크 드라이브")을 함께 보여주므로, 서로 다른 탭에 있는 같은 이름의
설정도 구분할 수 있습니다. 결과를 선택하면(클릭, 또는 위/아래로 강조한 뒤 Enter) 올바른 섹션과 탭으로
전환되고, 정확한 컨트롤이 화면에 보이도록 스크롤되며, 잠깐 그 주위에 강조 테두리가 깜빡입니다.

여러 섹션(일반, 단축키, 인덱스, 기록, 빠른 패널, 서비스 상태)은 페이지 상단에 자체적인 하위 탭 행으로
더 나뉩니다. 탭 레이블이 모두 들어가지 않으면 — 번역된 레이블은 보통 중국어 원문보다 길어지므로 대개
영어에서 그렇습니다 — 행의 양 끝에 좌우 화살표 버튼이 나타나, 그냥 잘리는 대신 스크롤로 나머지도 계속
접근할 수 있습니다.

설정 창의 왼쪽 사이드바에는 열 개의 섹션이 있습니다.

| 섹션 | 다루는 내용 |
|---|---|
| [서비스 상태](./service-status) | 백그라운드 서비스 설치, App/Hook/Service 로그 뷰어. |
| [인덱스](./index-drives) | 로컬 드라이브, 네트워크 드라이브, WSL 배포판(감지된 경우), 폴더 인덱스, 제외 규칙. |
| [일반](./general) | 시작 동작, 업데이트, 언어, 검색 바 레이아웃, 미리보기 창 크기. |
| [단축키](./hotkeys-page) | 전역 단축키, 플러그인별 동작 단축키, 프로세스 차단 목록. |
| [플러그인](./plugins) | 설치된 플러그인 및 기능별 활성화/비활성화 스위치. |
| [LocalSend](./localsend) | 로컬 네트워크를 통한 파일, 폴더 및 텍스트 전송 설정. |
| [즐겨찾기](./favorites) | 폴더, 파일, URL에 대한 커스텀 이름 바로가기. |
| [기록](./history) | 검색 기록과 퀵 창 키워드 기록. |


| [빠른 패널](./quick-panel) | 앞에 있는 창 위에 도킹되는 떠 있는 패널: 워크스페이스, 각 워크스페이스의 소스, 플러그인이 제공하는 탭, 그리고 각 워크스페이스가 어느 앱에 속하는지. |
| [외관](./appearance) | 테마 선택기(테마별 미리보기 카드 포함)와 "시스템 라이트/다크 설정 따르기" 모드. 정보 위에 고정됨. |
| [정보](./about) | 버전 정보와 업데이트 확인. |

아래의 각 페이지는 해당 섹션의 모든 옵션을 순서대로, 기본값과 유효 범위와 함께 문서화합니다.
