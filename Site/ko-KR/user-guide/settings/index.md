# 설정 항목 참조

Lertaro는 풍부하고 세밀한 사용자 맞춤 설정 옵션을 제공합니다. 검색창의 픽셀 단위 크기 조절부터 전역 단축키 지정, 드라이브별 인덱싱 주기 변경, 타사 플러그인 및 워크스페이스 관리까지 모든 것을 설정 센터에서 제어할 수 있습니다.

## 1. 윈도우 기능 및 인터랙션

- **자유로운 창 조절 및 최대화**: 설정 창은 테두리를 드래그하여 크기를 조절하거나 제목 표시줄을 더블클릭하여 최대화할 수 있으며, 조절된 크기는 자동으로 기억됩니다.
- **전역 설정 퍼지 검색**: 설정 창 제목 표시줄 우측 상단에 설정 전용 검색창이 내장되어 있습니다. 메인 검색과 동일한 fzf 퍼지 매칭 엔진을 통해 플러그인 세부 옵션과 액션까지 검색할 수 있으며, 결과 선택 시 해당 설정 페이지로 즉시 이동하고 해당 컨트롤이 깜빡이며 강조 표시됩니다.
- **오버플로 방지 탭 바**: 여러 개의 하위 탭을 가진 섹션(일반, 단축키, 인덱싱 등)에서는 텍스트가 길어져도 좌우 스크롤 화살표가 나타나 모든 탭에 쉽게 접근할 수 있습니다.

## 2. 설정 섹션 전체 개요

설정 창 좌측 사이드바는 다음 10개 핵심 섹션으로 구성됩니다.

| 섹션 | 핵심 관리 항목 |
| :--- | :--- |
| **[서비스 상태](./service-status)** | Windows 백그라운드 서비스 동작 상태, 건전성 모니터링, Service / App / Hook 프로세스의 실시간 로그 뷰어. |
| **[인덱싱 관리](./index-drives)** | 로컬 드라이브(NTFS / ReFS / FAT32), 네트워크 공유 드라이브(SMB / NAS), WSL 배포판, 사용자 지정 폴더 및 세 가지 제외 규칙. |
| **[일반 설정](./general)** | 시작 시 자동 실행, 하드웨어 가속, IPC 호환 서비스, 검색창 픽셀 크기 레이아웃, 메인 윈도우 테이블 열 정렬 및 미리보기 매개변수. |
| **[단축키](./hotkeys-page)** | 전역 검색 단축키, 기능 탐색 키, 플러그인 액션 바로가기, 프로세스 블랙리스트 및 전체화면 예외 규칙. |
| **[플러그인](./plugins)** | 설치된 플러그인 목록, 구성 요소별 개별 토글, 플러그인 상세 설정 폼, Flow Launcher 커뮤니티 생태계 관리 및 실행 상태 확인. |
| **[LocalSend](./localsend)** | LocalSend 공식 클라이언트 호환 무선 LAN 전송 프로토콜 설정(기기 이름, 포트, PIN 인증, 자동 저장). |
| **[즐겨찾기](./favorites)** | 자주 쓰는 폴더, 파일, 웹사이트의 별표 등록, 드래그 정렬 및 빠른 별칭 검색. |
| **[검색 기록](./history)** | 검색 결과 실행 기록과 입력 키워드 기록의 관리, 스마트 우선 노출 및 초기화. |
| **[빠른 실행](./quick-launch)** | 수동 빠른 실행 항목을 관리하고 빈 빠른 검색 창에 표시할 동적 데이터 소스를 선택합니다. |
| **[퀵 패널](./quick-panel)** | 활성 창에 도킹되는 플로팅 워크스페이스, 다중 소스 폴더 집계, 드래그 앤 드롭 파일 수신 및 플러그인 동적 탭. |
| **[모양 및 테마](./appearance)** | 라이트 / 다크 / 시스템 연동 모드 전환 및 기본/추천 테마 카드의 실시간 축소 썸네일 미리보기. |
| **[정보 및 업데이트](./about)** | 컴포넌트 버전 정보, 사용자/머신 데이터 디렉토리 바로가기, 백업 롤링 보관 메커니즘 및 무음 업데이트. |

다음 장에서는 각 섹션의 세부 옵션, 값의 범위 및 기본 동작 방식을 순서대로 안내합니다.
