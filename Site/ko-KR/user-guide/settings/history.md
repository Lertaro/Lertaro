# 검색 기록

기록 설정 페이지에서는 Lertaro의 사용 흔적과 스마트 추천 가중치를 관리합니다. 상단에는 **검색 기록**과 **키워드 기록**의 2개 탭이 제공됩니다.

## 1. 검색 기록 (Search History)

검색 결과에서 실제로 클릭하거나 Enter를 눌러 실행한 항목과 당시 사용했던 검색어를 쌍으로 학습하여 기억합니다.

- **스마트 우선 재호출**: 이전 쿼리와 유사한 검색어를 입력하면 과거에 실행했던 항목이 결과 목록 상단에 우선적으로 추천됩니다(예: `bcomp`로 `BCompare.exe`를 실행한 적이 있다면 향후 `bc`만 입력해도 상위에 노출).
- **사용량 기반 정렬**: 기록 후보는 일치 시작 위치, 사용 횟수 내림차순, 최근 실행 시간 내림차순, 퍼지 일치 가중치 순으로 정렬됩니다. 이 규칙은 기록 후보에만 적용되며 다른 결과 유형의 정렬은 바뀌지 않습니다.
- **인라인 윈도우 스마트 분류**: 파일 대화상자의 인라인 검색 시 현재 열린 폴더 내부의 일치 항목은 "현재 폴더", 나머지는 "전체 검색" 그룹으로 자동 분류됩니다.
- **삭제된 경로 자동 필터링**: 파일이 이동되거나 삭제된 경우 유효하지 않은 경로는 목록에서 자동 제외되며 동일 경로는 중복 표시되지 않습니다.
- **관리 기능**:
  - **기록 기능 활성화**: 전체 스위치. 끄면 기존 기록은 유지됩니다. 새 항목은 추가되지 않지만 기존 항목을 다시 실행하면 사용 횟수는 계속 누적됩니다.
  - **검색 필터링**: 상단 검색창으로 특정 기록을 빠르게 검색.
  - **사용 횟수 및 정리**: 각 항목에 실행 횟수가 표시됩니다. 횟수 임계값을 선택하고 **N회 이하 기록 지우기**를 누르면 사용 빈도가 낮은 항목을 삭제할 수 있으며, 개별 삭제와 **모든 기록 삭제**도 사용할 수 있습니다.
  - **실시간 업데이트**: 다른 검색 창에서 새 항목을 실행하면 목록의 사용 횟수가 자동으로 갱신됩니다.

## 2. 키워드 기록 (Keyword History)

결과나 액션을 실행했거나 해당 검색어로 메인 윈도우를 열 때 실제로 사용한 **원시 검색 문자열 자체**를 기억합니다. 검색어만 입력한 뒤 퀵 검색창을 닫거나 포커스를 잃으면 기록에 추가되지 않습니다.

- **단축키 빠른 탐색**: 퀵 검색창에서 **`Alt+Up`**(이전) / **`Alt+Down`**(다음)을 눌러 과거 검색어를 순서대로 불러올 수 있으며, **`Ctrl+Delete`**를 눌러 현재 표시된 검색어를 기록에서 즉시 삭제할 수 있습니다.
- **사용 횟수 및 정리**: 각 키워드에 사용 횟수가 표시됩니다. 횟수 임계값을 선택하고 **N회 이하 기록 지우기**를 누르면 사용 빈도가 낮은 키워드를 삭제할 수 있습니다.
- **독립 관리**: 검색 기록과 동일하게 **기록 기능 활성화** 스위치, 검색 필터링, 개별 삭제 및 **모든 기록 삭제** 버튼을 제공합니다. 끈 상태에서도 기존 키워드의 사용 횟수는 누적되지만 새 키워드는 추가되지 않습니다.
