# 검색 기록

세 탭에서 연 항목, 검색어, 검색어 연결을 각각 관리합니다.

## 1. 검색 기록 (Search History)

검색 결과에서 연 파일, 폴더, 앱의 횟수와 시간을 기록합니다.

- **순위 반영**: 열 때마다 1점씩 더하며 최대 10점입니다. 점수는 90일마다 절반으로 줄어듭니다. 유효 점수가 3이면 H3, 5이면 H5 대상이 됩니다. 빠른 검색은 H5 최대 3개와 H3 10개, 인라인 검색은 1개와 3개를 배정합니다. 전체 창은 개수 제한이 없습니다.
- **순위 상승 범위**: 유효 일치 등급과 우선순위가 같은 결과 안에서 사용 기록을 비교합니다. 빠른 검색의 유형 설정은 파일·폴더의 전체 이름 일치 등급에도 영향을 줍니다. [검색 문법](../search-syntax)을 참고하세요.
- **인라인 그룹**: 현재 폴더와 전체 결과를 나누어 표시합니다. 존재하지 않는 경로는 건너뜁니다.
- **관리**: 키워드 필터, 개별 삭제, 사용 횟수 N 이하 삭제, 전체 삭제를 지원합니다. 다른 창에서 항목을 열면 목록도 갱신됩니다. 기록을 끄면 새 항목은 추가하지 않지만 기존 항목의 횟수와 시간은 갱신합니다.

## 2. 키워드 기록 (Keyword History)

결과나 작업을 실행하거나 전체 창을 열 때의 원래 검색어를 저장합니다. 입력한 뒤 빠른 검색을 닫기만 하면 기록하지 않습니다.

- **Alt+Up / Alt+Down**으로 이전 검색어를 찾고 **Ctrl+Delete**로 현재 항목을 삭제합니다.
- 필터, 개별 삭제, 전체 삭제, 횟수별 삭제를 지원합니다. 별도의 기록 스위치를 끄면 새 검색어는 추가하지 않고 기존 검색어의 횟수만 갱신합니다.

## 3. 검색어 연결 (Query Associations)

**검색어 → 대상 경로** 연결을 일반 사용 점수와 별도로 저장합니다.

- 같은 정규화 검색어의 일반 검색 결과에서 대상을 **3번 이상** 열면 연결을 통해 결과를 보충할 수 있습니다. 학습된 연결만으로 표시된 항목을 다시 열어도 확인 횟수는 늘지 않습니다.
- 검색마다 연결을 최대 **1개** 보충합니다. 낮은 우선순위 대상은 제외하며 연결만으로 찾은 결과는 직접 일치 뒤에 표시합니다.
- 연결을 필터링하거나 개별·전체 삭제해도 경로 사용 점수는 유지됩니다.
