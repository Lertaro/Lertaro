# 인덱스

다섯 개의 탭이 순서대로 있습니다: **로컬 드라이브**, **네트워크 드라이브**, **WSL**(배포판이 감지된 경우에만 표시), **폴더**, **제외 규칙**.

## 로컬 드라이브

- 인덱싱된 드라이브와 항목 수를 요약하는 상태 카드와, 전체 재스캔을 위한 **인덱스 재구축** 버튼입니다.
- 로컬 드라이브마다 한 행씩: **활성화/비활성화 체크박스**, 드라이브 이름, 파일 시스템(NTFS/ReFS/...), 현재 상태, 인덱싱된 항목 수, 그리고 행별 **재구축**/**제거** 동작입니다 — 진짜 NTFS를 제외한 모든 드라이브(NTFS의 스캔은 안전하게 중단할 지점이 없습니다)는 재구축이 진행되는 동안 **중지** 동작도 있습니다.
- NTFS와 ReFS 드라이브는 Windows USN 저널을 통해 변경 사항을 지속적으로 추적합니다. 다른 로컬 파일 시스템(FAT32, exFAT 등)에는 읽을 저널이 없으므로, 대신 변경 사항을 직접 감시합니다. 어느 쪽이든 수동 재구축이 필요한 경우는 드물지만, 뭔가 어긋난 것처럼 보일 때를 위해 존재합니다 — 그리고 중단되었다면(중지되었거나, 스캔 도중 앱/서비스가 재시작되었다면), 다음 재구축은 처음부터 다시 시작하는 대신 멈췄던 지점부터 이어서 진행합니다.

재구축이 진행되는 동안에도 검색은 그대로 동작합니다. 재구축 중인 드라이브는 새 인덱스가 준비될 때까지 이전 인덱스로 계속 응답하며, 다른 드라이브는 영향을 받지 않습니다. 재구축 때문에 결과 목록이 비는 일은 없습니다.

## 네트워크 드라이브

- 로컬 드라이브와 동일한 상태 카드와 **인덱스 재구축** 버튼입니다.
- 매핑된 네트워크 드라이브마다 한 행씩: 활성화 체크박스, 경로/이름, 상태(인덱싱 중 / 준비됨 / 캐시됨 / 실패 / 대기 중 / 연결됨), 항목 수, 그리고 **새로 고침 모드** 드롭다운입니다:
  - **수동** — 요청 시에만(인덱스 재구축을 통해) 새로 고칩니다.
  - **15분마다**
  - **매시간**
  - **매일**

네트워크 공유는 로컬 NTFS 볼륨처럼 변경 저널을 노출하지 않으므로, 실시간이 아니라 일정에 따라 새로 고쳐집니다. 스캔 엔진에는 분기 상위 경로 스택 및 심볼릭 링크 루프 감지 메커니즘이 내장되어 있어 NAS/SMB 공유에 상위 디렉터리를 가리키는 심볼릭 링크가 존재하더라도 무한 루프를 자동으로 방지하고 인덱스 수를 정확하게 유지합니다.

## WSL

WSL 배포판이 하나 이상 감지되었을 때만 표시됩니다 — 네트워크 드라이브와 동일한 형태입니다(상태 카드, **인덱스 재구축** 버튼, 배포판마다 상태/항목 수/**새로 고침 모드**가 있는 한 행). 배포판은 자동으로 감지되며, 수동으로 "추가"하는 단계는 없습니다.

## 폴더

전체 드라이브나 공유 대신 임의의 개별 폴더를 인덱싱합니다 — 해당 볼륨의 다른 모든 것을 끌어들이지 않고 하나의 하위 트리만 인덱싱하고 싶을 때 유용합니다.

- **폴더 추가** 버튼은 폴더 선택기를 엽니다. **인덱스 재구축** 버튼은 목록의 모든 폴더를 다시 스캔합니다.
- 추가된 폴더마다 한 행씩: 활성화 체크박스, 경로, 상태, 항목 수, 그리고 네트워크 드라이브와 동일한 **새로 고침 모드** 드롭다운(수동 / 15분마다 / 매시간 / 매일)입니다 — 폴더는 네트워크 공유와 마찬가지로 지속적으로 추적되는 대신 일정에 따라 스캔됩니다.
- 폴더 선택기는 선택기 안의 *네트워크*를 통해 탐색한 **UNC 네트워크 공유 경로**(예: `\\server\share`, 또는 그 안의 하위 폴더)도 허용합니다 — 서버 전체를 매핑된 네트워크 드라이브로 추가하지 않고도 단일 공유나 하위 트리를 인덱싱하는 데 유용합니다.

## 제외 규칙

세 개의 하위 탭이 있으며, 모두 동일한 형태입니다: 단일 항목 텍스트 상자 + **추가** 버튼, 기존 규칙 목록(각각 편집/삭제 가능), 그리고 한 번에 모든 것을 편집하기 위한 **목록에서 생성** / **목록에 적용** 버튼이 있는 일괄 여러 줄 텍스트 상자입니다.

- **경로 제외** — 전체 경로 또는 환경 변수(예: `D:\Cache`, `%ProgramData%`).
- **글롭 와일드카드** — `*`(파일명 안의 임의 문자), `?`(단일 문자), `**`(재귀적 디렉터리). 예: `*.tmp`, `**/node_modules/**`, `bin/**`.
- **정규식 패턴** — 경로/파일명에 매칭되는 임의의 정규 표현식(부분 매칭). 예: `^\.`(숨김 파일), `~$`(Office 임시 파일), `\.git\`.

제외는 로컬, 네트워크, 폴더 인덱싱 모두에 동일하게 적용되며, 네트워크 드라이브/폴더는 제외 변경 사항을 적용한 후 자동으로 다시 스캔됩니다.
