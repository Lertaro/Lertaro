# 플러그인 관리

Lertaro는 고도로 모듈화된 플러그인 아키텍처를 갖추고 있습니다. 핵심 확장 기능, 네이티브 C# 플러그인, Flow Launcher 커뮤니티 플러그인을 **설정 → 플러그인**에서 통합 관리할 수 있습니다.

## 1. 페이지 레이아웃 및 SDK 버전

- **Plugin SDK 배지**: 우측 상단에 현재 로드된 `Lertaro.PluginSdk` 버전이 표시됩니다. 클릭하면 [**개발자 가이드**](../../dev-guide/)로 바로 이동합니다.
- **좌우 2단 독립 스크롤**: 좌측에는 설치된 플러그인 목록, 우측에는 선택된 플러그인의 상세 정보 및 설정 폼이 표시되며 각각 독립적으로 스크롤됩니다.

## 2. 플러그인 상세 정보 및 구성 요소 제어

좌측 목록에서 플러그인을 선택하면 우측에 아이콘, 이름, 버전 및 설명이 표시됩니다.

### 세부정보 탭 (Details)

- **구성 요소 목록**: 등록된 모든 하위 기능 컴포넌트(검색 소스, 액션 제공자, 퀵 내비게이션 항목, 미리보기 핸들러 등)를 분류별로 표시.
- **컴포넌트 개별 스위치**: 각 항목마다 **활성화 체크박스**가 제공됩니다. 자물쇠 아이콘이 있는 필수 핵심 구성 요소는 비활성화할 수 없습니다.
- **전체 선택 / 전체 해제**: 그룹 내 여러 항목이 있을 경우 편리하게 일괄 토글할 수 있는 링크 제공.
- **상세 툴팁**: 각 항목의 **(!)**에 마우스를 올리면 컴포넌트의 상세 설명과 동작 방식을 확인할 수 있습니다.

### 구성 탭 (Configure)

- **인라인 설정 폼**: 플러그인 고유의 설정 항목(텍스트 상자, 숫자 조절, 토글, 드롭다운, 하위 탭 등)이 팝업 창 없이 우측 패널에 직접 렌더링됩니다.
- **안전한 임시 적용 및 롤백**: **확인**을 누르기 전까지 변경 사항은 메모리에만 유지되며, 저장하지 않고 다른 플러그인으로 이동하면 변경 내용이 안전하게 취소됩니다.

## 3. Flow Launcher 커뮤니티 생태계 지원

네이티브 `Lertaro.PluginSdk` 플러그인뿐만 아니라, 내장된 **Flow Launcher Bridge**를 통해 Flow Launcher 커뮤니티 플러그인을 완벽하게 실행할 수 있습니다.

### 다중 언어 런타임 및 완전 격리 환경

- **다양한 언어 호환**: **C# (.NET)**, **Python 3.12**, **Node.js v20 LTS** 및 실행 파일(`.exe`) 기반의 Flow 플러그인을 네이티브급으로 실행.
- **시스템 오염 없는 독립 환경**: Python(`FlowData\PythonEmbeded-{arch}`) 및 Node.js(`FlowData\NodeEmbeded-{arch}`) 런타임은 Lertaro 데이터 디렉토리에 자동 격리 배치되어 Windows 전역 PATH를 전혀 건드리지 않습니다.
- **의존성 자동 설치**: 최초 로드 시 `requirements.txt`(Python pip) 또는 `package.json`(Node.js npm)을 감지하여 필요한 패키지를 백그라운드에서 자동 설치합니다.

### 스토어 및 패키지 관리 명령

Lertaro 검색창에서 명령어를 입력하여 Flow 플러그인을 직접 관리할 수 있습니다:

- **`flow install <키워드>`**: Flow.Launcher 공식 커뮤니티 리포지토리를 검색하고 원클릭으로 다운로드, 압축 해제, 의존성 설치까지 자동 완료.
- **`flow update`**: 설치된 모든 Flow 플러그인의 업데이트를 확인하고 일괄 갱신.
- **`flow uninstall <플러그인명>`**: 플러그인을 안전하게 제거하고 로컬 디렉토리를 정리.
- **수동 설치**: 다운로드한 폴더를 `<사용자데이터>\FlowData\Plugins\`에 직접 넣어도 인식됩니다.

### 설정, 트리거 키워드 및 리치 미리보기

- **ActionKeyword 변경**: **설정 → 플러그인 → Flow Launcher Bridge → 구성**에서 각 Flow 플러그인의 활성화 여부와 호출 키워드(ActionKeyword)를 개별 변경 가능(`FlowData\Settings\Plugins.json`에 영구 보관).
- **동적 설정 폼**: YAML/JSON 템플릿(`SettingsTemplate.yaml`/`.json`) 및 C# WPF 패널(`ISettingProvider`)에 완벽 대응하며 다크/라이트 테마 및 다국어 i18n을 지원.
- **WebView2 리치 미리보기**: 사전(MDict), 실시간 날씨, API 디버깅, 웹 스냅샷 등 인터랙티브 미리보기를 QuickLook 패널 내에서 매끄럽게 자동 렌더링.
- **호스트 기능과의 완벽한 통합**：Flow 플러그인이 API를 통해 폴더를 열 때 호스트에 구성된 서드파티 파일 관리자를 자동으로 따르고, 메시지 상자는 호스트 테마 다이얼로그로 렌더링되며, 내부 로그는 설정 센터 로그 뷰어로 통합됩니다.
- **목록 확인**: 검색창에 `flow`를 입력하여 로드된 모든 Flow 플러그인과 트리거 키워드를 즉시 조회.
