# 즐겨찾기

자주 사용하는 폴더, 파일, URL을 고정해 두어 언제나 키 하나로 접근할 수 있게 합니다.

## 즐겨찾기 추가하기

- **표시 이름** — 선택 사항입니다. 비워두고 대상이 로컬 경로라면 경로의 파일명으로 자동 채워집니다.
- **대상 경로** — 로컬 경로 또는 `http://`/`https://` URL입니다.
- **폴더 찾아보기** / **파일 찾아보기** 버튼은 직접 입력하는 대신 네이티브 선택기를 엽니다.
- **추가** 버튼 — 경로가 입력되면 활성화됩니다.

## 목록 관리하기

목록의 각 즐겨찾기는 이름과 대상 경로를 보여주며, 행별 동작을 제공합니다.

- **위로 이동** / **아래로 이동** — 목록 순서를 바꾸며, 이는 즐겨찾기가 다른 검색 결과와 비교해
  어떻게 순위가 매겨지는지에도 영향을 줍니다. 각 행은 왼쪽 가장자리의 점 여섯 개짜리 손잡이로 직접
  드래그할 수도 있습니다 — 이는 설정의 다른 모든 재정렬 가능한 목록(결과 유형 우선순위, 빠른 탐색
  순서, 사이드바 필터 순서, 결과 그리드 열 순서)이 사용하는 것과 동일한
  드래그하여 재정렬하는 손잡이입니다.
- **편집** — 변경을 위해 항목을 위의 필드로 다시 불러옵니다.
- **제거** — 삭제합니다.

## 즐겨찾기가 검색에 나타나는 방식

매칭되는 즐겨찾기는 폴더/경로 레이블 옆에 **★** 표시와 함께 결과에 나타나며, 표시 이름으로 검색할 수
있습니다 — 이름에 중국어 문자가 포함되어 있다면 다른 결과와 마찬가지로 병음으로도 검색됩니다. 이는
Lertaro에서 커스텀 검색 별칭에 가장 가까운 기능입니다. 자세한 내용은
[검색 문법](../search-syntax#즐겨찾기-커스텀-별칭이-아닙니다)을 참고하세요.
