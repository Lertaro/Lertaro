# 즐겨찾기

즐겨찾기는 자주 사용하는 폴더, 파일, 스크립트 또는 웹 URL을 고정 등록하여 전용 사용자 지정 이름과 최우선 검색 순위를 부여하는 기능입니다. 설정 경로는 **설정 → 즐겨찾기**입니다.

## 1. 즐겨찾기 항목 추가

상단 등록 폼에서:

- **표시 이름**: 선택 사항. 비워둘 경우 대상이 로컬 경로이면 해당 파일이나 폴더의 이름이 자동으로 채워집니다.
- **대상 경로**: 로컬 파일/폴더의 절대 경로 또는 `http://` / `https://`로 시작하는 웹 URL 입력.
- **찾아보기**: **폴더 찾아보기** 또는 **파일 찾아보기**를 클릭하여 네이티브 파일 선택기로 직접 지정.
- **추가**: 유효한 경로를 입력한 후 **추가** 버튼을 클릭하여 저장.

## 2. 목록 관리 및 드래그 앤 드롭 정렬

등록된 항목은 하단 목록에 표시되며 다음과 같이 관리할 수 있습니다.

- **6점 드래그 핸들 정렬**: 각 행 좌측의 6점 핸들을 드래그하여 순서를 변경하거나 우측의 **위로 이동** / **아래로 이동** 버튼을 사용할 수 있습니다. 이 순서는 검색 결과와 퀵 내비게이션 메뉴의 노출 우선순위에 즉시 반영됩니다.
- **편집**: 클릭 시 해당 항목 데이터가 상단 폼으로 다시 로드되어 수정 후 저장할 수 있습니다.
- **삭제**: 즐겨찾기에서 항목을 안전하게 제거합니다.

## 3. 검색 재호출 및 시각적 표시

- **별표 배지 (★)**: 검색 결과에 즐겨찾기 항목이 일치하면 경로 옆에 눈에 띄는 **★** 배지가 표시됩니다.
- **커스텀 별칭 검색**: 깊숙한 경로에 기억하기 쉬운 별칭을 부여할 수 있습니다(예: `D:\Workspace\2026\Q1\Financial\Summary.xlsx`에 `재무총괄` 지정). 검색창에 해당 이름을 입력하면 즉시 호출됩니다.
- **다중 인터페이스 연동**: 등록된 즐겨찾기는 [**퀵 내비게이션**](../hotkeys#3-퀵-내비게이션-마우스-트리거) 메뉴 및 [**퀵 패널**](./quick-panel#4-플러그인-동적-탭-plugin-tabs)의 "즐겨찾기" 탭에 자동 동기화됩니다.
