# 퀵 패널 설정

**퀵 패널 (Quick Panel)** 은 자주 사용하는 파일의 빠른 호출, 프로젝트 컨텍스트 관리 및 데스크톱 드래그 앤 드롭 파일 스테이징을 위해 설계된 플로팅 워크스페이스입니다. 단축키를 누르면 활성 창의 우측 하단에 자동 도킹되어 작업 중인 컨텍스트를 벗어나지 않고 파일을 빠르게 탐색하고 활용할 수 있습니다.

## 1. 핵심 아키텍처 및 메인 스위치

- **퀵 패널 활성화**: 전체 켜기/끄기 스위치로, 끄면 호출 단축키가 작동하지 않습니다.
- **호출 단축키**: 기본값 **`Ctrl+F2`**([**설정 → 단축키**](./hotkeys-page)에서 변경 가능).
- **스마트 도킹 및 크기 제한**: 호스트 창의 너비 및 높이의 각 1/2 크기로 표시됩니다(시인성을 위해 최소 `280 × 200px`로 제한). Lertaro 자체 창이 활성 상태일 때는 중복 실행 방지를 위해 호출이 무시되며, 패널이 열려 있을 때 동일한 단축키를 누르면 닫힙니다.
- **퀵 점프 연동**: 패널이 열려 있는 동안 선택된 그룹의 디렉토리가 작업 경로로 자동 기록되어 파일 대화상자에서 `Ctrl+G`를 누르면 해당 경로로 즉시 이동합니다.

## 2. 워크스페이스 (Workspaces)

프로젝트나 업무 단위로 폴더 그룹을 구성합니다.

- **워크스페이스 관리**: 좌측 목록에서 **새로 만들기**, **복제**, **삭제**가 가능하며 드래그하여 탭 바의 표시 순서를 변경할 수 있습니다.
- **속성**:
  - **이름**: 탭에 표시되는 텍스트(비워둘 경우 언어 설정에 따른 기본 이름 적용).
  - **활성화 스위치**: 탭 바 표시 여부 제어. 패널에서 탭의 **×** 버튼을 눌러 숨긴 경우 여기서 다시 켤 수 있습니다.

선택한 워크스페이스는 우측의 **소스** 및 **애플리케이션** 탭에서 구성합니다.

## 3. 소스 설정 (Sources)

각 소스는 워크스페이스 내의 독립된 폴더 그룹을 나타냅니다.

- **폴더 추가**: 대상 디렉토리를 선택합니다.
- **표시 모드 (Display Mode)**:
  - **최근 변경된 파일** —— 메모리 인덱스에서 최근 수정된 파일을 밀리초 단위로 조회(최신순).
  - **모든 파일, 최신순** —— 수정일자 내림차순으로 전체 파일 표시.
  - **모든 파일, 이름순** —— 고정 바로가기 바 형태로 활용.
- **하위 폴더 포함**: 하위 디렉토리 파일을 재귀적으로 포함합니다.
- **드롭된 파일 수락**: 켜면 외부 파일, 폴더, 웹 이미지를 이 그룹으로 끌어다 놓아 복사할 수 있습니다(충돌 알림 및 실행 취소를 지원하는 Windows 표준 복사 사용).
- **필터링 규칙**: 와일드카드 또는 검색 구문의 `@` 필터로 표시할 확장자 제한(예: `*.mp4;*.mkv`, `*.lnk;:@doc;:@img`, `*.lnk;:@doc|img`).
- **최대 항목 수 및 시간 제한**: 최대 표시 개수(0은 무제한) 및 N분 내 수정된 파일만 표시하도록 제한.
- **상세 목록 vs 썸네일 타일**: 그룹별로 목록 뷰 또는 썸네일 그리드 뷰를 선택 가능(타일은 원본 비율을 유지하며 균등 확장).

## 4. 플러그인 동적 탭 (Plugin Tabs)

플러그인이 제공하는 동적 목록을 퀵 패널에 배치할 수 있습니다. CoreExtensions에는 5개의 기본 탭이 포함되어 있습니다.

| 플러그인 탭 | 내용 |
| :--- | :--- |
| **즐겨찾기** | 별표로 등록된 항목(URL은 브라우저에서 실행). |
| **기록** | Lertaro를 통해 실행된 최근 항목 및 프로그램. |
| **Windows 기록** | Windows "최근 사용한 파일"을 실제 파일 경로로 해석. |
| **최근 디렉토리** | 탐색기나 대화상자에서 직전에 탐색했던 폴더 추적. |
| **최근 파일** | 설정된 폴더들의 최신 파일들을 인덱스를 통해 집계 표시. |

각 탭의 표시 여부와 목록/타일 뷰 형식을 개별 설정할 수 있습니다.

## 5. 앱 연동 및 전용 블랙리스트

- **애플리케이션 연동 (Applications)**: 특정 프로세스 이름(예: `chrome.exe` 또는 `devenv.exe`)을 등록하면 해당 앱 위에서 퀵 패널을 호출했을 때 해당 워크스페이스가 자동 활성화됩니다.
- **퀵 패널 전용 블랙리스트**: 패널 표시를 차단할 프로세스를 등록합니다. 전역 블랙리스트에 **추가**되어 작동합니다.

## 6. 패널 조작 가이드

- **실시간 퍼지 필터링**: 우측 상단 검색창에서 fzf 퍼지 매칭 및 한어병음으로 작업 공간을 빠르게 필터링.
- **키보드 탐색**: 방향키로 그룹을 넘나들며 탐색하고 `Enter`로 실행.
- **탭 전환**: `Ctrl` + `1`–`9`로 각 탭 간 빠른 이동.
- **QuickLook 미리보기 및 고정**: `Alt+P`로 미리보기 패널 호출, `Ctrl+T`로 포커스를 잃어도 닫히지 않도록 고정.
