# 정보

App, Core, Service, CLI 구성 요소의 버전 번호(서비스가 현재 정상 상태인지를 색상으로 반영)와 Lertaro에
대한 간단한 설명, 프로젝트 홈페이지 및 온라인 사용자 가이드로의 링크를 보여줍니다.

## 구성 폴더

바로 아래에 두 개의 링크가 더 있으며, Lertaro가 자체 설정을 읽고 쓰는 폴더를 엽니다 — 각각 실제
경로를 클릭 가능한 링크 텍스트로 보여주며, 아직 존재하지 않으면 먼저 폴더를 생성합니다.

- **사용자 구성 폴더** — `user-settings.json`을 담고 있는 사용자별 폴더입니다. 설정이 저장될 때마다
  이전 파일은 새 파일이 쓰이기 전에 `user-settings.json.bak.1`로 회전되며(더 오래된 백업은 최대
  `.bak.5`까지 밀려납니다), 잘못된 수정이나 저장 도중 크래시가 발생해도 항상 복원할 수 있는 최근 사본이
  남아 있습니다.
- **시스템 구성 폴더** — 백그라운드 서비스가 사용하는 공유된, 머신 전체의 폴더입니다
  (`machine-settings.json`, 인덱스 캐시, 서비스 측 로그).

## 업데이트 확인

- **업데이트 확인** 버튼 — 더 새로운 릴리스가 있는지 조회합니다. 버튼 자체의 레이블이 진행 상황을
  반영합니다("확인 중...", 그다음 "최신 버전입니다" 또는 발견된 새 버전 번호).
- 관리자가 아닌 계정이 업데이트를 제자리에 설치하기 위해 백그라운드 서비스를 중지할 수 없다면, 경고
  배너가 이를 설명하고 대신 수동 다운로드 페이지로 안내합니다.
- 새 버전을 찾으면:
  - **자동 무음 업데이트** — 진행률 표시줄을 보여주며 백그라운드에서 다운로드하고 설치한 뒤,
    자동으로 Lertaro를 재시작합니다.
  - **다운로드 페이지로 이동** — 수동 설치를 위해 브라우저에서 GitHub 릴리스 페이지를 엽니다.

이는 [일반 → 시스템](./general#시스템) 아래의 **업데이트 자동 확인** / **자동 무음 업데이트**
체크박스와 대응합니다 — 그 체크박스들은 시작 시 이 확인이 자동으로 이루어질지를 제어하며, 이 페이지는
언제든 수동으로 트리거할 수 있게 해줍니다.
