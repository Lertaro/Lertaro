# 정보 및 업데이트

정보 페이지에서는 Lertaro의 전체 컴포넌트 버전 정보, 사용자 및 시스템 데이터 디렉토리 바로가기, 온라인 업데이트 확인 및 원클릭 무음 업데이트 기능을 제공합니다. 설정 경로는 **설정 → 정보**입니다.

## 1. 컴포넌트 버전 및 프로젝트 정보

상단 영역에는 Lertaro 아키텍처를 구성하는 4대 핵심 컴포넌트의 버전이 표시됩니다.

- **App 버전**: 전면 WPF 사용자 인터페이스 버전.
- **Core 버전**: 검색 및 인덱싱 코어 로직 라이브러리 버전.
- **Service 버전**: 백그라운드 Windows 인덱싱 서비스 버전(글자 색상으로 서비스 연결 상태 실시간 반영).
- **CLI 버전**: 명령줄 터미널 유틸리티 `lff` 버전.

하단에는 공식 웹사이트, GitHub 오픈소스 리포지토리 및 온라인 문서 센터 링크가 제공됩니다.

## 2. 데이터 디렉토리 및 5단계 백업 롤링 보관

클릭 시 탐색기로 해당 경로를 바로 열 수 있는 두 개의 링크가 제공됩니다(폴더가 없으면 자동 생성):

### 사용자 데이터 디렉토리 (User Data Directory)

- **저장 내용**: 사용자 설정 파일(`user-settings.json`), 검색 및 키워드 기록, 사용자 전용 캐시 및 보안 인증서.
- **5단계 백업 롤링 보관**: 설정을 저장할 때마다 기존 설정 파일이 `user-settings.json.bak.1`로 순환 백업되며 최대 `.bak.5`까지 유지됩니다. 오류나 시스템 충돌 시에도 최근 5회의 백업에서 안전하게 복원할 수 있습니다.

### 머신 데이터 디렉토리 (Machine Data Directory)

- **저장 내용**: 관리자 권한 서비스용 설정(`machine-settings.json`), 디스크 물리 인덱스 영구 캐시 및 백그라운드 서비스 로그.

### 저장 경로 아키텍처

- **설치형 버전**: 사용자 데이터는 `%LocalAppData%\Lertaro`, 머신 데이터는 `%ProgramData%\Lertaro`에 보관.
- **포터블 버전**: 프로그램 실행 파일 옆의 `Data\Users\<SID hash>` 및 `Data\Machine`에 보관되어 완전한 격리형 무설치 환경 지원([**포터블 데이터 격리 안내**](../getting-started#포터블-데이터-격리-구조) 참고).

## 3. 업데이트 확인 및 원클릭 업데이트

- **업데이트 확인 버튼**: 온라인 리포지토리에 새 버전을 질의하고 상태를 버튼에 표시("업데이트 확인 중..." → "최신 버전입니다" 또는 새 버전 안내).
- **새 버전 발견 시 업그레이드 방식**:
  - **무음 자동 업데이트** —— 백그라운드에서 다운로드 후 즉시 덮어쓰기 업데이트를 수행하고 완료 후 자동 재시작.
  - **다운로드 페이지로 이동** —— 기본 브라우저로 GitHub Releases 페이지를 열어 수동 다운로드.
- **권한 안내**: 표준 사용자 계정에서 백그라운드 서비스를 재시작할 수 없는 경우 수동 다운로드 페이지로 안내하는 배너가 표시됩니다.
