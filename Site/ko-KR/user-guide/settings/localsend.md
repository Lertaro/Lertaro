# LocalSend 설정

Lertaro는 오픈소스 [LocalSend](https://localsend.org) 프로토콜과 호환되는 로컬 네트워크 무선 전송 엔진을 내장하고 있습니다. 외부 인터넷이나 케이블 없이도 동일 LAN 내의 Windows PC, Mac, Linux, iPhone, iPad, Android 기기 간에 파일, 폴더, 텍스트를 초고속으로 주고받을 수 있습니다. 설정 경로는 **설정 → LocalSend**입니다.

## 1. 기본 서비스 설정

- **LocalSend 전송 서비스 활성화**: 전체 스위치. 활성화하면 백그라운드 리스너가 시작되고 트레이 메뉴에 "다른 기기로 보내기..." 항목이 활성화됩니다.
- **기기 이름**: 로컬 네트워크에서 다른 기기에 표시될 별칭. 기본적으로 컴퓨터 이름으로 자동 생성되며 자유롭게 변경 가능합니다(예: `업무용 노트북`).
- **서비스 포트**: HTTP/HTTPS 수신 포트(LocalSend 공식 표준 기본값 `53317`). 로컬 포트 충돌 시 변경할 수 있습니다.

## 2. 보안, 암호화 및 저장 경로

- **암호화 전송 (HTTPS)**: 기본 활성화. 기기 간 통신을 TLS로 암호화하여 패킷 감청을 방지합니다.
- **수신 PIN 번호**: 4~6자리 숫자 PIN을 설정 가능. 설정 시 발신 기기에서 일치하는 PIN을 입력해야 전송이 승인됩니다(비워둘 경우 무효화).
- **파일 자동 저장**: 활성화 시 로컬 기기로부터 수신된 파일 전송을 팝업 승인 없이 디스크에 자동 다운로드합니다.
- **저장 디렉토리**: 수신된 파일 및 폴더가 저장될 기본 경로(기본값: `Downloads\LocalSend`), 우측 찾아보기 버튼으로 변경 가능.

## 3. 발신 창 및 사용 방법

- **단축키 호출**: 전역 단축키 **`Ctrl+S`**([**설정 → 단축키**](./hotkeys-page)에서 변경 가능)를 눌러 LocalSend 발신 창을 즉시 호출할 수 있습니다.
- **전송 모드 전환**: 발신 창 상단에서 **[파일 / 폴더 전송]**과 **[텍스트 전송]** 모드를 간편하게 전환.
- **드래그 앤 드롭 전송**: Lertaro 검색 결과, 퀵 패널 또는 탐색기에서 파일을 발신 창으로 직접 끌어다 놓을 수 있습니다. 레이더로 감지된 대상 기기를 클릭하면 최고 속도로 전송됩니다.
