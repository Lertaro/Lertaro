# LocalSend 로컬 전송 설정

Lertaro에는 공식 [LocalSend](https://localsend.org) 프로토콜과 호환되는 로컬 네트워크 전송 기능이 내장되어 있어, 동일한 LAN 환경의 모바일 및 PC 기기 간에 파일, 폴더 및 텍스트를 전송할 수 있습니다. 설정 경로는 **설정 → LocalSend**입니다.

## 기본 설정

- **LocalSend 로컬 전송 활성화** —— LocalSend 전송 서비스의 켜기/끄기를 설정합니다. 활성화 시 트레이 메뉴에 "LocalSend로 전송..." 항목이 표시되며 전역 단축키에 응답합니다.
- **기기 이름** —— LAN의 다른 LocalSend 클라이언트에 표시되는 이름입니다. 기본적으로 컴퓨터 이름으로 자동 생성됩니다.
- **서비스 포트** —— 전송 요청을 수신하는 HTTP/HTTPS 포트입니다 (기본값 `53317`).

## 보안 및 암호화

- **암호화 전송 (HTTPS)** —— 데이터 전송 시 HTTPS 암호화 연결을 사용합니다 (상대 기기의 암호화 지원 필요).
- **수신 PIN 코드** —— 전송 수신 시 인증할 PIN 코드를 설정합니다 (비워두면 비활성화).

## 수신 및 저장

- **자동 저장 (Quick Save)** —— 수신된 파일을 매번 수동으로 확인하지 않고 자동으로 저장합니다.
- **저장 폴더** —— 수신된 파일이 저장될 기본 경로입니다.

## 불러오기 및 전송 모드

- **단축키 불러오기** —— 기본값 **`Ctrl+S`** ([단축키 설정](./hotkeys-page)에서 변경 가능) 또는 트레이 메뉴를 통해 전송 창을 엽니다.
- **모드 전환** —— 전송 창에서 [ 파일 / 폴더 전송 ] 및 [ 텍스트 전송 ] 모드를 전환할 수 있습니다.
