# 서비스 상태

백그라운드 인덱싱 서비스를 관리하며, 그 로그의 실시간 뷰를 제공합니다.

## 서비스 제어

상태 카드는 상승된 권한의 인덱서의 현재 상태 — **설치 중**, **인덱싱 중**, **준비됨**(실시간 파일/폴더
수와 함께), 또는 **오류** — 를 그에 맞는 아이콘(스피너, 체크 표시, 또는 오류 배지)과 함께 보여줍니다.

**서비스 설치 및 시작** 버튼은 서비스가 아직 설치되지 않았거나 오류가 발생했을 때만 나타납니다 — 일단
설치되어 실행 중이라면 이 페이지에는 수동 시작/중지/제거 컨트롤이 없습니다 — 서비스는 백그라운드에서
그냥 계속 실행되고 있을 것으로 예상됩니다.

## 로그

세 개의 탭 — **App**, **Hook**, **Service** — 은 Lertaro가 실행하는 세 프로세스(상승된 권한의
백그라운드 인덱서, 상호작용하는 사용자별 App, 키보드 훅 프로세스)에 대응합니다. 각 탭은 해당
프로세스의 로그 줄을 레벨별로 색상 코드화하여 보여줍니다.

- **레벨 필터** 드롭다운 — All / Error / Warn / Info / Debug.
- **검색 상자** — 표시되는 줄을 키워드로 필터링하며, 레벨 필터와 함께 결합됩니다.
- **지우기** 버튼 — 현재 선택된 탭의 로그를 비웁니다. Service 탭의 로그를 지우는 것은 서비스 자체를
  통해 이루어집니다(App 프로세스는 이를 직접 쓸 권한이 없습니다). App과 Hook 로그는 사용자별 파일이므로
  직접 지워집니다.

문제를 해결할 때 가장 먼저 확인해야 할 곳입니다 — 자세한 내용은
[문제 해결](../troubleshooting#그래도-해결되지-않는다면)을 참고하세요.
