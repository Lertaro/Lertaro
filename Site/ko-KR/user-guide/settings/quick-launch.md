# 빠른 실행 설정

빠른 실행은 검색 상자가 비어 있을 때 빠른 검색 창 아래에 표시되는 실행 패널입니다. 직접 관리하는 항목과 즐겨찾기, 기록 등 선택한 동적 데이터 소스를 함께 표시합니다.

## 1. 전체 스위치

- **빠른 실행 패널 사용**: 패널을 켭니다. 빠른 검색 창의 검색어가 비어 있고 하나 이상의 데이터 소스에 사용할 수 있는 데이터가 있을 때만 표시됩니다.
- 끄면 패널이 어떤 데이터 소스도 불러오지 않습니다.
- 패널 높이는 항목 수가 가장 많은 데이터 소스를 기준으로 계산되며 빠른 검색 창 결과 영역의 최대 높이를 넘지 않습니다.

## 2. 수동 빠른 실행 항목

**설정 → 빠른 실행 → 빠른 실행**을 열어 직접 등록한 항목을 관리할 수 있습니다.

- 파일, 폴더, URL 또는 Windows Shell 경로를 추가할 수 있습니다. 대상을 확인할 때 환경 변수도 확장됩니다.
- 표시 이름은 비워 둘 수 있으며, 비어 있으면 Lertaro가 대상에서 이름을 자동으로 만듭니다.
- 파일 및 폴더 찾아보기 버튼은 여러 항목을 한 번에 선택할 수 있으며, 유효하고 중복되지 않은 대상이 각각 독립된 항목으로 추가됩니다.
- 드래그 핸들로 순서를 바꿀 수 있습니다. 편집을 클릭하면 해당 행이 저장 및 취소 버튼이 있는 인라인 편집기로 바뀌고, 삭제 버튼으로 항목을 제거할 수 있습니다.
- 항목이 있으면 목록 제목 오른쪽의 **목록 지우기** 버튼으로 수동 항목을 한 번에 삭제할 수 있으며, 목록이 비어 있으면 버튼이 숨겨집니다.
- 현재 사용할 수 없는 대상은 패널에서 일시적으로 제외되며 다시 사용할 수 있게 되면 표시됩니다.

## 3. 데이터 소스

**설정 → 빠른 실행 → 데이터 소스**를 열어 동적 데이터 소스를 선택할 수 있습니다.

- 데이터 소스는 설치된 빠른 패널 탭 제공자에서 제공됩니다. 따라서 즐겨찾기, 기록, Windows 기록, 마지막 디렉터리, 최근 파일 및 향후 플러그인 소스를 별도로 복제하지 않고 재사용합니다.
- 제공자가 존재하는 소스는 기본적으로 활성화됩니다. 사용자 설정에는 명시적으로 비활성화한 소스만 저장됩니다.
- 활성화되어 있고 현재 데이터를 반환하는 소스만 패널 탭으로 만들어집니다. 데이터가 없는 소스는 숨겨집니다.
- 데이터 소스 옆의 드래그 핸들로 패널 탭 순서를 바꿀 수 있으며, 순서는 빠른 실행 설정에 저장됩니다.
- 수동 항목과 동적 데이터 소스가 모두 비어 있으면 빠른 실행 패널이 숨겨집니다.

## 4. 패널 사용

- 열 수는 검색창 너비에 맞춰 자동으로 조정됩니다.
- 소스가 하나뿐이면 하단 소스 표시기가 숨겨집니다.
- 소스가 여러 개이면 하단에 소스마다 점 하나가 표시됩니다. 선택한 점은 파란색, 선택하지 않은 점은 회색이며 점 위에 마우스를 올리면 소스 이름이 펼쳐집니다.
- 패널 위에서 **Shift** 를 누른 채 마우스 휠을 움직이면 소스를 순환할 수 있으며, 전환된 소스에는 같은 펼침 애니메이션이 잠시 재생됩니다.
- 패널의 항목이 세로 표시 영역을 초과하면 항목 영역에서 마우스 휠을 사용해 세로로 스크롤할 수 있으며, 항목 위에 마우스를 올려도 스크롤이 막히지 않습니다.
- 검색어를 입력하기 시작하면 패널이 숨겨집니다.
