# 검색 문법

Lertaro의 검색창은 단순한 텍스트 매칭을 뛰어넘는 강력한 검색 기능을 제공합니다. 초고속 검색 알고리즘을 바탕으로 퍼지(Fuzzy) 문자 도약 매칭, 논리 연산자, 단어 경계 수정자, 드라이브 및 경로 지정, 쿼리 토큰(Query Tokens)을 통한 2차 필터링 및 다국어 스마트 별칭을 지원하며, 모든 문법을 하나의 검색어 안에서 자유롭게 조합하여 사용할 수 있습니다.

## 1. 기본 매칭 모드 및 대소문자 규칙

### 퍼지 매칭(기본값)

Lertaro는 기본적으로 퍼지 매칭(Fuzzy Matching)이 활성화되어 있습니다. 검색어의 각 문자가 파일 또는 폴더 이름 내에 순서대로 나타나기만 하면, 중간에 다른 문자가 섞여 있어도 정확하게 찾아냅니다.

| 입력 예시 | 매칭 결과 예시 | 설명 |
| :--- | :--- | :--- |
| `ltro` | `Lertaro.exe` | `l` → `t` → `r` → `o` 순서로 도약 매칭 (**L**er**t**a**ro**.exe) |
| `vsc` | `Visual Studio Code.lnk` | 각 단어의 첫 글자 매칭 (**V**isual **S**tudio **C**ode) |
| `rt-fin` | `Q3-report-final.docx` | 연속된 부분 문자열 매칭 (Q3-repo**rt-fin**al.docx) |

**설정 → 일반 → 시스템 → 퍼지 매칭 활성화** 옵션을 끄면, 연산자가 없는 일반 검색어는 연속된 부분 문자열로 매칭되어야 합니다(`abc`는 더 이상 `a-b-c`에 매칭되지 않음). 이 설정은 수정자가 없는 일반 단어에만 영향을 미치며, 아래에서 설명하는 모든 연산자의 동작은 동일하게 유지됩니다.

### 스마트 대소문자 구분(Smart Case)

- **모두 소문자인 검색어**: 기본적으로 대소문자를 구분하지 않습니다. 예를 들어 `myfile`은 `myfile`, `MyFile`, `MYFILE` 등을 모두 매칭합니다.
- **대문자가 포함된 검색어**: 단어에 대문자가 하나라도 포함되면 자동으로 **대소문자를 엄격히 구분**합니다. 예를 들어 `MyFile`은 `MyFile`만 매칭하며, 소문자 `myfile`은 매칭하지 않습니다.

## 2. 다중 검색어 및 논리 연산

### 공백: AND (그리고)

여러 검색어를 공백으로 구분하면 모든 조건을 동시에 만족해야 합니다. 파일 이름 내에서 단어가 나타나는 순서는 **상관없습니다**.

```text
report final 2024
```

위 입력은 `2024-Q3-report-final.docx`와 `final_report_2024.pdf` 모두에 매칭됩니다.

### 파이프 `|`: OR (또는)

파이프 기호 `|`로 단어를 구분하면 둘 중 하나만 만족해도 결과에 포함됩니다.

```text
png | jpg | gif
```

AND와 OR 논리를 자유롭게 조합할 수 있습니다.

```text
report | summary 2024
```

이는 `report` 또는 `summary`를 포함하고, 동시에 `2024`도 포함하는 파일을 검색합니다. OR 검색에서는 조건을 만족한 모든 단어가 결과 이름에서 동시에 강조 표시(하이라이트)됩니다.

### 연산자 우선순위: OR이 AND보다 우선

하나의 검색어 안에 공백(AND)과 파이프 `|`(OR)를 함께 사용하면, `|`의 우선순위가 공백보다 **높습니다**. `|` 양쪽의 단어가 먼저 하나의 OR 그룹으로 합쳐지고, 공백으로 구분된 그룹끼리 AND로 결합됩니다. 괄호는 지원되지 않으므로 이 결합 순서를 바꿀 수 없습니다.

```text
report | summary 2024 | draft
```

이는 `(report OR summary) AND (2024 OR draft)`와 동일합니다.

참고: `|`는 양쪽에 공백이 있는 독립된 단어여야 하며, `a|b`나 `a |b`는 OR로 해석되지 않습니다. 또한 `!` 제외어를 `|`의 OR 그룹 안에 넣지 마세요(예: `b | !c`). 이는 "b가 일치하거나 c가 일치하지 않음"으로 해석됩니다. 단어를 전체적으로 제외하려면 공백으로 구분된 독립된 AND 조건으로 지정하세요(예: `b !c`).

### 단어 내 공백 및 따옴표 구문

공백이 포함된 구문 자체를 하나의 검색어로 다루려면 역슬래시로 공백을 이스케이프(`\ `)하거나, 작은따옴표 `'...'` 또는 큰따옴표 `"..."`로 감싸서 입력합니다.

```text
final\ report
'final report'
```

두 입력 방식 모두 `final report`를 두 개의 독립된 AND 단어가 아닌 공백이 포함된 하나의 완전한 구문으로 검색합니다.

### 여러 줄 텍스트 붙여넣기 시 자동으로 OR 변환

스프레드시트, 텍스트 파일, 로그 등에서 여러 줄의 텍스트(한 줄에 파일명 하나씩)를 복사하여 검색창에 붙여넣으면, Lertaro가 자동으로 각 줄을 `|`로 연결하여 하나의 OR 검색어로 변환합니다(빈 줄은 자동 제외).

```text
123
456
678
```

붙여넣으면 다음과 같이 자동 변환됩니다.

```text
123 | 456 | 678
```

## 3. 검색 연산자 요약표

### 연산자 표

| 연산자 / 문법 | 유형 | 효과 설명 | 입력 예시 | 매칭 결과 예시 |
| :--- | :--- | :--- | :--- | :--- |
| *(없음)* | 기본 퍼지 | 문자가 순서대로 나타나면 매칭 (퍼지 켜짐 시) | `report` | `Q3-report-final.docx` |
| `!` | 제외 | 해당 부분 문자열이 정확히 포함된 모든 결과 제외 | `!temp` | `temp`가 포함된 파일 필터링 제외 |
| `'` | 정확도 반전 | 퍼지 켜짐 시 정확한 부분 매칭, 퍼지 꺼짐 시 퍼지 매칭 | `'report` | 연속된 `report` 문자열이 반드시 포함되어야 함 |
| `'...'` | 단어 경계 매칭 | 단어 경계에서 정확히 일치 (단어 중간 부분 오일치 방지) | `'app'` | `app.exe`, `my-app.log` 매칭, `whatsapp.exe` 불일치 |
| `^` | 접두사 매칭 | 파일/폴더 이름이 해당 문자로 시작해야 함 | `^IMG` | `IMG_20240101.jpg` (`MY_IMG.jpg` 불일치) |
| `$` | 접미사 매칭 | 파일/폴더 이름이 해당 문자로 끝나야 함 | `.pdf$` | `document.pdf` (`document.pdf.bak` 불일치) |
| `^...$` | 완전 일치 | 이름 전체가 해당 문자와 정확히 일치해야 함 | `^readme.md$` | `readme.md`에만 정확히 일치 |
| `\|` | OR 논리 | 파이프 기호 양쪽 조건 중 하나 이상 만족 | `doc \| pdf` | `doc` 또는 `pdf`가 포함된 이름 매칭 |

### 연산자 심화 설명 및 실전 조합

1. **제외 수정자 `!`**: `!term`은 `term` 부분 문자열을 포함하는 결과를 즉시 제외합니다. 무고한 파일이 누락되지 않도록 제외 항목에는 병음/별칭 확장이 적용되지 않습니다.
2. **정확도 반전 `'`**: 전체 퍼지 매칭이 켜진 상태에서 검색어 앞에 `'`를 붙이면 해당 단어만 연속된 정확한 부분 문자열로 검색됩니다.
   - 예를 들어 `lertaro 'v1.2`는 `lertaro`는 퍼지로, `v1.2`는 정확한 연속 문자로 찾습니다.
   - 정확 검색이어도 병음 별칭이 있는 파일 이름은 계속 매칭됩니다. 예를 들어 `'exe$`는 `古恩希尔`(병음이 `gexe`로 매핑됨)도 찾습니다.
3. **단어 경계 일치 `'...'`**: 단어를 따옴표로 감싸면(예: `'app'`), 매칭 엔진이 앞뒤 경계(공백, 기호, 하이픈, 언더바, 문자열 끝)를 확인하여 긴 단어 중간에서 원치 않게 일치하는 현상을 방지합니다.
4. **완전 일치 `^...$`**: `^`와 `$`가 **동일한 단어**를 감싸고 있을 때만 작동합니다. 서로 다른 단어에 각각 지정된 경우(예: `^src md$`)에는 독립적인 접두사 및 접미사 필터로 작동합니다.

**다중 연산자 조합 실전 예시**:

- `^IMG !.png$ 2024`: `IMG`로 시작하고 `2024`를 포함하며 확장자가 `.png`가 **아닌** 파일을 검색합니다.
- `'data | 'backup ^2024 .zip$`: `2024`로 시작하고 `.zip`으로 끝나며, 이름에 `data` 또는 `backup`이 정확히 포함된 압축 파일을 검색합니다.
- `^report '公告 | 'gw .pdf$ !draft`: 이름이 `report`로 시작하고 `.pdf`로 끝나며 `draft`를 포함하지 않고, 이름에 `公告`, `gw`, `公文` 또는 `gw` 병음에 해당하는 기타 문자열 조합이 정확히 포함된 파일을 검색합니다(`'公告 | 'gw`가 하나의 OR 그룹을 이루며, 나머지 공백 조건과 AND로 결합됩니다).

## 4. 경로 모드 및 드라이브 범위 지정

### 드라이브 지정

검색창 맨 앞에 드라이브 문자와 콜론을 입력하여 검색 범위를 특정 드라이브로 제한할 수 있습니다.

```text
d: report
```

공백은 생략 가능하며, `d:report`와 `d: report`는 동일합니다.

### 전체 경로 모드

검색어에 경로 구분 기호(`\` 또는 `/`)가 포함되어 있으면 Lertaro가 자동으로 전체 경로 매칭 모드로 전환됩니다.

```text
D:\Projects\Lertaro
```

경로 구분 기호로 끝나는 경우(예: `D:\Projects\`) 해당 폴더 **내부**의 직속 항목들을 직접 검색합니다.

### 상위 폴더 이름 대체 매칭 (Folder Matching)

파일명 단독 검색으로 결과 목록 상한을 채우지 못한 경우, Lertaro는 파일명에 매칭되지 않은 나머지 검색어를 사용하여 상위 폴더 이름과의 매칭을 자동으로 보완합니다.

```text
d01j dcj
```

`dcj`라는 문자열이 파일 자체의 이름에 없더라도, `dcj`라는 이름의 폴더 안에 있는 `d01j.txt` 파일을 찾아낼 수 있습니다.

> [!NOTE]
> 검색어 중 최소 하나는 파일명 자체와 일치해야 하며, 파일명 단독 매칭 결과가 부족할 때만 작동합니다. 보완된 결과는 항상 일반 검색 결과 뒤에 배치되므로 일반 결과의 순서를 방해하지 않습니다.

## 5. 쿼리 토큰 및 2차 필터링 (Query Tokens)

Lertaro는 기본 검색어 뒤에 콜론 `:`(**설정 → 일반 → 시스템 → 쿼리 토큰 총 접두 문자**에서 변경 가능)으로 시작하는 **쿼리 토큰(Query Tokens)**을 추가하여 1차 검색 결과를 정렬하거나 2차 필터링할 수 있습니다.

하나의 `:` 뒤에 쉼표 `,`로 구분하여 여러 토큰을 연쇄 결합할 수 있습니다(예: `report :@doc,M-,:-F`).

### 파일 카테고리 필터 (`:@<카테고리명>`)

미리 정의된 확장자 카테고리 규칙을 빠르게 적용하며, `|`를 사용한 다중 지정도 가능합니다.

- `:@doc`: 문서류 (`*.doc; *.docx; *.pdf; *.txt; *.ppt; *.pptx; *.xls; *.xlsx; *.csv; *.rtf; *.md; *.wps`)
- `:@img`: 이미지류 (`*.jpg; *.jpeg; *.png; *.gif; *.bmp; *.webp; *.ico; *.svg; *.tif; *.tiff; *.psd; *.ai`)
- `:@video`: 동영상류 (`*.mp4; *.mkv; *.avi; *.mov; *.wmv; *.flv; *.m4v; *.webm; *.3gp; *.rmvb; *.ts`)
- `:@audio`: 오디오류 (`*.mp3; *.wav; *.flac; *.aac; *.ogg; *.m4a; *.wma; *.ape`)
- `:@zip`: 압축 파일류 (`*.zip; *.rar; *.7z; *.tar; *.gz; *.bz2; *.xz; *.iso`)

**예시**:

- `재무 :@doc`: 문서류에서 "재무" 검색.
- `배경화면 :@img`: 이미지 파일에서 "배경화면" 검색.
- `clip :@video|audio`: 동영상 또는 오디오 파일에서 "clip" 검색.

**설정 → 플러그인 → CoreExtensions**에서 카테고리 규칙을 수정하거나 새 카테고리를 추가할 수 있습니다.

### 확장자 직접 지정 필터 (`:.ext` 또는 `:.ext1.ext2`)

점으로 시작하는 확장자를 직접 입력합니다(폴더는 자동 제외).

- `report :.pdf`: `.pdf` 파일만 유지.
- `data :.csv.xlsx`: `.csv` 또는 `.xlsx` 스프레드시트 파일만 유지.

### 결과 정렬 및 파일/폴더 필터 (`:[SCMAF]`)

단일 영문자로 속성을 지정합니다: `S`(크기/Size), `C`(생성일/Created), `M`(수정일/Modified), `A`(액세스일/Accessed), `F`(폴더/파일 필터).

기본 문자는 **오름차순**(작은 순 / 오래된 순)을 나타내며, 마이너스 `-` 기호(접두사 또는 접미사, 예: `M-` 또는 `:-M`)를 붙이면 **내림차순**(큰 순 / 최신 순) 또는 반전 필터링이 됩니다.

| 토큰 문법 | 효과 설명 | 대표적인 활용 시나리오 |
| :--- | :--- | :--- |
| `:S` | 파일 크기 오름차순 (가장 작은 파일 먼저) | 빈 파일 또는 용량이 작은 파일 찾기 |
| `:S-` 또는 `:-S` | 파일 크기 내림차순 (가장 큰 파일 먼저) | `log :S-` (용량을 많이 차지하는 대용량 로그 파일 찾기) |
| `:M` | 수정일 오름차순 (가장 오래된 수정 먼저) | 오랫동안 수정되지 않은 파일 점검 |
| `:M-` 또는 `:-M` | 수정일 내림차순 (최근 수정된 파일 먼저) | `report :M-` (최근 작업한 문서 빠르게 찾기) |
| `:C` / `:C-` | 생성일 오름차순 / 내림차순 | `build :C-` (가장 최근에 생성된 빌드 파일 찾기) |
| `:A` / `:A-` | 액세스일 오름차순 / 내림차순 | `project :A-` (최근에 열어본 프로젝트 찾기) |
| `:F` | **폴더만 표시** (일반 파일 제외) | `config :F` (config라는 이름의 디렉토리만 찾기) |
| `:-F` 또는 `:F-` | **파일만 표시** (폴더 제외) | `config :-F` (config라는 이름의 파일만 찾기) |

### 와일드카드 2차 필터 (`:?<패턴>` 또는 `?<패턴>`)

표준 Windows 와일드카드(`?`는 임의의 한 문자, `*`는 0개 이상의 문자)를 사용하여 정밀하게 필터링하며, `|`나 `;`로 여러 OR 조건을 지정할 수 있습니다.

- `mp4 :?(2026???????????)`: `2026` 및 11자리 타임스탬프가 포함된 비디오 파일 매칭.
- `photo :?IMG_????.jpg|DSC_????.jpg`: 특정 카메라 형식의 사진 번호 매칭.

### 경로 부분 일치 필터 (`::<경로패턴>`)

상위 폴더 이름이나 파일명 자체에 지정된 퍼지 키워드가 포함되어야 합니다.

- `report ::2024`: 파일이 위치한 상위 경로 어디에든 `2024`가 포함되어야 함.
- `main ::"src\core"`: `src\core` 하위 경로에 위치한 파일로 한정.

### 연쇄 토큰 결합 예시

여러 토큰을 하나의 `:` 뒤에 결합하여 사용할 수 있습니다.

- `재무보고서 :@doc,M-`: "재무보고서"를 검색하고, 문서류로 한정하며, 수정일 최신순으로 정렬.
- `backup :.zip,S-,:-F`: "backup"을 검색하고, `.zip` 압축 파일로 한정하며, 크기가 큰 순서대로 파일만 표시.
- `icon ::assets,?*128*`: "icon"을 검색하고, 경로에 `assets`가 포함되며 파일명에 `128` 크기 표시가 있는 항목만 필터링.

## 6. 특수 검색 기능

### 1회성 검색에서 제외 규칙 임시 무시

검색어 맨 앞에 `*`를 붙이면 [**제외 규칙**](./settings/index-drives#제외-규칙)에 설정된 경로 제외, Glob, 정규식을 이번 검색에 한해 임시로 무시하고 검색할 수 있습니다.

```text
*node_modules
```

맨 앞의 `*`는 매칭 전에 자동으로 제거됩니다. 이미 인덱싱된 항목만 찾을 수 있으며(네트워크나 WSL에서 아예 스캔되지 않은 폴더는 나타나지 않음), 시스템 숨김 파일 필터링 등은 그대로 유지됩니다.

### 결과 유형 트리거

**설정 → 일반 → 퀵 검색창 → 결과 유형 우선순위**에서 특정 결과 유형(응용 프로그램, 시스템 설정, 파일 카테고리, 플러그인 항목, 일반 파일 등)에 1글자의 **트리거 문자**를 할당할 수 있습니다.

퀵 검색창 맨 앞에 해당 트리거 문자를 입력하면 해당 유형의 결과만 표시되고 다른 유형은 모두 숨겨집니다.

```text
;vs
```

예를 들어 `;`가 "응용 프로그램"에 할당되어 있다면, 위 입력은 응용 프로그램 중에서만 Visual Studio를 검색합니다. 퀵 창과 인라인 창에서는 트리거와 무관하게 히스토리와 즐겨찾기가 항상 최상단에 고정 표시됩니다.

## 7. 다국어 스마트 별칭

### 중국어 파일명: 병음 별칭

기본 내장된 병음 별칭 플러그인(`PinyinAlias`)을 통해 설정 없이도 로마자 병음으로 중국어 파일명을 검색할 수 있습니다.

- **전체 병음**: `chongqing`을 입력하여 `重庆.docx` 매칭.
- **초성 / 이니셜**: `cq`를 입력하여 `重庆.docx` 매칭, `wzry`로 `王者荣耀.exe` 매칭.
- **다음자(다양한 발음) 지원**: 여러 발음을 가진 한자도 자주 쓰이는 독음으로 자동 인덱싱됩니다.

**설정 → 플러그인**에서 `PinyinAlias` 플러그인의 활성화 여부를 확인할 수 있습니다.

### 스페인어 파일명: 악센트 별칭

내장된 `SpanishAlias` 플러그인을 통해 악센트 문자(`á`, `é`, `í`, `ó`, `ú`, `ü`, `ñ`)가 포함된 파일명을 일반 ASCII 문자로 원활하게 검색할 수 있습니다.

- `cancion`으로 `Canción.mp3` 매칭.
- `nino`로 `Niño.txt` 매칭.
- `ciguena`로 `Cigüeña.png` 매칭.

일치한 문자(원래 파일명의 악센트 문자 포함)가 정확하게 하이라이트됩니다.

## 8. 자주 묻는 질문 및 즐겨찾기

### 즐겨찾기, 커스텀 별칭이 아닙니다

Lertaro는 범용적인 "사용자 지정 검색 별칭/매크로" 시스템을 별도로 두지 않습니다. 가장 가까운 기본 기능은 [**즐겨찾기**](./settings/favorites)입니다. 원하는 파일, 폴더, 웹 URL을 커스텀 표시 이름으로 즐겨찾기에 등록하면 해당 이름으로 즉시 검색할 수 있습니다(결과에 ★ 아이콘 표시).

특정 키워드로 프로그램을 실행하거나 스크립트를 호출하려면 [**커스텀 명령어**](./instant-answers#커스텀-명령어)를 참조하세요.
