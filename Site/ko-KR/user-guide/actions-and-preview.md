# 액션 메뉴 및 즉시 미리보기

Lertaro는 파일 검색과 함께 컨텍스트 액션 시스템과 즉시 미리보기 패널을 통합하여, 파일 탐색기를 자주 열지 않고도 파일 검토, 관리 및 실행을 완료할 수 있습니다.

## 1. 액션 메뉴 상세 안내

퀵 윈도우에서 강조된 결과에 `Ctrl+O` 또는 방향키 `→`를 누르면 컨텍스트 액션 메뉴가 펼쳐집니다. 단 `→`는 캐럿이 이미 검색어 끝에 있을 때만 동작하므로, 텍스트 앞쪽을 편집하고 있는 동안 커서 이동을 가로채지 않습니다. 같은 키는 파일 대화상자 **밖**의 인라인 카드에서도 동작하며, 열기/저장/찾아보기 대화상자에 도킹된 카드에는 액션 메뉴가 아예 없습니다. 전체 검색 창에서는 두 키 모두 연결되어 있지 않고, 결과를 마우스 오른쪽 버튼으로 클릭하거나 `Apps`(`Shift+F10`)를 눌러 동일한 메뉴를 엽니다.

모든 행에 메뉴가 있는 것은 아닙니다. **더 보기** 행, 플러그인이 제공한 결과, 웹 링크 즐겨찾기, 어떤 프로바이더도 가져가지 않는 즉시 결과, 퀵 윈도우 밖의 응용 프로그램, 그리고 모든 파일 대화상자에서는 메뉴가 제공되지 않습니다. 이런 행에서는 빈 패널을 열어 주는 대신 메뉴 키가 아무 동작도 하지 않습니다.

### 기본 핵심 액션 목록

| 액션 이름 | 기본 단축키 | 기능 설명 |
| :--- | :--- | :--- |
| **열기** | `Enter` | 시스템 기본 연결 프로그램으로 파일을 열거나 응용 프로그램을 실행합니다. 전체 검색 창에서는 `Enter`가 **선택된 모든** 행에 적용되고, 더블클릭은 더블클릭한 행에만 적용됩니다. |
| **탐색기에서 위치 확인** | `Ctrl+Enter` | 상위 폴더를 열고 파일 탐색기에서 해당 파일을 선택한 상태로 표시합니다. |
| **관리자 권한으로 실행** | `Ctrl+Shift+Enter` | 관리자 권한으로 프로그램을 실행합니다(실행 파일, 바로가기, 배치 스크립트 등). |
| **전체 경로 복사** | `Ctrl+Shift+C` | 파일의 절대 경로(예: `D:\Projects\app.exe`)를 클립보드에 복사합니다. |
| **이름 복사** | `Shift+C` | 선택한 파일 또는 폴더의 이름을 경로 없이 클립보드에 복사합니다. |
| **파일 복사** | `Ctrl+C` | 파일 자체를 클립보드에 담아 탐색기나 다른 폴더에 직접 붙여넣을 수 있게 합니다. |
| **잘라내기 / 파일 복사** | `Ctrl+X` / `Ctrl+C` | 파일 자체를 클립보드에 담아 탐색기나 다른 폴더에 직접 붙여넣을 수 있게 합니다. 검색창에 텍스트가 선택되어 있으면 두 키는 텍스트에 대한 명령으로 남습니다. |
| **여기에 붙여넣기** | `Ctrl+V` | 폴더가 강조되어 있을 때 클립보드의 파일을 그 디렉토리에 바로 붙여넣고, 파일이 강조되어 있을 때 해당 파일의 부모 폴더에 붙여넣습니다. 클립보드에 실제 파일 목록이 있어야 하므로 검색어에 텍스트를 붙여넣는 일은 영향을 받지 않습니다. |
| **삭제 (휴지통으로 이동)** | `Delete` | 선택한 파일이나 폴더를 Windows 휴지통으로 안전하게 이동합니다. `Delete` 같은 단독 키는 캐럿이 이미 검색어 끝에 있을 때만 이 액션에 도달하며, 이어서 네이티브 휴지통 확인 창이 나타납니다. |
| **영구 삭제** | `Shift+Delete` | 선택 항목을 영구적으로 삭제합니다(네이티브 "영구적으로 삭제하시겠습니까?" 확인 창을 거친 뒤에는 복구할 수 없습니다). |
| **이름 바꾸기** | — | Windows Shell을 통해 존재하는 파일 또는 폴더 하나의 이름을 바꿉니다. 대화상자에서 이름 부분을 미리 선택합니다. |
| **Windows 우클릭 메뉴** | — | Windows 파일 탐색기의 전체 기본 컨텍스트 메뉴(보내기 및 타사 확장 메뉴 포함)를 엽니다. |

### 액션 메뉴 인터랙션 및 즉시 필터링

- **입력하여 즉시 필터링**: 액션 메뉴가 열린 상태에서 글자를 입력하면 액션 이름을 실시간으로 검색할 수 있습니다(예: `copy` 입력 시 복사 관련 액션 즉시 표시). 필터 상자가 키보드를 잡기 때문에, 다른 곳으로 이동해도 원래 검색어는 전혀 건드리지 않습니다.
- **메모 문자**: 액션마다 강조된 문자가 표시될 수 있습니다. 그 문자를 누르면 **액션이 즉시 실행**되며 단순히 강조만 하는 것이 아닙니다. 단 필터 상자가 아직 비어 있을 때만 해당하므로, 필터를 위해 입력하는 첫 글자는 빼앗기지 않습니다.
- **독립 검색 상자**: 액션 메뉴에는 독립된 검색 상자가 있으며 메뉴를 열면 자동으로 포커스를 받습니다. 액션 필터링은 기본 검색어를 바꾸지 않습니다. 메뉴 계층을 전환하면 액션 필터가 지워지고 새 계층의 검색 상자에 포커스가 이동합니다.
- **플로팅 액션 패널**: 빠른 창, 빠른 실행 패널, 전체 검색 창의 액션은 현재 항목 근처에 플로팅 패널로 표시됩니다. 빠른 실행 패널은 액션 목록의 전체 작업 높이로 잠시 확장되며 메뉴를 닫으면 원래의 컴팩트한 높이로 돌아갑니다.
- **계층 탐색**: 하위 메뉴가 있는 항목(예: "보내기")에서 `→`, `Tab` 또는 `Enter`를 눌러 진입하고, `←` 또는 검색어가 빈 상태에서 `Backspace`를 누르면 상위로 돌아갑니다. 중첩 메뉴에서는 `Escape` 또는 마우스 오른쪽 버튼 클릭으로 상위 계층으로 돌아가며, 루트에서는 액션 메뉴를 닫습니다.
- **탐색 키도 그대로 동작**: 설정해 둔 다음/이전 항목 선택 단축키(기본값 `Ctrl+N` / `Ctrl+P`)는 액션 목록 안에서도 강조 표시를 이동시킵니다. 처음과 마지막 항목을 지나 순환하며, 구분선·제목·비활성 액션은 건너뜁니다. `Tab`은 다음/이전 항목 단축키에 지정하지 않았을 때만 하위 메뉴 진입에 사용됩니다.
- **바깥쪽 클릭으로 닫기**: 플로팅 액션 패널 바깥을 클릭하면 패널이 닫힙니다. 호스트가 지원하는 경우 패널이 열린 상태에서 다른 결과를 마우스 오른쪽 버튼으로 클릭하면 현재 액션 대상만 그 자리에서 바뀝니다.
- **액션 단축키**: 패널에 포커스가 있을 때 프로바이더가 정의한 액션 단축키를 사용할 수 있습니다. 실행 후 플로팅 패널은 닫히지만 전체 검색 창 또는 빠른 실행 패널은 열린 상태로 유지됩니다.

## 2. 메인 윈도우 결과 목록 기능

메인 검색 윈도우(`Ctrl+F`)는 대규모 파일 관리와 심층 탐색을 위해 설계되었습니다.

- **경로 열 더블클릭 이동**: 목록의 **이름** 열을 더블클릭하면 파일이 실행되고, **경로** 열을 더블클릭하면 해당 파일이 위치한 상위 폴더가 열립니다. 여기서 더블클릭은 *왼쪽* 버튼만 의미하며, 열 제목(헤더)을 더블클릭하면 아무 동작도 하지 않고, 최대화/복원은 창 상단의 입력 영역이 아닌 부분을 더블클릭합니다.
- **다중 선택**: 목록은 일반 Windows 리스트와 똑같이 동작합니다. `Ctrl`+클릭으로 행을 추가하거나 제외하고, `Shift`+클릭으로 범위를 선택한 뒤 `Enter`를 누르면 **선택된 모든** 행에 한 번에 작업이 적용되고, 더블클릭은 더블클릭한 행에만 적용됩니다. 이미 선택된 행을 마우스 오른쪽 버튼으로 클릭하면 그 행 하나로 줄지 않고 전체 선택이 유지됩니다.
- **스트리밍 결과 로딩**: 수백만 개의 항목을 스캔할 때도 인덱싱 엔진에서 수신된 결과가 목록에 실시간 스트리밍 방식으로 추가됩니다. 전체 스캔 완료를 기다릴 필요 없이 즉시 조작할 수 있으며, 새 행이 추가될 때 선택과 스크롤 위치가 유지됩니다. 완전히 새로운 결과집합이면 맨 위로 다시 시작합니다.
- **루프 탐색**: 첫 번째 행에서 `↑`를 누르면 마지막 행으로, 마지막 행에서 `↓`를 누르면 첫 번째 행으로 이동합니다. 퀵 윈도우와 인라인 카드에서도 같은 순환이 적용되어, 아직 아무것도 선택하지 않은 상태에서 `↑`를 누르면 마지막 행으로, `↓`를 누르면 첫 번째 행으로 갑니다. 퀵 패널만 그룹을 하나의 연속된 목록으로 다루며 **순환하지는** 않습니다.
- **가로 스크롤**: 목록 위에서 `Shift` + 마우스 휠을 굴리면 한 칸에 3열씩 이동하며, 좁은 창에서 오른쪽 끝 열까지 볼 때 사용합니다.
- **파일 밖으로 드래그**: 어떤 행이든 실제 파일 드래그로 탐색기, 대화상자, 채팅 창에 그대로 끌어다 놓을 수 있고, 여러 행을 선택한 상태에서 그중 하나를 드래그하면 **전부** 함께 이동합니다. Lertaro 바깥에 놓으면 창이 숨겨지며, 드래그가 진행 중일 때는 닫힘을 지연시켜 드래그 커서가 고정되는 상황을 막습니다.
- **선택 수 요약**: 여러 행을 선택하면 상태 표시줄에 전체 결과 수와 함께 현재 선택한 항목 수가 표시됩니다.
- **마우스 올리기 미리보기**: 행 위에 포인터를 올리면 선택은 바꾸지 않은 채 이미 열려 있는 미리보기 패널의 대상만 전환됩니다. 그래서 후보를 넘기다가 되돌아온 행에서 `Enter`를 누르면 됩니다.
- **창 드래그 및 크기 기억**: 창 상단의 빈 영역을 드래그하여 위치를 옮길 수 있으며, 조절된 크기는 다음 실행 시에도 유지됩니다.

## 3. QuickLook 즉시 미리보기 기능

미리보기 가능한 결과에서 `Alt+P`를 누르면 검색창 옆에 미리보기 패널이 도킹되고, 그 행을 **휠클릭(중간 버튼)** 해도 같은 패널이 토글됩니다. 두 제스처 모두 인라인 창에서는 사용할 수 없고, 퀵 패널에서는 둘 다 지원합니다.

### 미리보기에는 키보드가 없습니다

미리보기 패널은 의도적으로 활성화되지 않는 창입니다: 검색 창에서 포커스를 빼앗지 않으므로 입력할 대상이 없고 `Escape`로도 닫히지 않습니다. `Alt+P`로 토글하거나, 패널이 도킹된 창을 닫아서 숨기세요. 미디어 재생 바, 스크롤바, 플러그인 카드 등 모든 컨트롤은 마우스 전용이며, 키보드 포커스는 원래 있던 자리에 그대로 남아 있습니다.

### 다양한 파일 형식 지원

- **이미지**: JPG, PNG, GIF, BMP, ICO 이미지 형식의 크기 조절 렌더링.
- **텍스트 및 코드**: TXT, Markdown, JSON, XML, YAML, C#, Python, JS, HTML 등의 내용을 등폭 폰트로 그대로 표시(구문 강조 없음).
- **오디오/비디오 즉시 재생**: MP4, M4V, WMV, AVI, MOV, MPG/MPEG 영상과 MP3, WAV, WMA, M4A, AAC 오디오는 미리보기가 열리는 즉시 **자동 재생**되며 미니 컨트롤 바(재생/일시정지, 탐색 바, 시간 표시, 음소거)가 제공됩니다. 항목 전환 시 즉시 중지됩니다.
- **폴더 구조 검사**: 폴더를 선택하면 직속 하위 항목 최대 30개가 아이콘 및 크기와 함께 표시됩니다(숨김/시스템 파일 제외).

### 레이아웃 및 대화상자 자동 회피

- **화면 영역 자동 맞춤**: 미리보기 크기는 [**설정 → 일반 → 미리보기**](./settings/general#_4-미리보기-윈도우-preview-window)에서 변경할 수 있으며 화면을 벗어나지 않도록 자동 제어됩니다.
- **도킹 방향**: 패널은 검색 창의 **오른쪽**에 도킹되며, 오른쪽에 들어가지 않을 때만 왼쪽으로 전환합니다. 더 넓은 쪽을 따라가지 않으므로, 넓은 창을 스크롤해도 위치가 흔들리지 않습니다. 이후 창을 이동하거나 크기를 바꾸면 소유 창을 따라갑니다.
- **크기 기억은 세션 단위**: 리사이즈 그립을 드래그하거나 패널을 옮긴 결과는 미리보기가 계속 사용 중인 동안에는 기억되지만, 검색 창이 다시 숨겨지거나 닫히면 패널은 설정된 크기와 도킹 방향으로 돌아갑니다.
- **네이티브 대화상자 자동 회피**: 비밀번호가 걸린 Office 문서를 미리볼 때 암호 입력 창이 뜨면 Lertaro 창을 일시적으로 숨겨 입력을 방해하지 않으며, 완료 후 자동으로 복구됩니다.
- **미리보기 창에서 드래그 앤 드롭**: 미리보기 패널 상단을 드래그하여 외부 앱이나 탐색기로 파일을 직접 끌어다 놓을 수 있습니다. 하단 푸터 바를 드래그하면 패널 자체가 이동합니다.

## 4. 플러그인 리치 텍스트 및 대화형 미리보기

QuickLook은 로컬 파일뿐 아니라 플러그인의 인터랙티브 패널도 지원합니다.

- **테마 자동 적응형 리치 텍스트**: WebView2 및 네이티브 컴포넌트로 렌더링되어 다크/라이트 테마에 자동 맞춤되며 깔끔한 타이포그래피와 반투명 스크롤바를 제공합니다.
- **다양한 플러그인 카드**: 사전 검색 카드, 실시간 날씨, 웹 스냅샷, API 디버깅 정보 등 풍부한 인터랙티브 패널을 지원합니다.

## 5. 타사 독립 QuickLook 연동 (선택 사항)

독립된 오픈소스 도구인 **QuickLook**([GitHub의 QL-Win/QuickLook](https://github.com/QL-Win/QuickLook))을 설치하여 사용 중인 경우, [**설정 → 플러그인**](./settings/plugins)에서 **QuickLook 브리지** 플러그인을 활성화할 수 있습니다.

- **외부 미리보기 연결**: 로컬 명명된 파이프를 통해 외부 QuickLook 프로세스에 연결하여 미리보기 창을 Lertaro 옆에 도킹합니다.
- **자동 대체**: 외부 QuickLook 프로세스가 실행 중이지 않은 경우 내장 미리보기 엔진으로 대체됩니다.

## 6. 파일 점유 해제

공식 **파일 점유 해제** 플러그인은 존재하는 파일을 하나만 선택했을 때 사용할 수 있는 액션을 제공합니다. 파일을 사용 중인 프로세스와 PID, 실행 파일 경로를 표시하고 해당 프로세스에 파일 해제를 요청합니다. 폴더, 존재하지 않는 파일 또는 여러 항목을 선택하면 액션을 사용할 수 없으며, 점유 프로세스가 없을 때는 해제 요청 버튼도 비활성화됩니다. 대화상자는 호스트 테마를 사용하고 검색 창 위에 표시되며 Alt+Tab 목록에는 나타나지 않습니다. 새로 고침도 지원합니다.

## 7. 즐겨찾기에 추가

CoreExtensions는 존재하는 파일 또는 폴더 하나를 즐겨찾기에 추가하는 **즐겨찾기에 추가** 액션을 제공합니다. 테마가 적용된 대화상자에서 표시 이름을 입력할 수 있으며, 같은 경로가 이미 즐겨찾기에 있으면 액션을 표시하지 않습니다.

## 8. 이름 바꾸기

CoreExtensions는 존재하는 파일 또는 폴더 하나에 사용할 수 있는 **이름 바꾸기** 액션을 제공합니다. 테마가 적용된 대화상자에 현재 전체 이름이 표시되고 이름 부분이 미리 선택됩니다. 예를 들어 `report.pdf`에서는 `report`만 선택되며, 폴더와 확장명이 없는 이름은 이름 전체가 선택됩니다. `Enter`를 누르면 확인하고 `Esc`를 누르면 취소합니다. 확인 후 실제 이름 변경은 Windows Shell에 위임됩니다.
