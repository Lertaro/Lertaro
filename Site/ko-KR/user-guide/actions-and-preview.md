# 액션 메뉴 및 즉시 미리보기

Lertaro는 초고속 파일 검색뿐만 아니라 강력한 컨텍스트 액션 시스템과 다채로운 미리보기 패널을 통합하여, 파일 탐색기를 열지 않고도 파일 검토, 관리 및 실행을 빠르게 완료할 수 있습니다.

## 1. 액션 메뉴 상세 안내

검색 결과(파일, 폴더, 앱, 플러그인 항목)에서 `Ctrl+O` 또는 방향키 `→`를 누르면 컨텍스트 액션 메뉴가 펼쳐집니다.

### 기본 핵심 액션 목록

| 액션 이름 | 기본 단축키 | 기능 설명 |
| :--- | :--- | :--- |
| **열기** | `Enter` | 시스템 기본 연결 프로그램으로 파일을 열거나 응용 프로그램을 실행합니다. |
| **탐색기에서 위치 확인** | `Ctrl+Enter` | 상위 폴더를 열고 파일 탐색기에서 해당 파일을 선택한 상태로 표시합니다. |
| **관리자 권한으로 실행** | `Ctrl+Shift+Enter` | 관리자 권한으로 프로그램을 실행합니다(실행 파일, 바로가기, 배치 스크립트 등). |
| **전체 경로 복사** | `Ctrl+Shift+C` | 파일의 절대 경로(예: `D:\Projects\app.exe`)를 클립보드에 복사합니다. |
| **파일 잘라내기 / 복사** | `Ctrl+X` / `Ctrl+C` | 파일 자체를 클립보드에 담아 탐색기나 다른 폴더에 직접 붙여넣을 수 있게 합니다. |
| **여기에 붙여넣기** | `Ctrl+V` | 선택 항목이 폴더인 경우 클립보드의 파일을 해당 디렉토리 내에 붙여넣습니다. |
| **삭제 (휴지통으로 이동)** | `Delete` | 선택한 파일이나 폴더를 Windows 휴지통으로 안전하게 이동합니다. |
| **영구 삭제** | `Shift+Delete` | 선택 항목을 영구적으로 삭제합니다(복구 불가, 확인 대화상자 표시). |
| **Windows 우클릭 메뉴** | — | Windows 파일 탐색기의 전체 기본 컨텍스트 메뉴(보내기 및 타사 확장 메뉴 포함)를 엽니다. |

### 액션 메뉴 인터랙션 및 즉시 필터링

- **입력하여 즉시 필터링**: 액션 메뉴가 열린 상태에서 글자를 입력하면 액션 이름을 실시간으로 검색할 수 있습니다(예: `copy` 입력 시 복사 관련 액션 즉시 표시).
- **계층 탐색**: 하위 메뉴가 있는 항목(예: "보내기")에서 `→` 또는 `Enter`를 눌러 진입하고, `←` 또는 검색어가 빈 상태에서 `Backspace`를 누르면 상위로 돌아갑니다.
- **메뉴 닫기**: `Escape`를 누르면 액션 메뉴를 닫고 검색 목록으로 돌아갑니다.

## 2. 메인 윈도우 결과 목록 기능

메인 검색 윈도우(`Ctrl+F`)는 대규모 파일 관리와 심층 탐색을 위해 설계되었습니다.

- **경로 열 더블클릭 이동**: 목록의 **이름** 열을 더블클릭하면 파일이 실행되고, **경로** 열을 더블클릭하면 해당 파일이 위치한 상위 폴더가 열립니다.
- **스트리밍 결과 로딩**: 수백만 개의 항목을 스캔할 때도 인덱싱 엔진에서 수신된 결과가 목록에 실시간 스트리밍 방식으로 추가됩니다. 전체 스캔 완료를 기다릴 필요 없이 즉시 조작할 수 있습니다.
- **루프 탐색**: 첫 번째 행에서 `↑`를 누르면 마지막 행으로, 마지막 행에서 `↓`를 누르면 첫 번째 행으로 이동합니다.
- **창 드래그 및 크기 기억**: 창 상단의 빈 영역을 드래그하여 위치를 옮길 수 있으며, 조절된 크기는 다음 실행 시에도 유지됩니다.

## 3. QuickLook 즉시 미리보기 기능

검색 결과에서 `Alt+P`를 누르면 검색창 옆에 강력한 미리보기 패널이 열립니다.

### 다양한 파일 형식 지원

- **이미지 및 벡터 그래픽**: JPG, PNG, GIF(움짤 자동 재생), BMP, WebP, ICO, SVG 등의 고해상도 렌더링.
- **문서 및 코드 구문 강조**: TXT, Markdown, JSON, XML, YAML, C#, Python, JS, HTML 등의 텍스트 서식 표시.
- **오디오/비디오 즉시 재생**: MP4, MKV, AVI, MOV, WMV, MP3, WAV, FLAC, WMA 등의 미디어는 미리보기가 열리는 즉시 **자동 재생**되며 미니 컨트롤 바(재생/일시정지, 탐색 바, 시간 표시, 음소거)가 제공됩니다. 항목 전환 시 즉시 중지됩니다.
- **폴더 구조 검사**: 폴더를 선택하면 직속 하위 항목 최대 30개가 아이콘 및 크기와 함께 표시됩니다(숨김/시스템 파일 제외).

### 레이아웃 및 대화상자 자동 회피

- **화면 영역 자동 맞춤**: 미리보기 크기는 [**설정 → 일반 → 미리보기**](./settings/general#미리보기)에서 변경할 수 있으며 화면을 벗어나지 않도록 자동 제어됩니다.
- **네이티브 대화상자 자동 회피**: 비밀번호가 걸린 Office 문서를 미리볼 때 암호 입력 창이 뜨면 Lertaro 창을 일시적으로 숨겨 입력을 방해하지 않으며, 완료 후 자동으로 복구됩니다.
- **미리보기 창에서 드래그 앤 드롭**: 미리보기 패널 상단을 드래그하여 외부 앱이나 탐색기로 파일을 직접 끌어다 놓을 수 있습니다.

## 4. 플러그인 리치 텍스트 및 대화형 미리보기

QuickLook은 로컬 파일뿐 아니라 플러그인의 인터랙티브 패널도 지원합니다.

- **테마 자동 적응형 리치 텍스트**: WebView2 및 네이티브 컴포넌트로 렌더링되어 다크/라이트 테마에 자동 맞춤되며 깔끔한 타이포그래피와 반투명 스크롤바를 제공합니다.
- **다양한 플러그인 카드**: 사전 검색 카드, 실시간 날씨, 웹 스냅샷, API 디버깅 정보 등 풍부한 인터랙티브 패널을 지원합니다.

## 5. 타사 독립 QuickLook 연동 (선택 사항)

독립된 오픈소스 도구인 **QuickLook**([GitHub의 QL-Win/QuickLook](https://github.com/QL-Win/QuickLook))을 설치하여 사용 중인 경우, [**설정 → 플러그인**](./settings/plugins)에서 **QuickLook 브리지** 플러그인을 활성화할 수 있습니다.

- **외부 미리보기 연결**: 로컬 명명된 파이프를 통해 외부 QuickLook 프로세스에 연결하여 미리보기 창을 Lertaro 옆에 도킹합니다.
- **자동 대체**: 외부 QuickLook 프로세스가 실행 중이지 않은 경우 내장 미리보기 엔진으로 부드럽게 대체됩니다.

## 6. 파일 점유 해제

공식 **파일 점유 해제** 플러그인은 존재하는 파일을 하나만 선택했을 때 사용할 수 있는 액션을 제공합니다. 파일을 사용 중인 프로세스와 PID, 실행 파일 경로를 표시하고 해당 프로세스에 파일 해제를 요청합니다. 폴더, 존재하지 않는 파일 또는 여러 항목을 선택하면 액션을 사용할 수 없으며, 점유 프로세스가 없을 때는 해제 요청 버튼도 비활성화됩니다. 대화상자는 호스트 테마를 사용하고 검색 창 위에 표시되며 Alt+Tab 목록에는 나타나지 않습니다. 새로 고침도 지원합니다.
