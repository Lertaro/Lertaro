# 개발자 매뉴얼

Lertaro는 서드파티 어셈블리가 검색 동작을 확장하고, 컨텍스트 메뉴 동작을 추가하고, 다른 창과 통합하고,
UI를 커스터마이즈할 수 있도록 개방형 플러그인 SDK(`Lertaro.PluginSdk`)를 제공합니다. 이 매뉴얼은 그
표면을 문서화합니다.

- **[아키텍처](./architecture)** — App, 백그라운드 Service, 플러그인이 어떻게 맞물리는지 설명합니다.
- **[시작하기](./getting-started)** — 플러그인 프로젝트를 스캐폴딩하고 로드하는 방법입니다.
- **Plugin SDK 참조**:
  - **[핵심 검색 및 동작](./sdk/core-search-actions)** — 검색 결과와 결과 동작을 기여하는 방법입니다.
  - **[시스템 및 대화상자 어댑터](./sdk/system-adapters)** — 파일 탐색기, 네이티브 파일 대화상자, 그 밖의
    포그라운드 창과 통합하는 방법입니다.
  - **[UI 및 미리보기 확장](./sdk/ui-extensions)** — 사이드바 필터, 결과 열, 파일 미리보기, 썸네일, 테마,
    번역입니다.
  - **[공유 추상화](./sdk/abstractions)** — 플러그인이 받는 읽기 전용 모델(`ISearchResult`,
    `IPluginSearchWindow`)과 설정 스키마(`IConfigurable`)입니다.
  - **[호스트 서비스](./sdk/services)** — 호스트가 플러그인에 다시 노출하는 정적 서비스(아이콘, 즐겨찾기,
    기록, 파일 메타데이터, 디렉터리 인덱싱, 플러그인별 설정, 로깅)입니다.
- **[예제 플러그인](./examples)** — 실제로 함께 제공되는 두 개의 플러그인을 사례로 살펴봅니다.
- **[패키징 및 배포](./packaging)** — 빌드된 플러그인 DLL이 어떻게 발견되고 로드되는지 설명합니다.

여기 실린 모든 인터페이스 시그니처는 현재의 `PluginSdk` 소스 코드와 직접 대조하여 검증되었습니다 — 만약
차이를 발견하셨다면, 코드 쪽이 항상 우선합니다.
