# 空间分析

空间分析把 Lertaro 已有的文件索引转换成类似 SpaceSniffer 的快速可视化概览。它不会扫描磁盘，因此即使多个磁盘包含数百万条目，也能迅速打开。

## 打开空间分析

打开 Lertaro 完整搜索窗口并让搜索框保持为空，空间分析会自动作为窗口首页显示，并呈现 Lertaro 当前已加载的全部索引。输入查询会立即切换到搜索结果，清空查询则会回到空间分析之前所在的位置。使用鼠标左键双击磁盘或文件夹即可进入；使用向上箭头或任意面包屑路径可返回上级位置。

## 查看和操作

- 左侧矩形树会给较大的条目分配更大的面积，明暗表示大小占比，不同边框用于区分文件夹和文件。
- 右侧列表显示同一批条目并按大小降序排列，每行下方的细条表示它在当前位置可见总大小中的占比；在任意一侧选中条目，另一侧也会同步高亮。
- 右键单击卡片或列表行，会打开与搜索结果相同的动作菜单，包括打开、定位、复制以及适用的插件动作。
- 只有名称或大小被截断时才会显示工具提示。

## 统计范围

这里只包含 Lertaro 已启用索引中现有的条目，空间分析不会通过遍历文件系统来补齐缺失内容。被排除和未索引的内容不会参与统计；隐藏条目会正常显示，系统条目不会单独显示，但其大小仍可能计入可见上级文件夹的总大小。

界面显示的是文件逻辑大小，而非实际占用的磁盘空间。文件夹总大小包含其已索引的后代条目，硬链接数据只会计入一次，因此统计结果可能与 Windows 资源管理器或扇区级磁盘分析工具不同。

空间分析页面可见时会自动监听相关的内存索引变更事件，并合并连续通知后更新当前视图；它始终不会打开或重新加载索引缓存文件。开始搜索后会暂停空间分析更新，关闭完整搜索窗口时会释放已经渲染的条目和共用界面缓存。
