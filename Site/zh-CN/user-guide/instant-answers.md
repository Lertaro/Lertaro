# 即时答案与关键词功能

有些结果会在你打字的同时立刻出现，不需要等文件搜索完成——要么是始终生效的，要么是需要你先输入一个简短的关键词、再接你真正想查的内容(这样像"搜索浏览器历史记录"这类分量较重的功能，就不会在你打每一个跟它无关的字符时都来抢注意力)。大多数需要关键词的功能，其关键词都可以在**设置 → 插件 → 配置**
里自行修改。

## 始终生效

这些不需要关键词——只要你输入的内容匹配它们的模式，就会立刻触发。

### 计算器

直接输入数学表达式，结果会实时显示出来，按 **Enter** 把结果复制到剪贴板:

```
12 * (4 + 3)
```

也支持显式的进制转换:

```
255 to hex
0xFF to dec
```

### 环境变量

- `%NAME%` 展开某个具体的变量(包括像 `%PATH%` 这种多路径变量，会按路径逐条拆开列出)。
- `%partial` 模糊列出所有名称里包含 `partial` 的变量。

### 运行命令

- `#<命令>` 打开命令提示符窗口，**以管理员权限**运行 `<命令>`。
- `$<命令>` 打开命令提示符窗口，以普通权限运行 `<命令>`。

### 裸网址

直接输入或粘贴一个 `http://`/`https://` 地址，Lertaro 会提示直接打开它。

## 关键词触发(内置插件，前缀可配置)

输入关键词、一个空格，然后接你真正的查询内容。每个关键词都有一个默认的简短前缀，如果它和你常打的内容冲突，也可以在对应插件自己的**配置**对话框里单独修改。

| 关键词(默认) | 插件 | 搜索的内容 |
|---|---|---|
| `ps` | 进程管理 | 按名称、PID 或窗口标题搜索正在运行的进程(也支持模糊/拼音匹配)——选中一个即可结束它。 |
| `win` | 窗口切换器 | 当前打开的、可切换的窗口(和 Alt+Tab 显示的是同一批)，按标题、进程名或 PID 搜索——选中即可切换到该窗口。 |
| `bm` | 浏览器数据 | 搜索你在该插件设置里添加的 Chrome/Chromium 系和 Firefox 系浏览器配置文件里的书签与历史记录。 |
| `set` | 核心扩展 | 应用内的每一项设置，按名称模糊匹配——选中一项即可直接跳转到设置里对应的那一行并高亮。只打 `set` 不加任何内容会列出所有设置。 |

窗口切换器默认会把每个窗口实际内容的实时缩略图作为图标——截图在后台进行，不会拖慢输入速度：先立即显示程序图标，缩略图准备好之后再补上。在**设置 → 插件 → 窗口切换器 → 配置**里关掉"用窗口内容作为图标"就能完全跳过这部分截图，始终用程序图标。真正的独占全屏窗口(大多数游戏默认用的其实是无边框窗口化，这种没问题)截不到内容，会自动回退到程序图标。

浏览器数据插件的书签和历史记录是各自独立索引的——**索引书签**和**索引历史记录**是**设置 → 插件
→ 浏览器数据 → 配置**里两个独立的开关，所以你可以只关掉历史记录(它通常比书签多得多)而继续搜索书签，反过来也一样。

## 网页搜索

网页搜索插件自带了几个引擎/网站的默认关键词——`bd`(百度)、`g`(谷歌)、`bing`(必应)、`gh`
(GitHub)、`wiki`(维基百科)、`yt`(YouTube)——你也可以在**设置 → 插件 → 网页搜索 → 配置**里完全自由地新增、编辑或删除条目，每一条都有自己的名称、关键词、图标和网址模板。

```
g lertaro github
```

会在浏览器里打开一次"lertaro github"的谷歌搜索。

## 文件过滤器

在**设置 → 插件 → 文件过滤器 → 配置**里，为特定文件夹单独建立索引规则。每条规则都有自己的
**监控文件夹列表**(递归扫描)、一个**匹配后缀**字段(例如 `*.exe;*.lnk`——支持用 `;` 或 `,`
分隔多个模式，全部都会被匹配；默认的 `*` 匹配所有文件)，以及一个可选的**过滤器名称**，会显示在结果的描述里。子文件夹永远会被收录，不受匹配后缀影响——匹配后缀只过滤文件。

给规则加上**触发关键字**，可以把它的结果收在一个前缀关键词后面(和上面的内置关键词一样)，而不是始终混在通用索引结果里参与排序。

## 完全自定义(关键词你说了算)

### 自定义命令

定义你自己的 `<关键词> <参数>` 命令，用来启动一个外部程序，全部在**设置 → 插件 → 自定义命令 →
配置**里配置。命令的参数模板支持位置占位符(`%s1`、`%s2`……对应每个用空格分隔的参数)，以及一个
"剩余全部内容"占位符(`%s`，代表关键词之后你输入的所有内容)。

每条命令还有一个**在快速导航中显示**勾选框(默认关闭)——打开后，这条命令会额外作为一个条目出现在[快速导航](./hotkeys#快速导航鼠标)菜单的根层级，不用打关键词也能点开执行。**快速导航子菜单**
字段可以把它归到某个具名子菜单下，而不是直接放根层级——用 `/` 可以嵌套多级(比如"工具/网络"代表两级子菜单);留空则保持在根层级。以这种方式执行时，命令会按配置好的参数原样运行，因为这里没有打字输入的参数内容可以代入 `%s1`/`%s`。

文件夹/应用程序搜索的模糊查询语言，和本页内容是两回事。
