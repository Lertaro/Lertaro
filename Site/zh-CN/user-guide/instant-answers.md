# 即时解答与关键词扩展功能

除了本地文件检索之外，Lertaro 还内置了一系列强大的即时计算、系统工具与关键词扩展插件。无需等待文件检索，输入对应指令即可即刻得到答案或触发专业功能。

## 1. 始终生效的即时解答

无需输入任何前缀关键词，只要输入的文本匹配特定模式即可立即触发：

### 计算器与进制转换

直接在搜索框中输入数学表达式，计算结果将在第一行实时呈现。按下 `Enter` 键即可将计算结果复制到剪贴板：

```text
12 * (4 + 3)
100 * (1 - 0.15)
```

支持常见的进制转换表达：

```text
255 to hex
0xFF to dec
101010 to bin
```

### 环境变量展开与查询

- **精准展开变量**：输入 `%NAME%`（如 `%PATH%`、`%APPDATA%`）可直接查看变量值。对于包含多个路径的变量（如 `PATH`），Lertaro 会自动将其拆分为清晰的逐行列表，便于检查环境配置。
- **模糊搜索变量**：输入 `%` 加上关键词（如 `%temp`）可模糊搜索所有名称中包含该关键词的系统与用户环境变量。

### 快捷运行命令

无需先打开终端窗口，直接在搜索框中输入：

- `#<命令>`：打开命令行窗口并**以管理员权限**执行该命令（例如 `#sfc /scannow` 或 `#net start Lertaro.Service`）。
- `$<命令>`：打开命令行窗口以**当前普通用户权限**执行该命令（例如 `$ping 1.1.1.1` 或 `$ipconfig /all`）。

### 网址直达

直接输入或粘贴以 `http://` 或 `https://` 开头的完整网址，按下 `Enter` 即可立即在默认浏览器中打开该页面。

## 2. 关键词触发功能（内置插件）

通过输入简短的**触发关键词 + 空格**，再输入实际查询内容，即可调用专项插件能力。各关键词均可在[**设置 → 插件**](./settings/plugins)中自定义修改。

| 默认关键词 | 插件名称 | 功能说明与使用场景 | 典型使用示例 |
| :--- | :--- | :--- | :--- |
| `ps` | **进程管理** | 按进程名、PID 或窗口标题搜索运行中的进程（支持拼音），回车一键结束进程。 | `ps chrome` 或 `ps 1234` |
| `win` | **窗口切换器** | 搜索并即时切换到当前打开的应用窗口，支持后台实时抓取窗口缩略图。 | `win code` 或 `win 微信` |
| `bm` | **浏览器数据** | 搜索 Chrome、Edge、Firefox 等浏览器的书签与历史访问记录（书签与历史可独立开关）。 | `bm github` |
| `set` | **设置搜索** | 模糊搜索 Lertaro 自身的所有设置选项，选中即可直接跳转到对应设置页并高亮该项。 | `set 热键` 或 `set 模糊` |
| `flow` | **Flow 插件桥接** | 列出所有已加载的 Flow.Launcher 插件及其触发词，支持无缝调用 Flow 社区生态。 | `flow` |

## 3. 网页搜索快捷引擎

网页搜索插件内置了主流搜索引擎快捷方式，输入对应前缀并跟随关键词即可一键拉起浏览器搜索：

| 快捷词 | 对应搜索引擎 | 示例 | 说明 |
| :--- | :--- | :--- | :--- |
| `bd` | 百度 (Baidu) | `bd 深度学习` | 在百度中搜索关键词 |
| `g` | 谷歌 (Google) | `g lertaro github` | 在 Google 中搜索关键词 |
| `bing` | 必应 (Bing) | `bing 微软文档` | 在 Bing 中搜索关键词 |
| `gh` | GitHub | `gh Lertaro` | 直接在 GitHub 仓库中搜索 |
| `wiki` | 维基百科 (Wikipedia) | `wiki 量子力学` | 在维基百科中查阅词条 |
| `yt` | YouTube | `yt lofi hip hop` | 在 YouTube 中搜索视频 |

你可以在**设置 → 插件 → 网页搜索 → 配置**中自由新增、修改或删除搜索引擎与自定义 URL 模板。

## 4. 即时翻译

输入默认触发词 `tr` 并在其后输入待翻译的内容，即可自动翻译为 Lertaro 当前所选的界面语言：

```text
tr Hello, how are you today?
```

- 翻译结果随输入异步呈现，按 `Enter` 键即可一键复制译文。
- 可在**设置 → 插件 → 翻译 → 配置**中更改触发词或查看联网状态。

## 5. 文件过滤器

在**设置 → 插件 → 文件过滤器 → 配置**中，你可以为特定目录和扩展名建立专属过滤器规则：

- **指定监控目录**：递归扫描指定工作目录（如 `D:\Engineering\Drawings`）。
- **指定匹配规则**：例如 `*.dwg;*.dxf` 或 `*.pdf;*.docx`（不影响子文件夹收录）。
- **设置触发关键字**：为该规则绑定专属前缀（如 `cad` 或 `doc`），输入 `cad 零件图` 即可实现特定业务资料的精准隔离搜索。

## 6. 自定义命令

在**设置 → 插件 → 自定义命令 → 配置**中，你可以将任意复杂的命令行工具、脚本或外部应用包装为一个简短的启动命令：

- **参数占位符**：支持位置占位符 `%s1`、`%s2`……（对应以空格分隔的参数）以及全文占位符 `%s`（代表关键词后的所有输入文本）。
- **快速导航集成**：勾选“在快速导航中显示”后，该命令会直接作为菜单项出现在[**快速导航**](./hotkeys#3-快速导航鼠标触发)中，支持使用 `/` 创建多级子菜单分类（如 `开发工具/重启服务`）。
