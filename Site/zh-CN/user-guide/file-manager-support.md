# 支持的文件管理器与对话框集成

Lertaro 不仅是一款独立的桌面启动器，更具备深度嵌入各类文件资源管理器与软件对话框的强大集成能力。通过无缝接管文件交互，极大提升文件打开、保存与目录跳转的效率。

## 1. 三大核心集成能力

根据目标宿主窗口的特性，Lertaro 的集成最多可提供以下三种核心能力：

- **内嵌搜索（Inline Search）**：Lertaro 的极速搜索框直接嵌入到目标窗口顶部或对话框内部，无需离开当前工作界面即可在当前目录或全局发起检索。
- **快速导航（Quick Navigation）**：在目标窗口空白处点击鼠标中键（或双击左键），或点击内嵌搜索框的图标，即可弹出包含当前已打开文件夹、收藏夹、最近历史与自定义快捷目录的级联菜单。
- **活动路径检测（Active Path Detection）**：实时感知宿主窗口当前所处的物理文件目录，自动将搜索范围智能限定在当前目录内，或用于解析相对路径操作。

## 2. 系统原生组件支持（内置开箱即用）

以下系统原生组件均由 Lertaro 核心引擎直接支持，无需单独安装或配置任何插件：

| 宿主窗口类型 | 内嵌搜索 | 快速导航触发方式 | 活动路径检测 |
| :--- | :--- | :--- | :--- |
| **Windows 文件资源管理器** | 支持 | 空白区域双击左键或点击鼠标中键 | 支持 |
| **现代打开/保存文件对话框** | 支持（直接嵌入对话框） | 鼠标中键，或左键点击内嵌搜索框 Logo 图标 | — |
| **经典打开/保存文件对话框** | 支持 | 鼠标中键，或左键点击内嵌搜索框 Logo 图标 | — |
| **经典“浏览文件夹”对话框** | 支持 | 鼠标中键，或左键点击内嵌搜索框 Logo 图标 | — |

> [!NOTE]
> 在各类文件选择对话框中，由于 Lertaro 已经直接内嵌在对话框内部，因此无需额外的活动路径检测；点击快速导航中的目标后，对话框会直接精准跳转到该目录。

## 3. 专业第三方文件管理器支持（可选插件）

针对高级用户常用的第三方文件管理工具，Lertaro 提供了深度对接插件。你可以在[**设置 → 插件**](./settings/plugins)中按需启用，并在各插件的**配置**面板中单独开关内嵌搜索与快速导航：

| 文件管理器 | 内嵌搜索 | 快速导航触发方式 | 活动路径检测 | 核心通信技术与协议 |
| :--- | :--- | :--- | :--- | :--- |
| **Directory Opus** | 支持 | 文件列表区域点击鼠标中键 | 支持 | `WM_COPYDATA` 官方远程控制接口 |
| **Total Commander** | 支持 | 文件列表区域点击鼠标中键 | 支持 | `WM_COPYDATA` 官方消息接口 |
| **XYplorer** | 支持 | 文件列表区域点击鼠标中键 | 支持 | 专用进程接口通信 |
| **Files** | 支持 | 文件列表区域点击鼠标中键 | 支持 | Windows UI Automation 现代化自动化接口 |
| **One Commander** | 支持 | 文件列表区域点击鼠标中键 | 支持 | Windows UI Automation 现代化自动化接口 |

### Directory Opus 专属深度集成

- **递归文件夹大小列（Lertaro 大小）**：启用 Directory Opus 插件中的“启用 Lertaro 大小列”后，Lertaro 会自动向 Directory Opus 注入自定义脚本列。该列直接从 Lertaro 的内存索引读取文件夹递归总容量，**完全无需扫描磁盘**即可秒级呈现整个磁盘所有文件夹的实际体积。
- **持久化配置**：在 Directory Opus 的列选择器中添加“Lertaro 大小”列后，依次点击**文件夹 → 文件夹格式 → 保存 → 将格式保存给所有文件夹**即可全局生效。

### Everything 兼容服务 (IPC)

在[**设置 → 通用 → 系统**](./settings/general#系统)中勾选**启用 Everything 兼容服务 (IPC)**后，Lertaro 会在后台模拟标准的 Everything Win32 IPC 接口。Directory Opus、Total Commander、Flow Launcher 等第三方软件无需额外安装或运行 Everything，即可直接通过原有的 Everything 插件调用 Lertaro 的极速内存索引。

## 4. 常用软件自绘对话框支持（专用插件）

许多专业软件并未使用 Windows 原生对话框，而是自绘了特殊窗口。Lertaro 为以下主流软件的专用对话框提供了定制化内嵌支持：

| 软件名称与对话框类型 | 内嵌搜索 | 快速导航触发方式 | 适配说明 |
| :--- | :--- | :--- | :--- |
| **WPS Office** 打开/保存对话框 | 支持 | 鼠标中键，或点击内嵌 Logo 图标 | 全面覆盖 WPS 文字、表格、演示与 PDF 组件 |
| **WinRAR** 解压对话框 | 支持 | 鼠标中键，或点击内嵌 Logo 图标 | 解压文件时快速定位目标解压目录 |
| **Bandizip** 解压对话框 | 支持 | 鼠标中键，或点击内嵌 Logo 图标 | 快速指定解压输出路径 |
| **Bandizip** 添加文件对话框 | 支持 | 鼠标中键，或点击内嵌 Logo 图标 | 压缩打包时快速选择源文件 |
| **AutoCAD** 打开/保存对话框 | 支持 | 鼠标中键，或点击内嵌 Logo 图标 | 适配工程图纸的快速归档与调用 |

各插件通过识别窗口底层的控件结构与句柄层级进行挂载，不受软件多语言界面或不同版本界面微调的影响。
