# 内容搜索

内容搜索插件可以检索本地文档中的正文，并在后台建立索引，与 Lertaro 原有的文件名搜索并行工作。

## 开始使用

打开**设置 → 插件 → 内容搜索 → 配置**，至少设置一个监测文件夹并保存。默认触发关键字为 `cs`：

```text
cs 项目计划
```

关键字后必须跟一个空格。如果 `cs` 与你的使用习惯冲突，可以在插件设置中改成其他关键字。

## 索引内容

- **监测文件夹**：插件会向宿主索引服务注册配置的本地文件夹，通过 SDK 的索引目录枚举和防抖的目录变更通知完成首次及增量发现，并支持 `%USERPROFILE%` 等环境变量。
- **文件后缀**：默认包含 `txt`、`md`、`pdf`、`docx`、`docm`、`pptx`、`pptm`、`xlsx`、`xlsm` 和 `csv`，你可以按需要修改逗号分隔的列表。
- **PDF 文件**：会同时检索可提取的页面正文和已保存的可填写 PDF 表单字段值。
- **文件大小**：超过单个文件大小上限的文件会被跳过；内容索引还有独立的体积上限，设为 `0` 表示不限制。
- **排除路径**：输入以分号分隔的正则表达式来排除匹配的完整路径。文件夹路径匹配时，其内容也会被排除。

只有成功提取出正文的文件才会参与搜索。没有对应文档提取器的二进制文件会被跳过，不会作为乱码文本写入索引。

## 搜索方式

在快速搜索窗口中输入 `cs`、空格和关键词即可搜索。结果会显示匹配文件的正文片段及所在文件夹，按下 `Enter` 可打开选中的文件。查询有结果时，在未选择类型筛选的情况下，完整搜索窗口中也会显示这些文件结果。

首次建立索引时，`cs` 占位结果会显示已索引文件数和剩余任务数。宿主监听器报告新增或变化的目录后，插件会在后台处理其中的文件，因此索引期间不会影响普通文件名搜索；索引稳定后不会再循环扫描文件系统。

## 清空与重建

内容搜索设置中提供两个不同的操作：

- **清空索引**：删除内容索引，但不会重新扫描监测文件夹。
- **重建索引**：删除内容索引，然后重新扫描所有监测文件夹。

这两个操作只影响内容搜索索引，不会删除 Lertaro 的普通文件名索引。

## 使用提示

- 如果文件没有出现在结果中，请检查它所在的文件夹、后缀、排除规则和大小上限。
- 修改监测文件夹或索引规则后，请保存设置并等待后台扫描完成。
- 修改规则后如果希望重新提取已有文件，请使用**重建索引**。
