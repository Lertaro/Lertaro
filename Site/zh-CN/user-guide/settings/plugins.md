# 插件管理

Lertaro 拥有高度模块化的插件化架构体系。无论是核心扩展组件、本地工具还是社区第三方生态，均可在插件管理中心中统一查看、管理与配置。页面路径为**设置 → 插件**。

## 1. 页面布局与 SDK 版本

- **Plugin SDK 徽标**：页面顶部右上角醒目标注了当前运行时加载的 `Lertaro.PluginSdk` 版本号。点击该徽标可直接跳转至[**开发者手册**](../../dev-guide/)查阅接口文档。
- **左右双栏独立滚动**：左侧展示已安装的所有插件列表，右侧展示当前选中插件的详细信息与配置面板，两侧独立滚动互不干扰。

## 2. 插件详情与组件开关

点击左侧列表中的任意插件后，右侧会展示该插件的图标、名称、版本号与功能简介：

### 详情标签页（Details）

- **组件清单与分组**：清晰列出该插件注册的所有底层功能组件（例如：搜索源、右键动作、快速导航提供者、即时预览解析器等）。
- **组件级独立开关**：每个非必要组件均配有独立的**启用/禁用复选框**；带有锁形图标的组件为系统级必要核心，不可关闭。
- **一键全选/全不选**：当某个组件分组包含多个可切换项目时，标题右侧会提供便捷的“全选/全不选”链接。
- **组件悬停说明**：鼠标悬停在组件旁边的 **(!)** 图标上，可查看该组件的底层实现说明与触发方式。

### 配置标签页（Configure）

- **原生嵌入式表单**：插件自定义的配置项会直接渲染在右侧面板中，无需弹出额外的杂乱对话框。支持文本框、数字调节、开关、下拉选择及多分组子标签页。
- **安全提交与回滚机制**：在右下角点击**确定**之前，任何修改均仅暂存于内存中；若直接切换至其他插件或离开页面，未保存的修改会自动安全回滚至原始状态，防止误提交。

## 3. Flow Launcher 社区生态深度支持

除了基于 `Lertaro.PluginSdk` 构建的原生 C# 插件之外，Lertaro 还通过内置的 **Flow Launcher Bridge** 提供了对庞大 Flow Launcher 社区插件生态的原生级兼容支持。

### 多语言运行时与隔离环境

- **全类型插件兼容**：无缝运行由 **C# (.NET)**、**Python 3.12**、**Node.js v20 LTS** 以及独立可执行程序（`.exe`）编写的 Flow Launcher 插件。
- **零依赖污染与自包含运行时**：Python（`FlowData\PythonEmbeded-{arch}`）与 Node.js（`FlowData\NodeEmbeded-{arch}`）运行时完全隔离在 Lertaro 的用户数据目录中按需自动下载部署，不依赖且绝不污染 Windows 系统的全局环境变量与 PATH。
- **依赖自动安装**：插件首次加载时，系统会在后台静默根据 `requirements.txt` 安装 Python `pip` 依赖，或根据 `package.json` 执行 `npm` 依赖安装。

### 在线社区市场与包管理指令

你可以直接在 Lertaro 搜索框中键入以下指令管理 Flow 插件：

- **`flow install <关键词>`**：实时在线检索 Flow.Launcher 官方社区插件库，选中后一键自动下载、解压、部署并拉起依赖安装。
- **`flow update`**：自动检测所有已安装 Flow 插件的更新版本并支持一键升级。
- **`flow uninstall <插件名>`**：一键安全卸载指定的 Flow 插件并清理相关本地目录。
- **手动安装**：亦可将下载好的第三方 Flow 插件文件夹直接放入 `<用户数据目录>\FlowData\Plugins\` 完成本地离线安装。

### 插件配置、触发词与交互式预览

- **集中管理与触发词修改**：在**设置 → 插件 → Flow Launcher Bridge → 配置**中，可为每个 Flow 插件单独开关，并自由修改其专属**触发词（ActionKeyword）**。配置集中持久化在 `FlowData\Settings\Plugins.json` 中，插件更新后配置不丢失。
- **动态配置表单**：完整支持 Flow 插件基于 YAML/JSON 模板表单（`SettingsTemplate.yaml`/`.json`）或 C# WPF 设置面板（`ISettingProvider`）的配置界面，自动融合当前深浅色主题并支持 i18n 本地化。
- **WebView2 交互式富文本预览**：支持 Flow 插件返回的复杂预览面板（如 MDict 词典释义、天气卡片、API 调试信息、网页快照等），在 QuickLook 中免额外按键平滑展开；Lertaro 会自动注入深浅色自适应样式、清晰字体与精致滚动条。
- **宿主能力深度融合**：Flow 插件通过 API 打开文件夹时自动遵循宿主配置的第三方文件管理器，弹窗消息框自动渲染为宿主主题自绘样式，且内部日志无缝汇入设置中心日志查看器。
- **快捷总览**：在搜索框中直接输入 `flow` 即可列出当前已加载的所有 Flow 插件及其触发词。
