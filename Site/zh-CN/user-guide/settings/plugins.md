# 插件

列出所有已安装的插件，页面头部的徽标显示当前加载的 Plugin SDK 版本——点击它可以直接打开[开发手册](../../dev-guide/)，这个版本号正是为了对照手册开发插件而准备的。

页面分成左右两栏：左边是已安装的插件，右边是选中插件的详情。两栏各自独立滚动，插件列表很长和配置表单很长互不牵扯。

如果没有安装任何插件，页面会显示一个空状态提示。

## 插件列表

每个已安装的插件占一行，显示名称，下方是它的版本号。点击某一行，右侧就会打开该插件。

列表按"有什么可操作的"排序：先是有自己配置项的插件，其次是有组件可以关闭的，最后是其余的；每一档内部按名称排列。

## 选中的插件

右栏最上方是插件的图标、名称和**总体功能简介**。

再往下，如果插件暴露了自己的配置项(超出简单启用/禁用的范畴)，会出现**详情**和**配置**两个标签页。没有任何配置项的插件不会显示标签栏——整栏就是它的详情。

### 详情

该插件注册的功能组件，按类型分组（搜索源、动态菜单提供者等）。每个可切换的组件都有自己的**启用/禁用复选框**；标记为必要项的组件会显示一个锁形图标，不能关闭。把鼠标悬停在组件旁边的 **(!)** 上，可以看到该组件的详细功能说明。

当某个分组（或整个插件）有 2 个及以上可切换组件时，标题旁会出现一个**全选/全不选**链接，点击即可一次性切换该范围内的所有复选框，不用逐个手动勾选。

### 配置

插件自己的设置项，直接在这里编辑，不再另开对话框。如果插件把设置分成了 2 组及以上，这里还会有一行属于它自己的标签页，每组一个。

按下**确定**之前，什么都不会写入。离开这个标签页——切回详情，或者选择另一个插件——会把这些字段回滚到已保存的值，这样你放弃掉的修改就不会在之后被误提交。

想看插件配置实际长什么样、能改什么(比如改一个触发关键词)，可以参考[即时答案与关键词功能](../instant-answers)。

## Flow Launcher 插件生态支持

除了基于 `Lertaro.PluginSdk` 构建的原生 C# 插件之外，Lertaro 还通过内置的 Flow Launcher Bridge 提供了对庞大 Flow Launcher 社区插件生态的原生级兼容支持。

- **支持的插件类型**：兼容 **C# (.NET)**、**Python 3.12**（支持根据 `requirements.txt` 自动在后台安装 `pip` 依赖）、**Node.js v20 LTS**（支持根据 `package.json` 自动在后台安装 `npm` 依赖）以及独立**可执行程序**（`.exe`）编写的 Flow Launcher 插件。
- **安装方式**：直接将第三方 Flow Launcher 插件文件夹放入 `<用户数据目录>\FlowData\Plugins\`，Lertaro 会自动识别、加载并注册其搜索触发词与动作。
- **纯净隔离运行环境**：Python（`FlowData\PythonEmbeded-{arch}`）与 Node.js（`FlowData\NodeEmbeded-{arch}`）运行时完全隔离在 Lertaro 的数据目录中按需自动下载部署，不依赖也不污染系统的全局环境变量与 PATH。
- **插件管理与配置**：在搜索框中直接输入 `flow` 关键词即可列出所有已加载的 Flow 插件清单、查看其触发词与状态；选中支持自定义配置的插件按 **Enter** 即可唤起专属设置窗口，享有确定保存与取消回滚保护机制。
