# 快速面板设置

**快速面板（Quick Panel）** 是 Lertaro 专为高频文件取用、项目上下文管理与桌面拖拽交互打造的浮动工作区。它会在按下热键时自动停靠在当前前台活动窗口的右下角，让你无需离开当前工作窗口即可快速浏览、拖入或分发常用文件。

## 1. 核心机制与总开关

- **启用快速面板**：总开关，关闭后将不再监听呼出热键。
- **唤起热键**：默认快捷键为 **`Ctrl+F2`**（可在[**设置 → 热键**](./hotkeys-page)中自定义）。
- **智能贴靠与尺寸约束**：面板默认尺寸为宿主窗口宽高的各二分之一（最小尺寸限制为 `280 × 200px`，确保内容与筛选框完整可用）。若当前处于 Lertaro 自身窗口时按热键会被安全忽略，防止窗口重叠；面板打开状态下再次按下同款热键可一键关闭。
- **快速跳转联动**：面板打开期间，当前选中分组所指向的物理目录会被自动记录为活动目录。在任意系统文件对话框中按下快速跳转快捷键（默认 `Ctrl+G`），即可直接跳转到该目录。

## 2. 工作区（Workspaces）

工作区用于按项目或任务组织一组相关的文件夹来源：

- **工作区列表管理**：左侧列表呈现已创建的工作区，支持**新建工作区**、**复制工作区**与**删除工作区**，可通过拖拽左侧手柄调整其在面板标签栏中的前后排列顺序。
- **工作区属性**：
  - **名称**：标签页显示的文本（留空时将自动使用跟随系统语言的默认名称）。
  - **启用开关**：勾选状态决定是否在面板标签栏中显示。在面板中点击标签上的 **×** 按钮即是将该工作区临时隐藏，可在此处重新勾选恢复。

选中的工作区可通过右侧的两个子标签进行精细化配置：**来源**与**应用**。

## 3. 来源配置（Sources）

每个来源代表工作区内部的一个独立内容分组：

- **添加文件夹**：点击**添加文件夹**按钮选择物理目录。
- **显示模式（Display Mode）**：
  - **最近改动的文件** —— 由内存索引毫秒级直接应答，仅展示近期发生变动的文件（最新排在最前）。
  - **全部内容，最新在前** —— 呈现全部文件，按修改时间降序排列。
  - **全部内容，按名称** —— 适合作为固定文件的快捷工具栏。
- **包含子文件夹**：开启后将递归收录其所有子目录下的文件。
- **接受拖入的文件**：开启后，支持直接从外部将文件、文件夹或浏览器图片拖入该分组，Lertaro 会自动调用 Windows 原生复制接口将文件复制进该目录（具备冲突提示与撤销支持）。
- **文件过滤规则**：可使用通配符或搜索语法中的 `@` 过滤器限制该分组展示的文件类型（例如 `*.mp4;*.mkv`、`*.lnk;:@doc;:@img` 或 `*.lnk;:@doc|img`）。
- **最大条数与时间限制**：可限制最大展示数量（设为 0 表示不限制）及仅展示若干分钟内改动过的文件。
- **明细列表 vs 缩略图平铺**：支持按分组独立选择以列表形式还是缩略图网格平铺展示（平铺时自动等比拉伸并保持画面原始比例）。

## 4. 插件标签（Plugin Tabs）

除自定义工作区外，插件亦可直接向快速面板注册全局动态清单。CoreExtensions 核心插件内置了五个实用标签：

| 插件标签 | 内容说明 |
| :--- | :--- |
| **收藏夹** | 集中展示你的星标收藏项目，网址点击后在浏览器中打开。 |
| **历史记录** | 展示你通过 Lertaro 打开过的最近项目与应用程序。 |
| **Windows 历史记录** | 自动解析 Windows 系统级的“最近使用的文档”并列出真实物理文件。 |
| **上次目录** | 自动追踪并递回你在资源管理器或文件对话框中刚刚离开的目录。 |
| **最近文件** | 由后台内存索引直接汇总呈现所有配置目录下的最新变动文件。 |

可在列表右侧独立控制各插件标签的显示状态以及采用平铺还是列表视图。

## 5. 应用绑定与独立黑名单

- **应用关联（Applications）**：可为工作区指定一个或多个前台进程名（如 `chrome.exe` 或 `devenv.exe`）。当你在该软件上呼出快速面板时，面板将自动直达该关联工作区，免去手动切标签的麻烦。
- **仅快速面板黑名单**：可在此配置不希望被快速面板打扰的进程名单。该名单会**叠加**在全局热键黑名单之上，专用于处理不希望被面板遮挡但无需全局禁用的特殊程序。

## 6. 面板交互指南

- **即时模糊过滤**：面板右上角内置搜索过滤框，支持 fzf 模糊匹配与拼音别名，输入即可即时筛选当前工作区。
- **全键盘流畅导航**：使用上下方向键可无缝跨越不同分组连续滚动；在选中的条目上按下 `Enter` 键即可直接打开。
- **标签快捷切换**：按住 `Ctrl` + `1`–`9` 即可在各个工作区与插件标签间快速跳转。
- **QuickLook 预览与钉住**：选中条目后按 `Alt+P` 可在面板侧边呼出即时预览；按 `Ctrl+T` 可钉住面板使其在失去焦点时不自动消失。
