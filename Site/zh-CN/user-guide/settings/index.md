# 设置项参考

设置窗口可以像普通窗口一样调整大小和最大化：拖动边缘、点击标题栏的最大化按钮，或者双击标题栏。插件页尤其值得这么做——它把插件列表和该插件的配置并排放在一起，宽度是用得上的。

设置窗口标题栏上有一个搜索框。匹配方式是模糊匹配(和主搜索窗口同一套 fzf 模式匹配,支持拼音别名)，不只是简单的子串匹配，覆盖所有分区——包括插件页面下每个插件自己的条目、热键页"插件动作"
标签里的动态内容。每条结果都会显示面包屑(例如"索引 › 网络驱动器"),避免不同标签下同名的设置混淆。选中一条结果(点击，或用上下键高亮后回车)会跳转到对应分区和标签、把具体控件滚动到可见范围，并短暂给它加一个高亮边框闪烁提示。

部分分区(通用、热键、索引、历史记录、快速面板、运行状态)页面顶部还会再分一层子标签。如果标签文字放不下——最常见于英文界面，因为翻译后的文字通常比中文原文长——两端会出现左右箭头按钮，可以滚动看到剩下的标签，而不是被直接裁掉看不到。

设置窗口左侧导航栏共有十个分区:

| 分区 | 内容 |
|---|---|
| [运行状态](./service-status) | 后台服务的安装，以及 App/Hook/Service 日志查看器。 |
| [索引](./index-drives) | 本地驱动器、网络驱动器、WSL 发行版(检测到时才出现)、文件夹索引，以及排除规则。 |
| [通用](./general) | 启动行为、更新、语言、搜索栏布局、预览窗口大小。 |
| [热键](./hotkeys-page) | 全局热键、各插件动作热键、进程黑名单。 |
| [插件](./plugins) | 已安装的插件及各功能组件的启用/禁用开关。 |
| [LocalSend](./localsend) | 局域网跨设备文件、文件夹与纯文本传输设置（协议兼容 LocalSend 官方客户端）。 |
| [收藏夹](./favorites) | 自定义命名的文件夹/文件/网址快捷方式。 |
| [历史记录](./history) | 搜索历史与快速窗口关键字历史。 |
| [快速面板](./quick-panel) | 停靠在前台窗口上的浮动面板:它的工作区、每个工作区的来源、插件提供的标签，以及各工作区归属的应用。 |
| [外观](./appearance) | 主题选择器(每个主题都有预览卡片)，以及"跟随系统浅色/深色"模式。固定在"关于"上方。 |
| [关于](./about) | 版本信息与检查更新。 |

以下每篇文章都会按顺序列出该分区的每一项设置，包括默认值和取值范围。
