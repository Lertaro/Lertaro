# 设置中心参考

Lertaro 提供了极其丰富且细致的个性化配置选项。无论你是想要微调搜索框的像素级尺寸、定制全局热键、调整不同磁盘的索引频率，还是管理第三方插件与工作区，都可以在设置中心中完成。

## 1. 窗口特性与即时交互

- **自适应窗口与全键盘操作**：设置窗口支持自由拖拽边框调整宽高、双击标题栏最大化，并自动记住你调整的尺寸。
- **全局设置模糊搜索**：设置窗口标题栏右上角内置了全局设置搜索框。搜索算法采用与主搜索相同的 fzf 模糊匹配与拼音别名引擎。输入关键词即可跨所有分区（包括插件配置与动态动作）检索选项，回车即可瞬间跳转至目标页面并闪烁高亮该控件。
- **防溢出标签栏导航**：在包含多层子标签页的分区（如通用、热键、索引等）中，当标签文本较长时两端会自动呈现滚动箭头，确保在任何语言环境下标签均能完整查看。

## 2. 设置分区总览

设置窗口左侧导航栏共包含以下十个核心分区：

| 分区模块 | 核心管理内容 |
| :--- | :--- |
| **[运行状态](./service-status)** | 后台 Windows 服务的运行状态、健康度监控，以及 Service / App / Hook 三大进程的实时日志查看器。 |
| **[索引管理](./index-drives)** | 本地磁盘（NTFS / ReFS / FAT32）、网络共享驱动器（SMB / NAS）、WSL 子系统发行版、自定义文件夹及三类排除规则。 |
| **[通用设置](./general)** | 开机自启、硬件加速、IPC 兼容服务、搜索框像素级尺寸布局、主窗口表格列排序与预览窗口参数。 |
| **[热键绑定](./hotkeys-page)** | 全局呼出快捷键、功能热键、插件专属动作快捷键，以及前台进程黑名单与全屏放行规则。 |
| **[插件管理](./plugins)** | 已安装插件列表、各组件独立开关、插件表单配置面板，以及 Flow Launcher 社区插件生态管理。 |
| **[LocalSend 传输](./localsend)** | 兼容 LocalSend 官方客户端的局域网无线传输协议配置（设备名称、端口、PIN 码与自动保存）。 |
| **[收藏夹](./favorites)** | 常用文件夹、文件与网址的星标别名收藏，支持拖拽排序与拼音检索。 |
| **[历史记录](./history)** | 搜索结果命中历史与输入关键词历史的管理、智能召回及清理。 |
| **[快速启动](./quick-launch)** | 管理手动快速启动项目，并选择哪些动态数据源显示在快速搜索窗口的空白状态下。 |
| **[快速面板](./quick-panel)** | 停靠在活动窗口旁的浮动工作区、多来源文件夹聚合、文件拖入接收与插件动态标签页。 |
| **[外观与主题](./appearance)** | 浅色/深色/跟随系统模式切换，以及自带与随包精选主题卡片的实时缩略图预览。 |
| **[关于与更新](./about)** | 各组件版本号、用户与机器数据目录快速直达、数据备份轮转机制与一键静默升级。 |
