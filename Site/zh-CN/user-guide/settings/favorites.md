# 收藏夹

收藏夹用于将你最高频使用的文件夹、文件、脚本或网页 URL 固定下来，赋予专属的自定义名称与最高检索优先级。设置页面路径为**设置 → 收藏夹**。

## 1. 添加收藏项目

在页面上方的添加表单中：

- **显示名称**：自定义名称（可选）。若留空且目标为本地路径，系统会自动使用目标文件或文件夹的文件名作为默认名称。
- **目标路径**：支持输入本地文件/目录的绝对路径，或以 `http://` / `https://` 开头的完整网页网址。
- **浏览选择**：点击**浏览文件夹**或**浏览文件**按钮可直接调用原生文件选择器，免去手动输入路径的繁琐。
- **添加**：填入有效路径后点击**添加**按钮即可将该项存入收藏列表。

## 2. 列表管理与拖拽排序

下方列表集中展示所有已添加的收藏项，支持细致的排序与维护：

- **六点拖拽手柄排序**：每一行左侧均配有六点拖拽手柄，你可以按住手柄直接上下拖动调整条目顺序，亦可点击右侧的**向上移动** / **向下移动**按钮微调。这里的排列顺序直接决定了该收藏项在搜索结果与快速导航菜单中的先后次序。
- **编辑此项**：点击后将该收藏项的数据重新加载至上方表单，修改完成后点击保存即可更新。
- **删除此项**：从收藏夹中安全移除该条目。

## 3. 搜索召回与视觉呈现

- **专属星标徽标（★）**：在快速窗口或主搜索窗口中检索到收藏项时，结果旁会显示醒目的 **★** 星标徽标。
- **自定义别名搜索**：你可以为复杂的路径起一个简短好记的显示名称（例如将 `D:\Workspace\2026\Q1\Financial\Summary.xlsx` 命名为 `财务总表`）。在搜索框中输入 `cwzb` 即可通过拼音别名秒级召回该文件。
- **多端聚合呈现**：所有收藏项会自动同步呈现在[**鼠标快速导航**](../hotkeys#3-快速导航鼠标触发)菜单与[**快速面板**](./quick-panel#4-插件标签plugin-tabs)的“收藏夹”标签中，点击即可秒开。
