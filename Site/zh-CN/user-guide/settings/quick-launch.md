# 快速启动设置

快速启动是快速搜索窗口在搜索框为空时显示的启动面板。它会组合手动管理的项目，以及收藏夹、历史记录等已选中的动态数据源。

## 1. 总开关

- **启用快速启动面板**：启用该面板。只有在快速搜索窗口的搜索框为空，且至少有一个数据源存在可用数据时，面板才会显示。
- 关闭后，面板不会加载任何数据源。
- 面板高度会根据项目数量最多的数据源计算，同时不会超过快速搜索窗口结果区域的最大高度。

## 2. 手动快速启动项目

打开**设置 → 快速启动 → 快速启动**，即可管理自己的项目：

- 可以添加文件、文件夹、网址或 Windows Shell 路径，检查目标时支持展开环境变量。
- 显示名称可以留空，留空时 Lertaro 会根据目标自动生成名称。
- 使用拖拽手柄调整顺序，并使用编辑或删除按钮管理项目。添加项目时也可以使用文件和文件夹浏览按钮。
- 当前不可用的目标会从面板中隐藏，目标恢复可用后会自动重新出现。

## 3. 数据源

打开**设置 → 快速启动 → 数据源**，即可选择动态数据源：

- 数据源来自已安装的快速面板标签页提供程序，因此快速启动可以直接复用收藏夹、历史记录、Windows 历史记录、上次目录、最近文件以及后续插件数据源，不需要维护第二份数据。
- 数据源提供程序存在时默认启用，用户设置中只保存明确关闭的数据源。
- 只有已启用且当前能返回数据的数据源才会创建面板标签页，没有数据的源会隐藏。
- 当所有手动项目和动态数据源都没有数据时，快速启动面板会隐藏。

## 4. 面板交互

- 面板列数会根据搜索栏宽度自适应。
- 只有一个数据源时，底部数据源指示器会隐藏。
- 有多个数据源时，底部会为每个数据源显示一个圆点。选中的圆点为蓝色，未选中的圆点为灰色；鼠标悬停时圆点会展开显示数据源名称。
- 在面板上按住 **Shift** 滚动鼠标滚轮可以循环切换数据源，切换后的数据源会短暂播放同样的展开动画。
- 开始输入搜索内容后，面板会隐藏。
