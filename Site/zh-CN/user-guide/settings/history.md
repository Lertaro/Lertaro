# 历史记录

历史记录页面通过三个相互独立的标签页管理使用频率、输入词条与跨名关联：**搜索记录**、**关键字记录**与**查询关联**。

## 1. 搜索记录（Search History）

搜索记录按路径统计实际打开过的文件、文件夹与应用程序的使用频率和最近时间：

- **同级衰减微调**：高频使用的项目按 90 天半衰期计算有效分，仅在**同一文本匹配等级内**优先排列，绝不会越过完整或更干净的直接名称命中。
- **内嵌窗口智能分区**：在文件选择对话框的内嵌搜索中，当前目录内项目归入“当前文件夹”，其余归入“全局搜索”，同层内直接命中始终排在学习关联之前。
- **失效路径自动过滤**：被移动或删除的路径在检索时自动跳过，保证列表不重复、无死链。
- **管理操作**：支持**启用历史记录**总开关、关键词过滤、**清除少于等于 N 次的记录**、单条删除、**清空全部记录**以及跨窗口实时刷新。

## 2. 关键字记录（Keyword History）

关键字记录记忆实际执行过结果或动作，或用于打开完整窗口的**原始查询字符串**。仅输入关键词后关闭快速搜索窗口不会新增记录：

- **快捷键快速翻阅**：在快速搜索窗口中按 **`Alt+Up`** / **`Alt+Down`** 翻阅最近搜索词，按 **`Ctrl+Delete`** 直接删除当前词条。
- **独立清理维护**：提供独立的启用开关、搜索过滤、按次数阈值清理、单条删除与清空全部功能。

## 3. 查询关联（Query Associations）

查询关联独立存储已确认的 **查询词 → 目标路径** 习惯映射，与路径使用频率完全分离：

- **3 次自然打开门槛**：同一规范化查询词下至少**自然打开 3 次**后，才会在后续输入时补充召回该目标，避免偶尔误点一次就长期污染结果。
- **阻断自强化与尾部补充**：点击由查询关联补充出的条目不会反向自增未确认计数，不召回低优先级缓存路径，且始终排在直接文本命中之后。
- **独立清理**：可随时筛选、单条删除或清空全部查询关联，而不会重置路径使用频率。
