# 通用设置

通用设置涵盖系统的核心运行行为、搜索窗口外观与布局参数、各结果类型的优先级权重以及预览组件的调度顺序。页面顶部共分为六个标签页：**系统**、**快速搜索窗口**、**完整搜索窗口**、**预览窗口**、**快速导航**与**预览与缩略图**。

## 1. 系统（System）

- **开机自动启动 Lertaro**：勾选后在 Windows 用户登录时自动启动 Lertaro。
- **启动时自动检查更新**：勾选后在软件每次启动时自动联网查询最新版本。
- **自动静默更新**：仅在以管理员身份运行且开启“检查更新”时可用。检测到新版本后将在后台静默下载并自动覆盖升级，免去手动操作。
- **启用硬件加速**：默认开启。该项作用于你长时间停留的窗口（设置、完整搜索窗口、预览窗口）；只是呼出又收回的窗口（快速搜索、内嵌卡片、通知）一律使用软件渲染，这是它们能带着已绘制好的画面出现、而不先闪出一个空框的原因。若遇到笔记本独立显卡（如 NVIDIA Advanced Optimus）因 Lertaro 驻留而无法自动休眠切换核显的问题，可关闭该项让所有窗口都改用软件渲染。修改后需重启 Lertaro 生效。
- **隐藏托盘图标**：勾选后隐藏 Windows 任务栏右下角的系统托盘图标。快速搜索窗口内的 Logo 图标依然能呼出完整的系统托盘菜单，不会丢失任何入口。
- **启用 Everything 兼容服务 (IPC)**：默认关闭。开启后，Lertaro 会在后台模拟标准 Everything Win32 IPC 协议接口，让 Directory Opus、Total Commander 等第三方软件无需额外安装运行 Everything 即可直接调用 Lertaro 的内存索引。
- **启用模糊匹配**：默认开启。开启时支持跳跃字符模糊匹配；关闭后要求普通查询词必须为连续子串（详见[**搜索语法**](../search-syntax)）。即时生效无需重启。
- **关闭窗口后保留搜索框内容**：默认关闭。开启后，无论是隐藏快速窗口，还是在完整搜索窗口中按 `Escape`，都不再清空搜索框；完整搜索窗口里的 `Escape` 第一次按下就会直接关闭窗口，不需要多按一次。窗口下次被唤起时携带的搜索内容会**整段选中**，因此第一个按键会替换它而不是续写。该效果仅在本次运行期间有效，内容绝不会写入磁盘。
- **在内嵌搜索中显示当前打开的文件夹**：内嵌窗口停靠在文件对话框时，在搜索内容为空的状态下显示该对话框当前打开的文件夹，默认开启。
- **内嵌窗口宽度 (%)**：文本框，取值 `20`–`100`，默认 `60`。内嵌窗口以它所停靠的那个窗口宽度的这个百分比取宽；默认值 `60` 表示没有选择：保存 60 时配置里不留数字，未曾调整过的卡片改取该窗口宽度的 40% 与屏幕宽度的 1/5 中的较大者。实际宽度还会按屏幕自动收放，不少于该窗口宽度的 20% 与屏幕宽度的 1/6 中的较大者，不超过该窗口本身与屏幕宽度的 90% 中的较小者。全屏时若觉得卡片挡住了太多视线，可以把它调小。
- **内嵌窗口显示条数（普通窗口）**：文本框，取值 `4`–`10`，默认 `10`。内嵌窗口停靠在普通窗口上时显示的结果条数。分区标题不计入，它们在你设定的条数之外另占自己的行。`Ctrl+1`–`Ctrl+9` 选中第 1–9 条结果，`Ctrl+0` 选中第 10 条，所以上限是 10。屏幕高度不够时只显示放得下的行数，其余滚动查看。
- **内嵌窗口显示条数（文件对话框）**：同样取值 `4`–`10`，默认 `4`。这是停靠在文件对话框（打开/保存/浏览）时的条数；对话框里大多是别的程序的控件，所以这张卡片默认更矮。标题、快捷键和屏幕限制都与上面一致。
- **查询标记总前导字符**：单字符文本框（默认为 `:`）。用于设置搜索框尾部后缀切分标记（如 `:.pdf`、`:@doc`、`:[S]`）的总引导符。
- **日志等级**：下拉选择“错误 / 警告 / 信息 (默认) / 调试”，控制系统各进程日志输出的详细程度。
- **界面语言**：下拉选择 Lertaro 的全局显示语言。

## 2. 快速搜索窗口（Quick Search Window）

本标签页用于精细化配置快速居中浮窗的几何尺寸与结果排序：

### 搜索栏布局

- **搜索栏宽度 (像素)**：取值范围 `300–1200px`，默认 `570px`。
- **搜索栏高度 (像素)**：取值范围 `45–120px`，默认 `60px`。该数值会按比例同步驱动结果列表的图标大小、行高与字体字号，确保视觉协调。
- **搜索框内显示时钟**：开启后，在搜索框为空时将提示文字替换为当前实时日期、星期与时间。输入文字后时钟自动隐藏。
- **再次按下快捷键时打开完整窗口**：开启后，在快速窗口已显示状态下再次按下全局呼出快捷键，将携带当前输入内容直接切换至完整主搜索窗口。
- **锁定位置**：开启后禁止鼠标拖拽移动快速窗口，防止误触改变位置。
- **自动将剪贴板文本填入快速搜索框**：默认关闭。快速窗口在没有预填内容时，如果剪贴板中有新的非空文本，就将其用作搜索内容。手动粘贴和其他窗口不受影响。
- **重置布局设置**：一键将快速窗口尺寸与布局恢复为系统初始默认值。

### 结果类型优先级与触发符

- **优先级排序列表**：支持拖拽左侧手柄或上下移动各结果类型（应用程序、系统设置、文件、插件扩展项等），决定**相关性相近的干净直接命中之间**的排列先后，不会越过明显更强的完整命中。
- **专属单字符触发符**：可为特定结果类型配置专属单字符前缀（如将文件过滤器设为 `;`）。在搜索框开头输入该字符即可直接过滤出该类型的专属结果。
- **排序详情导出**：在快速窗口中右键任意结果，选择**导出本页排序详情**，会为当前显示页写出一个明文 `.txt`。后台不记录任何排序日志；开关“允许导出本页排序详情”默认开启。

## 3. 完整搜索窗口（Full Search Window）

用于配置大尺寸主搜索窗口（`Ctrl+F`）的默认行为与表格视图：

- **窗口宽度 / 高度 (像素)**：宽度范围 `640–2000px`（默认 `854px`），高度范围 `400–1400px`（默认 `480px`）。
- **仅允许一个完整搜索窗口**：开启后，再次打开完整窗口将直接激活已有实例，避免重复创建多开。
- **再次按下快捷键时关闭完整窗口**：默认关闭，此时在完整窗口已获得焦点的情况下再次按下全局呼出快捷键，会携带当前输入内容切回快速搜索窗口，并在两个窗口之间反复切换，直到按 `Esc` 退出。开启后，再次按下快捷键将直接关闭完整窗口。无论开关如何设置，完整窗口可见但未获得焦点时按下快捷键都只会将其拉回前台。
- **重置搜索窗口设置**：一键恢复主窗口默认宽高设置。
- **结果表格列顺序**：拖拽自定义表格视图中各列（名称、路径、修改时间等）的先后排列顺序。
- **侧边栏筛选顺序**：拖拽调整主窗口左侧分类筛选栏的展示顺序；筛选栏会实时动态呈现当前关键词在各分类下的匹配条目数量。
- **动作菜单分组顺序**：拖拽调整上下文动作菜单（`Ctrl+O`）中各功能分组的显示先后。

## 4. 预览窗口（Preview Window）

- **预览窗口宽度 / 高度 (像素)**：宽度范围 `250–900px`，高度范围 `250–1200px`。
- **重置预览窗口设置**：将 QuickLook 预览浮窗的尺寸重置为标准默认比例。系统会自动计算避免预览窗口超出当前显示器的工作可视区域。

## 5. 快速导航（Quick Navigation）

- **提供者顺序**：通过上下箭头或拖拽手柄，调整快速导航菜单根层级各个提供者分组的排列顺序。每行对应一个快速导航提供器，例如级联文件夹浏览器、系统命令执行器，以及各文件管理器插件贡献的书签分组。

## 6. 预览与缩略图（Previews & Thumbnails）

- **文件预览提供者顺序**：调整多个预览插件（如内置富文本/媒体解码器与第三方 QuickLook 桥接）的调用优先级。
- **缩略图提供者顺序**：调整结果列表中文件图标与缩略图提取组件的调用优先级。
