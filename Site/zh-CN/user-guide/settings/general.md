# 通用设置

通用设置涵盖系统的核心运行行为、搜索窗口外观与布局参数、各结果类型的优先级权重以及预览组件的调度顺序。页面顶部共分为六个标签页：**系统**、**快速搜索窗口**、**完整搜索窗口**、**预览窗口**、**快速导航**与**预览与缩略图**。

## 1. 系统（System）

- **开机自动启动 Lertaro**：勾选后在 Windows 用户登录时自动启动 Lertaro。
- **启动时自动检查更新**：勾选后在软件每次启动时自动联网查询最新版本。
- **自动静默更新**：仅在开启“检查更新”时可用。检测到新版本后将在后台静默下载并自动无缝覆盖升级，免去手动操作。
- **启用硬件加速**：默认开启。若遇到笔记本独立显卡（如 NVIDIA Advanced Optimus）因 Lertaro 驻留而无法自动休眠切换核显的问题，可关闭该项改用软件渲染。修改后需重启 Lertaro 生效。
- **隐藏托盘图标**：勾选后隐藏 Windows 任务栏右下角的系统托盘图标。快速搜索窗口内的 Logo 图标依然能呼出完整的系统托盘菜单，不会丢失任何入口。
- **启用 Everything 兼容服务 (IPC)**：默认关闭。开启后，Lertaro 会在后台模拟标准 Everything Win32 IPC 协议接口，让 Directory Opus、Total Commander 等第三方软件无需额外安装运行 Everything 即可直接调用 Lertaro 的极速内存索引。
- **启用模糊匹配**：默认开启。开启时支持跳跃字符模糊匹配；关闭后要求普通查询词必须为连续子串（详见[**搜索语法**](../search-syntax)）。即时生效无需重启。
- **查询标记总前导字符**：单字符文本框（默认为 `:`）。用于设置搜索框尾部后缀切分标记（如 `:.pdf`、`:@doc`、`:[S]`）的总引导符。
- **日志等级**：下拉选择“错误 / 警告 / 信息 (默认) / 调试”，控制系统各进程日志输出的详细程度。
- **界面语言**：下拉选择 Lertaro 的全局显示语言。

## 2. 快速搜索窗口（Quick Search Window）

本标签页用于精细化配置快速居中浮窗的几何尺寸与结果排序：

### 搜索栏布局

- **搜索栏宽度 (像素)**：取值范围 `300–1200px`，默认 `570px`。
- **搜索栏高度 (像素)**：取值范围 `45–120px`，默认 `60px`。该数值会按比例同步驱动结果列表的图标大小、行高与字体字号，确保视觉协调。
- **搜索框内显示时钟**：开启后，在搜索框为空时将提示文字替换为当前实时日期、星期与时间。输入文字后时钟自动隐藏。
- **再次按下快捷键时打开完整窗口**：开启后，在快速窗口已显示状态下再次按下全局呼出热键，将携带当前输入内容直接切换至完整主搜索窗口。
- **锁定位置**：开启后禁止鼠标拖拽移动快速窗口，防止误触改变位置。
- **重置布局设置**：一键将快速窗口尺寸与布局恢复为系统初始默认值。

### 结果类型优先级与触发符

- **优先级排序列表**：支持拖拽左侧手柄或上下移动各结果类型（应用程序、系统设置、文件、插件扩展项等）。排在前面的类型在综合搜索结果中享有更高的排列权重。
- **专属单字符触发符**：可为特定结果类型配置专属单字符前缀（如将文件过滤器设为 `;`）。在搜索框开头输入该字符即可直接过滤出该类型的专属结果。

## 3. 完整搜索窗口（Full Search Window）

用于配置大尺寸主搜索窗口（`Ctrl+F`）的默认行为与表格视图：

- **窗口宽度 / 高度 (像素)**：宽度范围 `640–2000px`（默认 `854px`），高度范围 `400–1400px`（默认 `480px`）。
- **仅允许一个完整搜索窗口**：开启后，再次打开完整窗口将直接激活已有实例，避免重复创建多开。
- **重置搜索窗口设置**：一键恢复主窗口默认宽高设置。
- **结果表格列顺序**：拖拽自定义表格视图中各列（名称、路径、修改时间等）的先后排列顺序。
- **侧边栏筛选顺序**：拖拽调整主窗口左侧分类筛选栏的展示顺序；筛选栏会实时动态呈现当前关键词在各分类下的匹配条目数量。
- **动作菜单分组顺序**：拖拽调整上下文动作菜单（`Ctrl+O`）中各功能分组的显示先后。

## 4. 预览窗口（Preview Window）

- **预览窗口宽度 / 高度 (像素)**：宽度范围 `250–900px`，高度范围 `250–1200px`。
- **重置预览窗口设置**：将 QuickLook 预览浮窗的尺寸重置为标准默认比例。系统会自动计算避免预览窗口超出当前显示器的工作可视区域。

## 5. 快速导航（Quick Navigation）

- **提供者顺序**：通过上下箭头或拖拽手柄，调整鼠标快速导航级联菜单根层级各个数据源提供者（收藏夹、历史记录、已打开文件夹、第三方管理器书签等）的分组排列顺序。

## 6. 预览与缩略图（Previews & Thumbnails）

- **文件预览提供者顺序**：调整多个预览插件（如内置富文本/媒体解码器与第三方 QuickLook 桥接）的调用优先级。
- **缩略图提供者顺序**：调整结果列表中文件图标与缩略图提取组件的调用优先级。
