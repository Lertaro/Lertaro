# 快捷键设置

快捷键设置页面集中管理 Lertaro 的所有全局唤起按键、应用内导航快捷键、插件动作快捷方式以及前台进程过滤规则。页面顶部包含三个标签页：**全局**、**插件动作**与**进程黑名单**。

## 1. 全局（Global）

### 全局快捷键分组

- **显示/隐藏快速搜索**：专属按键录制框。支持录制为**单键双击模式**（默认双击 `Ctrl`，亦可设为双击 `Alt` 或 `Shift`），或录制为**常规组合键**（如 `Alt+Space` 等）。
- **默认打开完整面板**：复选框（默认关闭）。开启后，全局唤起快捷键会改为打开完整窗口，而不是快速窗口。首次唤起时只将窗口置于前台并聚焦一次；窗口已显示但未激活时再次按下会重新激活，窗口已经激活时再次按下则默认切回快速窗口，开启“再次按下快捷键时关闭完整窗口”后则直接关闭。窗口不会自动保持置顶。
- **全屏应用聚焦时仍然响应**：复选框（默认关闭）。开启后，即使前台有独占全屏程序（如全屏游戏或视频），Lertaro 依然会响应快捷键呼出搜索框；保持关闭则自动放行按键不抢占焦点。
- **快速跳转（Quick Jump）**：默认 `Ctrl+G`。在各类文件对话框中按下即可直接跳转到最近在文件管理器中浏览过的目录。
- **快速导航菜单**：默认不分配快捷键。可为它分配一个可选的全局快捷键来打开级联式菜单。在桌面或普通应用中呼出时使用桌面上下文；在文件资源管理器和原生文件对话框中呼出时使用当前窗口上下文。即使普通前台保护会抑制全局快捷键，文件管理器和文件对话框仍会放行。

### 功能按键分组

页面提供了一系列独立的按键录制控件，支持任意单键或组合键录制：

- **选中下一项 / 上一项**：默认 `Ctrl+N` / `Ctrl+P`（与方向键 `↓` / `↑` 等效）。
- **跳转结果修饰键**：默认 `Ctrl`，配合数字键 `1`–`9` 即可在快速窗口中直达前 9 项结果。
- **打开动作菜单**：默认 `Ctrl+O`（与方向键 `→` 等效）。两者都作用于快速窗口以及文件对话框之外的内嵌卡片；完整窗口改用鼠标右键或 `Apps` 键打开同一个菜单。
- **从选中项补全搜索词**：默认 `Ctrl+Tab`。
- **QuickLook 即时预览**：默认 `Alt+P`。
- **上/下一条关键字历史**：默认 `Alt+Up` / `Alt+Down`。
- **删除当前关键字历史**：默认 `Ctrl+Delete`。
- **打开完整搜索主窗口**：默认 `Ctrl+F`。
- **打开发送窗口（LocalSend）**：默认 `Ctrl+S`。
- **保持窗口不消失（钉住）**：默认 `Ctrl+T`。
- **呼出/关闭快速面板**：默认 `Ctrl+F2`。

### 快速导航鼠标触发分组

- **在空白处双击左键**：复选框（**默认关闭**）。在桌面或文件资源管理器空白处双击弹出快速导航菜单。
- **在空白处点击中键**：复选框（默认开启）。在桌面、文件资源管理器或文件选择对话框中点击鼠标中键弹出快速导航菜单。

双击这种形式只有桌面和文件资源管理器支持；第三方文件管理器只认鼠标中键。指针位于 Lertaro 自己的卡片之上时，这两种触发都会被跳过；而即便黑名单或全屏状态本会屏蔽全局触发，文件管理器和文件对话框上的这两种触发依然保持有效。

### 录制快捷键

每一次按键都会进入录制框，而不是背后的那个应用，因此录制框本身就构成了一套手势：

- **`Escape`**：取消录制并清空该值。没有“放弃并还原”这一说，按下的瞬间框子就空了。
- **`✕`** 清空录制框；**`↺`** 还原本行的出厂默认值。两者同一时刻只显示其中一个：已设置组合键时显示清除，清空之后显示还原。
- **单独的修饰键**（`Ctrl`、`Alt`、`Shift`）只在那些单按即有意义的行上才被接受，即唤起快捷键（由此变为双击模式）与跳转修饰键。在普通的组合键行上，按下并松开一个孤立修饰键会**清空**该行，而不是存下一个永远无法触发的值。
- **Windows 已占用的组合键**（`Win+E`、`Win+D` 等）会被拒绝：取值被强制置空，因此录制框直接变空白。
- **不做冲突检测。** 两行绑定同一个组合键也不会有任何提示；只有收藏项的快捷键会报告重复或被系统拒绝的组合，而且是在你应用之后才报告。

### 收藏项专属快捷键

每一个收藏项（[**设置 → 收藏夹**](./favorites)）都可以带上自己的一份**操作系统级全局**快捷键，即使 Lertaro 没有打开任何窗口它同样生效，并能把前台文件管理器直接跳到该文件夹。与上面的录制行不同，它必须搭配修饰键、拒绝孤立修饰键，也不能使用 `F12`。

## 2. 插件动作（Plugin Actions）

各插件注册的专属动作快捷键（例如内置的文件操作：复制路径 `Ctrl+Shift+C`、复制名称 `Shift+C`、剪切 `Ctrl+X`、复制 `Ctrl+C`、粘贴 `Ctrl+V`、删除 `Delete`、彻底删除 `Shift+Delete` 等）均汇集于此。

- **分组查看**：按注册动作的来源插件清晰分组。
- **独立重录**：每个动作均配有专属的按键录制框，点击即可按下新按键进行覆盖绑定。

## 3. 进程黑名单（Process Blacklist）

用于配置特定前台应用程序的静默放行机制。当黑名单中的程序处于系统前台聚焦状态时，Lertaro 会完全放行所有全局快捷键与鼠标触发手势，绝不进行拦截。

- **不区分大小写**：添加 `game.exe` 或 `game` 均可生效。
- **单条添加**：在单条输入框中输入进程名，点击**添加进程**按钮。
- **批量管理**：支持点击**生成文本**将当前黑名单导出为多行文本，或在多行文本框中直接粘贴编辑后点击**应用到列表**进行一键批量导入。
- **文件对话框安全豁免**：即使某个程序处于黑名单中，当它弹出系统文件选择对话框时，Lertaro 的内嵌搜索与鼠标快速导航依然会被安全放行，确保文件选取效率不受影响。
