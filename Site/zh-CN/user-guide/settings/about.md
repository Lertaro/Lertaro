# 关于

显示 App、Core、Service、CLI 四个组件的版本号(颜色会反映服务当前是否健康)、Lertaro 的简短说明，以及项目主页和在线使用手册的链接。

## 数据目录

紧接着下方还有两个链接，用来打开 Lertaro 读写自身配置的文件夹——链接文字本身就是实际路径，点击时如果文件夹还不存在会先创建出来:

- **用户数据目录** —— 存放 `user-settings.json` 的每用户目录。每次保存设置时，都会先把当前文件轮转备份为 `user-settings.json.bak.1`(旧的备份依次往后顺延，最多保留到 `.bak.5`)，再写入新文件，所以一次误改或者保存过程中崩溃，总能找到一份最近的备份恢复。搜索历史、证书和用户专属缓存也保存在这里。
- **机器数据目录** —— 后台服务使用的机器级目录(`machine-settings.json`、本地磁盘索引缓存，以及服务端日志)。

安装版使用 `%LocalAppData%\Lertaro` 和 `%ProgramData%\Lertaro`。便携版在程序旁使用 `Data\Users\<SID hash>` 和 `Data\Machine`;如果便携版的 `Data` 目录尚未创建，为了兼容会复用已有的安装版数据。目录优先级请参阅[便携版数据](../getting-started#便携版数据)。

## 检查更新

- **检查更新** 按钮 —— 查询是否有新版本;按钮文字本身会反映进度("正在检查更新..."，之后显示
  "已是最新版本"或找到的新版本号)。
- 如果非管理员账户无法停止后台服务来原地安装更新，会显示一条警告横幅，并引导你前往手动下载页面。
- 一旦发现新版本:
  - **静默自动更新** —— 后台下载安装，显示进度条，完成后自动重启 Lertaro。
  - **前往下载页面** —— 在浏览器中打开 GitHub release 页面，手动安装。

这个页面和[通用 → 系统](./general#系统)里的**启动时自动检查更新** / **自动静默更新**两个复选框是配套的——那两项控制是否在启动时自动执行这次检查;这个页面则是让你随时手动触发一次。
