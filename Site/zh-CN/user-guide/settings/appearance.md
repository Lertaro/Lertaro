# 外观与主题

Lertaro 提供了高颜值的现代化界面设计体系，支持精细化的主题模式切换与丰富的配色方案。外观设置页面位于设置中心左侧侧边栏底部（“关于”上方）。

## 1. 主题模式（Theme Modes）

页面顶部提供三种主题模式切换卡片，点击即可瞬间切换生效：

- **浅色模式（Light）**：固定使用浅色调界面风格，下方的主题选择网格将仅展示浅色风格的主题卡片。
- **深色模式（Dark）**：固定使用深色调界面风格，下方网格将仅展示深色风格的主题卡片。
- **跟随系统（Follow System）**：界面将根据 Windows 系统的深浅色设置自动实时切换。在此模式下，下方网格会分别呈现**浅色主题**与**深色主题**两个选择区，你可以为白天和黑夜分别指定心仪的配色方案，系统切换时无需重启 Lertaro 即可平滑过渡。

> [!NOTE]
> Lertaro 会独立记忆你在浅色与深色模式下分别选中的主题。当你在不同模式之间切换时，已选定的配色方案绝不会丢失。

## 2. 界面主题选择卡片

主题选择区采用可视化的缩略图卡片网格呈现，每张卡片都真实反映了搜索框、边框阴影、文字层级与选中高亮行的实际配色效果，当前生效的主题右上角带有清晰的勾选徽标。

### 内置与随包主题介绍

- **核心内置主题（CoreExtensions）**：
  - **浅色（Light）** / **深色（Dark）**：经典简约的黑白基底设计，完美融入 Windows 原生系统风格。
  - **北欧蓝（Nordic Blue）**：冷色调极简极客风，低饱和度的冰蓝与深海背景。
  - **樱花粉（Sakura Pink）**：柔和清新的粉白配色，细腻优雅。
  - **赛博朋克（Cyberpunk）**：高对比度的霓虹黄与深紫夜色，充满未来科技感。
- **动漫主题包（AnimeThemes，随包提供）**：
  - **新世纪（Evangelion）**、**樱花盛开（Sakura Blossom）**、**天气之子（Weathering with You）**。
- **臻选成对主题（Curated Themes，随包提供）**：
  - 精心调配的 10 组浅色 / 深色成对主题：**冰川蓝（Glacier Blue）**、**陶土棕（Terracotta）**、**森林绿（Forest Green）**、**紫水晶（Amethyst）**、**绯红（Crimson）**、**石墨灰（Graphite）**、**靛蓝夜（Indigo Night）**、**薄荷青（Mint Cyan）**、**香槟金（Champagne Gold）**、**琥珀金（Amber Gold）**。

### 插件主题扩展能力

所有主题均基于 `Lertaro.PluginSdk` 的 UI 主题标准规范开发。第三方开发者可以通过编写主题插件向此网格动态注册全新的个性化配色方案。
