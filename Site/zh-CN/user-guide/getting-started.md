# 快速上手

欢迎使用 Lertaro！Lertaro 是一款为 Windows 深度定制的极速文件检索与生产力启动器。本章将带你了解安装方式、核心架构、三种窗口形态以及基本的日常搜索操作。

## 1. 下载与安装

你可以在官网首页获取最新版本。每个正式发布版本均提供两种运行形式，并分别编译了 **x64** 与 **ARM64** 原生版本：

### 安装包（`Lertaro-Setup.exe`，推荐）

- **自动化配置**：安装向导会自动注册后台索引服务（`Lertaro.Service`），配置开机自启动项，并自动检测与安装所需的 .NET 桌面运行时。
- **平滑升级**：支持静默自动检查更新与一键覆盖升级。

### 便携版（`Lertaro-Portable.zip`）

- **解压即用**：解压至任意目录即可直接运行主程序，不强制要求安装。
- **环境补齐**：若系统尚未安装对应的 .NET 桌面运行时，可直接运行解压目录自带的 `install-dotnet-runtime.bat` 脚本一键安装。
- **数据独立与隔离**：便携版默认将机器全局数据保存在程序同级目录的 `Data\Machine`，并将各用户的私有设置保存在 `Data\Users\<SID hash>`。若该 `Data` 目录尚未创建，会自动兼容读取系统的 `%ProgramData%\Lertaro` 和 `%LocalAppData%\Lertaro`；一旦目录生成，便携版将优先读取本地独立数据，实现完全自包含。
- **干净卸载与清理**：当不再需要使用便携版时，在删除文件夹前请先执行自带的 `portable-cleanup.bat` 脚本。该脚本会自动停止并卸载后台服务，并清理当前用户的 `lertaro://` URI 协议及自启注册表项。

> [!TIP]
> 如果你在 Windows on ARM 设备（如 Surface Pro X、高通骁龙笔记本）上运行，请优先下载 `Lertaro-Setup-arm64.exe` 或 `Lertaro-Portable-arm64.zip` 原生版本，以获得最佳性能与更低的功耗。

## 2. 核心架构认知

首次运行 Lertaro 时，系统会安装并启动一个独立的 Windows 后台服务（`Lertaro.Service`）。理解该设计有助于你更好地掌握其工作原理：

- **前台 App（UI 与交互层）**：负责渲染搜索窗口、悬浮面板、动作菜单、快捷键拦截与即时预览。前台进程始终保持极低内存占用与即时响应。
- **后台 Service（索引与数据层）**：以系统服务权限在后台运行，专门负责读取 NTFS / ReFS 的 USN 日志、监听其他文件系统的实时变动、维护网络共享索引，并建立极速内存索引树。
- **架构优势**：前台界面的重启、崩溃或更新绝不会导致后台索引丢失或重新全盘扫描；而后台的实时索引同步也绝不会阻塞前台 UI 的流畅打字体验。你可以在[**设置 → 运行状态**](./settings/service-status)中随时查看服务运行状态与索引健康度。

## 3. 三种窗口形态

Lertaro 并非只有一个固定的搜索窗口，而是针对不同工作流设计了三种各具特色的窗口形态：

| 窗口形态 | 默认唤起方式 | 核心特点与设计定位 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **快速窗口（Quick Window）** | 双击 `Ctrl`（可自定义） | 紧凑型屏幕居中浮窗，即输即搜，肌肉记忆友好，支持数字键快速跳转与全键盘流操作 | 日常高频启动应用、查找特定文件、快速计算或翻译 |
| **主窗口（Full Window）** | 任务栏/开始菜单，或快捷键 `Ctrl+F` | 完整的大尺寸窗口，支持海量结果表格视图、侧边栏高级筛选、列排序与内置空间分析器 | 深度文件浏览、大范围检索、磁盘空间清理与高级筛选 |
| **内嵌窗口（Inline Window）** | 打开文件对话框或资源管理器时自动嵌入 | 无缝内嵌到系统文件对话框或第三方管理器中，无需离开当前工作上下文 | 在 Office/浏览器等软件中“打开”或“另存为”文件时快速定位目标 |

三种窗口形态底层共享完全相同的搜索引擎、快捷键体系、过滤规则与动作菜单。

## 4. 首次搜索与基本交互

### 即输即搜

打开搜索窗口后直接输入关键词即可，结果将随输入实时呈现（毫秒级响应）。搜索算法默认采用智能模糊匹配，字符无需连续输入即可跳跃命中。详细匹配规则与修饰符请参阅[**搜索语法**](./search-syntax)。

### 结果导航与打开

- **移动光标**：使用方向键 `↑` / `↓`（或配置的导航快捷键 `Ctrl+P` / `Ctrl+N`）在结果列表中上下移动选中项。
- **直接打开**：按下 `Enter` 立即使用默认程序打开选中的文件或启动应用程序。
- **定位目录**：按下 `Ctrl+Enter` 可在文件资源管理器中直接定位并选中该文件。
- **管理员身份运行**：按下 `Ctrl+Shift+Enter` 以管理员权限运行程序。
- **数字直达**：在快速窗口中，可直接按下 `Ctrl` + `1`–`9` 直接打开前 9 项结果。

### 动作菜单与扩展操作

按下 `Ctrl+O` 或在选中项上按方向键 `→`，即可展开功能强大的**动作菜单**，执行复制路径、属性查看、文件增删剪贴或调用插件扩展动作。更多操作技巧请阅读[**动作菜单与预览**](./actions-and-preview)与[**热键**](./hotkeys)。
