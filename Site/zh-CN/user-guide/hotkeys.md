# 热键

下面所有全局与应用内热键都可以在**设置 → 热键**里重新绑定；这里列出的是默认值。设置界面本身见[设置 → 热键页面](./settings/hotkeys-page)。

## 全局热键

| 动作 | 默认 | 说明 |
|---|---|---|
| 呼出/隐藏快速窗口 | 双击 `Ctrl` | 也可以设置成完整组合键(例如 `Alt+Space`)而不是双击模式。 |
| 快速切换 | `Ctrl+G` | 在支持的文件对话框中，跳转到最近一次从受支持文件管理器或快速面板采集的文件夹；内嵌搜索框为空时也会将该目标显示为一条结果。 |
| 选中下一项 | `Ctrl+N` | 与方向键的下键效果相同。在[快速面板](./settings/quick-panel)里，它走的是整个标签而不是单个分组：到了一个分组的末尾会继续进入下一个分组。 |
| 选中上一项 | `Ctrl+P` | 与方向键的上键效果相同。在快速面板里同样是跨分组走完整个标签。 |
| 跳转到结果 1–9 | `Ctrl` + 数字 | 修饰键可自定义;数字固定为 1–9。快速窗口里每个可见结果旁边都会显示对应快捷键的小徽章，不用自己数行数。 |
| 打开动作菜单 | `Ctrl+O` | 与在选中结果上按方向键右键效果相同。 |
| 从选中项补全 | `Ctrl+Tab` | 在快速窗口里，用选中结果的名称/路径填充搜索框。 |
| QuickLook 预览 | `Alt+P` | 切换选中结果的预览面板。[快速面板](./settings/quick-panel)用的是同一个键，并且会把预览窗口停靠到自己放得下的那一侧。 |
| 上一条关键字历史 | `Alt+Up` | 向前翻阅最近输入过的搜索词。 |
| 下一条关键字历史 | `Alt+Down` | 向后翻阅最近输入过的搜索词。 |
| 删除当前关键字历史 | `Ctrl+Delete` | |
| 打开完整窗口 | `Ctrl+F` | 直接打开完整窗口并带上当前搜索内容——效果和左键点击[快速窗口自带的图标](#搜索框图标)、在弹出菜单里选"显示主窗口"一样,只是省了点菜单这一步。可在**设置 → 热键**里自行设置。 |
| 打开发送窗口 | `Ctrl+S` | 打开发送文件或文本至 LocalSend 设备的窗口。可以在**设置 → 热键**里自行设置。 |
| 保持窗口不消失 | `Ctrl+T` | 焦点移到别处时不再自动隐藏，便于把别的窗口里复制来的文本拼成一条查询——否则每次隐藏都会清空搜索框。只在本次召唤期间有效，下次隐藏时解除。在快速窗口里，鼠标中键点击 logo 效果相同，开启期间 logo 会变亮；窗口还在但没有焦点时按呼出热键，会让它重新获得焦点而不是隐藏。[快速面板](./settings/quick-panel)复用同一个键，用它自己的「钉住」按钮作为标识。 |
| 呼出/关闭快速面板 | `Ctrl+F2` | 把[快速面板](./settings/quick-panel)停靠到当前前台窗口的右下角；已经打开时则关闭它。打开之后，按住「跳转到第 1–9 条结果」的修饰键再按 1–9 可以切换工作区。 |

## 搜索框图标

搜索框里那个小图标(具体在左侧还是右侧,取决于窗口)在[三种窗口](./getting-started#三种窗口)里各自有不同的作用：

- **快速窗口** —— 左键点击(不移动)会弹出和托盘图标右键一样的菜单(显示主窗口、切换热键、设置、关于、干净退出、退出)，菜单出现在光标位置；菜单里的"显示主窗口"还会带上你当前输入框里的搜索内容。按住左键拖动会移动窗口，和拖动搜索栏其它部分一样——拖动时(不管是拖搜索栏还是拖图标)按住 **Ctrl** 可以把移动方向限制成只能纵向，拖到一半按下/松开 Ctrl 也能实时生效，适合只想上下调整位置而不想带偏横向位置的时候用。右键点击会把窗口重置回默认屏幕位置(不影响大小)——和首次启动时的居中位置相同。鼠标悬停时的提示会把这三种手势都列出来。

  记住的位置是相对于上次所在显示器的相对位置，不是绝对屏幕坐标——换到另一台显示器(或者分辨率、
  DPI 缩放不同的显示器)上唤出时，会在那块屏幕上按比例换算到对应位置，而不会跑出屏幕外或落到错误的显示器上。
- **内嵌窗口** —— 只有当窗口停靠在原生的打开/保存/浏览文件夹对话框上时才可点击：左键点击会触发[快速导航](#快速导航鼠标)，效果和下面专门的触发方式一样。当停靠在普通资源管理器窗口或桌面上时不可点击，因为那种情况下没有什么可供跳转的目标——这时既不会有悬停高亮，也不会有提示。
- **主窗口** —— 这个图标在主窗口里纯粹是装饰性的，点击没有任何效果。

## 快速导航(鼠标)

中键点击默认启用，双击左键默认关闭；每种触发方式都可单独在设置里开关：

- 开启该触发方式后，在桌面或资源管理器窗口的空白处**双击左键**触发快速导航。
- 在桌面或资源管理器窗口的空白处、受支持的第三方文件管理器(Directory Opus、Total Commander、
  XYplorer、Files 等)的文件列表区域、或原生的打开/保存/浏览文件夹对话框里**点击中键**触发快速导航。这些其它窗口只响应中键——双击在那里已经是"打开这一项"的意思，所以没有把双击挪作他用。参见[支持的文件管理器](./file-manager-support)了解每种集成具体覆盖哪些能力。
- 当内嵌搜索窗口停靠在原生的打开/保存/浏览文件夹对话框上时，它自己的图标同样可以触发快速导航
  ——见上面的[搜索框图标](#搜索框图标)。

无论哪种方式触发，都会弹出一个级联菜单，内容是你的收藏夹、历史记录和配置好的快捷文件夹(见[设置 → 收藏夹](./settings/favorites)和[设置 → 历史记录](./settings/history))——插件也可以往里加自己的条目，比如你在 `wincmd.ini` 里配置过 Total Commander 的 Directory Hotlist 的话，它也会出现在这里，Directory Opus 自己的收藏夹菜单同样如此，或者是某条勾选了"在快速导航中显示"的[自定义命令](./instant-answers#自定义命令)(可以通过
`/` 分隔的路径把它归到某个子菜单下)。每个贡献条目的插件在菜单根层级都有自己独立的标题分组，这些分组的先后顺序可以自己调整——见[设置 → 通用 → 快速导航](./settings/general#快速导航)。点击文件夹会让目标窗口跳转过去；点击文件也会跳转过去，并在其所在文件夹中选中该文件，而不是打开它——唯一的例外是桌面，那里没有可供跳转的现有窗口面板，所以在桌面上点击文件夹或文件会直接打开它，效果和双击一样。如果是在文件选择器里，点击文件则是让对话框跳转到该文件所在的文件夹——绝不会替你自动确认"打开"/"保存"。

这个菜单实际上是由**级联文件夹浏览器**插件构建的。除了可以各自独立开关的收藏夹和历史记录，它还有自己的一份可配置快捷文件夹列表——在**设置 → 插件 → 级联文件夹浏览器 → 配置**里添加路径和可选的显示名称，再给它填一个 Submenu 值(比如 `工具/网络`，用 `/` 分隔可以嵌套多级)，就能把它归到某个分类下而不是直接显示在根层级。菜单的每一层——根层级和任意嵌套分类——的标题上都有一个小小的
**+** 按钮：点它可以把你当前浏览到的文件夹直接加进来，名称、路径和这一层自己的子菜单路径都会预填好(添加前仍可编辑)，不用离开菜单去设置里操作。

## 硬编码按键(不可配置)

无论热键设置如何，以下按键始终保持相同行为：

| 按键 | 场景 | 行为 |
|---|---|---|
| `Escape` | 任意场景 | 若搜索框有内容则清空;否则关闭窗口(或退出动作菜单)。 |
| `Enter` | 结果列表 | 打开选中结果。 |
| `Ctrl+Enter` | 结果列表 | 在资源管理器中定位该结果，而不是打开它。 |
| `Ctrl+Shift+Enter` | 结果列表 | 以管理员身份打开该结果。 |
| 左/右方向键 | 动作菜单 | 返回上一级菜单 / 进入子菜单。 |
| `Backspace` | 动作菜单 | 当搜索框已为空时，退出动作菜单。 |
| `Alt+Space` / `Alt+F4` | Lertaro 的所有窗口 | `Alt+Space` 在所有窗口上都会被屏蔽——它们都没有真正的标题栏，Windows 的系统菜单在这里无处可依。`Alt+F4` 在主窗口和设置窗口上照常关闭窗口；在快速窗口、内联窗口、QuickLook 以及各类对话框上仍然被屏蔽，因为它们是显示/隐藏的，而不是打开/关闭的。 |

## 插件动作热键

插件可以注册自己的动作并附带一个默认热键(例如复制路径 `Ctrl+Shift+C`、以管理员身份运行，或是内置的文件操作动作——剪切 `Ctrl+X`、复制 `Ctrl+C`、粘贴 `Ctrl+V`、删除 `Delete`、彻底删除
`Shift+Delete`)。这些会显示在**设置 → 热键 → 插件动作** 里，按注册它们的插件分组，重新绑定方式和内置热键相同。

## 进程黑名单

如果 Lertaro 的全局热键和某个应用(比如会独占键盘原始输入的游戏)冲突，把该进程加入**进程黑名单**即可——详见[设置 → 热键页面](./settings/hotkeys-page#process-blacklist)。当黑名单里的进程处于前台时，Lertaro 的全局热键、按键拦截，以及上面的快速导航鼠标触发都会被完全放行，不会拦截。

任何真正全屏的前台应用都会自动获得同样的效果，不需要手动加入黑名单。无论哪种情况，当前活动窗口如果是文件选择器，都会被豁免，快速导航依然可以正常使用。
