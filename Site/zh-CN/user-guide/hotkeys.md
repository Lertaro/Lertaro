# 快捷键与交互手势

Lertaro 采用键盘优先的交互设计，同时提供极其丰富的鼠标快捷手势与多级导航系统。除固定按键外，所有全局与应用内快捷键均可在[**设置 → 快捷键**](./settings/hotkeys-page)中自由重新绑定。

## 1. 全局快捷键速查表

| 功能动作 | 默认快捷键 | 功能说明与交互细节 |
| :--- | :--- | :--- |
| **呼出/隐藏快速窗口** | 双击 `Ctrl` | 可设置为双击模式或常规组合键（例如 `Alt+Space`、`Win+Space` 等）。双击是指**同一个**修饰键被连续按下两次、且两次释放相隔 **100–300 毫秒**——左 `Ctrl` 与右 `Ctrl` 是两个不同的按键，期间按下任何其他键都会让计数重新开始。双击模式下修饰键本身绝不会被吞掉，因此普通的 `Ctrl`+`C` 之类快捷键照常生效。启用“默认打开完整面板”后，该快捷键会改为打开完整窗口：首次显示时只将其置于前台并聚焦一次，窗口已显示但未激活时重新激活，窗口已经激活时再次按下则关闭；不会自动保持置顶。 |
| **快速切换（Quick Jump）** | `Ctrl+G` | 在文件对话框中直接跳转到最近一次从受支持文件管理器或快速面板中浏览的文件夹。 |
| **快速导航菜单** | 无默认快捷键 | 可选的全局快捷键，用于打开级联式快速导航菜单。在桌面或普通应用中呼出时使用桌面上下文；在文件资源管理器和原生文件对话框中呼出时使用当前窗口上下文。即使普通前台保护会抑制全局快捷键，文件管理器和文件对话框仍会放行。 |
| **选中下一项** | `Ctrl+N` 或 `↓` | 向下移动列表高亮项。在快速面板中支持无缝跨分组连续浏览；在快速启动面板中，方向键按照可见网格移动，左右键会跨越行边界，上下键会在相邻方向寻找最近的同列项目，也会跨越分组；只有相邻方向中整列都没有项目时才保持当前位置；快速启动面板显示且搜索内容为空时，`Ctrl+N` 会循环切换到下一个数据源。 |
| **选中上一项** | `Ctrl+P` 或 `↑` | 向上移动列表高亮项。在快速面板中同样支持跨分组遍历；在快速启动面板中，方向键按照可见网格移动，左右键会跨越行边界，上下键会在相邻方向寻找最近的同列项目，也会跨越分组；只有相邻方向中整列都没有项目时才保持当前位置；快速启动面板显示且搜索内容为空时，`Ctrl+P` 会循环切换到上一个数据源。 |
| **跳转至第 1–9 项结果** | `Ctrl` + `1`–`9` | 修饰键可自定义，快速窗口结果旁会显示对应的数字徽章，直接按键秒开目标项。数字指的是**从首个可见行算起**的第 N 个可选中项目，因此滚动列表时徽章会随之重新编号；`0` 未绑定。唯一的例外是起始页——它为磁贴绑定 `1`–`9`、`0` 与 `A`–`Z`，最多 36 个磁贴。 |
| **打开动作菜单** | `Ctrl+O` 或 `→` | 展开选中结果的上下文动作面板（复制路径、属性、管理员运行、文件操作等）。快速窗口和文件对话框**之外**的内嵌卡片都能用它；完整窗口改用鼠标右键或 `Apps` 键（`Shift+F10`）打开同一个菜单。 |
| **从选中项补全搜索词** | `Ctrl+Tab` | 将当前选中项的名称或完整路径直接填入搜索框，便于在此基础上做二次筛选。 |
| **QuickLook 即时预览** | `Alt+P` | 开启/关闭选中项的侧边预览面板（图片、文档、音视频即时播放、文件夹结构等）。快速窗口、完整窗口和快速面板均可用，内嵌卡片不支持；对可预览的行点击鼠标中键也能切换同一个面板。 |
| **上一条搜索历史词** | `Alt+Up` | 向前翻阅最近输入过的搜索关键词。 |
| **下一条搜索历史词** | `Alt+Down` | 向后翻阅最近输入过的搜索关键词。 |
| **删除当前历史词** | `Ctrl+Delete` | 从最近搜索历史记录中移除当前显示的这一条词汇。 |
| **打开完整搜索主窗口** | `Ctrl+F` | 直接打开大尺寸主搜索窗口，并自动同步当前快速窗口中的搜索词。 |
| **打开发送窗口（LocalSend）** | `Ctrl+S` | 打开 LocalSend 无线局域网传输窗口，快速发送文件或文本至跨平台设备。 |
| **保持窗口不消失（钉住）** | `Ctrl+T` | 临时锁定窗口，在失去焦点时不再自动隐藏（便于从其他窗口复制文字组合查询）。 |
| **呼出/关闭快速面板** | `Ctrl+F2` | 在当前前台活动窗口旁展开包含最近文件、收藏夹、工作区的快速停靠面板。 |

### 文件对话框中的空查询

当内嵌搜索框位于原生文件对话框中且搜索内容为空时，列表会先显示“上一次目录”分组。开启“在内嵌搜索中显示当前打开的文件夹”后，还会显示汇总受支持文件管理器正在浏览目录的“当前打开的文件夹”分组。当前文件对话框所在目录会被排除，重复路径会自动去重，空分组不会显示，分组标题也不会显示快捷键徽章。该开关默认开启，可在[**设置 → 通用 → 系统**](./settings/general)中修改。该行为只适用于文件对话框中的内嵌搜索，快速窗口和完整窗口不受影响。

### 内嵌窗口的呼出与焦点交接

停靠在原生文件对话框中的卡片刻意**不抢键盘**：焦点留在对话框上，所以你继续在对话框自己的文件名输入框里打字，卡片只是同步显示同样的内容。真正移动光标的操作是：

| 操作 | 效果 | 生效条件 |
| :--- | :--- | :--- |
| **键入字母或数字** | 呼出卡片，并把这第一个字符带进搜索框；之后的按键继续输入进去 | 只认真实按键——自动化工具合成的输入会原样放行；上下文菜单或系统菜单打开时不捕获任何按键 |
| **双击 `Ctrl`**（或你配置的呼出快捷键） | 把光标定位到卡片自身的搜索框。若搜索框已持有光标且内容为空，则改为清空内容并把焦点交还给对话框的输入框，卡片保持打开 | 与各处用的是同一个快捷键，所以在[**设置 → 快捷键**](./settings/hotkeys-page)里改绑时这里也会跟着变。即使进程黑名单或全屏状态通常会让全局快捷键静默放行，文件对话框依然照常生效 |
| **`Escape`** | **对话框**持有键盘时关闭卡片；**卡片**持有键盘时清空内容并把焦点交还给对话框（文件对话框中），或关闭卡片（停靠在普通资源管理器窗口上时） | |
| **搜索框为空时按 `Backspace`** | 与 `Escape` 一样退出搜索 | 仅在卡片持有光标时；焦点在对话框一侧时，该键只是编辑卡片的搜索内容 |
| **搜索框为空时按 `Enter`** | 与 `Escape` 一样退出搜索 | 仅在卡片持有光标时——焦点在对话框一侧时，`Enter` 打开高亮的浏览项 |
| **`Tab`** | 始终留给对话框自身的控件遍历，因此请改用呼出快捷键进入卡片 | |

> [!NOTE]
> 在文件对话框内，卡片没有动作菜单（`Ctrl+O`、`→` 和鼠标右键在那里都不起作用），也不提供 `Alt+P` 预览。鼠标在结果行上依然可用：**左键单击**打开高亮结果，**`Ctrl`+单击**以管理员身份打开，结果行可以被**拖出**到对话框里，仅仅**悬停**即可移动选中项——宿主文件管理器会同步这一选择。

## 2. 搜索框图标与鼠标手势

搜索框内的小图标不仅是品牌标识，更集成了多种实用的鼠标快捷手势：

### 快速搜索窗口中的图标手势

- **鼠标左键单击**：直接在光标处弹出快捷主菜单（显示主窗口、切换快捷键配置、打开设置、关于、干净退出、退出程序）。其中“显示主窗口”会自动携带当前输入的内容。
- **鼠标左键按住拖动**：自由拖动调整搜索栏在屏幕上的显示位置。**拖动时按住 `Ctrl` 键**可将移动方向严格锁定为**纯垂直方向**，避免水平位置发生偏移。
- **鼠标右键单击**：一键将快速窗口重置回屏幕初始默认居中位置（不改变已配置的窗口尺寸）。
- **鼠标中键单击**：快捷切换窗口“钉住（保持不消失）”状态，钉住期间 Logo 图标会高亮发光。

> [!NOTE]
> 快速窗口记录的屏幕坐标是相对于所在显示器的**相对比例坐标**。当你将窗口唤出在另一台不同分辨率、不同 DPI 缩放的显示器上时，Lertaro 会自动等比换算位置，绝不会跑出屏幕可视区域。

### 内嵌窗口与主窗口中的图标

- **内嵌窗口**：当嵌入在原生文件对话框（打开/保存/浏览）时，左键点击图标可直接展开[**快速导航**](#3-快速导航鼠标触发)级联菜单；停靠在普通资源管理器时仅作展示。拖动图标会移动卡片本身，之后每次停靠都会重新套用这个偏移量。
- **主窗口**：鼠标左键点击图标会打开上下文菜单；由于完整窗口已经打开，菜单中的“显示主窗口”项目会隐藏。鼠标中键点击可切换窗口的置顶状态。

### 搜索框手势（快速窗口）

- **在搜索框上滚动鼠标滚轮**：向前/向后翻阅最近的搜索词——与 `Alt+Up` / `Alt+Down` 完全相同的导航，手不必离开鼠标。
- **在搜索框上点击鼠标中键**：删除当前显示的这一条历史记录。该手势是硬编码的，并不是可配置的 `Ctrl+Delete` 绑定。
- **任何时候开始打字**都会结束本轮历史翻阅，因此下一格滚轮会重新从你当前的搜索内容出发。历史不会循环：翻到最旧一条就停在原地，最新一条则回到你最初输入的内容。

### 系统托盘图标

- **鼠标左键单击**：切换快速窗口的显示与隐藏，和呼出快捷键的效果完全一致。
- **鼠标右键单击**（或再次单击，因为没有注册双击处理）：在光标处弹出菜单——显示主窗口、发送到其他设备（仅在 LocalSend 启用时出现）、禁用/启用快捷键、设置、关于、干净退出（仅在 Lertaro 是唯一运行进程时出现）、退出。
- **隐藏托盘图标**（[**设置 → 通用 → 系统**](./settings/general)）只去掉图标，绝不会去掉窗口内 Logo 的菜单。当你通过该菜单禁用快捷键时，托盘图标会被强制显示出来，免得把自己锁在门外。

## 3. 快速导航（鼠标触发）

快速导航功能让你无需打字，通过鼠标点击即可在任意窗口中直达常用目录或打开文件。

你也可以在[**设置 → 快捷键**](./settings/hotkeys-page)中为快速导航菜单分配一个可选的全局快捷键。在桌面或普通应用中呼出时使用桌面上下文；在文件资源管理器和原生文件对话框中呼出时使用当前窗口上下文。

### 触发方式与支持环境

- **桌面空白处**：鼠标中键单击（或开启双击左键）直接弹出快速导航菜单，点击目录或文件直接打开。
- **文件资源管理器**：在资源管理器空白处点击鼠标中键触发，点击目标后当前窗口立即跳转到该路径。
- **第三方文件管理器**：在 Directory Opus、Total Commander、XYplorer、Files、One Commander 等工具的文件列表区点击鼠标中键触发（详见[**支持的文件管理器**](./file-manager-support)）。
- **系统文件对话框**：在任意软件的“打开/保存/浏览文件夹”对话框中点击中键或点击内嵌图标触发，点击后对话框直接跳转至目标目录，绝不会误触发“保存/打开”确认。

### 级联菜单内容与管理

快速导航菜单由**级联文件夹浏览器（Folder Cascader）**插件驱动，内容高度结构化：

1. **当前打开的文件夹**：自动汇总并去重所有受支持文件管理器当前正在浏览的真实目录，方便在不同应用间快速同步路径。
2. **收藏夹与历史记录**：自动按分类列出你的加星收藏与最近访问历史。
3. **自定义快捷分类**：支持在**设置 → 插件 → 级联文件夹浏览器**中自定义目录与子菜单（如使用 `工作/项目A` 创建多级分类）。
4. **一键添加目录（`+` 按钮）**：菜单每个层级的标题右侧均设有一个 `+` 按钮，点击即可直接将当前正在浏览的文件夹快速保存到该分类下，无需打开设置面板。

## 4. 硬编码核心按键（不可修改）

为了保证最核心交互的确定性与一致性，以下按键在任何配置下行为始终保持统一：

| 按键 | 触发场景 | 统一行为 |
| :--- | :--- | :--- |
| `Enter` | 结果列表 | 直接打开选中的结果（文件/目录/程序/动作）。在完整窗口中会打开**全部**选中行。内嵌搜索框内容为空时则改为退出搜索——此时并没有可打开的首条结果。 |
| `Ctrl+Enter` | 结果列表 | 在文件资源管理器中打开并定位选中项所在目录。 |
| `Ctrl+Shift+Enter` | 结果列表 | 以管理员权限启动选中的程序或文件。 |
| `Escape` | 快速窗口 | 隐藏窗口。这一次按键绝不会清空搜索框——内容是保留还是丢弃，改由**关闭窗口后保留搜索框内容**决定。 |
| `Escape` | 完整窗口 | 清空搜索内容并让搜索框重新获得焦点；搜索框已为空时才关闭窗口，而开启**关闭窗口后保留搜索框内容**时第一次按下就直接关闭（不必白按两次）。 |
| `Escape` | 内嵌卡片 | 参见上文的**内嵌窗口的呼出与焦点交接**：焦点在对话框一侧时关闭卡片，焦点在卡片一侧时交还焦点。 |
| `Escape` | 动作菜单 | 一次按键退回一层：先清空动作过滤词，再退出子菜单，最后离开动作菜单并恢复原来的搜索内容。 |
| `Backspace` | 动作菜单 | 当搜索过滤词已为空时，按下直接退出动作菜单返回结果列表。 |
| `←` / `→` 方向键 | 动作菜单 | 左箭头返回上一级菜单，右箭头进入子菜单。`Tab` 同样能进入子菜单，除非你把它绑定到了上/下一项快捷键。 |
| `Tab` | 内嵌卡片 | 按键被吞掉，焦点无法离开搜索框；而对话框自身的 `Tab` 照旧遍历它自己的控件。 |
| `Tab` | 动作菜单 | 进入高亮的子菜单——除非你把 `Tab` 绑定为上/下一项快捷键，那样以绑定为准。 |
| `Apps` / `Shift+F10` | 完整窗口 | 为当前选中项打开动作菜单，效果与鼠标右键完全一致。 |
| `Alt+Space` | 所有 Lertaro 窗口 | 强制屏蔽系统标题栏菜单，防止误触弹窗。 |
| `Alt+F4` | 主窗口 / 设置窗口 | 关闭当前窗口。在快速窗口、内嵌窗口、快速面板、预览浮窗、LocalSend 窗口以及应用内对话框上会被屏蔽（防止误关闭驻留服务）。 |

## 5. 插件动作快捷键与进程黑名单

### 插件独立动作快捷键

内置文件动作的默认快捷键如下：剪切 `Ctrl+X`、复制文件 `Ctrl+C`、粘贴 `Ctrl+V`、删除 `Delete`、彻底删除 `Shift+Delete`、复制路径 `Ctrl+Shift+C`、复制名称 `Shift+C`、在资源管理器中定位 `Ctrl+Enter`、以管理员身份运行 `Ctrl+Shift+Enter`。

有两道保险让这些有破坏性的按键在搜索框之下依然安全。组合键只有在搜索框**没有选中文本**时才会触发动作，因此 `Ctrl+X` / `Ctrl+C` / `Ctrl+V` 照旧是剪切、复制和粘贴你的搜索内容。`Delete` 这类单独按键只有在光标**已位于搜索内容末尾**时才会触发动作——在那里它已经没有字符可删；处在文本其他任何位置时，它仍然是个打字按键。而且两个删除动作都走 Shell 自己的 `IFileOperation`，所以原生的“移入回收站？”/“彻底删除？”确认框仍然横亘在按键与文件之间。想改绑或清空其中任何一个，请到**设置 → 快捷键 → 插件动作**。

### 进程黑名单与全屏自动放行

- **全屏应用自动放行**：当检测到前台有独占全屏运行的应用程序（如全屏 3D 游戏、全屏视频播放器）时，Lertaro 默认会自动放行所有全局快捷键，绝不抢占游戏控制。
- **自定义进程黑名单**：在[**设置 → 快捷键页面**](./settings/hotkeys-page#进程黑名单)中添加特定进程名（如 `game.exe`），当该程序处于前台时，全局快捷键与鼠标快速导航将完全静默放行。
