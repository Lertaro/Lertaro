# 用户手册

Lertaro 是一款为 Windows 打造的、键盘优先的极速文件检索启动器。它在后台索引你的本地磁盘(NTFS
和 ReFS 通过各自的变更日志，其他文件系统则直接监听变化)及网络共享，让你能在极短时间内跳转到任意文件、文件夹或应用程序。

本手册涵盖日常使用所需的一切：

- **[快速上手](./getting-started)** —— 安装 Lertaro，了解它的三种搜索窗口(主窗口/快速窗口/内嵌窗口)。
- **[搜索语法](./search-syntax)** —— 模糊匹配、排除/精确/前缀/后缀操作符、或组、盘符定向、路径模式，以及中文文件名的拼音别名匹配。
- **[热键](./hotkeys)** —— 每一个可配置快捷键与硬编码按键，及其默认绑定。
- **[动作菜单与预览](./actions-and-preview)** —— 类右键菜单的动作列表，以及 QuickLook 预览窗口。
- **[即时答案与关键词功能](./instant-answers)** —— 计算器、环境变量、运行命令这些快捷方式，以及进程管理、窗口切换器、浏览器数据、设置搜索、网页搜索、翻译这类关键词触发的插件。
- **[命令行搜索（lff）](./cli)** —— 可以在终端里使用的、fzf 风格的命令行伴侣工具。
- **[URI 协议（lertaro://）](./uri-protocol)** —— 通过一个链接、别的程序或脚本，直接跳转到某次搜索或某项具体设置。
- **[支持的文件管理器](./file-manager-support)** —— Lertaro 可以嵌入、触发快速导航、或检测当前文件夹的文件管理器和文件选择对话框都有哪些。
- **[设置项参考](./settings/)** —— 每一个设置页面、每一个 Tab、每一项设置，逐条列出。
- **[故障排查](./troubleshooting)** —— 常见问题与解决办法。
- **[捐赠支持](./donate)** —— 如果 Lertaro 对你有帮助。

如果是第一次配置 Lertaro，建议从**快速上手**开始阅读。
